## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 国内电商订单详情页 |
| 入口 | 列表点击订单编号 |
| 页面目标 | 只读查看一张国内电商订单全貌；追溯关联的销售出库单、销退入库单；查看异常回传记录 |
| 骨架结构 | 页头 → 订单基础信息 → 订单行快照 → 关联结果单 → 异常回传记录（条件） → 操作信息 |

本页落地 **F02（详情）、F03（关联结果单跳转）、F04（异常回传记录查看）**；状态—操作矩阵见主PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头只有`返回列表`与一枚回传状态StatusBadge；**不提供**编辑、取消、关闭、删除、重试、修复等按钮；
> - 关联结果单为销售出库单、销退入库单两个胶囊Tab，始终展示、无数据空态；
> - 异常回传记录仅在存在记录时展示该卡片，处理入口在系统集成中心（INT-FR05）；
> - 订单行快照不含价税拆分列（单价、税率、税额的渠道提供情况待联调核验，主PRD Q04）；
> - Demo 以桌面端为基准；订单行与关联简表窄视口横向滚动。

## 2. 页头

### 2.1 标题与状态

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `国内电商订单详情 · {订单编号}` |
| 状态标签 | 一枚 StatusBadge：回传状态 |
| 布局 | 单行：左侧标题 + 状态标签；右侧操作区 |

回传状态 tone：待回传→neutral；已回传→success；异常→danger。

### 2.2 页头操作按钮

`返回列表` 为唯一按钮，始终展示；不随回传状态增加按钮。

| 按钮 | 待回传 | 已回传 | 异常 | 说明 |
| :--- | :---: | :---: | :---: | :--- |
| 返回列表 | ✅ | ✅ | ✅ | 返回列表并保留查询条件与页码 |

本对象无业务动作，无二次确认弹窗（主PRD §6.4）。

## 3. 信息分区与字段

> 只读 **6 列栅格**（默认），标签在上、值在下；字段顺序与TSV分组一致。

**分区总览**：页头 → **3.1 订单基础信息** → **3.2 订单行快照** → **3.3 关联结果单** → **3.4 异常回传记录（条件）** → **3.5 操作信息**

### 3.1 订单基础信息

| 字段 | 展示说明 |
| :--- | :--- |
| 订单编号 | 原样展示 |
| 来源系统 | 枚举文字；本对象固定为聚水潭 |
| 渠道单号 | 原样展示；来源识别要素之一 |
| 平台单号 | 原样展示 |
| 平台 | 枚举文字 |
| 店铺 | 原样展示；长文本 `ellipsis` |
| 下单时间 | 日期时间 |
| 客户 | Code-Name（通用2C客户） |
| 币别 | 「编码 名称」，如 `CNY 人民币` |
| 成交优惠后金额合计 | 千分位、2位小数 |
| 退货金额合计 | 千分位、2位小数 |
| 回传状态 | 枚举文字；与页头StatusBadge一致 |

布局：第1行—订单编号、来源系统、渠道单号、平台单号、平台、店铺；第2行—下单时间、客户、币别、成交优惠后金额合计、退货金额合计、回传状态。

### 3.2 订单行快照

- 表格只读；数量、金额列**右对齐**；横向滚动；一期不分页。
- 列（从左到右）：行号、平台商品编码、商品编码、商品名称、基本单位、订购数量、累计实际出库数量、累计实际退回数量、成交优惠后金额、退货金额。
- 底部汇总行：首列文案 `合计`，汇总订购数量、累计实际出库数量、累计实际退回数量、成交优惠后金额、退货金额，与对应列右对齐。
- 商品未匹配时：平台商品编码原样展示，商品编码、商品名称、基本单位为 `-`，并在异常回传记录中体现（主PRD R09、R10）。
- 累计实际出库数量、累计实际退回数量为只读汇总值，不在页面编辑。

### 3.3 关联结果单

**展示条件**：始终展示；两个Tab都保留，无数据时展示空态，不隐藏Tab（《UI布局公共说明》「关联单据」）。

组件：`RelatedDocumentsCard` + `InnerTabs` `pill`；Tab 文案带数量。

| Tab | 列 | 排序 | 空态 |
| :--- | :--- | :--- | :--- |
| 销售出库单 (N) | 单号（链接）、业务日期、实际出库数量、审核状态、推送财务ERP状态、创建时间 | 业务日期降序 | 暂无关联的销售出库单 |
| 销退入库单 (M) | 单号（链接）、业务日期、实际退回数量、审核状态、推送财务ERP状态、创建时间 | 业务日期降序 | 暂无关联的销退入库单 |

- 单号点击跳转对应结果单详情；跳转后返回本页保留查询条件与页码。
- 列口径来自结果单对象（[《销售出库单主PRD》](../../销售出库单/销售出库单主PRD.md)、[《销退入库单主PRD》](../../../5-销售退货管理/销退入库单/销退入库单主PRD.md)，均为二版重建版）；结果单字段调整时同步本表列名。

### 3.4 异常回传记录

**展示条件**：仅当该订单存在异常回传记录时展示卡片；无记录不展示。

| 列（从左到右） | 展示说明 |
| :--- | :--- |
| 执行标识 | 原样展示；区分同一来源单的多次执行（INT-FR02） |
| 异常环节 | 枚举文字：商品匹配、归属识别、库存校验、其他处理 |
| 失败时间 | 日期时间 |
| 失败原因 | 长文本 `ellipsis`，hover 看全文 |
| 处理状态 | 语义色文字：待处理→warning；已处理→success |
| 关联结果单 | 处理成功后生成的结果单单号（链接）；未处理为 `-` |

- 记录按失败时间倒序；页面只读展示，**不提供**重试、修复、改单按钮；集中查看与处理记录在系统集成中心-推送异常-结果处理页签（INT-FR05），修复后在原记录上继续处理（SAL-FR12）。
- 字段口径引用[《推送异常（详细稿）》](../../../../../20260812-ERP项目第一版框架搭建/字段清单合集/集成相关/推送异常/推送异常（详细稿）.tsv)的「结果处理」「通用信息」分组及二版去重标识。

### 3.5 操作信息

胶囊 Tab：**制单信息** / **操作日志**。

| Tab | 内容 |
| :--- | :--- |
| 制单信息 | 创建人、创建时间、最后更新人、最后更新时间；系统接收生成时创建人、最后更新人展示「系统」 |
| 操作日志 | 表格列：操作时间、操作人、操作类型、说明；按时间倒序；含接收订单、关联结果单、累计数量刷新、异常记录与恢复等记录；系统触发时操作人为「系统」 |

## 4. 字段展示规范

空值、Code-Name、数字与日期格式、状态样式、关联简表均引用公共规范；不在此重抄。数量为整数，金额保留2位小数（主PRD、TSV、字段模板）。

| 字段或区域 | 本页差异 | 依据 |
| :--- | :--- | :--- |
| 订单编号 | 原样展示；单号前缀（GNDS）已定（2026-10-15 用户确认固化） | 主PRD Q01 |
| 商品编码、商品名称、基本单位 | 按匹配到的ERP商品资料关联展示，不保存名称快照；未匹配为 `-` | 主PRD R09 |
| 平台商品编码 | 渠道回传值原样展示，不做Code-Name拼接 | TSV「订单行快照」分组 |
| 金额（行与单头） | 沿用渠道来源；ERP不重算，不展示税额、税率列 | 主PRD R08、SAL-FR10、PRI-FR08 |
| 回传状态 | 展开说明：由关联结果单汇总派生，不参与审核流程 | 主PRD §6 |

## 5. 操作行为

| 操作 | 点击行为或弹窗入口 | 确认后页面表现 |
| :--- | :--- | :--- |
| 返回列表 | 返回列表页 | 保留原查询条件与页码 |
| 关联结果单单号 | 跳转对应结果单详情（销售出库单／销退入库单） | 目标页加载；返回本页保留查询条件与页码 |
| 异常回传记录的关联结果单 | 同上 | 同上 |
| 订单行与基础信息 | 无编辑、无弹窗 | 不适用（纯只读） |

没有独立弹窗PRD内容，本模块无确认弹窗（见弹窗与Mock文件§2）。

## 6. 反馈与页面状态

### 6.1 操作反馈（Toast）

| 操作 | 反馈类型 | 文案 |
| :--- | :--- | :--- |
| 跳转结果单失败 | Toast | 页面加载失败，请重试 |
| 操作失败——系统繁忙 | Toast | 操作失败，请稍后重试 |

页面无业务动作，无业务阻断文案；异常处理提示在系统集成中心。

### 6.2 加载与异常态

| 场景 | 页面表现 | 文案 / 操作 |
| :--- | :--- | :--- |
| 加载中 | 骨架屏 | — |
| 订单不存在 | 错误态 | 订单不存在或已不可查看；返回列表 |
| 加载失败 | 错误态 | 加载失败，请重试；重试 + 返回列表 |

## 7. Mock 与验收

### 7.1 Mock 覆盖清单

- 三种回传状态各至少 1 张订单；
- 至少 1 张有两次销售出库单关联、1 张有销退入库单关联、1 张两个Tab都为空（空态）；
- 至少 1 张存在未处理的异常回传记录（商品匹配失败）与 1 张已处理并生成结果单的记录；
- 至少 1 张订单行商品未匹配（行内商品列为 `-`）；
- 至少 1 张退货金额为0，1 张存在退货金额。

Mock 明细与关联关系见[《国内电商订单前端Demo版PRD_弹窗与Mock》](国内电商订单前端Demo版PRD_弹窗与Mock.md)§3。

### 7.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 正常路径 | 打开已有关联出库单但未收齐的订单详情 | 页头StatusBadge仍为待回传；关联结果单Tab可见多条出库；行累计出库数量未覆盖订购数量 |
| 已回传路径 | 打开已收齐订单详情 | 页头StatusBadge为已回传；金额千分位2位小数 |
| 状态一致 | 对照列表与详情 | 列表语义色文字与详情StatusBadge语义一致 |
| 未匹配商品 | 打开含未匹配行的订单 | 平台商品编码原样展示，商品编码、名称、基本单位为 `-`；异常回传记录可见 |
| 关联跳转 | 点击销售出库单Tab单号 | 跳转对应结果单详情；返回保留查询条件与页码 |
| 异常只读 | 打开有异常回传记录的订单 | 只读列展示；无重试、修复、改单按钮 |
| 无业务按钮 | 任意状态订单 | 页头只有返回列表；无编辑、取消、关闭、删除按钮 |
| 空态 | 打开无关联结果单的订单 | 两个Tab均展示对应空态文案，不隐藏Tab；无异常记录时不展示该卡片 |

Demo 验证页面呈现、跳转与本地数据联动；不代表生产接口、并发或后端事务行为。
