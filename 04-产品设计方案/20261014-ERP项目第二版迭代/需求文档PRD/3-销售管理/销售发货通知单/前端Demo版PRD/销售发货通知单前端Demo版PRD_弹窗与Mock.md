## 2. 取消通知单（F05）

**触发入口**：列表、详情「取消」；可用条件为**待推送**或**推送失败**（主 PRD §6.4）。

```
列表 / 详情
     │
点「取消」（待推送 / 推送失败）
     ▼
┌──────────────────────────────────────────┐
│  取消销售发货通知单                  [×] │
│  取消后通知不再执行，不可撤销…           │
│  推送失败时追加：请确认仓库尚未接收…     │
│  取消原因* [多行文本]                    │
│                    [取消] [确认取消]      │
└──────────────────────────────────────────┘
         │ 取消              │ 确认
         ▼                   ▼
    关闭弹窗，停留      已取消 + 释放占用
                        Toast「已取消」
```

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 取消销售发货通知单 |
| 正文 | 取消后通知不再执行，不可撤销，并释放订单占用额度。 |
| 推送失败补充 | 推送失败时追加：「请确认仓库尚未接收本通知。」 |
| 必填项 | 取消原因（多行） |
| 确认按钮 | 确认取消 |
| 取消按钮 | 取消 |
| 确认后 | 单据状态→已取消；记录取消原因、取消时间、取消操作人；释放全部通知占用；订单开放时恢复可下推量；Toast「销售发货通知单已取消」 |

## 3. 取消通知单（待发货）（F06）

**触发入口**：列表、详情「取消」；可用条件为**待发货**（主 PRD §6.4）。

```
列表 / 详情
     │
点「取消」（待发货）
     ▼
┌──────────────────────────────────────────┐
│  取消销售发货通知单                  [×] │
│  单据已推送仓库，取消需等待仓库回执。    │
│  取消原因* [多行文本]                    │
│                    [取消] [确认取消]      │
└──────────────────────────────────────────┘
         │ 取消              │ 确认
         ▼                   ▼

                        「已发起取消，等待仓库回执」
                              │
                    ┌─────────┴─────────┐
                    ▼                   ▼
              仓库同意              仓库拒绝
              已取消                待发货
```

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 取消销售发货通知单 |
| 正文 | 单据已推送仓库，取消需等待仓库回执。取消期间通知仍占用订单额度。 |
| 必填项 | 取消原因（多行） |
| 确认按钮 | 确认取消 |
| 取消按钮 | 取消 |
| 确认后 | 单据状态→取消中；Toast「已发起取消，等待仓库回执」 |

| 回执 | 结果状态 | 提示 |

| 仓库拒绝 | 待发货 | 仓库拒绝取消，请继续等待发货 |

## 5. Demo Mock：模拟仓库回传（F08）

**触发入口**：详情页「模拟仓库回传」；可用条件为**待发货**（Demo 环境）。

```
详情（待发货）
     │
点「模拟仓库回传」
     ▼
┌──────────────────────────────────────────┐
│  模拟仓库回传（Demo）                  [×] │
│  各行实出不能超过通知数量…               │
│  行号 | 商品编码 | 通知数量 | 实出数量   │
│  [ ] 零出（整单按取消结束）              │
│                    [取消] [确认回传]      │
└──────────────────────────────────────────┘
         │ 确认
         ▼
  有实出 → 已发货 + 生成出库单 Mock
  零出   → 已取消
```

### 5.1 弹窗规格

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 模拟仓库回传（Demo） |
| 正文 | 各行实出不能超过通知数量；少于通知量按缺量结束。勾选零出则整单按取消结束。 |
| 表格列 | 行号、商品编码、商品名称、通知数量、实出数量（可编辑整数） |
| 零出勾选 | 勾选后各行实出锁定为 0，按零出取消处理 |
| 确认按钮 | 确认回传 |
| 取消按钮 | 取消 |

### 5.2 回传规则（本地 Mock）

| 项目 | 规则 |
| :--- | :--- |
| 实出上限 | 每行 0～通知数量 |
| 有实出 | 状态→已发货；回写实出、缺出；生成销售出库单 Mock；更新来源订单累计实际出库与可下推量 |
| 零出 | 状态→已取消；释放占用；不生成出库单 |
| 运单号 | Demo 可随机生成 fictitious 运单号写入通知单 |
| 标注 | 界面或 Toast 标注「演示数据」 |

### 5.3 不做的事

- 不代替正式仓库接口回传
- 不在 Mock 中自动推财务ERP（出库单 Mock 可展示推送状态占位）
- 不把 Mock 行为写入主 PRD 正式验收

## 6. 人工确认（F09）

**触发入口**：详情页「人工确认」；可用条件为**已交给仓库**的状态（推送中、待发货、取消中；主 PRD §6.4）。

### 6.1 正式规则（必读）

接口拿不到接单、执行结束或取消结果时，操作人在详情页「人工确认」按实际发生情况填写：确认接单（推送中→待发货）、确认执行结束（待发货→已发货，逐行填实出数量）、零出（实出为0且本次执行已结束，按零出取消）、确认取消结果（取消中→已取消或待发货）。只适用于已交给仓库的通知；必须过业务校验（商品、发货仓库、数量按来源订单行回写）与适用审核；确认执行结束形成的销售出库单走草稿→待审核，审核通过才扣减库存并推送财务ERP（主 PRD R16、[《集成协作与人工补充》](../../../../../../03-业务分析和设计/07-集成协作与人工补充.md) §4.4、[《系统集成需求分析》](../../../../../../02-需求调研和分析/07-系统集成/系统集成需求分析.md) INT-FR06）。

```
详情（推送中/待发货/取消中）
     │
点「人工确认」
     ▼
┌──────────────────────────────────────────┐
│  人工确认（补记仓库实际结果）        [×] │
│  确认类型按当前状态给可选项…             │
│  确认执行结束：逐行填实出数量            │
│  [ ] 零出（整单按取消结束）              │
│  确认取消结果：仓库同意／仓库拒绝        │
│                    [取消] [确认]          │
└──────────────────────────────────────────┘
```

### 6.2 弹窗规格

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 人工确认（补记仓库实际结果） |
| 正文 | 只用于已交给仓库、接口拿不到结果的通知；确认前请先与仓库核实实际结果。 |
| 确认类型 | 按当前状态给出可选项：推送中—确认接单；待发货—确认执行结束；取消中—确认取消结果 |
| 执行结束时 | 逐行填写实出数量（0～通知数量，至少一行大于0）；可勾选「零出（整单按取消结束）」 |
| 取消结果 | 二选一：仓库同意取消／仓库拒绝取消 |
| 确认按钮 | 确认 |
| 取消按钮 | 取消 |
| 确认后 | 记录人工确认人、人工确认时间与人工确认内容；状态按确认结果更新；确认执行结束且实出>0时，形成销售出库单并提交审核（待审核） |
| 失败处理 | 超通知量、执行结束全部为0且未勾选零出、未核实等校验不通过时阻断并提示；状态不匹配时 Toast「当前单据状态为{状态}，不可执行人工确认」 |

### 6.3 Demo 本地 Mock 行为

| 场景 | Demo 行为 |
| :--- | :--- |
| 确认接单 | 单据状态→待发货；无结果单；Toast「已确认接单」 |
| 确认执行结束 | 按 §5.2 生成规则形成演示出库单，状态按正式口径为**待审核**（草稿→待审核）并标注「演示数据」；回写实出、缺出与订单占用；未审核前不记库存 |
| 零出 | 单据状态→已取消；释放占用；不生成出库单 |
| 确认取消结果 | 仓库同意→已取消；仓库拒绝→待发货 |

正式口径下形成出库单后的审核与推送进度，可在[《销售出库单前端Demo版PRD_弹窗与Mock》](../../销售出库单/前端Demo版PRD/销售出库单前端Demo版PRD_弹窗与Mock.md)查看演示。

### 6.4 不做的事

- 不代替正式接口回传与映射校验
- 不替代通知单上事先选择的虚拟出库；不提供无来源建单
- 不把 Mock 结果当作财务ERP正式验收
- Demo 中的「模拟仓库回传」保留用于演示接口回传链路，与本弹窗不重复触发同一张单的生成

## 7. 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 待推送取消 | 填取消原因并确认 | 已取消；订单可下推量回补 |
| 推送失败取消 | 确认前看到仓库未接收提示 | 已取消 |
| 待发货取消 | 确认取消 | 取消中；Toast 等待回执 |
| 仓库同意取消 | Demo 模拟同意回执 | 已取消 |
| 仓库拒绝取消 | Demo 模拟拒绝回执 | 恢复待发货 |
| 重试推送 | 推送失败单点重试 | 推送中 |
| Mock 少出 | 通知600，回传580 | 已发货；缺出20；订单可下推回补 |
| Mock 零出 | 勾选零出 | 已取消；不生成出库单 |
| 离开未保存 | 改备注后点取消 | 二次确认 |
| 人工确认接单 | 推送中单点人工确认并确认接单 | 待发货；记录人工确认人／时间／内容 |
| 人工确认执行结束 | 待发货单确认执行结束，实出580（通知600） | 已发货；缺出20；形成演示出库单（待审核）；订单占用替代 |
| 人工确认零出 | 勾选零出并确认 | 已取消；不生成出库单 |
| 人工确认取消结果 | 取消中单分别确认同意／拒绝 | 同意→已取消；拒绝→待发货 |

Demo 验证弹窗文案、必填项与 Mock 本地数据联动；不代表生产接口、并发或后端事务行为。
