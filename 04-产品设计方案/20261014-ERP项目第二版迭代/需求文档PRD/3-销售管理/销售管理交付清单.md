# 销售管理交付清单

> 清单版本：V0.2｜更新日期：2026-10-15｜状态：初稿，待评审（未纳入B10①评审范围）。V0.2：订单编码 GNDS/KJDS 前缀经用户确认固化（见「已定结论与后续事项」）。
> 二版说明：本模块六个对象中，独立站订单、国内电商订单、跨境电商订单为二版新增套件（B3）；销售出库单按 B5 重建、销售发货通知单按 B7 重建（主PRD、页面骨架、Demo、字段清单出二版）；销售订单二版未修订，继续引用一版文件。二版变化与一版文件去向登记见[《二版交付清单》](../../二版交付清单.md)§二。销售退货管理三个对象见[《销售退货管理交付清单》](../5-销售退货管理/销售退货管理交付清单.md)。

本套件覆盖销售管理一期六个对象：销售订单（B2B）、销售发货通知单、销售出库单，以及三套订单对象——独立站订单（ERP拉单并推动履约）、国内电商订单、跨境电商订单（渠道主控、只读归集，跨境电商不含FBA）。销售订单是业务安排；销售发货通知单是执行指令；销售出库单是实际结果，自动审核后记账并推送财务ERP；三个订单对象承接平台/渠道单号与结果追溯，不驱动履约。业务规则以[《销售与履约需求分析》](../../../../02-需求调研和分析/04-销售与履约/销售与履约需求分析.md)和[《销售与履约业务设计》](../../../../03-业务分析和设计/02-销售与履约业务设计.md)为准；字段与取值以`字段清单合集/销售相关`为准；状态以[《单据与状态流转》（一版）](../../../20260812-ERP项目第一版框架搭建/系统架构和流程/03-单据与状态流转.md)第二、三、四、五节为准（二版未修改，继续引用）。

## 已定结论与后续事项

| 事项 | 结论与处理 |
| --- | --- |
| 订单对象口径（B3，2026-10-14） | 国内/跨境电商订单只读为主（列表＋详情）：订单基础信息、平台/渠道单号、店铺、行与金额快照、回传状态、关联结果单列表（可跳转）、异常回传记录；无ERP建单/履约动作；不采用合并来源对象 |
| 结果单关联「分两张」（B5） | 销售出库单、销退入库单来源拆为「来源国内电商订单」「来源跨境电商订单」两个互斥字段；平台/渠道单号留在订单对象、不重复设在结果单；去重按「来源系统＋来源单号＋执行标识」 |
| 自动审核与异常（二版） | 渠道回传出库/退货入库结果→校验通过→自动生成已审核销售出库单/销退入库单→记库存→排队推金蝶；匹配失败、库存不足、重复回传不记账、不推财务ERP，修复后处理原记录 |
| 销售主控与FBA边界（二版） | 国内/跨境电商由聚水潭/领星主控履约，强盛不下发发货指令；跨境仅自发货，FBA消费者段不进入归集、不改逻辑仓库存、数据保留在领星 |
