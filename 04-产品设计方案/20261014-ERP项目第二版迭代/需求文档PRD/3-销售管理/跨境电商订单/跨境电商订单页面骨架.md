## 页面与弹窗清单

| 页面/容器 | 入口 | 用途 |
| --- | --- | --- |
| 跨境电商订单列表 | 销售管理-跨境电商订单 | 查询、筛选、查看与导出领星回传的跨境电商订单 |
| 跨境电商订单详情 | 列表点击订单编号 | 只读查看订单基础信息、行与金额快照、回传状态、关联结果单与异常回传记录 |
| 销售出库单详情（跳转） | 详情页「销售出库单」Tab单号 | 查看关联的销售出库单（跨模块页面） |
| 销退入库单详情（跳转） | 详情页「销退入库单」Tab单号 | 查看关联的销退入库单（跨模块页面） |

本对象只读：不提供新增、编辑、导入、删除页面，不提供订单侧业务弹窗；不存在占库、下推仓、发货指令等动作，也没有对应的确认弹窗。FBA消费者订单不进入本对象，页面不设FBA入口（主PRD §7.6）。

## 文档说明

骨架展示页面分区、字段位置、基本控件、按钮与虚构示例值。字段以TSV为准，业务动作以主PRD为准，详细交互、校验和反馈见Demo PRD。

各页按“用途／关键要素／线框／补充说明”组织。图前简述本页任务及重点，图后只补图中省略项和条件差异；无补充内容时写“无”。

## 绘制约定

遵循[《页面骨架模板-V2》](../../../../../05-常用模板/02-模块设计交付/页面骨架模板-V2.md)与[《UI布局公共说明》](../../../../../05-常用模板/02-模块设计交付/UI布局公共说明.md)。本模块补充：

- 字段名、按钮文案与TSV、Demo PRD一致；示例值为虚构；订单编号示例按已定前缀 KJDS 书写（2026-10-15 用户确认）。
- 平台枚举按主PRD Q03（2026-10-15 已确认）：Temu、eBay、Shopee、Ozon、Walmart、Etsy、MercadoLibre；骨架示例使用其中若干项。
- 客户、币别等引用按Code-Name或「编码 名称」展示（《6.强盛ERP的编码规则和通用字段规则》2.3）；平台商品编码、商品编码为外部编码与ERP编码的明文展示。
- 数量列为整数、右对齐；金额列千分位、2位小数、右对齐；0按0展示，未填写展示 `-`。
- 回传状态为语义色文字（列表）或StatusBadge（详情页头），tone映射见Demo PRD。
- **每行必须画满 6 列**（用 `|` 分隔）；字段不足 6 个时，剩余列标「（空）」留空，不要省略列线。

## 列表页

- **用途**：查询领星回传的跨境电商订单，按单号、渠道与平台单号、店铺、平台、回传状态、下单时间与商品追溯，进入详情或导出。
- **关键要素**：页头只有导出；查询区按订单编号、渠道单号、平台单号、店铺、平台、回传状态、下单时间、商品编码、平台商品编码；回传状态为多选；列表按订单编号进入详情，行内不设按钮；无新增、导入入口。

| 下单时间          | 商品编码          | 平台商品编码      |               |               |               |
| [不限 v]          | [请输入商品编码]  | [请输入平台商品编码]|              |               |               |

**补充说明**：

- **重点突出**：页头只有「导出」，不提供新增、导入、编辑、删除入口；查询区下方独立一行，左侧「收起过滤」、右侧「重置/查询」；回传状态多选、未选等同全部；商品编码与平台商品编码为行级匹配，命中订单行即返回该订单所在记录，不展开为多行。
- **图中省略**：列设置等交互见Demo PRD；导出范围见主PRD F05；平台筛选项见主PRD Q03 与字段详细稿。
- 订单编号为链接列，点击进入详情；行内不设「查看」；批量栏一期仅已选中计数与列设置，勾选配合导出「已勾选」。
- 金额列不前缀币别符号，币别单独一列按「编码 名称」展示；跨境订单币别可能非人民币，按辅助资料币别字典展示。
