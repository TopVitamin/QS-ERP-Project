## 1. 页面目标与范围

- 页面名称：独立站订单列表页（`sales-shopify-order`）
- 查看视角：**仅单据视角**（每行 = 一张独立站订单；单据行视角本期不做）
- 作为导入、详情、导出、批量选仓选物流的统一入口
- **待提交／待审核**主流程（选仓选物流、提交、审核、撤回、删除）在表格左上角**批量操作区**执行；行内保留状态特异或低频操作
- 勾选配合导出「已勾选」与批量操作
- 功能与状态—操作矩阵见[《独立站订单主PRD》](../独立站订单主PRD.md) §6.4；本页落地 F01 及列表侧行操作入口

> **本期边界**：
> - 页头**无「新增」**——订单由接口拉取、人工导入或复制新单生成，不提供手工建单（B3 边界）。
> - 页头**导出**为一期正式能力（异步任务，见 §8）；**导入**为正式能力方向（INT-FR06），覆盖的订单类型与模板待确认，Demo 以 Mock 演示（见 §7、弹窗 PRD §5）。
> - 批量操作栏提供「选仓选物流」「提交」「审核」「撤回」「删除」（SAL-FR07 等）；须勾选≥1条且所选单据**状态一致**（待提交或待审核），混选或状态不符时 Toast 阻断。
> - 列表行**不提供**「推送」「查看」按钮；推送在审核通过后自动进行，查看下游走详情页「关联单据」。
> - 已发货、已取消为终态：不显示编辑、提交、审核、取消审核、申请取消；仅保留查看与条件动作（复制新单、重新回写）。
> - 金额沿用Shopify、ERP不能改（PRI-FR08）；列表金额仅展示，不提供维护入口。

## 2. 查询区

> 可筛选字段与顺序以[《独立站订单（详细稿）》](../../../../字段清单合集/销售相关/独立站订单/独立站订单（详细稿）.tsv)「可筛选=是」为准；下表为默认查询方案呈现顺序。

| 查询字段 | type | 匹配 | placeholder / 说明 |
| :--- | :--- | :--- | :--- |
| 单号 | `search` | 模糊 | 请输入独立站订单号 |
| Shopify来源单号 | `search` | 模糊 | 请输入Shopify来源单号 |
| 单据状态 | `multi-select` | 精确（OR） | 全部；待提交／待审核／已审核／推送失败／待发货／取消中／已发货／已取消；初值 `[]`，未选=全部 |
| 发货仓库 | `select` | 精确 | 全部仓库；实际选择逻辑仓；Code-Name 展示 |

查询区交互（收起过滤、重置、查询、空条件默认、查询后回第一页）见《原型开发说明》「查询区通用规则」。查询条件全空时，默认返回最新列表数据（默认按创建时间倒序）。

> 说明：独立站统一使用跨境电商2C通用客户，客户不作为筛选项；单据状态取值「草稿」在页面统一展示为「待提交」（主 PRD §6.1）。

### 6.2 批量操作（同质勾选）

| 动作 | 触发条件 | 弹窗/反馈要点 |
| :--- | :--- | :--- |
| 选仓选物流 | 勾选均为待提交 | 发货仓库*、物流服务产品*（不含备注）；Toast「已更新 N 张…」 |
| 提交 | 勾选均为待提交 | 确认后逐单提交；未选仓物流的单据在点批量前 Toast 阻断（R10） |

## 7. 导入（正式能力方向；Demo 以 Mock 演示）

接口未覆盖的Shopify订单支持人工导入（INT-FR06），入口为本页页头「导入」；按 Shopify来源单号 匹配与去重，校验通过后生成草稿并走提交审核（COM-FR02）。导入覆盖的订单类型、模板字段与校验规则随实际对接范围确认（主 PRD Q02）。

> **Demo 边界**：原型以 Mock 演示向导（弹窗 PRD §5），上传演示文件后生成 2～3 张标注「演示数据」的待提交草稿（获取方式=人工导入），**不接真实接口**；生成的记录仅存本地 Mock 存储，可被批量选仓选物流、提交、审核等后续动作串联。

| 步骤 | 内容 |
| :--- | :--- |
| 1. 下载模板 | 提供演示用 Excel 模板下载（Mock） |
| 2. 上传文件 | 支持 .xlsx；向导内提示「仅用于接口未覆盖的Shopify订单，导入后仍需提交审核」 |
| 3. 校验预览 | 演示成功/失败行数：按 Shopify来源单号 分组，任一行失败整组不导入；重复来源单号按识别规则处理 |
| 4. 导入 | 生成待提交草稿（获取方式=人工导入）；提示导入结果 |

### 9.1 Mock 数据覆盖
