## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 独立站订单详情页 |
| 入口 | 列表点击单号；系统集成中心-推送异常「推送电商平台」页签的单据编号点击直达本单详情；操作完成后可刷新本页 |
| 页面目标 | 只读查看一张独立站订单全貌；按当前状态办理允许的操作 |
| 骨架结构 | 页头 → 单据信息 → 来源信息 → 收货信息 → 发货与物流 → 商品明细 → 推送与回写 → 关联单据（条件）→ 终止信息（条件）→ 操作信息 |

本页落地 **F09（分区展示与追溯）** 及详情侧 **F04/F05/F06/F08/F10/F11/F12** 操作入口；状态—操作矩阵见主 PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码；从推送异常跳入时返回推送异常页（保留原页签） |

> **本期边界**：
> - 页头固定展示**单据状态**一枚 **StatusBadge**（单一状态字段；「草稿」展示为「待提交」）；不单开「状态信息」卡片。
> - **关联单据**在单据状态为已发货、已取消，或已生成关联结果单时展示；草稿、待审核、已审核、推送失败、待发货、取消中且无结果单时不展示。
> - 终止信息仅在**单据状态=已取消**时展示。
> - 操作信息含**制单信息 / 操作日志**胶囊 Tab；人工确认逐条留痕在操作日志，最近一次在制单信息区展示。
> - 二次确认弹窗正文在[弹窗 PRD](独立站订单前端Demo版PRD_弹窗与Mock.md)维护，本文只写入口与结果表现。
> - Demo 不调用真实Shopify与仓库接口：推送、回传、回写与人工确认按 Mock 分支演示（见弹窗 PRD §4、§5）。
> - Demo 以**桌面端**为基准；商品明细、关联简表在窄视口内**横向滚动**，不承诺移动端布局。

## 2. 页头

### 2.1 标题与状态

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `独立站订单详情 · {单号}`（单号随记录展示） |
| 状态标签 | 一枚 StatusBadge：单据状态 |
| 布局 | 单行：左侧标题 + 状态标签；右侧操作区（`DocumentDetailFrame`） |

列表状态列用语义色文字；**详情页头用 StatusBadge 胶囊**，tone 与列表语义一致（见《原型开发说明》）。

### 2.2 页头操作按钮

`返回列表` **始终排在最前**；其后按状态展示业务按钮。

| 按钮 | 待提交 | 待审核 | 已审核 | 推送失败 | 待发货 | 取消中 | 已发货 | 已取消 | 说明 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| 返回列表 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | 始终 |
| 编辑 | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | 打开选仓选物流弹窗 |
| 提交 | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | — |
| 删除 | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | 删除后返回列表 |
| 审核 | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | — |
| 撤回 | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | — |
| 取消审核 | ❌ | ❌ | ✅ | ✅ | ❌ | ❌ | ❌ | ❌ | 推送失败或推送结果不明确时须确认仓库未接收 |
| 重试推送 | ❌ | ❌ | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ | — |
| 申请取消 | ❌ | ❌ | ❌ | ❌ | ✅ | ❌ | ❌ | ❌ | — |
| 人工确认 | ❌ | ❌ | ✅ | ❌ | ✅ | ✅ | ❌ | ❌ | 确认类型按状态限定：已审核=确认接单、待发货=执行结束、取消中=取消结果 |
| 复制新单 | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | ✅ | 复制后进入新单详情或停留原单（见 §5） |
| 重新回写 | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | 条件✅ | 条件✅ | 仅回写状态=回写失败时展示 |

条件说明（详见主 PRD）：

| 按钮 | 条件摘要 |
| :--- | :--- |
| 取消审核 | R19：已审核（未推送成功）或推送失败；推送失败或结果不明确时确认仓库未接收；已推送成功的走「申请取消」 |
| 申请取消 | R20：待发货；进入取消中等待回执 |
| 人工确认 | R23：用于已交给仓库、接口拿不到结果时；按状态限定确认类型 |
| 复制新单 | R17：已取消；原单保持已取消 |
| 重新回写 | R18：回写状态=回写失败 |

已发货/已取消态按钮建议顺序（`返回列表` 之后）：已取消为 复制新单 → 重新回写（条件）；已发货为 重新回写（条件）。

**渲染纪律**：

- 条件不满足的按钮**直接不渲染**，不展示灰色 disabled 占位。
- 样式层级：**提交、审核** 用主要按钮（`primary`）；**编辑** 为待提交主按钮；**删除、撤回、取消审核、重试推送、申请取消、人工确认、复制新单、重新回写** 用次要按钮（`outline`）；**返回列表** 为幽灵/次要样式，固定最左。

## 3. 信息分区与字段

> 只读 **6 列栅格**，标签在上、值在下；备注占 **3 列**。字段顺序与 TSV 分组一致。

**分区总览**：页头 → **3.1 单据信息** → **3.2 来源信息** → **3.3 收货信息** → **3.4 发货与物流** → **3.5 商品明细** → **3.6 推送与回写** → **3.7 关联单据**（条件）→ **3.8 终止信息**（条件）→ **3.9 操作信息**

### 3.1 单据信息

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样 |
| 客户 | Code-Name（跨境电商2C通用客户） |
| 币别 | `{币别编码} {币别名称}`（如 `CNY 人民币`） |
| 价税合计 | 金额；千分位；沿用Shopify，不提供修改入口 |
| 税额 | 同上 |
| 金额 | 不含税金额合计；同上 |
| 总订购数量 | 整数 |
| 累计实际发货数量 | 整数；未发货为 `0` |
| 差额数量 | 整数；整单零执行时等于总订购数量 |
| 备注 | 占 3 列；长文本可换行 |

布局：第 1 行—单号、客户、币别、价税合计、税额、金额；第 2 行—总订购数量、累计实际发货数量、差额数量；第 3 行—备注从第 1 列起占 3 列（第 4～6 列留空）。

### 3.2 来源信息

| 字段 | 展示说明 |
| :--- | :--- |
| Shopify来源单号 | 原样展示；复制新单与原单同号，按单号可在列表中检索到同来源多单 |
| 获取方式 | 接口拉取／人工导入／复制生成 |

布局：第 1 行—Shopify来源单号、获取方式（后 4 列留空）。

### 3.3 收货信息

| 字段 | 展示说明 |
| :--- | :--- |
| 收货人姓名 | 文本 |
| 收货人电话 | 文本；缺失为 `-` |
| 国家／地区 | 文本 |
| 邮政编码 | 文本；缺失为 `-` |
| 收货地址 | 一行完整地址文本（省／州、城市与详细地址合并），占 3 列 |

布局：第 1 行—收货人姓名、收货人电话、国家／地区、邮政编码；第 2 行—收货地址占 3 列。

**说明**：收货信息随来源固化，不在详情页拆列编辑；来源变更未审核时由系统按本次拉取覆盖（主 PRD R04）。

### 3.4 发货与物流

| 字段 | 展示说明 |
| :--- | :--- |
| 发货仓库 | 逻辑仓 Code-Name；草稿未选时为 `-` |
| 物流服务产品 | Code-Name 或「由仓库指定」；草稿未选时为 `-` |
| 运单号 | 文本；未发货为 `-` |

布局：第 1 行—发货仓库、物流服务产品、运单号（后 3 列留空）。

### 3.5 商品明细

- 表格只读；**数量、单价、价税列右对齐**；横向滚动。
- 一期**不分页**，展示全部明细行。
- 不单独展示后台「商品」关联列；以**商品编码**列承载。
- 价税列顺序：**含税单价 → 税率 → 不含税单价 → 价税合计 → 税额 → 金额**。

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 自动编号 |
| 商品编码 | 文本 |
| 商品条码 | 文本；多条码一期可用英文分号 `;` 拼接展示，无条码为 `-` |
| 商品名称 | 文本（快照） |
| 基本单位 | 文本 |
| 订购数量 | 整数 |
| 实际发货数量 | 回写列；整单发出后等于订购数量；零执行时 `0` |
| 差额数量 | 回写列；订购数量−实际发货数量 |
| 含税单价 | 千分位；4 位小数 |
| 税率 | 百分比，如 `13%` |
| 不含税单价 | 系统计算；4 位小数 |
| 价税合计 / 税额 / 金额 | 系统计算；2 位小数 |

**回写列显隐**：详情页一期**始终展示** 实际发货数量、差额数量；未执行时为 `0`，不隐藏列。

**底部汇总行**（`DocumentSummaryBar`）：

| 汇总项 | 展示 |
| :--- | :--- |
| 首列 | 文案 `合计`（占行号列） |
| 订购数量合计 | 与「订购数量」列右对齐，整数 |
| 价税合计 / 税额 / 金额 | 与对应列右对齐；千分位、2 位小数 |

### 3.6 推送与回写

| 字段 | 展示说明 |
| :--- | :--- |
| 推送时间 | 日期时间；未推送为 `-` |
| 最终发货确认时间 | 日期时间；未确认/未结束时为 `-`（整单零执行确认时也记录） |
| 最近处理时间 | 日期时间 |
| 回写状态 | 未回写／已回写／回写失败 |
| 回写内容 | 发货结果与运单／取消结果；未回写为 `-` |
| 回写时间 | 日期时间；未回写为 `-` |
| 推送失败原因 | 多行文本；**有值时独占一行占 3 列**，附「查看推送异常」文字入口（跳转系统集成中心-推送异常「推送外部仓库」页签） |
| 回写失败原因 | 多行文本；**有值时独占一行占 3 列**，附「查看推送异常」文字入口（跳转「推送电商平台」页签） |

布局：第 1 行—推送时间、最终发货确认时间、最近处理时间、回写状态、回写内容、回写时间；失败原因行按有值条件展示（详见图示与骨架）。

**说明**：推送失败、回写失败的完整记录与处理状态见[《推送异常主PRD》](../../../../../20260812-ERP项目第一版框架搭建/需求文档PRD/8-系统集成/推送异常/推送异常主PRD.md)；本页不提供修改业务内容入口，重试推送/重新回写为本页对应按钮。

### 3.7 关联单据

**展示条件**：单据状态为已发货、已取消，或已生成关联结果单（含人工确认形成的出库单草稿）时展示；其他状态不展示本区。

组件：`RelatedDocumentsCard`；胶囊 Tab（`InnerTabs` `pill` 变体）；Tab 文案带数量，如 `销售出库单 (1)`。默认选中「销售出库单」。

| Tab | 列 | 排序 | 空态 |
| :--- | :--- | :--- | :--- |
| 销售出库单 | 单号、审核状态、推送财务ERP状态、实际出库数量、价税合计、创建时间 | 创建时间倒序 | 暂无关联的销售出库单 |
| 销退入库单 | 单号、审核状态、推送财务ERP状态、实际入库数量、价税合计、创建时间 | 创建时间倒序 | 暂无关联的销退入库单 |

单号可跳转对应详情；销退入库单为空态时不强制引导（退货走销售退货链路办理）。

### 3.8 终止信息

**展示条件**：单据状态 = **已取消**。

| 字段（占前 4 列） | 展示说明 |
| :--- | :--- |
| 取消方式 | 取消审核（终止）／申请取消（仓库确认）／整单零执行取消 |
| 取消原因 | 业务取消时展示填写原因；整单零执行取消为 `-`，用取消方式区分 |
| 取消时间 | 日期时间 |
| 取消操作人 | 姓名；整单零执行由回传触发时为 `-`，用取消方式区分 |

### 3.9 操作信息

胶囊 Tab：**制单信息**（默认）/ **操作日志**。

| Tab | 内容 |
| :--- | :--- |
| 制单信息 | 第 1 行：创建人、创建时间、最后更新人、最后更新时间；第 2 行：审核人、审核时间、撤回意见（占 3 列，有值时展示）；第 3 行：人工确认人、人工确认时间、人工确认内容（占 3 列，有值时展示） |
| 操作日志 | 表格：操作时间、操作人、操作类型、说明；按时间倒序；一期从创建、覆盖/新建（来源变更）、选仓选物流、提交、审核、撤回、推送失败/重试、回传结果、申请取消/取消审核、仓库回执、人工确认、复制新单、重新回写等推导 |

## 4. 字段展示规范

| 规范 | 说明 |
| :--- | :--- |
| 空值 | 文本类统一英文连字符 `-`（`EMPTY_PLACEHOLDER`） |
| 名称展示 | 客户、逻辑仓、物流服务产品及商品名称均使用本单保存的名称快照并按 Code-Name 展示；不实时读取主数据 |
| 币别 | 独立字段展示 `CNY 人民币`；明细金额列不重复币别前缀 |
| 金额 | 千分位；2 位小数；单价 4 位 |
| 数量 | 整数；`0` 按有效值展示 |
| 税率 | 百分比，如 `0%`、`13%` |
| 日期 | `YYYY-MM-DD` |
| 日期时间 | `YYYY-MM-DD HH:mm:ss` |
| 页头状态 | StatusBadge 胶囊，非列表语义色文字 |
| 系统赋值 | 拉取生成的单据创建人、最后更新人显示「系统」；人工导入记录导入人 |

## 5. 操作行为

| 操作 | 行为 |
| :--- | :--- |
| 编辑 | 打开「选仓选物流」弹窗（含备注）；保存后刷新详情 |
| 提交 / 审核 / 撤回 / 取消审核 / 申请取消 / 重试推送 / 复制新单 / 删除 / 重新回写 | 打开弹窗 PRD 对应弹窗 → 成功后刷新详情或返回列表 |
| 人工确认 | 打开「人工确认」弹窗（弹窗 PRD §4）→ 按确认类型刷新状态、明细与操作信息；执行结束生成销售出库单草稿并提示到出库单提交审核 |
| 复制新单 | 确认后生成新草稿并跳转新单详情（返回原单入口保留）；原单保持已取消 |
| 查看推送异常 | 打开系统集成中心-推送异常对应页签；返回后保留本单上下文 |
| 返回列表 | 回到列表，保留筛选、页码与列表上下文；从推送异常跳入时返回推送异常页并保留原页签 |

## 7. Mock 与验收

### 7.1 Mock 覆盖清单

- **待提交** 至少 2 单：1 单未选仓物流（发货仓库、物流服务产品为 `-`）；1 单已选仓物流可编辑
- **待审核** 至少 1 单：可审核/撤回；明细回写列为 `0`
- **已审核** 至少 1 单：可取消审核、人工确认（确认接单）
- **推送失败** 至少 1 单：推送失败原因有值、展示「查看推送异常」入口；可重试推送、取消审核
- **待发货** 至少 1 单：可申请取消、人工确认（执行结束）；可含人工确认后生成的销售出库单草稿记录
- **取消中** 至少 1 单：可人工确认（取消结果）
- **已发货** 至少 1 单：已回写记录 + 关联销售出库单；另 1 单回写状态=回写失败，展示回写失败原因与「重新回写」
- **已取消** 至少 2 单：1 单整单零执行取消（实发 `0`、差额定购数、取消方式=整单零执行取消）；1 单业务终止（取消原因有值）；均展示终止信息与「复制新单」
- 关联 Tab：至少 1 单含出库单记录、1 单含销退入库单记录、1 个 Tab 为空态
- 来源变更示例：同 Shopify来源单号 的两张单据（1 张已审核/待发货、1 张待提交新建）

### 7.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 待提交详情 | 打开未选仓的待提交单 | StatusBadge=待提交；仓库、物流为 `-`；可编辑/提交/删除；无关联单据、无终止信息 |
| 选仓选物流 | 点编辑→选仓库物流→保存 | 发货与物流区刷新；操作日志新增记录 |
| 审核占库 | 待审核单点审核，库存充足 | 转已审核；推送信息更新；Demo 接续推送 Mock |
| 取消审核 | 已审核单选终止/调整 | 终止转已取消（展示终止信息）；调整回待提交可编辑 |
| 人工确认 | 待发货单确认执行结束（整单发出） | 生成销售出库单草稿并提示提交审核；审核通过后转已发货；操作信息展示确认人/时间/内容 |
| 人工确认零执行 | 待发货单确认执行结束且实发为0 | 按零出取消：转已取消、实发0、差额=订购数量、无零数量出库单；保留确认记录 |
| 零执行再发 | 已取消（零执行）单点复制新单 | 生成待提交新单、同Shopify来源单号；原单保持已取消 |
| 回写失败 | 打开回写失败的已发货单 | 回写状态=回写失败、原因与「查看推送异常」入口；可重新回写 |
| 推送异常跳转 | 推送异常「推送电商平台」点单据编号 | 直达本单详情；返回推送异常保留原页签 |
| 来源变更展示 | 打开同来源单号的两张单据 | 分别展示各自状态与执行记录，互不覆盖 |
| 操作信息 | 切换 Tab | 默认制单信息；操作日志含人工确认、取消、回写等记录，倒序只读 |
