# 采购退货管理交付清单

> 清单版本：V0.1｜更新日期：2026-10-15｜状态：初稿，待评审（未纳入B10①评审范围）。
> 二版说明：本模块三个对象中，采退发货通知单、采退出库单按 B4 重建（主PRD、页面骨架、详情页与弹窗类 Demo、字段清单出二版；列表页等未变文件继续引用一版）；采购退货单二版未修订，继续引用一版文件。二版变化与一版文件去向登记见[《二版交付清单》](../../二版交付清单.md)§二。

本套件覆盖采购退货管理一期三个对象：采购退货单、采退发货通知单、采退出库单。采购退货单是业务安排，审核时占用可用库存、控制可退额度；采退发货通知单是执行指令，负责仓库发货（自营仓直连、电商仓经聚水潭／领星中转）或虚拟出库；采退出库单是实际结果，自动审核后记账并推送财务ERP。业务规则以[《采购业务管理需求分析》](../../../../02-需求调研和分析/02-采购业务管理/采购业务管理需求分析.md)和[《采购业务设计》](../../../../03-业务分析和设计/01-采购业务设计.md)为准；字段与取值以`字段清单合集/采购相关`为准；状态以[《单据与状态流转》（一版）](../../../20260812-ERP项目第一版框架搭建/系统架构和流程/03-单据与状态流转.md)第二、三、四节为准（二版未修改，继续引用）。

## 已定结论与后续事项

| 事项 | 结论与处理 |
| --- | --- |
| 电商仓经SaaS中转（B4，2026-10-14） | 采退发货通知单经聚水潭／领星下推其对接仓库；渠道出库结果回传形成采退出库单；SaaS原样转达、一套实物作业只驱动一次；自营仓维持直连作业系统；虚拟出库不推仓库、仅在ERP内记账 |
| 渠道回传来源标识与匹配（B4） | 采退出库结果按「来源系统＋来源单号＋执行标识」标识与去重；匹配通知行，生成（或完成）采退出库单；匹配失败不记账、不推财务ERP，修复后处理原记录；不向渠道推送出库结果，不新增推送类别 |
| 人工确认（采退发货通知单，B4） | 详情页入口（推送中／待发货／取消中）：确认接单、执行结束、取消结果、实际出库数量；仍过业务校验与适用审核；留痕「人工确认人／人工确认时间／人工确认内容」；不得替代虚拟出库、不得无来源新建采退出库单（《集成协作与人工补充》§4.4、INT-FR06） |
| 推送失败去向（B4） | 系统集成中心「推送异常－推送外部仓库」页签；推送失败自动重试最多3次、仍失败可人工重试（一版结论） |
| 采购退货单（一版结论，未变） | 审核时占用可用库存；无来源退货每行大于0、不套原单额度；退货截止日期后T+2自动关闭（全部退足不自动关闭）；已实出只能关闭余量 |
| 接口与渠道产品名 | 渠道侧产品名与字段待联调核验，文件内标「待确认」；商品外部映射与SKU分发暂缓（00 §五） |
| 原型实现差异 | 见09[《待改项》](../../../../09-产品原型/待改项.md)；本清单只记录入口，不用原型替代业务规则 |
