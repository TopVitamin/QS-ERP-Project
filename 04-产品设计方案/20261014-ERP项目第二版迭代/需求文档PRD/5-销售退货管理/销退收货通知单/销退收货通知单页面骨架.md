- **与 TSV 的分工**：字段名称、分组、列表列与筛选项以[《销退收货通知单（详细稿）》](../../../字段清单合集/销售相关/销退收货通知单（详细稿）.tsv)为准；骨架示例列不全时以 TSV 补全。

## 绘制约定

遵循[《页面骨架模板-V2》](../../../../../05-常用模板/02-模块设计交付/页面骨架模板-V2.md)「UI布局规则」与「绘制约定」。本模块补充：

- 字段名、按钮文案与TSV、Demo PRD一致；示例值为虚构。
- 来源销售退货单、客户、收货仓库等关联选择按 Code-Name（`{编码} {名称}`）画示例值；商品明细拆列展示编码、条码、名称、基本单位——编码、条码、名称对应TSV「商品编码」「商品条码」「商品名称」行，「商品」为后台关联字段不单独成列。
- 页头单据状态在**编辑页、详情页**用标签展示，**下推创建页不展示**；不单开「状态信息」区块。
- TSV「字段所属分组」= 卡片分区；组内字段按 TSV 行序填入 6 列栅格。
- **每行必须画满 6 列**（用 `|` 分隔）；字段不足 6 个时，剩余列标「（空）」留空。
- 备注占 3 列时，标签行与值行仍保留 6 条列线。
- 列表页**不提供「新增」**；创建只能从销售退货单下推进入。

**补充说明**：

- **重点突出**：页头仅「导出」，无「新增」；查询区下方独立一行，左侧「收起过滤」、右侧「重置/查询」；单据状态为语义色文字（非 StatusBadge）；来源销售退货单列可点击跳转退货单详情。
- 单据状态、收货处理方式为**多选**下拉，未选等同全部。
- **图中省略**：校验、排序、分页交互见 Demo PRD；列表状态列用语义色文字，详情页头用 StatusBadge。
- 单号可点进详情，行内不设「查看」。
- 批量操作栏一期仅已选中计数与列设置；勾选配合页头导出「已勾选」。
- 行内操作按状态互斥展示，最多直出 3 个 +「更多」下拉。

## 编辑备注页

- **用途**：修改待推送或推送失败通知单的备注。
- **关键要素**：页头与明细数量只读；页头展示当前单据状态标签；仅备注可改。

```text
+--------------------------------------------------------------------------------------------------+
| 编辑销退收货通知单 XTSHTZ-20260919-0002  [待推送]           [取消] [保存]                    |
| （单据信息、商品明细均只读；备注可编辑）                                                         |
+--------------------------------------------------------------------------------------------------+
```

**补充说明**：

- **重点突出**：布局与创建页相同，但单号、来源、仓库、处理方式、明细数量均只读。
- 仅待推送、推送失败可进入；推送中、待收货、取消中、已收货、已取消不可进入。

## 弹窗/抽屉

- **用途**：二次确认取消、重试推送、人工确认；Demo 模拟仓库回传。
- **关键要素**：标题、核心提示文案、必填项、确认/取消按钮。

弹窗字段少，沿用纵向「标签在上、控件在下」，不强行套6列。

### 人工确认

```text
+------------------------------------------------------------------------------+
| 人工确认（补记仓库实际结果）                                              [×] |
|------------------------------------------------------------------------------|
| 只用于已交给仓库、接口拿不到结果的通知；确认前请先与仓库核实实际结果。        |
| 确认类型                                                                    |
| ( ) 确认接单（推送中）  ( ) 确认执行结束（待收货）  ( ) 确认取消结果（取消中） |
| 执行结束时（仅选「确认执行结束」时展示）                                     |
| 行号 | 商品编码  | 商品条码  | 商品名称   | 通知数量 | 实收数量              |

|------------------------------------------------------------------------------|
|                                              [取消] [确认]                   |
+------------------------------------------------------------------------------+
```

**补充说明**：

- **重点突出**：确认类型按当前状态给出可选项；确认执行结束逐行填实收数量；零收按取消结束；取消结果二选一。
- **边界**：不替代事先选择的虚拟入库；不能无来源新建销退入库单；校验不通过不能确认；确认后记录人工确认人、人工确认时间与人工确认内容，确认类型与填写内容进操作日志。
