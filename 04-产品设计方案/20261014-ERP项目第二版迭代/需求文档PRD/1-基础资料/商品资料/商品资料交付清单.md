## 已定结论与后续事项

| 事项 | 结论与处理 |
| --- | --- |
| 商品外部映射维护位置（2026-09-24确认，二版延续） | 由系统集成改为商品资料——独立页面按「平台＋店铺」维护多条外部编码，修改权限按角色（权限配置见[《用户与权限主PRD》](../../../需求文档PRD/9-系统设置/用户与权限/用户与权限主PRD.md)，二版，收口COM-FR01、COM-FR02）；仓库映射与货主标识随实体仓创建、编辑维护；不设系统集成-外部映射页 |
| 商品外部映射与SKU分发暂缓（2026-10-14） | 暂不纳入本轮，待想清楚后再处理（00 §五）；映射字段与页面设计随商品资料PRD下一轮补充 |
| SKU分发目标（一版已同步） | 第三方WMS、财务ERP、聚水潭、领星（2026-09-24确认）；分发字段范围随接口设计（商品与主数据需求分析Q08） |
| 初始价格（一版已定，V0.18） | 商品建档生成初始采购价／销售价，允许为空；非空时必须大于0，单价最多4位小数；采购税率与不含税单价为空、采购单命中后手填（2026-09-24确认） |
| 编码与条码（一版已定） | 商品名称允许重复；商品编码与条码各自唯一；编码保存后不可改；系统生成或手工录入（全局规则） |
| 商品分类（一版已定） | 三级分类树；不审核、新增默认启用；编码系统生成、保存后不可改；上级分类禁用不级联下级 |
| 原型实现差异 | 商品编码系统生成入口未实现（当前只能手工录入）；商品保存未生成初始价目记录（价目表按建档字段推导模拟）；多条码展开、图片放大、金额/税率精度校验待补（低优先）。均登记09[《待改项》](../../../../../09-产品原型/待改项.md)基础资料核验段 |
| 待确认事项 | 供应商／客户联系人类型、地址类型选项与地区字典来源等基础资料Q项仍待确认；导入规则、库存阈值与含电池默认值列在对应主PRD Q项（走查报告未替业务定值） |
