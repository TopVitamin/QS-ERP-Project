# 用户与权限前端Demo版PRD·弹窗与Mock

> **模板版本**：V2（标准型适配）
> **更新时间**：2026-10-15（本次变化：数据权限收口为「一期不启用数据权限过滤（预留结构）」，弹窗占位与Mock口径同步；用户裁定，2026-10-15）
> **定位**：供 AI 生成用户与权限页面（原型 `settings-users`）的弹窗、校验、反馈与演示数据使用。字段定义见[《账号（详细稿）》](../../../../字段清单合集/系统设置相关/用户与权限/账号（详细稿）.tsv)、[《角色（详细稿）》](../../../../字段清单合集/系统设置相关/用户与权限/角色（详细稿）.tsv)、[《数据权限（详细稿）》](../../../../字段清单合集/系统设置相关/用户与权限/数据权限（详细稿）.tsv)；业务规则见[《用户与权限主PRD》](../用户与权限主PRD.md)。
> **本文件只描述页面呈现规则，不重复定义字段含义与枚举取值（枚举一律以字段清单为准）。**

关联资料：[《用户与权限主PRD》](../用户与权限主PRD.md)、[《用户与权限页面骨架》](../用户与权限页面骨架.md)、[《用户与权限前端Demo版PRD_列表页》](用户与权限前端Demo版PRD_列表页.md)、[《原型开发说明》](../../../../../../09-产品原型/原型开发说明.md)（主数据弹窗、表单页标准接线）。

## 1. 弹窗清单与共同规则

| 弹窗 | 入口 | 容器形式 | 保存/确认后的处理 |
| :--- | :--- | :--- | :--- |
| 新增账号 | 账号页签页头「新增」 | 弹窗（6列栅格表单） | 关闭弹窗，列表新增记录并刷新 |
| 编辑账号 | 账号页签行内「编辑」 | 弹窗；登录账号只读、不展示初始密码 | 关闭弹窗，列表刷新 |
| 账号查看 | 账号页签点击登录账号 | 只读弹窗 | 关闭弹窗 |
| 重置密码 | 账号页签行内「重置密码」 | 弹窗（纵向） | 关闭弹窗，Toast提示 |
| 新增角色 | 角色页签页头「新增」 | 弹窗（6列栅格表单） | 关闭弹窗，列表新增记录并刷新 |
| 编辑角色 | 角色页签行内「编辑」 | 弹窗；角色编码只读 | 关闭弹窗，列表刷新 |
| 角色查看 | 角色页签点击角色名称 | 只读弹窗 | 关闭弹窗 |
| 配置功能权限 | 角色页签行内「配置功能权限」 | 弹窗（勾选树） | 保存后关闭，Toast提示；系统管理员角色只读 |
| 配置数据权限 | 数据权限页签行内「配置」 | 弹窗（一期预留占位，不可编辑） | 仅关闭；一期不启用（预留），不保存 |
| 确认弹窗 | 停用账号、停用角色、删除角色、离开未保存 | 二次确认弹窗 | 见 §3「反馈文案与确认弹窗」 |

共同规则：

- 字段内联报错沿用《UI布局公共说明》「表单校验」：控件红底线＋下方「{字段名}不能为空」，标签不变红，保存失败聚焦首错字段；不用必填项汇总Toast。
- 有未保存修改的弹窗在取消、关闭、点遮罩时统一走「离开未保存」确认。
- 新增/编辑弹窗采用主数据弹窗样式（标签在上、控件在下），字段较多时按6列栅格两行排布；保存成功后关闭弹窗并在列表刷新。

## 2. 各弹窗设计

| 姓名 | 输入框，请输入姓名 | 可编辑 | — | 详细稿 |

| 取消/关闭 | 有未保存修改 | 点击取消、关闭或遮罩时 | 弹窗提示「离开后未保存的内容将丢失，确认离开？」 | 确认后关闭，不保存 |

### 2.6 配置功能权限

| 内容 | 设计 |
| :--- | :--- |

| 系统管理员 | 打开时全部勾选且只读，不提供保存按钮，底部提示「系统管理员角色拥有全部权限点，不可修改」 |

| 取消/关闭 | 有未保存改动 | 「离开后未保存的内容将丢失，确认离开？」 | 关闭，不保存 |

## 3. 反馈文案与确认弹窗

操作反馈（Toast）：

| 操作 | 文案 |
| :--- | :--- |
| 新增/编辑账号成功 | 账号已保存 |
| 重置密码成功 | 密码已重置，请将新初始密码线下告知用户 |
| 停用账号成功 | 账号已停用，该账号将不能登录 |
| 启用账号成功 | 账号已启用 |
| 新增/编辑角色成功 | 角色已保存 |
| 停用角色成功 | 角色已停用，已分配账号将失去该角色权限 |
| 启用角色成功 | 角色已启用 |
| 删除角色成功 | 角色已删除 |
| 配置功能权限保存成功 | 功能权限已保存，对已分配账号立即生效 |
| 保存失败（校验） | 按字段内联提示，不弹Toast汇总 |
| 操作失败——权限不足 | 您暂无{动作}权限，请联系管理员（原型无权限模型，接入后统一补） |

确认弹窗：

| 操作 | 弹窗标题 | 正文 | 确认按钮 | 取消按钮 | 确认后的处理 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 停用账号 | 停用账号 | 停用后该账号立即不能登录，历史记录不受影响。 | 确认停用 | 取消 | 执行停用并刷新，Toast提示 |
| 停用角色 | 停用角色 | 停用后已分配账号将立即失去该角色对应的菜单与操作权限，分配关系保留，重新启用后恢复。 | 确认停用 | 取消 | 执行停用并刷新，Toast提示 |
| 删除角色 | 删除角色 | 删除后不可恢复；只有未被账号引用的角色可删除。 | 确认删除 | 取消 | 执行删除并刷新，Toast提示 |
| 离开未保存 | 离开当前弹窗？ | 离开后未保存的内容将丢失。 | 确认离开 | 继续编辑 | 关闭弹窗，不保存 |
| 停用系统管理员角色（被阻止） | 不可停用 | 系统管理员角色不可停用，用于保证系统始终有可管理人员。 | 知道了 | — | 仅关闭提示，不执行停用 |
| 删除被引用角色（被阻止） | 不可删除 | 该角色已分配给账号，不能删除，可改为停用。 | 知道了 | — | 仅关闭提示，不执行删除 |

启用账号、启用角色不弹确认；删除未被引用角色使用上表「删除角色」确认。
