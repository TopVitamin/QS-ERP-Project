## 1. 页面目标与范围

- 页面名称：用户与权限；入口：系统设置-用户与权限菜单（原型页面 id `settings-users`）。
- 页面结构：页头标题 → 页内页签（账号／角色／数据权限）→ 查询区 → 批量操作栏 → 表格 → 分页；三个页签共用同一页面框架。
- 页签与功能对应：账号（主PRD F01）、角色（F02、F03配置入口）、数据权限（F04）。
- 默认页签：账号；切换页签时各自保留查询条件与列设置，清空勾选，回第一页；页签数据与状态互相独立。
- 本期边界：
  - 三个页签均**不提供**导入、导出、删除入口；账号不提供删除（用停用代替，主PRD R09）；
  - 批量操作栏仅「已选中 0 条」计数与列设置，不提供批量业务动作；
  - 数据权限页签为一期不启用（预留）框架：字段按「一期不启用（预留）」展示，不启用数据过滤（主PRD Q01、Q02，2026-10-15 已定）；
  - 权限按角色控制是系统能力，本页的按钮不做权限判断；原型没有真实登录与权限模型，本页按管理员视角完整展示（Mock边界见弹窗与Mock文件）。

## 3. 列表展示与行操作

### 3.1 账号页签

| # | 列名 | 展示形式 | 对齐 | 排序 | 空值 | 格式/示例 | 说明 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 登录账号 | 链接 | 左 | 否 | `-` | `asheng` | 固定左侧；点击打开账号查看弹窗，行内不设「查看」 |
| 2 | 姓名 | 文本 | 左 | 否 | `-` | `阿盛` | 用户引用展示姓名 |
| 3 | 手机号 | 文本 | 左 | 否 | `-` | `138****8888` | 演示值按脱敏样式展示，正式以原样保存与展示 |
| 4 | 邮箱 | 文本 | 左 | 否 | `-` | `asheng@qiangsheng.com` | |
| 5 | 角色 | 文本 | 左 | 否 | `-` | `ROLE_ADMIN 系统管理员;ROLE_CG 采购业务员` | 多个角色按英文分号 `;` 连接；按Code-Name展示；含已停用角色 |

| 按钮 | 启用 | 禁用 | 说明 |
| :--- | :---: | :---: | :--- |
| 编辑 | ✅ | ✅ | 打开编辑账号弹窗，登录账号只读 |

## 4. 页面状态与反馈文案

| 操作 | 反馈方式 | 文案 |
| :--- | :--- | :--- |
| 查询成功 | 无额外反馈 | — |
| 查询失败 | Toast | 查询失败，请稍后重试（原型无失败分支，接后端后统一补） |
| 账号空态 | 无数据 | 暂无账号，点击「新增」开始维护 |
| 角色空态 | 无数据 | 暂无角色，点击「新增」开始维护 |
| 数据权限空态 | 无数据 | 一期不启用数据权限过滤（预留结构），启用后在此按角色配置 |
| 无查询结果 | 保留筛选与勾选状态 | 没有符合条件的记录，请调整筛选条件 |
| 操作失败——权限不足 | Toast | 您暂无{动作}权限，请联系管理员（原型无权限模型，接入后统一补） |
| 操作失败——状态不匹配 | Toast | 当前状态为{状态}，不可执行{动作} |

页面反馈与确认弹窗的完整文案见[《用户与权限前端Demo版PRD_弹窗与Mock》](用户与权限前端Demo版PRD_弹窗与Mock.md) §3「反馈文案与确认弹窗」与 §4「演示数据与Mock边界」。

## 5. 本页验收

| 场景 | 前置 | 操作 | 预期 |
| :--- | :--- | :--- | :--- |
| 页签切换 | 已进入用户与权限 | 在账号、角色、数据权限之间切换 | 各页签显示各自的查询区与列表；切换保留各自查询条件与列设置，清空勾选 |
| 账号筛选 | 演示数据含启用、禁用账号 | 组合登录账号、姓名、角色、使用状态查询 | 只显示同时满足条件的记录；重置后恢复全量并清除勾选 |
| 角色筛选 | 演示数据含启用、禁用角色 | 用角色编码、名称、使用状态查询 | 同上 |
| 数据权限占位 | 数据权限页签 | 查看列表与提示条 | 每条记录按角色展示，数据范围、受控模块显示「一期不启用（预留）」；提示条文案正确（一期不启用口径） |
| 行操作互斥 | 账号行含启用与禁用两种状态 | 查看行内按钮 | 启用行显示「停用」、禁用行显示「启用」；角色行按状态与引用关系展示，删除进「更多」 |
| 登录账号进入查看 | 任意账号行 | 点击登录账号 | 打开只读查看弹窗，不展示密码 |
| 列设置范围 | 账号、角色页签 | 打开列设置 | 可选列与详细稿「列表展示=是」一致；恢复默认可用 |

Demo验证列表查询、页签切换与行操作入口可连续演示；正式实现按主PRD的规则与权限判断执行。
