## 绘制约定

遵循[《页面骨架模板-V2》](../../../../../05-常用模板/02-模块设计交付/页面骨架模板-V2.md)「UI布局规则」与「绘制约定」。本模块补充：

- 字段名、按钮文案与TSV、Demo PRD一致；示例值为虚构。
- 来源采购订单、收货仓库等关联选择按 Code-Name（`{编码} {名称}`）画示例值；商品明细拆列展示编码、条码、名称、基本单位。
- 页头单据状态在**编辑页、详情页**用标签展示，**下推创建页不展示**；不单开「状态信息」区块。
- TSV「字段所属分组」= 卡片分区；组内字段按 TSV 行序填入 6 列栅格。
- **每行必须画满 6 列**（用 `|` 分隔）；字段不足 6 个时，剩余列标「（空）」留空。
- 备注占 3 列时，标签行与值行仍保留 6 条列线。
- 列表页**不提供「新增」**；创建只能从采购订单下推进入。

## 下推创建页

从采购订单带入来源信息；用户录入各行通知数量与备注。**下推创建页页头不展示状态标签**；保存创建后在详情页展示实际状态。

```text
+--------------------------------------------------------------------------------------------------+
| 创建采购收货通知单                                        [取消] [保存并创建]                |
|--------------------------------------------------------------------------------------------------|
| 单据信息（6列栅格；本组4个字段，后2列留空）                                                        |
| 单号        | 来源采购订单 | 供应商      | 收货仓库    | （空）      | （空）        |
| [保存后显示] | CGDD-...0002只读| SUP000001 深圳示例只读| WH000001 华东仓只读|             |               |
| 备注（占3列）         |             |             |             |             |             |
| [请输入备注          ]|             |             |             |             |             |
|--------------------------------------------------------------------------------------------------|
| 商品明细                                                                              （只读列+录入）|
| 行号 | 商品编码      | 商品条码   | 商品名称     | 基本单位 | 可下推数量只读 | 通知数量* | 操作 |
| 1    | SP-...001只读 | 690...001只读| 示例充电器只读| 件 只读  | 420            | [420    ] | —    |
| 2    | SP-...002只读 | 690...002只读| 示例数据线只读| 件 只读  | 200            | [200    ] | —    |
（通知数量默认带出可下推数量，可修改；可下推为0的行不展示）
+--------------------------------------------------------------------------------------------------+
```

说明：「可下推数量」为创建页辅助展示列，来源于来源订单行当前可下推量，便于录入校验，非 TSV 独立字段。至少一行通知数量>0方可创建。

## 编辑备注页

布局与创建页相同，但单号、来源、仓库、明细数量均只读；仅备注可改。页头展示当前单据状态标签。

```text
+--------------------------------------------------------------------------------------------------+
| 编辑采购收货通知单 CGSHTZ-20260919-0002  [待推送]           [取消] [保存]                    |
| （单据信息、商品明细均只读；备注可编辑）                                                         |
+--------------------------------------------------------------------------------------------------+
```

仅待推送、推送失败可进入；推送中、待收货、取消中、已收货、已取消不可进入。

页头按钮示例：

- 待推送：`[返回列表] [编辑] [取消]`

- 待收货：`[返回列表] [取消]`（无编辑）
- 推送中/取消中：`[返回列表]`（仅查看）
- 已收货/已取消：`[返回列表]`

已收货时展示「关联单据」分组，胶囊 Tab「采购入库单」列出下游入库结果；单号跳转入库单详情（见[《采购入库单主PRD》](../采购入库单/采购入库单主PRD.md)）。
