## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 采购收货通知单详情页 |
| 入口 | 列表点击单号；操作完成后可刷新本页 |
| 页面目标 | 只读查看一张通知单全貌；按当前状态办理允许的操作 |
| 骨架结构 | 页头 → 单据信息 → 商品明细 → 关联单据（条件）→ 终止信息（条件）→ 操作信息 |

本页落地 **F04（分区域展示与追溯）** 及详情侧 **F03/F05/F06/F07/F08** 操作入口；状态—操作矩阵见主 PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头固定展示**单据状态**一枚 **StatusBadge**（与单据信息分区并列，不单开「状态信息」卡片）。
> - **关联单据**仅**单据状态=已收货**时展示；未收货不展示下游 Tab。
> - 终止信息仅在**单据状态=已取消**时展示；非已取消不展示该分组。
> - 操作信息含**制单信息 / 操作日志**胶囊 Tab；完整审计日志后置，一期由单据字段推导。
> - 二次确认弹窗正文在[弹窗 PRD](采购收货通知单前端Demo版PRD_弹窗与Mock.md)维护，本文只写入口与结果表现。
> - Demo 以**桌面端**为基准；商品明细、关联简表在窄视口内**横向滚动**。

## 2. 页头

### 2.1 标题与状态

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `采购收货通知单详情 · {单号}`（单号随记录展示） |
| 状态标签 | 一枚 StatusBadge：单据状态 |
| 布局 | 单行：左侧标题 + 状态标签；右侧操作区（`DocumentDetailFrame`） |

列表状态列用语义色文字；**详情页头用 StatusBadge 胶囊**，tone 与列表语义一致（见《原型开发说明》）。

### 2.2 页头操作按钮

`返回列表` **始终排在最前**；其后按状态展示业务按钮。

| 按钮 | 待推送 | 推送中 | 推送失败 | 待收货 | 取消中 | 已收货 | 已取消 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 返回列表 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 编辑 | ✅ | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ |
| 取消 | ✅ | ❌ | ✅ | ✅ | ❌ | ❌ | ❌ |
| 重试推送 | ❌ | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ |
| 模拟仓库回传 | ❌ | ❌ | ❌ | ✅（Demo） | ❌ | ❌ | ❌ |

条件说明（详见主 PRD）：

| 按钮 | 条件摘要 |
| :--- | :--- |
| 编辑 | 待推送、推送失败（F03/R12） |
| 取消 | 待推送、推送失败（F05/R09）；待收货进入取消中（F06/R10） |
| 重试推送 | 推送失败（F07）；正式环境须已自动重试满3次仍失败 |
| 模拟仓库回传 | Demo 且待收货等（F08） |

各状态按钮建议顺序（`返回列表` 之后）：

- 待推送：编辑 → 取消
- 推送失败：编辑 → 重试推送 → 取消
- 待收货：取消

**渲染纪律**：

- 条件不满足的按钮**直接不渲染**，不展示灰色 disabled 占位。
- 样式层级：**编辑** 为待推送/推送失败主按钮；**取消、重试推送** 用次要按钮（`outline`）；**返回列表** 为幽灵/次要样式，固定最左。

### 2.3 二次确认与弹窗

| 操作 | 弹窗 PRD | 确认后页面表现 |
| :--- | :--- | :--- |
| 取消 | §2 | 刷新详情；Toast「采购收货通知单已取消」或「已发起取消，等待仓库回执」 |
| 重试推送 | §3 | 刷新为推送中；Toast「已重新推送仓库」 |
| 模拟仓库回传 | §4 | 刷新详情；按回传结果更新状态与数量 |

弹窗标题、正文、必填项不在本文重复。

## 3. 信息分区与字段

> 只读 **6 列栅格**，标签在上、值在下；备注占 **3 列**。字段顺序与 TSV 分组一致。

**分区总览**：页头 → **3.1 单据信息** → **3.2 商品明细** → **3.3 关联单据**（已收货）→ **3.4 终止信息**（已取消）→ **3.5 操作信息**

### 3.1 单据信息

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样 |
| 来源采购订单 | Code-Name；可跳转采购订单详情 |
| 供应商 | Code-Name |
| 收货仓库 | 逻辑仓 Code-Name |
| 收货处理方式 | 仓库收货／虚拟入库 |
| 推送时间 | 日期时间；未推送或虚拟入库时为 `-` |
| 最终收货确认时间 | 日期时间；未确认时为 `-` |
| 推送失败原因 | 有值时占 3 列；未失败时整行不展示 |
| 备注 | 占 3 列；长文本可换行 |

布局：第 1 行—单号、来源采购订单、供应商、收货仓库、收货处理方式、推送时间；第 2 行—最终收货确认时间、推送失败原因（占后 3 列，有值时）；第 3 行—备注占 3 列。单据状态仅在页头 StatusBadge 展示。

### 3.2 商品明细

- 表格只读；**数量列右对齐**；横向滚动。
- 一期**不分页**，展示全部明细行。
- 不单独展示后台「商品」关联列；以**商品编码**列承载。

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 自动编号 |
| 商品编码 | 文本 |
| 商品条码 | 文本；多条码一期可用英文分号 `;` 拼接展示，无条码为 `-` |
| 商品名称 | 文本 |
| 基本单位 | 文本 |
| 通知数量 | 整数 |
| 实收数量 | 整数；未回传为 `0` |
| 缺收数量 | 整数；未结束为 `0` |

**底部汇总行**（`DocumentSummaryBar`）：

| 汇总项 | 展示 |
| :--- | :--- |
| 首列 | 文案 `合计`（占行号列） |
| 通知数量合计 | 与「通知数量」列右对齐，整数 |
| 实收数量合计 | 与「实收数量」列右对齐，整数 |
| 缺收数量合计 | 与「缺收数量」列右对齐，整数 |

### 3.3 关联单据

**展示条件**：单据状态 = **已收货**。

组件：`RelatedDocumentsCard`；胶囊 Tab（`InnerTabs` `pill` 变体）；Tab 文案带数量，如 `采购入库单 (1)`。

| Tab | 列 | 排序 | 空态 |
| :--- | :--- | :--- | :--- |
| 采购入库单 | 单号、审核状态、金蝶推送状态、实际入库数量、价税合计、实际入库时间 | 创建时间倒序 | 暂无关联的采购入库单 |

单号可跳转[采购入库单详情](../../采购入库单/前端Demo版PRD/采购入库单前端Demo版PRD_详情页.md)。零收取消不生成入库单，已取消不展示本分组。

### 3.4 终止信息

**展示条件**：单据状态 = **已取消**。

| 字段（占前 3 列） |
| :--- |
| 取消原因、取消时间、取消操作人 |

### 3.5 操作信息

胶囊 Tab：**制单信息**（默认）/ **操作日志**。

| Tab | 内容 |
| :--- | :--- |
| 制单信息 | 创建人、创建时间、最后更新人、最后更新时间（6 列栅格） |
| 操作日志 | 表格：操作时间、操作人、操作类型、说明；按时间倒序；一期从创建、推送仓库、收货完成、取消等推导 |

不在新增/编辑页展示本分区。

## 4. 字段展示规范

通用规则见《原型开发说明》「列表列通用呈现规则」中与详情相关的条目；下表写本页差异。

| 规范 | 说明 |
| :--- | :--- |
| 空值 | 文本类统一英文连字符 `-`（`EMPTY_PLACEHOLDER`）；**禁止**用中文破折号 `—` 或留空白 |
| 主数据 | Code-Name：`{编码} {名称}` |
| 数量 | 整数；`0` 按有效值展示 |
| 日期 | `YYYY-MM-DD` |
| 日期时间 | `YYYY-MM-DD HH:mm:ss` |
| 页头状态 | StatusBadge 胶囊，非列表语义色文字 |
| 关联简表 | 外框与表头样式见《原型开发说明》「详情内嵌简表」 |

| :--- | :--- |

## 6. 反馈与页面状态

### 6.1 操作反馈（Toast）

| 操作 | 反馈类型 | 文案 |
| :--- | :--- | :--- |
| 取消成功 | Toast | 采购收货通知单已取消 |
| 待收货取消成功 | Toast | 已发起取消，等待仓库回执 |
| 重试成功 | Toast | 已重新推送仓库 |
| 仓库拒绝取消 | Toast | 仓库拒绝取消，请继续等待收货 |
| Mock 回传成功 | Toast | 仓库回传已确认（Demo） |
| 状态已变更（阻断） | Toast | 操作失败，单据状态已变更，请刷新后重试 |
| 并发/版本冲突（如有） | Toast | 操作失败，当前单据已被修改，请刷新后重试 |

### 6.2 加载与异常态

| 场景 | 页面表现 | 文案 / 操作 |
| :--- | :--- | :--- |
| 加载中 | 骨架屏；分区占位（页头、单据信息、明细表等） | — |
| 单据不存在 | 错误态 | 采购收货通知单不存在或无权查看；提供「返回列表」 |
| 加载失败 | 错误态 | 加载失败，请重试；提供「重试」与「返回列表」 |
| 返回列表 | 跳转列表 | 恢复进入前的查询条件与页码；无历史筛选时回默认列表 |

## 7. Mock 与验收

### 7.1 Mock 覆盖清单

- **待推送** 至少 1 单：页头 StatusBadge；可编辑/取消；无关联单据、无终止信息
- **推送失败** 至少 1 单：展示推送失败原因；可编辑/重试/取消
- **待收货** 至少 1 单：可取消；实收/缺收为 0；Demo 可模拟回传
- **取消中** 至少 1 单：页头仅返回列表
- **已收货** 至少 1 单：明细含实收/缺收；有关联入库单 Tab；无业务按钮
- **已取消** 至少 1 单：展示终止信息；页头仅返回列表
- **虚拟入库** 至少 1 单：推送时间为 `-`；已收货且有入库单
- 关联 Tab：至少 1 单含入库单记录；零收取消单无关联 Tab
- 制单信息至少 1 个字段为空 `-`
- 操作日志 Tab 有可展示记录

### 7.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 待收货详情 | 打开待收货单 | 页头 StatusBadge 待收货；实收/缺收为 0；显示取消；无编辑 |
| 已收货详情 | 打开已收货单 | 明细数量正确；展示关联入库单；无取消按钮 |
| 关联跳转 | 点击入库单号 | 进入入库单详情 |
| 已取消详情 | 打开已取消单 | 展示终止信息；无业务按钮 |
| 推送失败 | 打开推送失败单 | 展示推送失败原因与重试按钮 |
| 操作信息 | 切换 Tab | 默认制单信息；操作日志倒序只读 |
| 页头布局 | 任意单 | `返回列表` 固定最前；左侧标题+状态，右侧操作 |
