## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 采购收货通知单下推创建 / 编辑备注 |
| 页面目标 | 从采购订单下推创建通知单，或修改待推送/推送失败通知单的备注 |
| 适用状态 | 下推创建：来源订单已审核+正常+有可下推量；编辑备注：待推送、推送失败 |
| 骨架结构 | 页头（标题 + 操作按钮）→ 单据信息 → 商品明细 |

> 操作按钮固定在**页头右侧**，不使用底部固定操作栏。推送中、待收货、取消中、已收货、已取消不可进入编辑页。本页落地 **F02（下推创建）**、**F03（编辑备注）**；状态—操作矩阵见主 PRD §6.4。

| 模式 | 入口 | 差异摘要 |
| :--- | :--- | :--- |
| **下推创建** | 采购订单列表/详情「下推通知单」 | 单号占位「保存后自动生成」；页头无状态标签；可编辑通知数量、收货处理方式、备注 |
| **编辑备注** | 列表/详情「编辑」 | 单号只读；页头 StatusBadge 展示单据状态；仅备注可改 |

**本期边界**：页头 **取消 / 保存并创建** 或 **取消 / 保存**；无保存草稿——仓库收货时创建即进入待推送并触发推送；虚拟入库时创建即已收货并生成入库单；操作信息、终止信息、推送时间等系统字段不在本页。

## 2. 页头

| 元素 | 规格 |
| :--- | :--- |
| 标题（下推创建） | `创建采购收货通知单` |
| 标题（编辑备注） | `编辑采购收货通知单`；单号在标题或表单区只读展示 |
| 状态标签 | 下推创建不展示；编辑备注展示一枚 StatusBadge（单据状态） |
| 操作区（下推创建） | 从左到右：`取消` → `保存并创建` |
| 操作区（编辑备注） | 从左到右：`取消` → `保存` |

| 按钮 | 说明 |
| :--- | :--- |
| 取消 | 返回上一页；有未保存修改时二次确认（弹窗 PRD §4） |
| 保存并创建 | 通过 §4.3 校验后创建通知单 |
| 保存 | 通过 §4.3 校验后更新备注 |

保存/创建时当前按钮 loading，另一操作按钮同步 disabled，防重复点击；失败保留已填内容。

## 3. 表单分区与字段

> 单头 **6 列栅格**，标签在上、控件在下；备注占 **3 列**。控件 `type` 对齐原型 `FormControl` / `LineItemTable`。主数据按 Code-Name（`{编码} {名称}`）展示。**placeholder** 指控件无值时的占位文案；只读/禁用填 `—`。

区域顺序：**单据信息 → 商品明细**（与 TSV 一致）。

### 3.1 单据信息

| 字段 | 控件 type | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 单号 | `disabled` | `保存后自动生成`（下推创建）/ `—`（编辑有值） | 编辑只读展示系统单号（R01） |
| 来源采购订单 | `disabled` | `—` | 带入来源订单 Code-Name；不可改（R02） |
| 供应商 | `disabled` | `—` | 沿用来源订单供应商 Code-Name |
| 收货仓库 | `disabled` | `—` | 沿用订单收货仓库 Code-Name |
| 收货处理方式 | `select` | `请选择` | 仓库收货／虚拟入库；默认仓库收货；保存后不可改（R13） |
| 备注 | `textarea` | `请输入备注` | 选填；占 3 列 |

下推创建页页头**不展示状态标签**——通知单尚未保存，没有可展示的状态。

### 3.2 商品明细

独立表格区块，横向滚动。

#### 3.2.1 表格操作

下推创建页展示来源订单全部可下推行（可下推量>0）；可下推量为 0 的行隐藏。编辑备注页明细全部只读，无添加/删除。

#### 3.2.2 列定义

| 列名 | 可编辑 | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 行号 | 只读 | `—` | 从 1 起自动编号 |
| 商品编码 | 只读 | `—` | 沿用来源订单行 |
| 商品条码 | 只读 | `—` | 沿用来源订单行；无条码展示 `-` |
| 商品名称 | 只读 | `—` | 沿用来源订单行 |
| 基本单位 | 只读 | `—` | 随商品带出 |
| 可下推数量 | 只读 | `—` | 来源订单行当前可下推量；**仅下推创建页展示**；非 TSV 独立字段 |
| 通知数量 | 下推创建可编辑 | `—` | `QTY_INT`；正整数 >0；≤可下推数量；默认=可下推数量（R03）；创建后只读 |

编辑备注页不展示「可下推数量」列；通知数量只读。

#### 3.2.3 底部汇总

| 汇总项 | 展示 |
| :--- | :--- |
| 通知数量合计 | 与「通知数量」列右对齐，整数 |

## 4. 校验规则

弹窗见[弹窗 PRD](采购收货通知单前端Demo版PRD_弹窗与Mock.md)。下文 **保存并创建** 指点「保存并创建」，**保存** 指点编辑备注页的「保存」。

### 4.1 校验分层总览

| 层级 | 本页行为 | 典型错误位置 |
| :--- | :--- | :--- |
| 录入限制 | 通知数量禁小数等 | 阻止输入或即时提示 |
| 失焦 | 数量整数校验（§4.2） | 字段下或 Toast；改值后**即时**清除该项错误 |
| 保存并创建 | 下推创建全量校验（§4.3） | 单头内联；明细 Toast 或错误条 |
| 保存（编辑备注） | 备注长度（§4.4） | 字段下 |
| 请求中 | 按钮 loading；另一按钮 disabled | — |

### 4.2 录入与失焦

| 字段 | 模板 | 格式与范围 | 录入/失焦处理 | 典型提示 |
| :--- | :--- | :--- | :--- | :--- |
| 收货处理方式 | 枚举 | 仓库收货／虚拟入库 | 下拉选择 | `收货处理方式不能为空` |
| 备注 | `REMARK_500` | 0～500 字 | 超限阻止输入 | `备注已达 500 字上限` |
| 通知数量 | `QTY_INT` | 正整数 >0 | 禁小数点；失焦非整数视为未填 | `第 N 行通知数量须为正整数` |

### 4.3 点击「保存并创建」

**入口校验**：来源订单须为已审核+正常+至少一行可下推量>0；否则阻断并提示「当前采购订单不可下推收货通知」。

| 校验对象 | 条件 | 错误位置 | 阻断 | 文案 |
| :--- | :--- | :--- | :---: | :--- |
| 收货处理方式 | 必填 | 字段下方 | 是 | `收货处理方式不能为空` |
| 商品明细 | 至少一行通知数量>0 | Toast / 错误条 | 是 | `请至少填写一行通知数量` |
| 通知数量（每行） | 正整数 >0 | Toast | 是 | `第 N 行通知数量必须大于 0` |
| 通知数量（每行） | ≤可下推数量 | Toast | 是 | `第 N 行通知数量不能超过可下推数量{可下推量}` |

通过后：

- **仓库收货**：创建通知、分配单号、占用订单额度；状态→待推送并触发自动推送（R05）；Toast「采购收货通知单已创建」；跳转详情或返回订单。
- **虚拟入库**：创建通知；状态→已收货；各行实收=通知数量、缺收=0；生成已审核采购入库单（R13）；Toast「采购收货通知单已创建」；跳转详情或返回订单。

### 4.4 点击「保存」（编辑备注）

| 校验对象 | 条件 | 错误位置 | 阻断 | 文案 |
| :--- | :--- | :--- | :---: | :--- |
| 备注 | 0～500 字 | 字段下方 | 是 | `备注已达 500 字上限` |

通过后：更新备注与操作信息；Toast「采购收货通知单已保存」；返回详情。

### 4.5 并发与额度变化

| 场景 | 页面表现 | 文案 |
| :--- | :--- | :--- |
| 下推时额度并发变化 | 保留输入 | `可下推数量已变化，请刷新后重试` |

### 4.6 错误展示与纠错

| 类型 | 表现 | 纠错 |
| :--- | :--- | :--- |
| 单头必填 | 红底线 + 字段下文案 | 修改该字段后清除 |
| 明细/全局 | Toast（含「第 N 行」） | 修正后清除对应提示 |
| 取消离开 | 确认框 | `离开后未保存的内容将丢失，确认离开？` |

## 6. 操作行为

| 操作 | 行为 |
| :--- | :--- |
| 保存并创建 | 执行 §4.3；通过后创建通知并提示成功；跳转详情或返回订单 |
| 保存 | 执行 §4.4；通过后更新备注并提示成功 |
| 取消 | 有未保存修改则确认；确认后返回上一页 |
| 编辑页进入 | 加载中展示占位；失败展示「采购收货通知单不存在或无权查看」；非待推送/推送失败不可进入，提示「当前状态不可编辑」 |

## 10. Mock 与验收

### 10.1 Mock 覆盖

- 可下推订单：至少 2 行明细，各行可下推量>0
- 编辑用待推送单：仅备注可改
- 推送失败单：验证可进入编辑备注
- 待收货/已收货单：验证不可进入编辑页

### 10.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 默认带出 | 订单行可下推420 | 进入下推页，通知数量默认420 |
| 正常下推 | 改通知为400并保存（仓库收货） | 创建成功；订单可下推减少 |
| 虚拟入库 | 选虚拟入库并保存 | 通知已收货；实收=通知数量；出现关联入库单 |
| 超量阻断 | 填通知超过可下推量 | 阻断并提示超过可下推量 |
| 全空阻断 | 所有行通知数量空 | 提示至少一行通知数量 |
| 编辑备注 | 待推送单改备注保存 | 仅备注更新 |
| 不可编辑 | 待收货/已收货单点编辑 | 不进入或提示当前状态不可编辑 |
