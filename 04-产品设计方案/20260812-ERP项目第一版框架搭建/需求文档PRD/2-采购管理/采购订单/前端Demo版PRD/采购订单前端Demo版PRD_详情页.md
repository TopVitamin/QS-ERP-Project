## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 采购订单详情页 |
| 入口 | 列表点击单号；操作完成后可刷新本页 |
| 页面目标 | 只读查看一张采购订单全貌；按当前状态办理允许的操作 |
| 骨架结构 | 页头 → 单据信息 → 收货与交期 → 商品明细 → 关联单据（条件）→ 终止信息（条件）→ 操作信息 |

本页落地 **F05（分区域展示与追溯）** 及详情侧 **F02/F03/F04/F06** 操作入口；状态—操作矩阵见主 PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头固定展示**审核状态、业务状态、收货状态**三枚 **StatusBadge**（与单据信息分区并列，不单开「状态信息」卡片）。
> - **关联单据**仅**审核状态=已审核**时展示；草稿、待审核不展示下游 Tab。
> - 终止信息仅在**业务状态=已关闭或已取消**时展示；正常单不展示该分组。
> - 操作信息含**制单信息 / 操作日志**胶囊 Tab；完整审计日志后置，一期由单据字段推导。
> - 二次确认弹窗正文在[弹窗 PRD](采购订单前端Demo版PRD_弹窗与Mock.md)维护，本文只写入口与结果表现。
> - **已审核+正常+全部收货**（S08/R12）：仅查看，无下推、取消、关闭、调整交期。
> - 主 PRD 规定承诺交期后T+2自然日自动关闭；Demo 不运行定时关单任务，详情仅展示样例数据中已有的关闭状态。
> - Demo 以**桌面端**为基准；商品明细、关联简表在窄视口内**横向滚动**，不承诺移动端布局（明细表 `min-width` 与工程内 `LineItemTable` 一致，约 1880px 量级）。

## 2. 页头

### 2.1 标题与状态

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `采购订单详情 · {单号}`（单号随记录展示） |
| 状态标签 | 三枚 StatusBadge：审核状态 / 业务状态 / 收货状态 |
| 布局 | 单行：左侧标题 + 状态标签；右侧操作区（`DocumentDetailFrame`） |

列表状态列用语义色文字；**详情页头用 StatusBadge 胶囊**，tone 与列表语义一致（见《原型开发说明》）。

### 2.2 页头操作按钮

`返回列表` **始终排在最前**；其后按状态展示业务按钮。编辑为草稿主按钮，由详情框架 `canEdit` 提供（与业务按钮分区展示，顺序以原型为准）。

| 按钮 | 草稿+正常 | 待审核+正常 | 已审核+正常（收货≠全部） | 已审核+正常+全部收货 | 已取消/已关闭 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 返回列表 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 编辑 | ✅ | ❌ | ❌ | ❌ | ❌ |
| 提交 | ✅ | ❌ | ❌ | ❌ | ❌ |
| 删除 | ✅ | ❌ | ❌ | ❌ | ❌ |
| 审核 | ❌ | ✅ | ❌ | ❌ | ❌ |
| 撤回 | ❌ | ✅ | ❌ | ❌ | ❌ |
| 取消 | ❌ | ✅ | 条件✅ | ❌ | ❌ |
| 下推通知单 | ❌ | ❌ | 条件✅ | ❌ | ❌ |
| 关闭 | ❌ | ❌ | 条件✅ | ❌ | ❌ |
| 调整交期 | ❌ | ❌ | 条件✅ | ❌ | ❌ |

条件说明（详见主 PRD）：

| 按钮 | 条件摘要 |
| :--- | :--- |
| 删除 | 草稿+正常，且无下游引用（R11） |
| 取消（已审核） | R09：无实际入库等；有执行中通知须先处理 |
| 下推通知单 | 有可下推数量（R07）；入口文案「下推通知单」 |
| 关闭 / 调整交期 | R12：收货状态≠全部收货；关闭另须满足 R10 |
| 取消与关闭 | 已审核+正常时可**同时出现**，按各自条件独立判断 |

已审核态按钮建议顺序（`返回列表` 之后）：下推通知单 → 取消 → 关闭 → 调整交期（与列表行内、骨架一致）。

**渲染纪律**：

- 条件不满足的按钮**直接不渲染**，不展示灰色 disabled 占位。
- 样式层级（与原型一致）：**提交、审核** 用主要按钮（`primary`）；**编辑** 为草稿主按钮；**删除、取消、关闭、撤回、调整交期、下推通知单** 用次要按钮（`outline`）；**返回列表** 为幽灵/次要样式，固定最左。

### 2.3 二次确认与弹窗

| 操作 | 弹窗 PRD | 确认后页面表现 |
| :--- | :--- | :--- |
| 提交 | §2 | 刷新为待审核；Toast「采购订单已提交」 |
| 审核 | §3.1 | 刷新为已审核；Toast「采购订单已审核」；可选 Mock 引导（§4） |
| 撤回 | §3.2 | 回到草稿；Toast「采购订单已撤回，请修改后重新提交」 |

| 删除 | 详情内确认 | 删除后返回列表 |

## 3. 信息分区与字段

> 只读 **6 列栅格**，标签在上、值在下；备注占 **3 列**。字段顺序与 TSV 分组一致。

**分区总览**：页头 → **3.1 单据信息** → **3.2 收货与交期** → **3.3 商品明细** → **3.4 关联单据**（已审核）→ **3.5 终止信息**（已关闭/已取消）→ **3.6 操作信息**

### 3.1 单据信息

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样 |
| 供应商 | Code-Name |
| 币别 | `{币别编码} {币别名称}`（如 `CNY 人民币`） |
| 价税合计 | 金额；千分位；可与币别符号同区展示（与原型一致） |
| 税额 | 同上 |
| 金额 | 不含税金额合计；同上 |
| 备注 | 占 3 列；长文本可换行 |

布局：第 1 行—单号、供应商、币别、价税合计、税额；第 2 行—金额；备注占后 3 列。

### 3.2 收货与交期

| 字段 | 展示说明 |
| :--- | :--- |
| 收货仓库 | 逻辑仓 Code-Name |
| 承诺交期 | 日期 |

占前两列，后 4 列留空。

### 3.3 商品明细

- 表格只读；**数量、单价、价税列右对齐**；横向滚动（`min-width` 见 `LineItemTable` `order` 变体）。
- 一期**不分页**，展示全部明细行。
- 不单独展示后台「商品」关联列；以**商品编码**列承载。
- 价税列顺序：**含税单价 → 税率 → 不含税单价 → 价税合计 → 税额 → 金额**（与全局价税字段命名一致）。

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 自动编号 |
| 商品编码 | 文本 |
| 商品条码 | 文本；多条码一期可用英文分号 `;` 拼接展示，无条码为 `-`（多条码命中规则仍以 TSV 为准） |
| 商品名称 | 文本 |
| 基本单位 | 文本 |
| 采购数量 | 整数 |
| 含税单价 | 千分位；4 位小数 |
| 税率 | 百分比，如 `13%` |
| 不含税单价 | 系统计算；4 位小数 |
| 价税合计 / 税额 / 金额 | 系统计算；2 位小数 |
| 累计入库数量 | 回写列 |
| 剩余入库数量 | 回写列 |
| 可下推数量 | 回写列 |
| 在途通知数量 | 回写列 |

**回写列显隐**：详情页一期**始终展示**上述四列（与原型 `viewColumns` 一致）；草稿、待审核时尚无执行数据，数值展示 **`0`**，不隐藏列。

**底部汇总行**（`DocumentSummaryBar`）：

| 汇总项 | 展示 |
| :--- | :--- |
| 首列 | 文案 `合计`（占行号列） |
| 采购数量合计 | 与「采购数量」列右对齐，整数 |
| 价税合计 / 税额 / 金额 | 与对应列右对齐；千分位、2 位小数；价税合计可加粗强调 |
| 样式 | 汇总行与表头列对齐分别展示，不用合并多列写成单行右对齐文案 |

### 3.4 关联单据

**展示条件**：审核状态 = **已审核**（含业务已取消/已关闭的已审核单，若有下游历史）。

组件：`RelatedDocumentsCard`；胶囊 Tab（`InnerTabs` `pill` 变体）；Tab 文案带数量，如 `采购收货通知单 (2)`。默认选中「采购收货通知单」。当前 Tab 无记录时展示空态文案。

| Tab | 列 | 排序 | 空态 |
| :--- | :--- | :--- | :--- |
| 采购收货通知单 | 单号、单据状态、通知数量、实收数量、缺收数量、创建时间 | 创建时间倒序 | 暂无关联的采购收货通知单 |
| 采购入库单 | 单号、来源采购收货通知单、审核状态、推送财务ERP状态、实际入库数量、价税合计、创建时间 | 创建时间倒序 | 暂无关联的采购入库单 |

空态仅提示暂无数据，不强制引导创建（下推通知单入口在页头）。单号可跳转对应详情。Tab 下表不重复展示与来源订单相同的供应商、仓库。规则见[《采购收货通知单主PRD》](../../采购收货通知单/采购收货通知单主PRD.md)、[《采购入库单主PRD》](../../采购入库单/采购入库单主PRD.md)。

### 3.5 终止信息

**展示条件**：业务状态 = **已关闭** 或 **已取消**。

| 业务状态 | 字段（占前 4 列） |
| :--- | :--- |
| 已关闭 | 关闭方式、关闭原因、关闭时间、关闭操作人 |
| 已取消 | 取消原因、取消时间、取消操作人 |

系统自动关闭时关闭原因留空，以关闭方式区分（主 PRD）。

### 3.6 操作信息

胶囊 Tab：**制单信息**（默认）/ **操作日志**。

| Tab | 内容 |
| :--- | :--- |
| 制单信息 | 创建人、创建时间、最后更新人、最后更新时间（6 列栅格） |
| 操作日志 | 表格：操作时间、操作人、操作类型、说明；按时间倒序；一期从创建、提交、审核、撤回、取消、关闭、调整交期等推导 |

不在新增/编辑页展示本分区。

## 4. 字段展示规范

通用规则见《原型开发说明》「列表列通用呈现规则」中与详情相关的条目；下表写本页差异。

| 规范 | 说明 |
| :--- | :--- |
| 空值 | 文本类统一英文连字符 `-`（`EMPTY_PLACEHOLDER`）；**禁止**用中文破折号 `—` 或留空白 |
| 名称展示 | 供应商、逻辑仓及商品名称使用本单保存的名称快照并按 Code-Name 展示；下游通知与入库结果继承来源快照；详情不实时读取主数据 |
| 币别 | 独立字段展示 `CNY 人民币`；明细金额列不重复币别前缀 |
| 金额 | 千分位；2 位小数；单价 4 位 |
| 数量 | 整数；`0` 按有效值展示 |
| 税率 | 百分比，如 `0%`、`13%` |
| 日期 | `YYYY-MM-DD` |
| 日期时间 | `YYYY-MM-DD HH:mm:ss` |
| 页头状态 | StatusBadge 胶囊，非列表语义色文字 |
| 关联简表 | 外框与表头样式见《原型开发说明》「详情内嵌简表」 |

## 5. 操作行为

| 操作 | 行为 |
| :--- | :--- |
| 编辑 | 跳转编辑页；返回后刷新详情 |
| 下推通知单 | 跳转收货通知单创建页并带入来源订单（非弹窗） |
| 提交 / 审核 / 撤回 / 取消 / 关闭 / 调整交期 / 删除 | 打开弹窗 PRD 对应弹窗 → 成功后刷新详情或返回列表 |
| 返回列表 | 回到列表，保留筛选、页码与列表上下文 |

## 6. 反馈与页面状态

### 6.1 操作反馈（Toast）

| 操作 | 反馈类型 | 文案 |
| :--- | :--- | :--- |
| 提交成功 | Toast | 采购订单已提交 |
| 审核成功 | Toast | 采购订单已审核 |
| 撤回成功 | Toast | 已撤回，请修改后重新提交 |
| 取消成功 | Toast | 采购订单已取消 |
| 关闭成功 | Toast | 采购订单已关闭 |
| 调整交期成功 | Toast | 承诺交期已更新 |
| 删除成功 | Toast | 采购订单已删除 |
| 取消/关闭失败（R09 等） | Toast | 如「存在执行中的收货通知，请先处理后再取消」 |
| 状态已变更（阻断） | Toast | 操作失败，单据状态已变更，请刷新后重试 |
| 并发/版本冲突（如有） | Toast | 操作失败，当前单据已被修改，请刷新后重试 |

Mock 审核后引导弹窗文案见弹窗 PRD §4。

### 6.2 加载与异常态

| 场景 | 页面表现 | 文案 / 操作 |
| :--- | :--- | :--- |
| 加载中 | 骨架屏；分区占位（页头、单据信息、明细表等） | — |
| 单据不存在 | 错误态 | 采购订单不存在或无权查看；提供「返回列表」 |
| 加载失败 | 错误态 | 加载失败，请重试；提供「重试」与「返回列表」 |
| 返回列表 | 跳转列表 | 恢复进入前的查询条件与页码；无历史筛选时回默认列表 |

## 7. Mock 与验收

### 7.1 Mock 覆盖清单

- **草稿+正常** 至少 1 单：页头三标签；可编辑/提交/删除；明细回写四列展示为 `0`；无关联单据、无终止信息
- **待审核+正常** 至少 1 单：审核/撤回/取消；无关联单据
- **已审核+正常+未收货/部分收货** 至少 1 单：明细含回写列；有关联单据 Tab；可下推/取消/关闭/调整交期（按条件）
- **已审核+正常+全部收货** 至少 1 单（S08）：页头仅返回列表；无下推、取消、关闭、调整交期
- **已关闭**、**已取消** 各至少 1 单：展示终止信息；页头仅返回列表
- 关联 Tab：至少 1 单含通知单与入库单记录；至少 1 个 Tab 为空态
- 制单信息至少 1 个字段为空 `-`（如未关闭单的关闭时间）
- 操作日志 Tab 有可展示记录

### 7.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 草稿详情 | 打开草稿单 | 三枚 StatusBadge；回写四列为 `0`；制单信息有创建人；无终止信息、无关联单据 |
| 已审核+部分收货 | 打开详情 | 明细回写列有值；价格数量只读；关联单据双 Tab |
| 关联跳转 | 点击通知单/入库单号 | 进入对应详情 |
| 全部收足 S08 | 打开详情 | 收货状态=全部收货；仅返回列表 |
| 已关闭 | 打开详情 | 终止信息展示关闭字段；无业务按钮 |
| 操作信息 | 切换 Tab | 默认制单信息；操作日志倒序只读 |
