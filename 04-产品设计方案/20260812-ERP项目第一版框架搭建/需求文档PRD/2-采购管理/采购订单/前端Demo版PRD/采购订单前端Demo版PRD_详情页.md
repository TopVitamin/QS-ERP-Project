## UI布局（与骨架、09原型一致）

| 区域 | 本页规则 |
| --- | --- |
| 页头 | 标题 + 三枚状态标签 + 业务操作按钮 + `[返回列表]` |
| 只读字段 | 6列栅格；标签在上、值在下；空值 `-` |

| 操作信息 | 页底胶囊 Tab：制单信息 / 操作日志；样式同关联单据 |
| 终止信息 | 条件展示；4字段占前4列 |

## 详情页

| 内容 | 设计 |
| --- | --- |
| 标题与入口 | 采购订单详情；列表点击单号进入 |
| 容器形式 | 独立页 |
| 区域顺序 | 页头状态标签 → 单据信息 → 收货与交期 → 商品明细 → 关联单据（已审核） → 终止信息（按状态） → 操作信息 |
| 返回/关闭 | 返回列表，保留原查询条件与页码 |

页头固定展示**审核状态、业务状态、收货状态**三个状态标签（与单据信息同属一区，不单开「状态信息」区块）。

| 分组 | 字段/明细列 | 显示形式 | 空值及长文本 | 关联跳转 |
| --- | --- | --- | --- | --- |
| 单据信息 | 单号、单据日期、供应商、币别、价税合计、税额、金额、备注 | 6列只读栅格，标签在上；备注占3列；供应商按 Code-Name 展示 | 空值 `-` | 无 |
| 收货与交期 | 收货仓库、承诺交期 | Code-Name 文字与日期 | 空值 `-` | 无 |
| 商品明细 | 行号、商品编码、商品条码、商品名称、基本单位、采购数量、含税单价、税率、不含税单价、价税合计、税额、金额、累计入库数量、剩余入库数量、可下推数量、在途通知数量 | 表格；不单独展示「商品」列 | 数值空显示 `0` | 无 |
| 关联单据 | 见下表两个 Tab | 分组标题「关联单据」；内嵌 Tab 切换，Tab 文案带数量，如「采购收货通知单 (2)」 | 当前 Tab 无记录时展示空态文案 | 单号可跳转对应详情 |
| 终止信息 | 已关闭：关闭方式、关闭原因、关闭时间、关闭操作人；已取消：取消原因、取消时间、取消操作人 | 文字 | 整组仅在业务状态=已关闭或已取消时展示 | 无 |
| 操作信息 | 胶囊 Tab 切换，默认「制单信息」 | 6列只读栅格 | 未发生留空 `-` | 无 |
| 制单信息（Tab） | 创建人、创建时间、最后更新人、最后更新时间 | 文字与日期时间 | — | 无 |
| 操作日志（Tab） | 操作时间、操作人、操作类型、说明 | 时间线表格；按操作时间倒序 | 一期从单据已有字段推导（创建、提交、审核、撤回、取消、关闭、调整交期等）；完整审计日志后置 | 无 |

**关联单据**（仅审核状态=已审核时展示；草稿、待审核不展示）：

交互：Tab 位于分组标题下方，采用圆角矩形胶囊样式（选中浅底 + 描边，无底部通栏分割线，避免与分组标题线叠成双线）；默认展示「采购收货通知单」Tab。列表页内 Tab 仍沿用下划线样式（见仓库资料列表）。

| Tab | 列 | 排序 | 空态 |
| --- | --- | --- | --- |
| 采购收货通知单 | 单号、单据状态、通知数量、实收数量、缺收数量、创建时间 | 创建时间倒序 | 暂无关联的采购收货通知单 |
| 采购入库单 | 单号、来源采购收货通知单、审核状态、金蝶推送状态、实际入库数量、价税合计、创建时间 | 创建时间倒序 | 暂无关联的采购入库单 |

Tab 下列从各自列表页精简，不重复展示与来源订单相同的供应商、仓库。通知单规则见[《采购收货通知单主PRD》](../../采购收货通知单/采购收货通知单主PRD.md)，入库单见[《采购入库单主PRD》](../../采购入库单/采购入库单主PRD.md)。

### 按钮与行操作

| 按钮文案 | 位置 | 可用条件及来源 | 点击行为 | 确认与反馈 |
| --- | --- | --- | --- | --- |
| 编辑 | 页头 | 审核状态=草稿（F02） | 进入编辑页 | 返回后刷新 |
| 提交 | 页头 | 草稿+正常（F03） | 打开提交确认弹窗 | 见弹窗PRD §一 |
| 下推通知单 | 页头 | 已审核+正常+有可下推量（F06） | 进入通知创建/Mock | 见弹窗PRD §三 |
| 审核 | 页头 | 待审核（F04） | 二次确认 | 提示已审核 |
| 撤回 | 页头 | 待审核（F04） | 撤回弹窗 | 必填撤回意见 |
| 删除 | 页头 | 草稿+正常（R11） | 二次确认 | 删除后返回列表 |
| 取消 | 页头 | 待审核+正常；或已审核+正常且满足R09 | 打开取消弹窗 | 见弹窗PRD §二 |
| 关闭 | 页头 | 已审核+正常且收货状态≠全部收货（F06/R12） | 关闭弹窗 | 必填关闭原因 |
| 调整交期 | 页头 | 已审核+正常且收货状态≠全部收货（F06/R12） | 调整交期弹窗 | 只改承诺交期 |
| 返回列表 | 页头 | 始终 | 返回列表 | 保留筛选 |

页头按钮集合须与[《采购订单主PRD》](../采购订单主PRD.md) §6.4 一致：草稿仅提交与删除；待审核为审核、撤回、取消；已审核态按钮顺序与列表相同（下推通知单、取消、关闭、调整交期，取消与关闭按条件可同时出现）。**已审核+正常+全部收货**（S08/R12）：页头仅保留「返回列表」，不显示下推、取消、关闭、调整交期。已取消、已关闭订单页头仅保留「返回列表」，不显示编辑、提交、下推、反关单。

## 页面状态与反馈文案

| 场景 | 触发条件 | 页面表现 | 显示文案 | 后续操作 |
| --- | --- | --- | --- | --- |
| 加载中 | 进入详情 | 骨架屏 | 加载中… | 等待 |
| 加载失败 | 单不存在 | 错误态 | 采购订单不存在或无权查看 | 返回列表 |
| 操作成功 | 交期/关闭/取消等 | 刷新详情 | 对应成功文案 | 查看更新后状态 |
| 终止信息隐藏 | 业务状态=正常 | 不展示终止信息分组 | — | — |

## 演示数据与验收

| 场景 | 示例条件 | 操作 | 预期页面结果 |
| --- | --- | --- | --- |
| 草稿详情 | 草稿单 | 打开详情 | 页头三标签；操作信息有创建人；无终止信息 |
| 已审核 | 已审核+部分收货 | 打开详情 | 明细显示累计入库、剩余入库、在途通知、可下推；数量价格只读；关联单据展示通知单与入库子表 |
| 关联单据 | 已审核+存在下游单 | 切换 Tab | Tab 带数量；单号可跳转；当前 Tab 无记录显示空态 |
| 全部收足 | 已审核+正常+全部收货 | 打开详情 | 页头三标签含全部收货；无下推、关闭、调整交期；仅返回列表 |
| 已关闭 | 手工关闭单 | 打开详情 | 展示终止信息关闭字段；无反关单按钮 |
| 已撤回 | 有撤回意见 | 打开详情 | 操作信息展示撤回意见 |
| 操作信息 | 任意单 | 切换 Tab | 制单信息默认展示；操作日志只读；不在新增编辑出现 |
