### 1.1 本模块不提供的弹窗

本期不提供以下弹窗：

| 弹窗 | 说明 |
| :--- | :--- |
| 重推金蝶确认框 | 金蝶推送失败后在**系统集成中心**针对原单重推（F08）；本模块列表/详情无重推按钮 |
| 提交 / 审核 / 撤回 | 入库单常规由系统自动生成并审核；无本模块人工建单页 |
| 取消 / 作废 | 已审核为终态，不可撤销 |

自动重试（正式环境）：推送明确失败后系统自动重试，**最多3次**；间隔由技术配置。3次仍失败则保持「推送失败」，到系统集成中心针对原单重推。

```
采购入库单列表 / 详情
         │
    用户查找重推入口
         │
         ▼
    本模块无重推按钮
         │
         ▼
  到系统集成中心办理（F08）
  须：已审核 + 金蝶推送状态=推送失败
```

## 2. Demo Mock：模拟回传自动生成（F09）

### 2.1 正式规则（必读）

正式环境中，采购收货通知单回传有实收并结束后，系统自动校验并生成**已审核**入库单，再触发金蝶推送。零收不生成入库单。**不提供无来源人工建单。** 已交给仓库、接口拿不到结果时，人工确认实际结果沿用 INT-FR06，入口不在本 Mock。

本节 Mock **仅用于 Demo 原型串联展示**，不属于 AC01～AC09 的正式验收项（主 PRD F09）。

### 2.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 收货通知详情 Mock 回传后 | 若实收>0，本地自动生成演示用采购入库单（已审核） |

```
收货通知详情
         │
    Mock 回传有实收
         │
         ▼
  实收合计 > 0？
         │
    ┌────┴────┐
   否         是
    │          │
    ▼          ▼
 不生成    尚无关联入库单？
 入库单         │
           ┌───┴───┐
          否       是
           │        │
           ▼        ▼
        阻断     §2.4 本地创建
        重复     已审核入库单
                   │
                   ▼
            金蝶推送状态=未推送
            Demo 可模拟推送进度
```

### 2.3 引导弹窗（可选）

若 Demo 需要显式确认，可使用以下弹窗；也可在通知 Mock 回传后直接生成，以实现为准。

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 模拟回传生成入库单（Demo） |
| 正文 | 按来源通知实收数量生成已审核入库单；生成后从未推送开始，由 Demo 模拟推送进度。 |
| 确认按钮 | 确认生成 |
| 取消按钮 | 取消 |
| 确认后 | 执行 §2.4 本地创建规则 |

### 2.4 生成规则（本地 Mock）

| 项目 | Mock 规则 |
| :--- | :--- |
| 生成条件 | 来源通知状态=已收货；实收合计>0；尚无关联入库单 |
| 单头 | 沿通知带入来源通知、来源订单、供应商、币别、入库仓库；业务日期=实际入库时间日期部分 |
| 明细 | 实际入库数量=通知实收；价税沿来源订单交易价格按入库数量计算 |
| 审核 | 创建即为已审核；审核人留空 |
| 金蝶 | 生成后从「未推送」开始，由 Demo 模拟推送进度；明确失败时可模拟自动重试 3 次 |
| 联动 | 更新来源采购订单累计入库、收货状态；库存 Mock 增加 |
| 单号 | 按 CGRK 编码规则生成 fictitious 编号 |

界面标注「演示数据」或「Mock」角标，与正式回传生成的入库单区分。

### 2.5 不做的事

- 不代替正式 WMS 回传与校验逻辑
- 不提供无来源人工建单页面
- 不把 Mock 推送当作金蝶正式验收
- 不在本模块演示系统集成中心重推

### 2.6 与收货通知 Mock 的关系

收货通知 Mock 回传见[《采购收货通知单前端Demo版PRD_弹窗与Mock》](../../采购收货通知单/前端Demo版PRD/采购收货通知单前端Demo版PRD_弹窗与Mock.md) §二。有实收结束后应继续生成本章演示入库单，串联采购主链。

## 3. 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| Mock 生成 | 已收货通知 Mock 回传有实收 | 自动生成已审核入库单；金蝶推送状态从未推送开始 |
| Mock 重复 | 同一通知再次生成 | 阻断，不重复 |
| 无重推弹窗 | 在入库单列表/详情查找重推 | 无重推按钮；无重推确认弹窗 |
| 推送失败展示 | 打开推送失败入库单详情 | 展示失败原因；重推须到系统集成中心 |

Demo 验证 Mock 本地数据联动；不代表生产接口、并发或后端事务行为。
