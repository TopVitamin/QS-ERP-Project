# 采购入库单前端Demo版PRD·新增/编辑页

> 用途：说明采购入库单本期页面范围。
> 版本：V0.2｜日期：2026-09-19｜状态：初稿，待评审。

## 本期结论

**本期不提供新增页、编辑页。**

采购入库单的唯一创建方式为：采购收货通知单推送到仓库 → 仓库回传实收并结束 → 系统自动生成已审核入库单。

用户侧只有**列表（F01）**和**详情（F04）**；金蝶推送失败时在列表/详情执行**重推金蝶（F08）**。

若原型中仍存在「新增采购入库单」「编辑」「确认入库」「作废」等页面或按钮，按[《采购入库单主PRD》](../采购入库单主PRD.md)移除或改造。
