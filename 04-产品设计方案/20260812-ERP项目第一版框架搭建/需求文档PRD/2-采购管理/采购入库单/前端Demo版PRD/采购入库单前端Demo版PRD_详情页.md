## 功能编号与主PRD对照

| 本页动作 | 功能编号 | 可用条件 |
| --- | --- | --- |
| 分区域只读展示 | F04 | 各状态 |
| 重推金蝶 | F08 | 已审核+推送失败 |
| Demo Mock | F09 | Demo |

本期详情页**不提供**编辑、提交、审核、撤回按钮。

## UI布局（与骨架、09原型一致）

| 区域 | 本页规则 |
| --- | --- |
| 页头 | 标题 + 审核状态标签 + 金蝶推送状态标签 + `[返回列表]`；推送失败时加 `[重推金蝶]` |
| 只读字段 | 6列栅格；标签在上、值在下；空值 `-` |
| 单据信息 | 单号、来源、仓库、币别、价税合计、税额、金额、业务日期、实际入库时间、推送时间、推送失败原因、备注 |
| 操作信息 | 页底6列栅格 |
| 商品明细 | 价税列顺序：含税单价、税率、不含税单价、价税合计、税额、金额 |

详见[《采购入库单页面骨架》](../采购入库单页面骨架.md)详情页 ASCII 图。

## 详情页

| 内容 | 设计 |
| --- | --- |
| 标题与入口 | 采购入库单详情；列表点击单号进入；收货通知详情可跳转 |
| 容器形式 | 独立页 |
| 区域顺序 | 页头双状态标签 → 单据信息 → 商品明细 → 操作信息 |
| 返回/关闭 | 返回列表，保留原查询条件与页码 |

| 分组 | 字段/明细列 | 显示形式 | 关联跳转 |
| --- | --- | --- | --- |
| 单据信息 | 单号、来源采购收货通知单、来源采购订单、供应商、入库仓库、币别、价税合计、税额、金额、业务日期、实际入库时间、推送时间、推送失败原因、备注 | 6列只读栅格；价税三字段按明细汇总；备注占3列 | 来源通知、来源订单可跳转 |
| 商品明细 | 行号、商品编码、商品条码、商品名称、基本单位、实际入库数量、含税单价、税率、不含税单价、价税合计、税额、金额 | 表格；价税字段沿用来源订单交易价格按入库数量计算 | 无 |
| 操作信息 | 胶囊 Tab：制单信息 / 操作日志 | 6列只读栅格 | — | 无 |
| 制单信息（Tab） | 创建人、创建时间、最后更新人、最后更新时间 | 文字与日期时间 | 无 |
| 操作日志（Tab） | 操作时间、操作人、操作类型、说明 | 时间线表格；按操作时间倒序 | 一期推导生成、自动审核、推送金蝶等记录 | 无 |

自动审核时审核人显示「—」或「系统」。

### 按钮

| 按钮文案 | 位置 | 可用条件 | 点击行为 |
| --- | --- | --- | --- |
| 重推金蝶 | 页头 | 已审核+推送失败（F08） | 打开重推确认弹窗 |
| 返回列表 | 页头 | 始终 | 返回列表 |

页头按钮须与主PRD §6.4 一致：推送失败时有重推，其余仅返回列表。

## 页面状态与反馈文案

| 场景 | 显示文案 |
| --- | --- |
| 加载失败 | 采购入库单不存在或无权查看 |
| 重推成功 | 已重新推送金蝶 |

## 演示数据与验收

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 正常详情 | 打开已审核单 | 整单只读；来源可跳转；双状态标签正确；单头与明细展示价税合计、税额、金额 |
| 推送失败 | 打开失败单 | 展示失败原因与重推按钮 |
| 无编辑 | 任意单 | 无编辑/提交/审核按钮 |
