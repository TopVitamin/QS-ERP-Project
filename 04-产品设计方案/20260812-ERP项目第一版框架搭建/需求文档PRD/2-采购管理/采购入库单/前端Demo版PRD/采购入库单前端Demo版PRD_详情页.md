> **更新时间**：2026-09-21
> **定位**：供 AI 生成采购入库单详情页前端原型。字段见[《采购入库单（详细稿）》](../../../../字段清单合集/采购相关/采购入库单（详细稿）.tsv)；业务规则见[《采购入库单主PRD》](../采购入库单主PRD.md)（§6.4、R05～R08、F04）。**本文件只写页面呈现，不重复字段含义与枚举。**
> **通用口径**：布局与详情页接线见[《UI布局公共说明》](../../../../../../05-常用模板/02-模块设计交付/UI布局公共说明.md)、[《原型开发说明》](../../../../../../09-产品原型/原型开发说明.md)（详情页标准接线、列表列通用规则中的 StatusBadge）；字段模板见[《6.强盛ERP的编码规则和通用字段规则》](../../../../../../01-全局背景信息/6.强盛ERP的编码规则和通用字段规则.md)。对象特例须有已确认依据；与全局规范冲突时，按根AGENTS.md核对后同步。

关联资料：[《采购入库单页面骨架》](../采购入库单页面骨架.md)、[《采购入库单前端Demo版PRD_弹窗与Mock》](采购入库单前端Demo版PRD_弹窗与Mock.md)。布局见骨架。

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 采购入库单详情页 |
| 入口 | 列表点击单号；收货通知详情跳转 |
| 页面目标 | 只读查看一张采购入库单全貌；追溯来源单据与推送结果 |
| 骨架结构 | 页头 → 单据信息 → 商品明细 → 操作信息 |

本页落地 **F04（分区域只读展示与追溯）**；状态—操作矩阵见主 PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头固定展示**审核状态、金蝶推送状态**两枚 **StatusBadge**（与单据信息分区并列，不单开「状态信息」卡片）。
> - 整单只读；**不提供**编辑、提交、审核、撤回、重推金蝶按钮。
> - 推送失败时展示失败原因；重推到**系统集成中心**办理（F08）。
> - 操作信息含**制单信息 / 操作日志**胶囊 Tab；完整审计日志后置，一期由单据字段推导。
> - Demo 以**桌面端**为基准；商品明细在窄视口内**横向滚动**，不承诺移动端布局。

## 2. 页头

### 2.1 标题与状态

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `采购入库单详情 · {单号}`（单号随记录展示） |
| 状态标签 | 两枚 StatusBadge：审核状态 / 金蝶推送状态 |
| 布局 | 单行：左侧标题 + 状态标签；右侧操作区（`DocumentDetailFrame`） |

列表状态列用语义色文字；**详情页头用 StatusBadge 胶囊**，tone 与列表语义一致（见《原型开发说明》）。

### 2.2 页头操作按钮

`返回列表` **始终排在最前**；本期无其他业务按钮。

| 按钮 | 已审核（任意推送状态） |
| :--- | :---: |
| 返回列表 | ✅ |

**渲染纪律**：

- 条件不满足的按钮**直接不渲染**，不展示灰色 disabled 占位。
- **返回列表** 为幽灵/次要样式，固定最左。

## 3. 信息分区与字段

> 只读 **6 列栅格**，标签在上、值在下；备注占 **3 列**。字段顺序与 TSV 分组一致。

**分区总览**：页头 → **3.1 单据信息** → **3.2 商品明细** → **3.3 操作信息**

### 3.1 单据信息

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样 |
| 来源采购收货通知单 | Code-Name；可跳转通知详情 |
| 来源采购订单 | Code-Name；可跳转订单详情 |
| 供应商 | Code-Name |
| 入库仓库 | 逻辑仓 Code-Name |
| 币别 | `{币别编码} {币别名称}`（如 `CNY 人民币`） |
| 价税合计 | 金额；千分位；可与币别符号同区展示（与原型一致） |
| 税额 | 同上 |
| 金额 | 不含税金额合计；同上 |
| 业务日期 | 日期；取实际入库时间的日期部分 |
| 实际入库时间 | 日期时间 |
| 推送时间 | 日期时间；未推送时 `-` |
| 推送失败原因 | 占 3 列；仅金蝶推送状态=推送失败时展示；长文本可换行 |
| 备注 | 占 3 列；长文本可换行 |

布局：第 1 行—单号、来源通知、来源订单、供应商、入库仓库、币别；第 2 行—价税合计、税额、金额、业务日期、实际入库时间、推送时间；第 3 行—推送失败原因（占 3 列，仅失败时）；第 4 行—备注（占 3 列）。

### 3.2 商品明细

- 表格只读；**数量、单价、价税列右对齐**；横向滚动。
- 一期**不分页**，展示全部明细行。
- 不单独展示后台「商品」关联列；以**商品编码**列承载。
- 价税列顺序：**含税单价 → 税率 → 不含税单价 → 价税合计 → 税额 → 金额**（与全局价税字段命名一致）。

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 自动编号 |
| 商品编码 | 文本 |
| 商品条码 | 文本；无条码为 `-` |
| 商品名称 | 文本 |
| 基本单位 | 文本 |
| 实际入库数量 | 整数 |
| 含税单价 | 千分位；4 位小数 |
| 税率 | 百分比，如 `13%` |
| 不含税单价 | 系统计算；4 位小数 |
| 价税合计 / 税额 / 金额 | 系统计算；2 位小数 |

**底部汇总行**（`DocumentSummaryBar`）：

| 汇总项 | 展示 |
| :--- | :--- |
| 首列 | 文案 `合计`（占行号列） |
| 实际入库数量合计 | 与「实际入库数量」列右对齐，整数 |
| 价税合计 / 税额 / 金额 | 与对应列右对齐；千分位、2 位小数；价税合计可加粗强调 |
| 样式 | 汇总行与表头列对齐分别展示，不用合并多列写成单行右对齐文案 |

### 3.3 操作信息

胶囊 Tab：**制单信息**（默认）/ **操作日志**。

| Tab | 内容 |
| :--- | :--- |
| 制单信息 | 审核人、审核时间、创建人、创建时间、最后更新人、最后更新时间（6 列栅格） |
| 操作日志 | 表格：操作时间、操作人、操作类型、说明；按时间倒序；一期从自动审核、推送金蝶等推导 |

人工审核时展示审核人姓名；自动审核时审核人留空。字段有无值见详细稿。

不在新增/编辑页展示本分区。

## 4. 字段展示规范

通用规则见《原型开发说明》「列表列通用呈现规则」中与详情相关的条目；下表写本页差异。

| 规范 | 说明 |
| :--- | :--- |
| 空值 | 文本类统一英文连字符 `-`（`EMPTY_PLACEHOLDER`）；**禁止**用中文破折号 `—` 或留空白 |
| 主数据 | Code-Name：`{编码} {名称}` |
| 币别 | 独立字段展示 `CNY 人民币`；明细金额列不重复币别前缀 |
| 金额 | 千分位；2 位小数；单价 4 位 |
| 数量 | 整数；`0` 按有效值展示 |
| 税率 | 百分比，如 `0%`、`13%` |
| 日期 | `YYYY-MM-DD` |
| 日期时间 | `YYYY-MM-DD HH:mm:ss` |
| 页头状态 | StatusBadge 胶囊，非列表语义色文字 |
| 推送失败原因 | 仅推送失败时展示；未失败时不渲染该行 |

## 5. 操作行为

| 操作 | 行为 |
| :--- | :--- |
| 返回列表 | 回到列表，保留筛选、页码与列表上下文 |
| 来源通知/订单跳转 | 点击来源单号进入对应详情 |

本期详情页无编辑、提交、审核、重推等业务操作。

## 6. 反馈与页面状态

### 6.1 操作反馈（Toast）

本页一期无业务操作 Toast。Mock 自动生成相关反馈见弹窗 PRD。

### 6.2 加载与异常态

| 场景 | 页面表现 | 文案 / 操作 |
| :--- | :--- | :--- |
| 加载中 | 骨架屏；分区占位（页头、单据信息、明细表等） | — |
| 单据不存在 | 错误态 | 采购入库单不存在或无权查看；提供「返回列表」 |
| 加载失败 | 错误态 | 加载失败，请重试；提供「重试」与「返回列表」 |
| 返回列表 | 跳转列表 | 恢复进入前的查询条件与页码；无历史筛选时回默认列表 |

## 7. Mock 与验收

### 7.1 Mock 覆盖清单

- **已审核+推送成功** 至少 1 单：双状态标签；来源可跳转；制单信息完整
- **已审核+推送失败** 至少 1 单：展示推送失败原因；无重推按钮
- **已审核+未推送/推送中** 各至少 1 单：验证双状态展示
- 商品明细至少 1 行；汇总行与单头价税一致
- 制单信息至少 1 个字段为空 `-`（如自动审核时审核人）
- 操作日志 Tab 有可展示记录（自动审核、推送金蝶等）

### 7.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 正常详情 | 打开已审核单 | 整单只读；来源可跳转；双状态标签正确；单头与明细展示价税合计、税额、金额 |
| 推送失败 | 打开失败单 | 展示推送失败原因；无重推按钮 |
| 无编辑 | 任意单 | 无编辑/提交/审核按钮；页头仅返回列表 |
| 操作信息 | 切换 Tab | 默认制单信息；操作日志倒序只读 |
| 来源跳转 | 点击来源通知/订单号 | 进入对应详情 |
