> **版本**：V0.1
> **更新时间**：2026-09-21
> **定位**：供 AI 生成销售出库单详情页前端原型。字段见[《销售出库单（详细稿）》](../../../../字段清单合集/销售相关/销售出库单（详细稿）.tsv)；业务规则见[《销售出库单主PRD》](../销售出库单主PRD.md)（§6.4、R05～R08、F04）。**本文件只写页面呈现，不重复字段含义与枚举。**

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 销售出库单详情页 |
| 入口 | 列表点击单号；发货通知详情关联单据 Tab 跳转 |
| 页面目标 | 只读查看一张出库单全貌；追溯来源单据与推送结果 |
| 骨架结构 | 页头 → 单据信息 → 商品明细 → 操作信息 |

本页落地 **F04（分区域只读展示与追溯）**；状态—操作矩阵见主 PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头固定展示**审核状态、金蝶推送状态**两枚 **StatusBadge**。
> - 整单只读；**不提供**编辑、提交、审核、撤回、重推金蝶按钮。
> - 推送失败时展示失败原因；重推到**系统集成中心**办理（F08）。
> - 操作信息含**制单信息 / 操作日志**胶囊 Tab。

## 3. 信息分区与字段

**分区总览**：页头 → **3.1 单据信息** → **3.2 商品明细** → **3.3 操作信息**

### 3.1 单据信息

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样 |
| 来源类型 | B2B发货通知／独立站订单／外部ToC |
| 来源销售发货通知单 | Code-Name；B2B可跳转通知详情；非B2B为 `—` |
| 来源销售订单 | Code-Name；可跳转订单详情；外部ToC可为 `—` |
| 外部原始订单 | 仅外部ToC路径展示；可跳转或展示来源单号 |
| 客户 | Code-Name |
| 出库仓库 | 逻辑仓 Code-Name |
| 币别 | `{币别编码} {币别名称}` |
| 价税合计 / 税额 / 金额 | 千分位；2 位小数 |
| 业务日期 | 日期 |
| 实际出库时间 | 日期时间 |
| 推送时间 | 日期时间；未推送时 `-` |
| 推送失败原因 | 占 3 列；仅金蝶推送状态=推送失败时展示 |
| 备注 | 占 3 列 |

布局：第 1 行—单号、来源类型、来源通知、来源订单、客户、出库仓库；第 2 行—币别、价税合计、税额、金额、业务日期、实际出库时间；第 3 行—推送时间、推送失败原因（占后 3 列，仅失败时）；第 4 行—备注（占 3 列）。外部原始订单在来源类型=外部ToC时插入单据信息区展示。

### 3.2 商品明细

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 自动编号 |
| 商品编码 | 文本 |
| 商品条码 | 文本；无条码为 `-` |
| 商品名称 | 文本 |
| 基本单位 | 文本 |
| 实际出库数量 | 整数 |
| 含税单价 | 4 位小数 |
| 税率 | 百分比 |
| 不含税单价 | 4 位小数 |
| 价税合计 / 税额 / 金额 | 2 位小数 |

**底部汇总行**：合计实际出库数量、价税合计、税额、金额，与对应列右对齐。

### 3.3 操作信息

胶囊 Tab：**制单信息** / **操作日志**。

**制单信息**：审核人、审核时间、创建人、创建时间、最后更新人、最后更新时间。

**操作日志** Tab：操作时间、操作人、操作类型、说明；按时间倒序；含自动审核、推送金蝶等记录。

## 4. 来源类型差异展示

| 来源类型 | 差异 |
| :--- | :--- |
| B2B发货通知 | 展示来源通知链接；价格沿销售订单 |
| 独立站订单 | 来源通知为 `—`；金额沿用Shopify |
| 外部ToC | 展示外部原始订单；金额沿用来源结果 |

---

## 5. Mock 数据要求

- 至少覆盖三类来源类型各 **1 单**
- 至少 **1 单** 金蝶推送失败，用于失败原因展示
- B2B单可与发货通知详情关联单据 Tab 互相跳转
