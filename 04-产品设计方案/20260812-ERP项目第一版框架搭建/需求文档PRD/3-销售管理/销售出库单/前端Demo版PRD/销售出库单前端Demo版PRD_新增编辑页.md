## 2. 本期结论

**本期不提供无来源新增页、已审核单的编辑页。**

销售出库单的常规创建方式为：

1. **B2B**：销售发货通知单推送到仓库 → 仓库回传实出并结束 → 系统自动生成已审核出库单；或通知选择虚拟出库并创建成功后自动生成；
2. **独立站**：独立站订单推送仓库 → 整单回传 → 系统自动生成已审核出库单；
3. **外部ToC**：聚水潭、领星等来源结果校验通过 → 系统自动生成已审核出库单。

已交给仓库、接口拿不到结果时，可人工确认实际结果（INT-FR06），入口在来源销售发货通知单或独立站订单详情页（2026-09-24调整），不是本模块无来源建单。形成的出库单走提交审核，不在本模块维护。

推送财务ERP失败时在**系统集成中心**重推原单（F08），不在列表/详情。

若原型中仍存在「新增销售出库单」「编辑」「确认出库」「作废」「重推财务ERP」等本模块按钮，按[《销售出库单主PRD》](../销售出库单主PRD.md)移除或改到系统集成中心。
