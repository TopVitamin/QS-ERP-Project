## 2. Demo Mock：模拟回传自动生成（F09）

### 2.1 正式规则（必读）

正式环境中，B2B销售发货通知单回传有实出并结束后，系统自动校验并生成**已审核**出库单，再触发推送财务ERP。零出不生成出库单。独立站、外部ToC按各自链路自动生成。**不提供无来源人工建单。**

本节 Mock **仅用于 Demo 原型串联展示**，不属于 AC01～AC12 的正式验收项（主 PRD F09）。

### 2.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 发货通知详情 Mock 回传后 | 若实出合计>0，本地自动生成演示用销售出库单（已审核） |

### 2.3 生成规则（本地 Mock）

| 项目 | 规则 |
| :--- | :--- |
| 来源类型 | B2B发货通知 |
| 来源 | 当前销售发货通知单及关联销售订单 |
| 审核状态 | 已审核 |
| 推送财务ERP状态 | 未推送（Demo 可配置数秒后模拟推送成功/失败） |
| 明细 | 按通知各行实出数量；价格沿销售订单 |
| 单号 | 按 XSCK 编码规则生成 fictitious 编号 |
| 库存与回写 | 订单累计实际出库增加；发货状态重算；可下推量按主PRD规则变化 |
| 标注 | 界面标注「演示数据」或「Mock」 |

### 2.4 不做的事

- 不代替正式仓库接口回传
- 不在 Mock 中自动完成真实推送财务ERP
- 不把 Mock 行为写入主 PRD 正式验收
