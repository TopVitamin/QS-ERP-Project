## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 销售订单新增 / 草稿编辑 |
| 页面目标 | 录入或修改草稿销售订单：向谁卖、卖什么、卖多少、价格与交期 |
| 适用状态 | 新增页建草稿；**仅审核状态=草稿**可进入编辑（含撤回后回到草稿） |
| 骨架结构 | 页头（标题 + 操作按钮）→ 单据信息 → 发货与交期 → 商品明细 |

> 操作按钮固定在**页头右侧**，不使用底部固定操作栏。待审核、已审核、已取消、已关闭不可进入本页；已审核后改交期走详情/列表弹窗。本页落地 **F02（保存）**、**F03（提交入口）**；状态—操作矩阵见主 PRD §6.4。

| 模式 | 入口 | 差异摘要 |
| :--- | :--- | :--- |
| **新增** | 列表「新增」 | 单号占位「保存后自动生成」；页头无状态标签 |
| **编辑** | 列表/详情「编辑」 | 单号只读；页头三枚 StatusBadge（审核/业务/发货） |

**本期边界**：页头 **取消 / 保存 / 提交**；无信用额度、业务员字段；操作信息、终止信息、关联单据不在本页；不做正式导入建单；**无单据日期字段**（待确认，见主 PRD Q01）。

## 3. 表单分区与字段

> 单头 **6 列栅格**，标签在上、控件在下；备注占 **3 列**。控件 `type` 对齐原型 `FormControl` / `LineItemTable`。主数据按 Code-Name（`{编码} {名称}`）展示。**placeholder** 指控件无值时的占位文案；只读/禁用填 `—`。

区域顺序：**单据信息 → 发货与交期 → 商品明细**（与 TSV 一致）。

### 3.1 单据信息

| 字段 | 控件 type | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 单号 | `disabled` | `保存后自动生成`（新增）/ `—`（编辑有值） | 编辑只读展示系统单号（R01） |
| 客户 | `select` | `请选择客户` | 审核通过且启用；变更清空明细价并默认带出币别（R02、R03） |
| 币别 | `select` | `请选择币别` | 选项如 `CNY 人民币`；变更清空明细价并重取（R03、R04） |
| 价税合计 | `disabled` | `—` | 明细汇总；千分位，带币别符号 |
| 税额 | `disabled` | `—` | 同上 |
| 金额 | `disabled` | `—` | 不含税金额合计；同上 |
| 备注 | `textarea` | `请输入备注` | 选填；`REMARK_500`；占 3 列 |

价税字段顺序：价税合计、税额、金额（金额与备注同一行，备注占后 3 列）。

### 3.2 发货与交期

| 字段 | 控件 type | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 发货仓库 | `select` | `请选择发货仓库` | 逻辑仓 Code-Name |
| 交期 | `date` | `请选择日期` | 必填 |

### 3.3 商品明细

独立表格区块，横向滚动。

#### 3.3.1 表格操作

| 操作 | 位置 | 说明 |
| :--- | :--- | :--- |
| 添加明细 | 工具条 | 打开 SKU 选择弹窗；确认后插入行 |
| 删除 | 行内 | 删除该行；至少保留一行 |

**明细区错误条**（工具条上方，可选实现）：仅用于「请至少添加一行有效商品明细」等**跨行**提示；修正后即时消除。单行字段问题优先用 Toast（与《原型开发说明》一致）。

#### 3.3.2 列定义

| 列名 | 可编辑 | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 行号 | 只读 | `—` | 从 1 起自动编号 |
| 商品编码 | 选品入口 | `请选择商品` | 行内或弹窗选 SKU；不按客户过滤（R04） |
| 商品条码 | 只读 | `—` | 随商品带出；无条码展示 `-` |
| 商品名称 | 只读 | `—` | 随商品带出 |
| 基本单位 | 只读 | `—` | 随商品带出 |
| 销售数量 | 可编辑 | `—` | `QTY_INT`；正整数 >0；录入禁止小数 |
| 含税单价 | 可编辑 | `—` | `PRICE_4`；≥0；展示千分位、录入不带 |
| 税率 | 可编辑 | `请选择` | `PCT_4`；Demo 下拉 0/6/9/13%；允许 0%；有值后展示如 `13%` |
| 不含税单价 | 只读 | `—` | 按 R05 实时计算 |
| 价税合计 | 只读 | `—` | 按 R05 实时计算 |
| 税额 | 只读 | `—` | 按 R05 实时计算 |
| 金额 | 只读 | `—` | 按 R05 实时计算 |
| 回写列 | 只读 | `—` | 仅编辑页且有数据时：累计实际出库、剩余发货、可下推、在途通知 |

#### 3.3.3 SKU 选择弹窗（本页配置）

| 配置项 | 本页取值 |
| :--- | :--- |
| 选品方式 | 支持搜索；可多选批量插入 |
| 商品范围 | 启用成品 SKU；**不按客户过滤**（R04） |
| 确认后写入 | 带出编码、条码、名称、单位；按客户+商品+币别带价，无价留空 |
| 更换商品 | 删除行后重新选品；行内编码列不直接手改 |

#### 3.3.4 底部汇总

| 汇总项 | 展示 |
| :--- | :--- |
| 销售数量合计 | 与「销售数量」列右对齐，整数 |
| 价税合计 / 税额 / 金额 | 与对应列右对齐；千分位、2 位小数；单头汇总区同步 |

## 4. 校验规则

提交相关弹窗见[弹窗 PRD §2](销售订单前端Demo版PRD_弹窗与Mock.md)。下文 **保存** 指点「保存」，**提交** 指点「提交」（含保存口径 + 加强项）。

### 4.1 校验分层总览

| 层级 | 本页行为 | 典型错误位置 |
| :--- | :--- | :--- |
| 录入限制 | 数量禁小数、备注 `maxLength`、金额禁负数等 | 阻止输入或即时提示 |
| 失焦 | 数量整数、单价小数位、备注长度（§4.2） | 字段下或 Toast；改值后**即时**清除该项错误 |
| 保存 | 单头必填 + 明细底线（§4.3）；**允许单价为空** | 单头内联；明细 Toast 或错误条 |
| 提交 | 在保存基础上补全价格与税率（§4.4）；零价二次确认 | 同上；通过后进确认弹窗 |
| 请求中 | 保存/提交按钮 loading；另一按钮 disabled | — |

### 4.2 录入与失焦

| 字段 | 模板 | 格式与范围 | 录入/失焦处理 | 典型提示 |
| :--- | :--- | :--- | :--- | :--- |
| 交期 | 日期 | 有效日期 | 日期选择器 | `交期不能为空` |
| 客户、发货仓库、币别 | 关联选择 | 须从选项选择 | 禁用项不可选 | `{字段名}不能为空` |
| 备注 | `REMARK_500` | 0～500 字 | 超限阻止输入；粘贴超长提示 | `备注已达 500 字上限` |
| 销售数量 | `QTY_INT` | 正整数 >0 | 禁小数点；失焦非整数视为未填 | `第 N 行销售数量须为正整数` |
| 含税单价 | `PRICE_4` | ≥0；最多 4 位小数 | 禁负数；超 4 位失焦四舍五入 | `第 N 行含税单价不能为负` |
| 税率 | `PCT_4` | 允许 0% | 下拉不可输非法值 | `第 N 行税率不能为空`（提交时） |
| 系统计算列 | — | 只读 | 不校验录入 | 见 §4.5 |

### 4.3 点击「保存」

| 校验对象 | 条件 | 错误位置 | 阻断 | 文案 |
| :--- | :--- | :--- | :---: | :--- |
| 客户、发货仓库、交期、币别 | 必填 | 字段下方 | 是 | `{字段名}不能为空` |
| 商品明细 | 至少一行有效明细 | Toast / 错误条 | 是 | `请至少添加一行有效商品明细` |
| 商品（每行） | 已选 | Toast | 是 | `第 N 行请选择商品` |
| 销售数量（每行） | 正整数 >0 | Toast | 是 | `第 N 行销售数量必须大于 0` |
| 含税单价（每行） | ≥0（可为空） | Toast | 是 | `含税单价不能为负数` |

通过后：仍为草稿+正常；Toast「销售订单已保存」；新增单首次保存生成单号。

### 4.4 点击「提交」

在 §4.3 全部通过基础上，追加：

| 校验对象 | 条件 | 错误位置 | 阻断 | 文案 |
| :--- | :--- | :--- | :---: | :--- |
| 含税单价（每行） | 非空 | Toast | 是 | `第 N 行含税单价不能为空` |
| 税率（每行） | 已选 | Toast | 是 | `第 N 行税率不能为空` |
| 含税单价 = 0 | 零价 | 确认框 | 确认后继续 | 见弹窗 PRD |
| 客户 | 仍启用 | Toast / 字段下 | 是 | `所选客户不可用` |

税率为 0% 允许提交，不额外确认。校验失败时聚焦首错（单头优先）；可用 Toast「请修正表单中的错误后再提交」作补充提示。

### 4.5 价税计算与汇总

依据 R05；明细变更**即时重算**。

| 计算项 | 公式 | 精度 |
| :--- | :--- | :--- |
| 行不含税单价 | 含税单价 ÷ (1 + 税率÷100)；税率 0 时等于含税单价 | 4 位 |
| 行价税合计 | 销售数量 × 含税单价 | 2 位 |
| 行金额 | 销售数量 × 行不含税单价 | 2 位 |
| 行税额 | 行价税合计 − 行金额 | 2 位；尾差进税额 |
| 单头三项汇总 | 汇总各行 | 2 位；展示带币别符号 |

### 4.6 错误展示与纠错

| 类型 | 表现 | 纠错 |
| :--- | :--- | :--- |
| 单头必填 | 红底线 + 字段下文案；标签不变红 | 修改该字段后清除 |
| 多字段错误 | 同时标出；聚焦首错 | 逐项清除 |
| 明细/全局 | Toast（含「第 N 行」） | 修正后清除对应提示 |
| 跨行（明细为空） | 错误条或 Toast | 补行后消除 |
| 取消离开 | 确认框 | `离开后未保存的内容将丢失，确认离开？` |

## 5. 联动规则

| 触发 | 效果 |
| :--- | :--- |
| 选客户 | 默认带出币别；清空明细含税单价与税率 |

## 6. 操作行为

| 操作 | 行为 |
| :--- | :--- |
| 保存 | 执行 §4.3；通过后写草稿并提示成功；新增首次保存生成单号；默认停留本页 |
| 提交 | 执行 §4.4 → 零价确认（如有）→ 提交确认弹窗；成功后变待审核并提示成功 |
| 取消 | 有未保存修改则确认；确认后回列表 |
| 编辑页进入 | 加载中展示占位；失败展示「销售订单不存在或无权查看」；非草稿不可进入 |

## 10. Mock 与验收

### 10.1 Mock 覆盖

- 可保存草稿：客户有默认币别、一行 SKU、数量 100
- 编辑用草稿：2 行明细 + 回写列 + 状态标签
- 零价明细：验证提交二次确认
- 待审核单：验证不可进入编辑页

### 10.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 正常建单 | 新增 → 保存 | 草稿/正常/未发货；单号已生成 |
| 币别联动 | 选客户 | 默认币别带出 |
| 改客户/币别 | 已有明细后更换 | 明细价格清空 |
| 无价保存 / 无价提交 | 明细无单价 | 保存成功；提交阻断 |
| 零价提交 | 单价为 0 | 零价确认 → 提交确认弹窗 |
| 数量小数 / 单价超 4 位 / 备注超长 | 见 §4.2 | 录入约束或保存/提交阻断 |
| 不可编辑 | 待审核单点编辑 | 不进入本页 |
