## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 销售发货通知单详情页 |
| 入口 | 列表点击单号；销售订单详情关联单据 Tab 点击单号；操作完成后可刷新本页 |
| 页面目标 | 只读查看一张通知单全貌；按当前状态办理允许的操作 |
| 骨架结构 | 页头 → 单据信息 → 发货与物流 → 商品明细 → 关联单据（条件）→ 终止信息（条件）→ 操作信息 |

本页落地 **F04（分区域展示与追溯）** 及详情侧 **F03/F05/F06/F07/F08** 操作入口；状态—操作矩阵见主 PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头固定展示**单据状态**一枚 **StatusBadge**（与单据信息分区并列，不单开「状态信息」卡片）。
> - **关联单据**仅**单据状态=已发货**时展示；未发货不展示下游 Tab。
> - 终止信息仅在**单据状态=已取消**时展示；非已取消不展示该分组。
> - 操作信息含**制单信息 / 操作日志**胶囊 Tab；完整审计日志后置，一期由单据字段推导。
> - 二次确认弹窗正文在[弹窗 PRD](销售发货通知单前端Demo版PRD_弹窗与Mock.md)维护，本文只写入口与结果表现。
> - Demo 以**桌面端**为基准；商品明细、关联简表在窄视口内**横向滚动**。

## 2. 页头

### 2.1 标题与状态

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `销售发货通知单详情 · {单号}`（单号随记录展示） |
| 状态标签 | 一枚 StatusBadge：单据状态 |
| 布局 | 单行：左侧标题 + 状态标签；右侧操作区（`DocumentDetailFrame`） |

列表状态列用语义色文字；**详情页头用 StatusBadge 胶囊**，tone 与列表语义一致（见《原型开发说明》）。

### 2.2 页头操作按钮

`返回列表` **始终排在最前**；其后按状态展示业务按钮。

| 按钮 | 待推送 | 推送中 | 推送失败 | 待发货 | 取消中 | 已发货 | 已取消 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 返回列表 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 编辑 | ✅ | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ |
| 取消 | ✅ | ❌ | ✅ | ✅ | ❌ | ❌ | ❌ |
| 重试推送 | ❌ | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ |
| 模拟仓库回传 | ❌ | ❌ | ❌ | ✅（Demo） | ❌ | ❌ | ❌ |

条件说明（详见主 PRD）：

| 按钮 | 条件摘要 |
| :--- | :--- |
| 编辑 | 待推送、推送失败（F03/R12） |
| 取消 | 待推送、推送失败（F05/R09）；待发货进入取消中（F06/R10） |
| 重试推送 | 推送失败（F07）；正式环境须已自动重试满3次仍失败 |
| 模拟仓库回传 | Demo 且待发货等（F08） |

各状态按钮建议顺序（`返回列表` 之后）：

- 待推送：编辑 → 取消
- 推送失败：编辑 → 重试推送 → 取消
- 待发货：取消 → 模拟仓库回传（Demo）

**渲染纪律**：

- 条件不满足的按钮**直接不渲染**，不展示灰色 disabled 占位。
- 样式层级：**编辑** 为待推送/推送失败主按钮；**取消、重试推送** 用次要按钮（`outline`）；**返回列表** 为幽灵/次要样式，固定最左。

### 2.3 二次确认与弹窗

| 操作 | 弹窗 PRD | 确认后页面表现 |
| :--- | :--- | :--- |
| 取消 | §2、§3 | 刷新详情；Toast「销售发货通知单已取消」或「已发起取消，等待仓库回执」 |
| 重试推送 | §4 | 刷新为推送中；Toast「已重新推送仓库」 |
| 模拟仓库回传 | §5 | 刷新详情；按回传结果更新状态与数量 |

弹窗标题、正文、必填项不在本文重复。

## 3. 信息分区与字段

> 只读 **6 列栅格**，标签在上、值在下；备注占 **3 列**。字段顺序与 TSV 分组一致。

**分区总览**：页头 → **3.1 单据信息** → **3.2 发货与物流** → **3.3 商品明细** → **3.4 关联单据**（已发货）→ **3.5 终止信息**（已取消）→ **3.6 操作信息**

### 3.1 单据信息

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样 |
| 来源销售订单 | Code-Name；可跳转销售订单详情 |
| 客户 | Code-Name |
| 发货仓库 | 逻辑仓 Code-Name |
| 发货处理方式 | 仓库发货／虚拟出库 |
| 推送时间 | 日期时间；未推送或虚拟出库时为 `-` |
| 最终发货确认时间 | 日期时间；未确认时为 `-` |
| 推送失败原因 | 有值时占 3 列；未失败时整行不展示 |
| 备注 | 占 3 列；长文本可换行 |

布局：第 1 行—单号、来源销售订单、客户、发货仓库、发货处理方式、推送时间；第 2 行—最终发货确认时间、推送失败原因（占后 3 列，有值时）；第 3 行—备注占 3 列。单据状态仅在页头 StatusBadge 展示。

### 3.2 发货与物流

| 字段 | 展示说明 |
| :--- | :--- |
| 发货方式 | 物流配送／自提 |
| 发货地址 | 自提时为 `-`；物流配送时展示完整地址文本（省市区+详细地址） |
| 物流服务产品 | 自提时为 `-`；物流配送时 Code-Name 或「由仓库指定」 |
| 运单号 | 未回传为 `-` |

布局：一行 4 字段 + 后 2 列留空。

### 3.3 商品明细

- 表格只读；**数量列右对齐**；横向滚动。
- 一期**不分页**，展示全部明细行。
- 不单独展示后台「商品」关联列；以**商品编码**列承载。

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 自动编号 |
| 商品编码 | 文本 |
| 商品条码 | 文本；多条码一期可用英文分号 `;` 拼接展示，无条码为 `-` |
| 商品名称 | 文本 |
| 基本单位 | 文本 |
| 通知数量 | 整数 |
| 实出数量 | 整数；未回传为 `0` |
| 缺出数量 | 整数；未结束为 `0` |

**底部汇总行**（`DocumentSummaryBar`）：

| 汇总项 | 展示 |
| :--- | :--- |
| 首列 | 文案 `合计`（占行号列） |
| 通知数量合计 | 与「通知数量」列右对齐，整数 |
| 实出数量合计 | 与「实出数量」列右对齐，整数 |
| 缺出数量合计 | 与「缺出数量」列右对齐，整数 |

### 3.4 关联单据

**展示条件**：单据状态 = **已发货**。

组件：`RelatedDocumentsCard`；胶囊 Tab（`InnerTabs` `pill` 变体）；Tab 文案带数量，如 `销售出库单 (1)`。

| Tab | 列 | 排序 | 空态 |
| :--- | :--- | :--- | :--- |
| 销售出库单 | 单号、审核状态、金蝶推送状态、实际出库数量、价税合计、实际出库时间 | 创建时间倒序 | 暂无关联的销售出库单 |

单号列可点击跳转[销售出库单详情](../../销售出库单/前端Demo版PRD/销售出库单前端Demo版PRD_详情页.md)。

### 3.5 终止信息

**展示条件**：单据状态 = **已取消**。

| 字段 | 展示说明 |
| :--- | :--- |
| 取消原因 | 文本 |
| 取消时间 | 日期时间 |
| 取消操作人 | 用户姓名 |

### 3.6 操作信息

胶囊 Tab：**制单信息** / **操作日志**。

**制单信息**（6 列栅格）：

| 字段 | 展示说明 |
| :--- | :--- |
| 创建人 | 用户姓名 |
| 创建时间 | 日期时间 |
| 最后更新人 | 用户姓名 |
| 最后更新时间 | 日期时间 |

**操作日志** Tab（一期简表）：

| 列 | 说明 |
| :--- | :--- |
| 操作时间 | 日期时间，倒序 |
| 操作人 | 用户姓名 |
| 操作类型 | 如创建、取消、重试推送、仓库回传 |
| 说明 | 摘要文案 |

完整审计日志后置；一期可由状态变化与终止信息推导演示数据。

## 4. 状态差异展示

| 状态 | 页面差异 |
| :--- | :--- |
| 待推送/推送失败 | 实出、缺出均为 0；无关联单据；可编辑备注 |
| 推送中/取消中 | 仅查看；页头无业务按钮（除返回列表） |
| 待发货 | 实出、缺出为 0；可取消；Demo 可模拟回传 |
| 已发货 | 展示实出、缺出；展示关联出库单 Tab |
| 已取消 | 展示终止信息；实出可能为 0（零出取消） |
