## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 销售发货通知单下推创建 / 编辑备注 |
| 页面目标 | 从销售订单下推创建通知单，或修改待推送/推送失败通知单的备注 |
| 适用状态 | 下推创建：来源订单已审核+正常+有可下推量；编辑备注：待推送、推送失败 |
| 骨架结构 | 页头（标题 + 操作按钮）→ 单据信息 → 发货与物流 → 商品明细 |

> 操作按钮固定在**页头右侧**，不使用底部固定操作栏。推送中、待发货、取消中、已发货、已取消不可进入编辑页。本页落地 **F02（下推创建）**、**F03（编辑备注）**；状态—操作矩阵见主 PRD §6.4。

| 模式 | 入口 | 差异摘要 |
| :--- | :--- | :--- |
| **下推创建** | 销售订单列表/详情「下推通知单」 | 单号占位「保存后自动生成」；页头无状态标签；可编辑通知数量、发货处理方式、备注；发货方式/地址/物流默认继承订单并可覆盖 |
| **编辑备注** | 列表/详情「编辑」 | 单号只读；页头 StatusBadge 展示单据状态；仅备注可改 |

**本期边界**：页头 **取消 / 保存并创建** 或 **取消 / 保存**；无保存草稿——仓库发货时创建即进入待推送并触发推送；虚拟出库时创建即已发货并生成出库单；操作信息、终止信息、推送时间等系统字段不在本页。

## 2. 页头

| 元素 | 规格 |
| :--- | :--- |
| 标题（下推创建） | `创建销售发货通知单` |
| 标题（编辑备注） | `编辑销售发货通知单`；单号在标题或表单区只读展示 |
| 状态标签 | 下推创建不展示；编辑备注展示一枚 StatusBadge（单据状态） |
| 操作区（下推创建） | 从左到右：`取消` → `保存并创建` |
| 操作区（编辑备注） | 从左到右：`取消` → `保存` |

| 按钮 | 说明 |
| :--- | :--- |
| 取消 | 返回上一页；有未保存修改时二次确认（弹窗 PRD §5） |
| 保存并创建 | 通过 §4.3 校验后创建通知单 |
| 保存 | 通过 §4.4 校验后更新备注 |

保存/创建时当前按钮 loading，另一操作按钮同步 disabled，防重复点击；失败保留已填内容。

## 3. 表单分区与字段

> 单头 **6 列栅格**，标签在上、控件在下；备注占 **3 列**。控件 `type` 对齐原型 `FormControl` / `LineItemTable`。主数据按 Code-Name（`{编码} {名称}`）展示。**placeholder** 指控件无值时的占位文案；只读/禁用填 `—`。

区域顺序：**单据信息 → 发货与物流 → 商品明细**（与 TSV 一致）。

### 3.1 单据信息

| 字段 | 控件 type | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 单号 | `disabled` | `保存后自动生成`（下推创建）/ `—`（编辑有值） | 编辑只读展示系统单号（R01） |
| 来源销售订单 | `disabled` | `—` | 带入来源订单 Code-Name；不可改（R02） |
| 客户 | `disabled` | `—` | 沿用来源订单客户 Code-Name |
| 发货仓库 | `disabled` | `—` | 沿用订单发货仓库 Code-Name |
| 发货处理方式 | `select` | `请选择` | 仓库发货／虚拟出库；默认仓库发货；保存后不可改（R13） |
| 备注 | `textarea` | `请输入备注` | 选填；占 3 列 |

下推创建页页头**不展示状态标签**——通知单尚未保存，没有可展示的状态。

### 3.2 发货与物流

| 字段 | 控件 type | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 发货方式 | `select` | `请选择` | 默认继承来源销售订单；物流配送／自提；保存后不可改（R15） |
| 发货地址 | `select` | `请选择客户地址` | 来源客户地址明细；默认继承订单约定地址；物流配送时必填；自提时隐藏；分批发货时可改选 |
| 物流服务产品 | `select` | `请选择物流服务产品` | 默认继承订单；启用的物流服务产品 + 「由仓库指定」；物流配送时必填；自提时隐藏 |

**发货方式联动**：

| 发货方式 | 发货地址 | 物流服务产品 |
| :--- | :--- | :--- |
| 物流配送 | 显示且必填 | 显示且必填（产品或「由仓库指定」） |
| 自提 | 隐藏，不校验 | 隐藏，不校验 |

地址下拉选项展示格式：`{省市区} {详细地址}`；默认选中来源订单约定地址；覆盖时仍从客户地址明细选择。订单为自提时继承自提，地址与物流控件隐藏。

物流下拉只列**启用**的物流服务产品；末尾固定「由仓库指定」选项（非档案记录）；默认选中来源订单物流服务产品。

编辑备注页本分区全部只读。

### 3.3 商品明细

独立表格区块，横向滚动。

#### 3.3.1 表格操作

下推创建页展示来源订单全部可下推行（可下推量>0）；可下推量为 0 的行隐藏。编辑备注页明细全部只读，无添加/删除。

#### 3.3.2 列定义

| 列名 | 可编辑 | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 行号 | 只读 | `—` | 从 1 起自动编号 |
| 商品编码 | 只读 | `—` | 沿用来源订单行 |
| 商品条码 | 只读 | `—` | 沿用来源订单行；无条码展示 `-` |
| 商品名称 | 只读 | `—` | 沿用来源订单行 |
| 基本单位 | 只读 | `—` | 随商品带出 |
| 可下推数量 | 只读 | `—` | 来源订单行当前可下推量；**仅下推创建页展示**；非 TSV 独立字段 |
| 通知数量 | 下推创建可编辑 | `—` | `QTY_INT`；正整数 >0；≤可下推数量；默认=可下推数量（R03）；创建后只读 |

编辑备注页不展示「可下推数量」列；通知数量只读。

#### 3.3.3 底部汇总

| 汇总项 | 展示 |
| :--- | :--- |
| 通知数量合计 | 与「通知数量」列右对齐，整数 |

## 4. 校验规则

弹窗见[弹窗 PRD](销售发货通知单前端Demo版PRD_弹窗与Mock.md)。下文 **保存并创建** 指点「保存并创建」，**保存** 指点编辑备注页的「保存」。

### 4.1 校验分层总览

| 层级 | 本页行为 | 典型错误位置 |
| :--- | :--- | :--- |
| 录入限制 | 通知数量禁小数等 | 阻止输入或即时提示 |
| 失焦 | 数量整数校验（§4.2） | 字段下或 Toast；改值后**即时**清除该项错误 |
| 保存并创建 | 下推创建全量校验（§4.3） | 单头内联；明细 Toast 或错误条 |
| 保存（编辑备注） | 备注长度（§4.4） | 字段下 |
| 请求中 | 按钮 loading；另一按钮 disabled | — |

### 4.2 录入与失焦

| 字段 | 模板 | 格式与范围 | 录入/失焦处理 | 典型提示 |
| :--- | :--- | :--- | :--- | :--- |
| 发货处理方式 | 枚举 | 仓库发货／虚拟出库 | 下拉选择 | `发货处理方式不能为空` |
| 发货方式 | 枚举 | 物流配送／自提 | 下拉选择 | `发货方式不能为空` |
| 发货地址 | 关联选择 | 客户地址明细 | 物流配送时必选 | `请选择发货地址` |
| 物流服务产品 | 关联选择 | 启用产品或「由仓库指定」 | 物流配送时必选 | `请选择物流服务产品或由仓库指定` |
| 备注 | `REMARK_500` | 0～500 字 | 超限阻止输入 | `备注已达 500 字上限` |
| 通知数量 | `QTY_INT` | 正整数 >0 | 禁小数点；失焦非整数视为未填 | `第 N 行通知数量须为正整数` |

### 4.3 点击「保存并创建」

**入口校验**：来源订单须为已审核+正常+至少一行可下推量>0；否则阻断并提示「当前销售订单不可下推发货通知」。

| 校验对象 | 条件 | 错误位置 | 阻断 | 文案 |
| :--- | :--- | :--- | :---: | :--- |
| 发货处理方式 | 必填 | 字段下方 | 是 | `发货处理方式不能为空` |
| 发货方式 | 必填 | 字段下方 | 是 | `发货方式不能为空` |
| 发货地址 | 发货方式=物流配送时必填 | 字段下方 | 是 | `请选择发货地址` |
| 物流服务产品 | 发货方式=物流配送时必填 | 字段下方 | 是 | `请选择物流服务产品或由仓库指定` |
| 商品明细 | 至少一行通知数量>0 | Toast / 错误条 | 是 | `请至少填写一行通知数量` |
| 通知数量（每行） | 正整数 >0 | Toast | 是 | `第 N 行通知数量必须大于 0` |
| 通知数量（每行） | ≤可下推数量 | Toast | 是 | `第 N 行通知数量不能超过可下推数量{可下推量}` |

通过后：

- **仓库发货**：创建通知、分配单号、占用订单额度；状态→待推送并触发自动推送（R05）；Toast「销售发货通知单已创建」；跳转详情或返回订单。
- **虚拟出库**：创建通知；状态→已发货；各行实出=通知数量、缺出=0；生成已审核销售出库单（R13）；Toast「销售发货通知单已创建」；跳转详情或返回订单。

### 4.4 点击「保存」（编辑备注）

| 校验对象 | 条件 | 错误位置 | 阻断 | 文案 |
| :--- | :--- | :--- | :---: | :--- |
| 备注 | 0～500 字 | 字段下方 | 是 | `备注已达 500 字上限` |

通过后：更新备注与操作信息；Toast「销售发货通知单已保存」；返回详情。

### 4.5 并发与额度变化

| 场景 | 页面表现 | 文案 |
| :--- | :--- | :--- |
| 保存并创建时订单可下推量已变化 | 阻断创建 | `第 N 行通知数量不能超过可下推数量{最新可下推量}` |
| 保存并创建时订单已关闭/已取消 | 阻断创建 | `当前销售订单不可下推发货通知` |
| 虚拟出库生成出库单失败 | 整笔回滚，停留本页 | `创建失败，请稍后重试` |

## 5. 页面跳转

| 场景 | 目标 |
| :--- | :--- |
| 下推创建成功 | 默认跳转新建通知单详情；也可配置返回来源销售订单详情 |
| 编辑备注成功 | 返回通知单详情 |
| 取消（无未保存修改） | 返回上一页（列表或详情或来源订单） |
| 取消（有未保存修改） | 二次确认后返回 |

## 6. Mock 数据要求

- 下推创建入口须关联至少 **1 张** 已审核+正常+有可下推量且已维护发货方式/地址/物流（物流配送时）的销售订单 Mock 数据
- 来源客户至少 **2 条** 地址（含 1 条默认且与订单约定地址一致），用于验证继承与覆盖
- 物流服务产品 Mock 至少 **2 条** 启用记录 + 「由仓库指定」选项
- 明细至少 **2 行** SKU，其中 1 行可下推量 < 订单销售数量，用于验证默认带出与上限校验
