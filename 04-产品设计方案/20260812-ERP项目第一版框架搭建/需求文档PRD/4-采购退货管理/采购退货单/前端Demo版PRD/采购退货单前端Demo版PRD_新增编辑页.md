## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 采购退货单新增 / 草稿编辑 |
| 页面目标 | 录入或修改草稿退货单：退给谁、退什么、从哪个仓出、退多少、退到什么时候 |
| 适用状态 | 新增页建草稿；**仅审核状态=草稿**可进入编辑（含撤回后回到草稿） |
| 骨架结构 | 页头（标题 + 操作按钮）→ 单据信息 → 商品明细 |

> 操作按钮固定在**页头右侧**，不使用底部固定操作栏。待审核、已审核、已取消、已关闭不可进入本页；已审核后改退货截止日期走详情/列表弹窗。本页落地 **F02（保存）**、**F03（提交入口）**；状态—操作矩阵见主PRD §6.4。

| 模式 | 入口 | 差异摘要 |
| :--- | :--- | :--- |
| **新增** | 列表「新增」 | 单号占位「保存后自动生成」；页头无状态标签；明细无累计实出数量列 |
| **编辑** | 列表/详情「编辑」 | 单号只读；页头两枚StatusBadge（审核/业务）；明细增列累计实出数量 |

**本期边界**：页头 **取消 / 保存 / 提交**；发货处理方式在采退发货通知单上维护，本页无该字段；本页无导入入口（导入在列表页头，见列表页 §7）；操作信息、终止信息、关联单据不在本页。

| 元素 | 规格 |
| :--- | :--- |
| 标题（新增） | `新增采购退货单` |
| 标题（编辑） | `编辑采购退货单`；单号在表单区只读展示 |

## 3. 表单分区与字段

> 单头 **6列栅格**，标签在上、控件在下；备注占 **3列**。控件 `type` 对齐原型 `FormControl` / `LineItemTable`。主数据按Code-Name（`{编码} {名称}`）展示。**placeholder** 指控件无值时的占位文案；只读/禁用填 `—`。

区域顺序：**单据信息 → 商品明细**（与TSV一致）。

### 3.1 单据信息

| 字段 | 控件type | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 单号 | `disabled` | `保存后自动生成`（新增）/ `—`（编辑有值） | 编辑只读展示系统单号，前缀CGTH（R01） |
| 来源采购入库单 | `select` | `请选择来源采购入库单（可选）` | 先选来源再带出；留空即无来源建单；选择后带出供应商、币别与明细，清空用字段右侧清除按钮（R03、R04） |
| 供应商 | `select` | `请选择供应商` | 审核通过且启用；一张退货单一个供应商（R02）；**有来源时由来源带出并只读**，无来源时自行选择 |
| 币别 | `select` | `请选择币别` | 选项如 `CNY 人民币`；取自辅助资料币别字典；**有来源时由来源带出并只读**；本单价格税率按PRI-FR07锁定规则处理 |
| 价税合计 | `disabled` | `—` | 明细汇总；千分位，带币别符号 |
| 税额 | `disabled` | `—` | 同上 |
| 金额 | `disabled` | `—` | 不含税金额合计；同上 |
| 出库仓库 | `select` | `请选择出库仓库` | 审核通过且启用的逻辑仓；一张单一个；**不随来源带出**，可自行选择；审核后不可改（R02、R09） |
| 退货截止日期 | `date` | `请选择日期` | 必填；到期未退部分在此日期过后T+2自然日自动关闭（R12）；审核后仅可调整本字段（R09） |
| 备注 | `textarea` | `请输入备注` | 选填；`REMARK_500`；占3列 |

栅格排布见骨架：单据信息10个字段（备注占3列）分三行；第三行为备注，占第1～3列。来源采购入库单排在第1行第2列，先选来源再带出供应商与币别（2026-09-23确认）。

### 3.2 商品明细

独立表格区块，横向滚动。

#### 3.2.1 表格操作

| 操作 | 位置 | 说明 |
| :--- | :--- | :--- |
| 添加明细 | 工具条 | 打开SKU选择弹窗；确认后插入行 |
| 取当前价 | 行内 | 按当前采购价目填入该行含税单价与税率（一并带入）；无价时Toast提示（R04、PUR-FR04） |
| 删除 | 行内 | 删除该行；至少保留一行 |

有来源时明细默认由原入库带出；「添加明细」用于无来源建单或补充行，补充的行「来源入库单行」留空，数量按无来源口径校验（每行>0）。

**明细区错误条**（工具条上方，可选实现）：仅用于「请至少添加一行有效商品明细」等**跨行**提示；修正后即时消除。单行字段问题优先用Toast（与《原型开发说明》一致）。

#### 3.2.2 列定义

| 列名 | 可编辑 | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 行号 | 只读 | `—` | 从1起自动编号 |
| 商品 | 选品入口 | `请选择商品` | 确认后按TSV「明细展示商品名称」显示；有来源时由原入库明细带出 |
| 基本单位 | 只读 | `—` | 随商品带出，与商品名称一起展示 |
| 来源入库单行 | 只读 | `—` | 有来源带出，如 `CGRK-20260910-0001 行1`；无来源留空 |
| 退货数量 | 可编辑 | `—` | `QTY_INT`；正整数 >0；有来源时改小且不超该行剩余可退额度（R03） |
| 含税单价 | 可编辑 | `—` | `PRICE_4`；≥0；有来源带出原入库含税价；草稿可改、提交后锁定；展示千分位、录入不带 |
| 税率 | 可编辑 | `请输入税率` | `PCT_4`；百分比数值输入，允许0%，最多2位小数；有来源时随原入库价格带出；取当前采购价时按供应商+商品+币别匹配，价目税率为空则留空并由采购人员结合供应商纳税人类型填写 |
| 不含税单价 | 只读 | `—` | 按R05实时计算 |
| 价税合计 | 只读 | `—` | 按R05实时计算 |
| 税额 | 只读 | `—` | 按R05实时计算 |
| 金额 | 只读 | `—` | 按R05实时计算 |
| 累计实出数量 | 只读 | `—` | **仅编辑页**展示（TSV：新增页不展示）；由采退出库单回写 |
| 在途通知数量 | 只读 | `—` | 新增页展示 `0`；未结束通知占用量（TSV：新增页=只读） |
| 可下推数量 | 只读 | `—` | 按公式实时计算；新增页展示当前值（TSV：新增页=只读） |

#### 3.2.3 SKU选择弹窗（本页配置）

| 配置项 | 本页取值 |
| :--- | :--- |
| 选品方式 | 支持搜索；可多选批量插入（与原型 `enableSkuPicker` 一致） |
| 商品范围 | 启用成品SKU |
| 确认后写入 | 按TSV展示商品名称、带出基本单位；有来源场景由原入库带出价格，无来源留空待手填或取当前价 |
| 更换商品 | 删除行后重新选品；行内商品列不直接手改 |

#### 3.2.4 底部汇总

| 汇总项 | 展示 |
| :--- | :--- |
| 退货数量合计 | 与「退货数量」列右对齐，整数 |
| 价税合计 / 税额 / 金额 | 与对应列右对齐；千分位、2位小数；单头汇总区同步 |

## 4. 校验规则

提交相关弹窗见[弹窗PRD §2](采购退货单前端Demo版PRD_弹窗与Mock.md)。下文 **保存** 指点「保存」，**提交** 指点「提交」（含保存口径 + 加强项）。

### 4.1 校验分层总览

| 层级 | 本页行为 | 典型错误位置 |
| :--- | :--- | :--- |
| 录入限制 | 数量禁小数、备注 `maxLength`、金额禁负数等 | 阻止输入或即时提示 |
| 失焦 | 数量整数、单价小数位、备注长度（§4.2） | 字段下或Toast；改值后**即时**清除该项错误 |
| 保存 | 单头必填 + 明细底线 + 有来源额度校验（§4.3）；**允许单价为空** | 单头内联；明细Toast或错误条 |
| 提交 | 在保存基础上补全价格与税率（§4.4）；零价二次确认 | 同上；通过后进确认弹窗 |
| 请求中 | 保存/提交按钮loading；另一按钮disabled | — |

### 4.2 录入与失焦

| 字段 | 模板 | 格式与范围 | 录入/失焦处理 | 典型提示 |
| :--- | :--- | :--- | :--- | :--- |
| 退货截止日期 | `DATE_ONLY` | 有效日期 | 日期选择器 | `{字段名}不能为空` |
| 供应商、出库仓库、币别、来源采购入库单 | 关联选择 | 须从选项选择 | 禁用项不可选 | `{字段名}不能为空` |
| 备注 | `REMARK_500` | 0～500字 | 超限阻止输入；粘贴超长提示 | `备注已达 500 字上限` |
| 退货数量 | `QTY_INT` | 正整数 >0 | 禁小数点；失焦非整数视为未填 | `第 N 行退货数量须为正整数` |
| 含税单价 | `PRICE_4` | ≥0；最多4位小数 | 禁负数；超4位失焦四舍五入 | `第 N 行含税单价不能为负` |
| 税率 | `PCT_4` | 非负数；最多2位小数 | 数值输入；格式不合法时阻止保存/提交 | `税率最多2位小数，允许0%`；提交时必填：`第 N 行税率不能为空` |
| 系统计算列 | — | 只读 | 不校验录入 | 见 §4.5 |

一期不为数量、单价设业务上限；极大值异常按技术设计处理。

### 4.3 点击「保存」

| 校验对象 | 条件 | 错误位置 | 阻断 | 文案 |
| :--- | :--- | :--- | :---: | :--- |
| 供应商、币别、出库仓库、退货截止日期 | 必填 | 字段下方 | 是 | `{字段名}不能为空` |
| 商品明细 | 至少一行有效明细 | Toast / 错误条 | 是 | `请至少添加一行有效商品明细` |
| 商品（每行） | 已选 | Toast | 是 | `第 N 行请选择商品` |
| 退货数量（每行） | 正整数 >0 | Toast | 是 | `第 N 行退货数量必须大于 0` |
| 退货数量（有来源行） | ≤该行剩余可退额度（R03） | Toast | 是 | `第 N 行退货数量超过该入库单剩余可退额度` |
| 含税单价（每行） | ≥0（可为空） | Toast | 是 | `含税单价不能为负数` |

通过后：仍为草稿+正常；Toast「采购退货单已保存」；新增单首次保存生成单号。草稿不占额度、不占库存（主PRD R03、§7.6）。

### 4.4 点击「提交」

在 §4.3全部通过基础上，追加：

| 校验对象 | 条件 | 错误位置 | 阻断 | 文案 |
| :--- | :--- | :--- | :---: | :--- |
| 含税单价（每行） | 非空 | Toast | 是 | `第 N 行含税单价不能为空` |
| 税率（每行） | 已选 | Toast | 是 | `第 N 行税率不能为空` |
| 含税单价 = 0 | 零价 | 确认框 | 确认后继续 | 见弹窗PRD §2.1 |
| 有来源额度 | 复核（含其他办理中退货） | Toast | 是 | `累计退货数量超过该入库单剩余可退额度` |
| 供应商、出库仓库 | 仍启用 | Toast / 字段下方 | 是 | `所选供应商不可用`／`所选出库仓库不可用` |

税率为0% 允许提交，不额外确认。校验失败时聚焦首错（单头优先）；可用Toast「请修正表单中的错误后再提交」作补充提示。提交成功后价格、税率锁定（R09），时间口径按创建时间。

### 4.5 价税计算与汇总

依据R05；明细变更**即时重算**。

| 计算项 | 公式 | 精度 |
| :--- | :--- | :--- |
| 行不含税单价 | 含税单价 ÷ (1 + 税率÷100)；税率0时等于含税单价 | 4位 |
| 行价税合计 | 退货数量 × 含税单价 | 2位 |
| 行金额 | 退货数量 × 行不含税单价 | 2位 |
| 行税额 | 行价税合计 − 行金额 | 2位；尾差进税额 |
| 单头三项汇总 | 汇总各行 | 2位；展示带币别符号 |

| 异常输入 | 页面表现 |
| :--- | :--- |
| 数量/单价为空或非数字 | 按0参与展示；保存/提交由 §4.3、§4.4阻断 |
| 仅有数量、单价为空 | 行价税显示0.00；**可保存**，**不可提交** |

### 4.6 错误展示与纠错

| 类型 | 表现 | 纠错 |
| :--- | :--- | :--- |
| 单头必填 | 红底线 + 字段下文案；标签不变红 | 修改该字段后清除 |
| 多字段错误 | 同时标出；聚焦首错 | 逐项清除 |
| 明细/全局 | Toast（含「第N行」） | 修正后清除对应提示 |
| 跨行（明细为空） | 错误条或Toast | 补行后消除 |
| 取消离开 | 确认框 | `离开后未保存的内容将丢失，确认离开？` |

## 5. 联动规则

| 触发 | 效果 |
| :--- | :--- |
| 首次选来源采购入库单 | 按原入库单带出单头与明细：**供应商、币别**（带出后只读）；明细为空时按原入库明细带出商品、基本单位、来源入库单行、退货数量默认原入库数量（可改小不超额度）、含税单价与税率按原入库价格（R03、R04） |
| 更换来源采购入库单 | 二次确认「更换后将按新来源重新带出供应商、币别与商品明细，原带出内容全部清空。」→ 确认后按新来源整组重带（供应商、币别、明细全部替换） |
| 清空来源采购入库单 | 用字段右侧清除按钮；二次确认后断开「来源入库单行」关联，并清空带出的供应商与币别（币别回默认）；已录商品与数量保留，转无来源口径（每行>0，不套原入库额度） |
| 出库仓库 | 不随来源带出，始终按逻辑仓自行选择（一张单一个） |
| 改退货数量（有来源） | 超出剩余可退额度时即时提示，保存/提交阻断（§4.3、§4.4） |
| 取当前价 | 按供应商+商品+币别匹配当前采购价目并带入含税单价与税率；税率为空时留空，按供应商纳税人类型手工补填；价目中无价时Toast「当前采购价目中无该商品价格，请手工填写」 |
| 改数量/单价/税率 | 重算行内价税四项与可下推数量 |
| 明细增删 | 重算单头价税合计、税额、金额 |

## 6. 操作行为

| 操作 | 行为 |
| :--- | :--- |
| 保存 | 执行 §4.3；通过后写草稿并提示成功；新增首次保存生成单号；默认停留本页 |
| 提交 | 执行 §4.4 → 零价确认（如有）→ 提交确认弹窗；成功后变待审核并提示成功 |
| 取消 | 有未保存修改则确认；确认后回列表 |
| 编辑页进入 | 加载中展示占位；失败展示「采购退货单不存在或无权查看」；非草稿不可进入 |

| 状态编辑控件 | 编辑页仅在页头只读展示两枚StatusBadge |
| 发货处理方式 | 在采退发货通知单创建时选择，不在本单维护（主PRD §3.4） |
| 终止信息、审核信息、系统信息 | 按状态在详情页展示 |
| 关联单据 | 采退发货通知单、采退出库单在详情页 |
| 累计实出数量 | 新增页不展示（TSV）；编辑页只读展示 |

## 10. Mock与验收

### 10.1 Mock覆盖

> 仅Demo，非正式验收。

- 可保存草稿：有来源（关联入库带出价格与额度）、一行SKU、数量100
- 无来源草稿：手工选品、手填价格、数量>0
- 编辑用草稿：2行明细 + 累计实出/在途/可下推列 + 两枚状态标签
- 零价明细：验证提交二次确认
- 超额度明细：验证保存阻断
- 待审核单：验证不可进入编辑页

### 10.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 正常建单 | 新增 → 保存 | 草稿+正常；单号按CGTH生成；时间口径按创建时间 |
| 来源带出 | 选择来源采购入库单 | 带出明细、原入库价格与税率；来源入库单行有值 |
| 额度阻断 | 有来源行数量超剩余可退额度 | 保存阻断，提示第N行超额度 |
| 改小数量 | 有来源行数量改小 | 保存成功；无来源行每行>0 |
| 无价保存 / 无价提交 | 明细无单价 | 保存成功；提交阻断 |
| 零价提交 | 单价为0 | 零价确认 → 提交确认弹窗 |
| 税率0% | 税率选0% | 允许提交；税额0.00、价税合计等于金额 |
| 数量小数 / 单价超4位 / 备注超长 | 见 §4.2 | 录入约束或保存/提交阻断 |
| 不可编辑 | 待审核单点编辑 | 不进入本页 |
