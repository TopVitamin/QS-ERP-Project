## 2. 提交相关弹窗（F03）

**触发入口**：新增/编辑页、列表、详情「提交」；可用条件均为**审核状态=草稿 + 业务状态=正常**（主PRD §6.4）。

**校验前置**：打开任何提交弹窗前，先按主PRD R04、R10与[新增编辑页 §4.4](采购退货单前端Demo版PRD_新增编辑页.md)校验当前单据。未通过则Toast或字段提示阻断，**不进入**下列弹窗。列表/详情提交已有草稿时，校验口径与表单页一致。

**弹窗顺序**：先零价确认（如有）→ 再提交确认。

```
列表 / 详情 / 新增·编辑页
         │
     点「提交」
         ▼
  新增编辑 §4.4 校验
         │
    ┌────┴────┐
  失败       通过
    │          │
    ▼          ▼
 Toast      存在零价明细？
 阻断          │
           ┌──┴──┐
          否      是
           │       │
           │       ▼
           │   §2.1 零价确认弹窗
           │    取消 │ 确认继续
           │       └──┬──┘
           └────┬────┘
                ▼
         §2.2 提交确认弹窗
          取消 │ 确认提交
               ▼
        待审核 + Toast「已提交」
```

### 2.1 零价确认

| 项目 | 内容 |
| :--- | :--- |
| 出现条件 | 任一明细行含税单价 = 0 |
| 弹窗标题 | 确认使用零价？ |
| 正文 | 第 {N} 行含税单价为0，请确认业务约定。多行零价时正文列出各行或合并为「存在零价明细，请确认业务约定。」 |
| 确认按钮 | 确认继续 |
| 取消按钮 | 取消 |
| 确认后 | 进入 §2.2提交确认弹窗 |

### 2.2 提交确认

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 确认提交采购退货单？ |
| 正文 | 提交后进入待审核状态，价格、税率不可再修改；审核通过后占用可用库存与原入库可退额度，审核前仍可撤回修改。 |
| 确认按钮 | 确认提交 |
| 取消按钮 | 取消 |
| 确认后 | 审核状态→待审核；Toast「采购退货单已提交」；刷新当前页或列表 |

| 来源页 | 确认后页面表现 |
| :--- | :--- |
| 新增/编辑页 | 停留本页并变为只读待审核态，或返回列表（以实现为准，须可连续演示） |
| 列表 / 详情 | 刷新；行内/页头操作变为审核、撤回等 |

## 3. 状态变更与删除确认弹窗（F04、F06、R14）

下列弹窗均在**二次确认**后执行。入口可用条件见主PRD §6.4与各页页头/行内矩阵；条件不满足时**不展示按钮**，无需弹窗阻断。

**阻断类失败**（不满足业务规则、未进入成功流）：取消/关闭若触发R11、R13等规则，直接Toast，例如「存在推送中、待发货或取消中的采退发货通知，请先处理后再取消」「退货单已有实际出库，无法取消整单，请使用关闭余量」。全部退足单不展示下推、取消、关闭、调整截止时间入口（R13、Q01）。

**通用弹窗结构**（无表单项时省略中间输入区；见 §3.2～§3.5各节表格）：

```
┌──────────────────────────────────────────┐
│  {弹窗标题}                          [×] │
├──────────────────────────────────────────┤
│  {正文说明}                               │
│  ┌────────────────────────────────────┐  │  ← 有必填项时，如撤回意见、
│  │ {多行文本 / 日期选择}           │  │     关闭原因、取消原因、新截止时间
│  └────────────────────────────────────┘  │
├──────────────────────────────────────────┤
│                    [取消]  [确认{动作}]   │
└──────────────────────────────────────────┘
         │ 取消              │ 确认
         ▼                   ▼
    关闭弹窗，停留      执行业务 + Toast + 刷新页面
```

**入口与阻断关系**（按钮不满足条件时直接不展示，不弹窗）：

```
页头 / 行内「{操作}」
         │
    主 PRD §6.4 允许？
         │
    ┌────┴────┐
   否        是
    │          │
    ▼          ▼
 不展示    R08 / R11 / R13 等
 该按钮      业务阻断？
              │
         ┌────┴────┐
        是         否
         │          │
         ▼          ▼
      Toast     打开 §3.x 弹窗
      阻断
```

### 3.1 审核

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「审核」 |
| 可用条件 | 待审核 + 正常 |
| 弹窗标题 | 确认审核？ |
| 正文 | 审核后占用出库仓可用库存与原入库可退额度，数量、价格、仓库不可再修改，仅可调整退货截止日期。 |
| 必填项 | 无 |
| 确认按钮 | 确认审核 |
| 取消按钮 | 取消 |
| 确认后 | 审核状态→已审核；记录审核人、审核时间；Toast「采购退货单已审核」；刷新页面。Demo可接续 §4 Mock引导弹窗 |

可用库存或可退额度不足时，确认后按阻断Toast处理（如「出库仓库可用库存不足，无法审核」），状态不变。

### 3.2 撤回

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「撤回」 |
| 可用条件 | 待审核 + 正常 |
| 弹窗标题 | 撤回采购退货单 |
| 正文 | 请填写撤回意见 |
| 必填项 | 撤回意见（多行） |
| 确认按钮 | 确认撤回 |
| 取消按钮 | 取消 |
| 确认后 | 审核状态→草稿；保存撤回意见；Toast「采购退货单已撤回，请修改后重新提交」 |

### 3.3 调整退货截止日期

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「调整截止时间」 |
| 可用条件 | 已审核 + 正常；未全部退足（R09、R13） |
| 弹窗标题 | 调整退货截止日期 |
| 正文 | 仅修改退货截止日期，数量、仓库与价格不变。 |
| 必填项 | 新退货截止日期（日期） |
| 确认按钮 | 确认 |
| 取消按钮 | 取消 |
| 确认后 | 更新退货截止日期；Toast「退货截止日期已更新」 |

### 3.4 关闭退货单

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「关闭」 |
| 可用条件 | 已审核 + 正常；未全部退足（R12、R13） |
| 弹窗标题 | 关闭采购退货单 |
| 正文 | 关闭后不可撤销，不能再新增采退发货通知；已有通知继续执行。 |
| 必填项 | 关闭原因（多行） |
| 确认按钮 | 确认关闭 |
| 取消按钮 | 取消 |
| 确认后 | 业务状态→已关闭；关闭方式=手动关闭，记录关闭时间与关闭操作人；释放尚未安排部分的预占；Toast见列表/详情PRD |

到期自动关闭不经过本弹窗：系统在退货截止日期过后T+2自然日当天0:00跑批，关闭方式=到期自动关闭，关闭原因与关闭操作人留空（主PRD R12）。

### 3.5 取消退货单

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「取消」 |
| 可用条件 | 待审核或已审核 + 正常；已审核时须满足R11 |
| 弹窗标题 | 取消采购退货单 |
| 正文 | 取消后整单不再执行，不可撤销；已有实际出库时不能取消整单。 |
| 必填项 | 取消原因（多行） |
| 确认按钮 | 确认取消 |
| 取消按钮 | 取消 |
| 确认后 | 业务状态→已取消；记录取消时间与取消操作人；待推送/推送失败通知随单取消；释放未执行预占（R11）；Toast见列表/详情PRD |

待审核取消与已审核取消共用本弹窗；待审核取消同时终止审核流程，结果为「原审核状态+已取消」。

### 3.6 离开未保存（表单页）

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 新增/编辑页点「取消」或路由离开，且存在未保存修改 |
| 弹窗标题 | 离开当前页面？ |
| 正文 | 离开后未保存的内容将丢失。 |
| 确认按钮 | 确认离开 |
| 取消按钮 | 取消 |
| 确认后 | 返回列表或上一页 |

表单页来源变更确认（更换/清空来源采购入库单）见[新增编辑页 §5](采购退货单前端Demo版PRD_新增编辑页.md)：更换正文「更换后将按新来源重新带出供应商、币别与商品明细，原带出内容全部清空。」；清空正文「清空后将断开来源入库单行关联，并清空带出的供应商与币别；已录商品与数量保留，按无来源口径校验。」错误展示与文案口径见新增编辑页 §4.6、§8。

### 3.7 删除草稿

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「删除」 |
| 可用条件 | 按钮仅在**草稿 + 正常**展示；确认时校验未被采退发货通知单等下游引用（主PRD R14、§6.4） |
| 弹窗标题 | 删除采购退货单草稿？ |
| 正文 | 删除后不可恢复，确定删除该草稿？ |
| 确认按钮 | 确认删除 |
| 取消按钮 | 取消 |
| 确认后 | 物理删除该草稿；从列表消失，详情页返回列表；Toast「采购退货单草稿已删除」 |
| 失败阻断 | 被下游引用时Toast「该草稿已被下游引用，不能删除」；非草稿或状态已变化时Toast「操作失败，单据状态已变更，请刷新后重试」；均不删除、记录保留 |

## 4. Demo Mock：审核后生成采退发货通知（F07）

> 本章为 **Demo Mock，仅Demo，非正式验收**。

### 4.1 正式规则

按PUR-FR04，退货单**审核通过后由采购员按退货安排手工创建采退发货通知单**，录入本次通知数量并选择发货处理方式（默认仓库发货）；系统**不会**自动生成通知单。

本节Mock **仅用于Demo原型串联**，不属于AC01～AC14正式验收（主PRD F07、AC12）。

### 4.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 列表/详情「审核」成功后 | 弹出Mock引导弹窗（Demo开关可配置，默认开启） |

```
§3.1 审核成功（已审核）
         │
    Demo Mock 开关？
         │
    ┌────┴────┐
  关闭       开启（默认）
    │          │
    ▼          ▼
 Toast      §4.3 引导弹窗
 结束      ┌────────────────────────────────────┐
            │ 采购退货单已审核                    │
            │ 正式流程需手工创建采退发货通知…      │
            │ [稍后手工创建]  [生成演示通知单Mock] │
            └────────────────────────────────────┘
                    │              │           [×]
         稍后手工创建│              │生成演示通知单
                    ▼              ▼
              关闭弹窗         §4.4 本地创建
              可点「下推」      通知单(Mock)
              走正式流程            │
                                   ▼
                            退货单占用 / 可下推量更新
                            （可接续通知 Mock 模拟回传）
```

### 4.3 引导弹窗

| 项目 | 内容 |
| :--- | :--- |
| 标题 | 采购退货单已审核 |
| 正文 | 正式流程需按退货安排手工创建采退发货通知。Demo可一键生成本次演示用通知单，便于查看主链。 |
| 主按钮 | 生成演示通知单（Mock） |
| 次按钮 | 稍后手工创建 |
| 关闭图标 | 关闭弹窗，仅刷新退货单状态 |

### 4.4 生成规则（本地Mock）

点击「生成演示通知单（Mock）」时，在本地Mock存储创建一条**采退发货通知单**：

| 项目 | 规则 |
| :--- | :--- |
| 来源 | 当前采购退货单 |
| 出库仓库 | 沿用退货单出库仓库（逻辑仓） |
| 发货处理方式 | 仓库发货（默认值） |
| 单据状态 | 待推送（虚拟出库不作为Mock默认路径） |
| 明细 | 按退货单每个SKU一行；通知数量 = 当前可下推数量（演示简化，不代表实际分批） |
| 单号 | 按通知单编码规则生成fictitious编号（前缀 `CTFHTZ`） |
| 占用 | 退货单在途通知数量增加；可下推数量相应减少 |
| 推送 | Demo不调用真实仓库；可配置数秒后模拟「待推送→待发货」 |

界面标注「演示数据」或「Mock」角标，与手工创建的通知单区分。

### 4.5 不做的事

- 不代替正式「创建采退发货通知单」页的数量录入、发货处理方式选择与校验
- 不在Mock中自动审核退货单、自动扣减库存或自动推送金蝶
- 不把Mock行为写入主PRD验收标准
- 导入不走Mock：列表导入为一期正式能力（主PRD F08、R15、Q08），本章Demo Mock仅保留§4审核后生成演示通知

### 4.6 与正式下推的关系

关闭引导弹窗后，可通过列表/详情「下推通知单」进入正式创建流程，见[《采退发货通知单前端Demo版PRD_新增编辑页》](../../采退发货通知单/前端Demo版PRD/采退发货通知单前端Demo版PRD_新增编辑页.md)。下游「模拟仓库回传」见[《采退发货通知单前端Demo版PRD_弹窗与Mock》](../../采退发货通知单/前端Demo版PRD/采退发货通知单前端Demo版PRD_弹窗与Mock.md)。

## 5. 导入向导弹窗文案（F08，一期正式）

```
列表页头「导入」（正式）
         ▼
┌─ 导入向导（Modal）────────────────────────────────┐
│ ① 下载模板 → ② 上传文件 → ③ 校验预览 → ④ 完成导入 │
```

| :--- | :--- | :--- | :--- |
| ① 下载模板 | 下载导入模板 | 模板列：单据序号、供应商、币别、出库仓库、退货截止日期、来源采购入库单号（可空）、备注、商品编码、退货数量、含税单价、税率 | 下载模板、取消 |
| ② 上传文件 | 上传导入文件 | 支持.xlsx；同一「单据序号」的行归并为一张退货单，同组单头字段必须一致；无来源退货来源采购入库单号留空 | 上一步、下一步、取消 |
| ③ 校验预览 | 校验预览 | 按保存草稿口径整批校验；**任一行失败则整批不导入**，逐行列出错误原因 | 上一步、下一步（仅校验通过时可点）、取消 |
| ④ 完成导入 | 导入完成 | 成功：成功导入N张退货单草稿，请逐单检查后提交审核；失败：导入校验未通过，本次未生成任何退货单 | 下载错误说明（失败时）、完成 |

错误示例：

| 场景 | 文案 |
| :--- | :--- |
| 单头必填缺失 | 第2行出库仓库不能为空 |
| 商品或数量非法 | 第5行请选择商品／第5行退货数量必须大于0 |
| 价格非法 | 第7行含税单价不能为负数 |
| 来源单号非法 | 第3行来源采购入库单号不是已审核的采购入库单 |
| 超可退额度 | 第4行退货数量超过该入库单剩余可退额度 |
| 同组单头不一致 | 单据序号A001的出库仓库与同组其他行不一致 |
| 整批失败 | 任一行校验失败，本次导入已取消，未生成任何退货单 |

导入结果不改变业务流程：生成的单据仍为**草稿+正常**，须逐单提交审核（COM-FR02、COM-AC02）。本节为一期正式能力文案，**不属于Demo Mock**。

## 6. 验收场景

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 提交 | 完整草稿点提交 | 校验通过→（零价确认）→提交确认→待审核 |
| 提交阻断 | 含税单价为空提交 | Toast阻断，不进入待审核 |
| 额度阻断 | 有来源行超剩余可退额度 | 保存/提交阻断并提示行号，不进入弹窗 |
| 零价 | 零价明细提交 | 先零价确认，再提交确认 |
| 撤回 | 待审核点撤回 | 必填撤回意见→草稿 |
| 删除 | 草稿单点删除 | 二次确认→物理删除→返回列表并Toast，列表不再显示该单 |
| 删除阻断 | 被下游引用的草稿点删除 | 确认后Toast「该草稿已被下游引用，不能删除」，记录保留 |
| 审核 | 待审核点审核 | 已审核；Mock开启时出现 §4引导弹窗 |
| 审核阻断 | 出库仓可用库存不足 | 确认后阻断Toast，状态不变 |
| Mock生成 | 点生成演示通知单 | 本地出现Mock通知；退货单在途通知增加、可下推减少 |
| Mock关闭 | Demo配置关闭Mock | 审核后仅成功提示，不弹 §4引导 |
| 调整截止时间 | 已审核+正常点调整截止时间 | 必填新截止时间→更新成功 |
| 关闭 | 未全部退足点关闭 | 必填关闭原因→已关闭；关闭方式=手动关闭 |
| R11阻断 | 有执行中通知或已有实出时取消 | Toast阻断，不进入取消成功流 |
| 全部退足 | 打开全部退足单 | 无下推、取消、关闭、调整截止时间入口，弹窗不可达 |
| 导入成功 | 页头点导入，上传全部校验通过的模板文件 | 四步走通，生成N张草稿并提示“成功导入N张退货单草稿，请逐单检查后提交审核”；单据为草稿+正常，仍需提交审核 |
| 导入整批失败 | 上传含一行非法数据的文件 | 校验预览逐行报错，整批不导入，可下载错误说明 |

Demo验证弹窗文案、必填项与Mock本地数据联动；不代表生产接口、并发或后端事务行为。
