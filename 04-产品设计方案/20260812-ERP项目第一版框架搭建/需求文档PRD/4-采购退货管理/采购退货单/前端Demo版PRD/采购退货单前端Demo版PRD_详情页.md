关联资料：[《采购退货单页面骨架》](../采购退货单页面骨架.md)、[《采购退货单前端Demo版PRD_弹窗与Mock》](采购退货单前端Demo版PRD_弹窗与Mock.md)。布局见骨架。

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 采购退货单详情页 |
| 入口 | 列表点击单号；操作完成后可刷新本页 |
| 页面目标 | 只读查看一张采购退货单全貌；按当前状态办理允许的操作 |
| 骨架结构 | 页头 → 单据信息 → 商品明细 → 关联单据（条件）→ 终止信息（条件）→ 审核信息 → 系统信息 |

本页落地 **F05（分区域展示与追溯）** 及详情侧 **F02/F03/F04/F06** 操作入口；状态—操作矩阵见主PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头固定展示**审核状态、业务状态**两枚 **StatusBadge**（与单据信息分区并列，不单开「状态信息」卡片）；本单**无第三维状态**，全部退足不是状态。
> - **关联单据**仅**审核状态=已审核**时展示；草稿、待审核不展示下游Tab。
> - 终止信息仅在**业务状态=已关闭或已取消**时展示；正常单不展示该分组。
> - 审核信息、系统信息按TSV分组展示，未产生的值展示 `-`。
> - 二次确认弹窗正文在[弹窗PRD](采购退货单前端Demo版PRD_弹窗与Mock.md)维护，本文只写入口与结果表现。
> - **全部退足**（S07/R13）：仅查看，无下推、取消、关闭、调整截止时间。
> - 草稿删除按R14提供（列表与详情均可，二次确认）；批量能力仍仅导出（可选已勾选）。
> - Demo以**桌面端**为基准；商品明细、关联简表在窄视口内**横向滚动**，不承诺移动端布局。

## 2. 页头

### 2.1 标题与状态

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `采购退货单详情 · {单号}` |
| 状态标签 | 两枚StatusBadge：审核状态 / 业务状态 |
| 布局 | 单行：左侧标题 + 状态标签；右侧操作区 |

列表状态列用语义色文字；**详情页头用StatusBadge胶囊**，tone与列表语义一致（见《原型开发说明》）。

### 2.2 页头操作按钮

`返回列表` **始终排在最前**；其后按状态展示业务按钮。编辑为草稿主按钮，与业务按钮分区展示，顺序以原型为准。

| 按钮 | 草稿+正常 | 待审核+正常 | 已审核+正常（未全部退足） | 已审核+正常+全部退足 | 已取消/已关闭 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 返回列表 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 编辑 | ✅ | ❌ | ❌ | ❌ | ❌ |
| 提交 | ✅ | ❌ | ❌ | ❌ | ❌ |
| 删除 | ✅ | ❌ | ❌ | ❌ | ❌ |
| 审核 | ❌ | ✅ | ❌ | ❌ | ❌ |
| 撤回 | ❌ | ✅ | ❌ | ❌ | ❌ |
| 取消 | ❌ | ✅ | 条件✅ | ❌ | ❌ |
| 下推通知单 | ❌ | ❌ | 条件✅ | ❌ | ❌ |
| 关闭 | ❌ | ❌ | 条件✅ | ❌ | ❌ |
| 调整截止时间 | ❌ | ❌ | 条件✅ | ❌ | ❌ |

条件说明（详见主PRD）：

| 按钮 | 条件摘要 |
| :--- | :--- |
| 删除 | R14：草稿+正常且未被采退发货通知单等下游引用；已提交、已审核或被引用不可删，删除不可恢复 |
| 取消（已审核） | R11：无实出、无阻挡通知；有执行中通知须先处理并取得仓库确认 |
| 下推通知单 | 有可下推数量（R08）；入口文案「下推通知单」，全称「创建采退发货通知单」 |
| 关闭 | R12：未全部退足；关闭原因必填 |
| 调整截止时间 | R09：已审核后唯一可改字段；R13：全部退足不提供 |
| 取消与关闭 | 已审核+正常时可**同时出现**，按各自条件独立判断 |

已审核态按钮顺序（`返回列表` 之后）：下推通知单 → 取消 → 关闭 → 调整截止时间（与骨架一致；列表行内直出前三项中的高频项，取消收在「更多」）。

**渲染纪律**：

- 条件不满足的按钮**直接不渲染**，不展示灰色disabled占位。
- 样式层级：**提交、审核** 用主要按钮（`primary`）；**编辑** 为草稿主按钮；**删除、取消、关闭、撤回、调整截止时间、下推通知单** 用次要按钮（`outline`）；**返回列表** 为幽灵/次要样式，固定最左。

### 2.3 二次确认与弹窗

| 操作 | 弹窗PRD | 确认后页面表现 |
| :--- | :--- | :--- |
| 提交 | §2 | 刷新为待审核；Toast「采购退货单已提交」 |
| 审核 | §3.1 | 刷新为已审核；Toast「采购退货单已审核」；可选Mock引导（§4） |

| 编辑 | 跳转编辑页 | 返回后刷新详情 |
| 删除 | §3.7 | 返回列表；Toast「采购退货单草稿已删除」 |

## 3. 信息分区与字段

> 只读 **6列栅格**，标签在上、值在下；备注占 **3列**。字段顺序与TSV分组一致。

**分区总览**：页头 → **3.1单据信息** → **3.2商品明细** → **3.3关联单据**（已审核）→ **3.4终止信息**（已关闭/已取消）→ **3.5审核信息** → **3.6系统信息**

### 3.1 单据信息

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样 |
| 供应商 | Code-Name |
| 币别 | `{币别代码} {币别名称}`（如 `CNY 人民币`） |
| 价税合计 | 金额；千分位；可与币别符号同区展示 |
| 税额 | 同上 |
| 金额 | 不含税金额合计；同上 |
| 出库仓库 | 逻辑仓Code-Name |
| 退货截止日期 | 日期 `YYYY-MM-DD` |
| 来源采购入库单 | 单号链接，跳转采购入库单详情；无来源展示 `-` |
| 备注 | 占3列；长文本可换行 |

栅格排布见骨架：10个字段（备注占3列）分三行，备注在第三行占第1～3列。

### 3.2 商品明细

- 表格只读；**数量、单价、价税列右对齐**；横向滚动。
- 一期**不分页**，展示全部明细行。
- 价税列顺序：**含税单价 → 税率 → 不含税单价 → 价税合计 → 税额 → 金额**（与全局价税字段命名一致）。

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 自动编号 |
| 商品 | 文本；按TSV展示商品名称 |
| 基本单位 | 文本 |
| 来源入库单行 | 文本；无来源为 `-` |
| 退货数量 | 整数 |
| 含税单价 | 千分位；4位小数 |
| 税率 | 百分比，如 `13%` |
| 不含税单价 | 系统计算；4位小数 |
| 价税合计 / 税额 / 金额 | 系统计算；2位小数 |
| 累计实出数量 | 回写列 |
| 在途通知数量 | 计算列 |
| 可下推数量 | 计算列 |

**回写列显隐**：详情页一期**始终展示**上述三列；草稿、待审核时尚无执行数据，数值展示 **`0`** 或按公式计算值，不隐藏列。关闭、取消后可下推数量保留数值但已无下推资格（R08）。

**底部汇总行**（`DocumentSummaryBar`）：

| 汇总项 | 展示 |
| :--- | :--- |
| 首列 | 文案 `合计`（占行号列） |
| 退货数量合计 | 与「退货数量」列右对齐，整数 |
| 价税合计 / 税额 / 金额 | 与对应列右对齐；千分位、2位小数；价税合计可加粗强调 |
| 样式 | 汇总行与表头列对齐分别展示，不用合并多列写成单行右对齐文案 |

### 3.3 关联单据

**展示条件**：审核状态 = **已审核**（含业务已取消/已关闭的已审核单，若有下游历史）。

组件：`RelatedDocumentsCard`；胶囊Tab（`InnerTabs` `pill` 变体）；Tab文案带数量，如 `采退发货通知单 (1)`。默认选中「采退发货通知单」。当前Tab无记录时展示空态文案。

| Tab | 列 | 排序 | 空态 |
| :--- | :--- | :--- | :--- |
| 采退发货通知单 | 单号、单据状态、通知数量、实出数量、缺出数量、创建时间 | 创建时间倒序 | 暂无关联的采退发货通知单 |
| 采退出库单 | 单号、来源采退发货通知单、审核状态、推送财务ERP状态、实际出库数量、价税合计、创建时间 | 创建时间倒序 | 暂无关联的采退出库单 |

空态仅提示暂无数据，不强制引导创建（下推通知单入口在页头）。单号可跳转对应详情。Tab下表不重复展示与来源退货单相同的供应商、仓库。规则见[《采退发货通知单主PRD》](../../采退发货通知单/采退发货通知单主PRD.md)、[《采退出库单主PRD》](../../采退出库单/采退出库单主PRD.md)。

### 3.4 终止信息

**展示条件**：业务状态 = **已关闭** 或 **已取消**。

| 业务状态 | 字段（6列栅格） |
| :--- | :--- |
| 已关闭 | 关闭方式、关闭原因、关闭时间、关闭操作人（占前4列，后2列留空） |
| 已取消 | 取消原因、取消时间、取消操作人（占前3列，后3列留空） |

到期自动关闭时关闭原因与关闭操作人留空，以关闭方式=「到期自动关闭」区分（主PRD R12）。

### 3.5 审核信息

| 字段 | 展示说明 |
| :--- | :--- |
| 审核人 | 展示姓名（USER_REF）；未审核时 `-` |
| 审核时间 | 日期时间；未审核时 `-` |
| 撤回意见 | 占第3～6列；多行文本；未撤回时 `-` |

### 3.6 系统信息

| 字段 | 展示说明 |
| :--- | :--- |
| 创建人 | 姓名 |
| 创建时间 | 日期时间 |
| 最后更新人 | 姓名 |
| 最后更新时间 | 日期时间 |

占前4列，后2列留空；本分区不设胶囊Tab，完整审计日志后置。

## 4. 字段展示规范

通用规则见《原型开发说明》「列表列通用呈现规则」中与详情相关的条目；下表写本页差异。

| 规范 | 说明 |
| :--- | :--- |
| 空值 | 文本类统一英文连字符 `-`（`EMPTY_PLACEHOLDER`）；**禁止**用中文破折号 `—` 或留空白 |
| 主数据 | Code-Name：`{编码} {名称}` |
| 币别 | 独立字段展示 `CNY 人民币`；明细金额列不重复币别前缀 |
| 金额 | 千分位；2位小数；单价4位 |
| 数量 | 整数；`0` 按有效值展示 |
| 税率 | 百分比，如 `0%`、`13%` |
| 日期 | `YYYY-MM-DD` |
| 日期时间 | `YYYY-MM-DD HH:mm:ss` |
| 页头状态 | StatusBadge胶囊（两枚），非列表语义色文字 |
| 关联简表 | 外框与表头样式见《原型开发说明》「详情内嵌简表」 |

## 5. 操作行为

| 操作 | 行为 |
| :--- | :--- |
| 编辑 | 跳转编辑页；返回后刷新详情 |
| 删除 | 打开删除草稿确认弹窗（弹窗PRD §3.7）→ 成功后返回列表 |
| 下推通知单 | 跳转采退发货通知单创建页并带入来源退货单（非弹窗） |
| 提交 / 审核 / 撤回 / 调整截止时间 / 关闭 / 取消 | 打开弹窗PRD对应弹窗 → 成功后刷新详情或返回列表 |
| 返回列表 | 回到列表，保留筛选、页码与列表上下文 |

## 6. 反馈与页面状态

### 6.1 操作反馈（Toast）

| 操作 | 反馈类型 | 文案 |
| :--- | :--- | :--- |
| 提交成功 | Toast | 采购退货单已提交 |
| 审核成功 | Toast | 采购退货单已审核 |
| 撤回成功 | Toast | 已撤回，请修改后重新提交 |
| 删除成功 | Toast | 采购退货单草稿已删除 |
| 删除失败——被引用或非草稿 | Toast | 该草稿已被下游引用，不能删除 |
| 取消成功 | Toast | 采购退货单已取消 |
| 关闭成功 | Toast | 采购退货单已关闭 |
| 调整截止时间成功 | Toast | 退货截止日期已更新 |
| 取消/关闭失败（R11、R13等） | Toast | 如「存在推送中、待发货或取消中的采退发货通知，请先处理后再取消」 |
| 状态已变更（阻断） | Toast | 操作失败，单据状态已变更，请刷新后重试 |
| 并发/版本冲突（如有） | Toast | 操作失败，当前单据已被修改，请刷新后重试 |

Mock审核后引导弹窗文案见弹窗PRD §4。

### 6.2 加载与异常态

| 场景 | 页面表现 | 文案 / 操作 |
| :--- | :--- | :--- |
| 加载中 | 骨架屏；分区占位（页头、单据信息、明细表等） | — |
| 单据不存在 | 错误态 | 采购退货单不存在或无权查看；提供「返回列表」 |
| 加载失败 | 错误态 | 加载失败，请重试；提供「重试」与「返回列表」 |
| 返回列表 | 跳转列表 | 恢复进入前的查询条件与页码；无历史筛选时回默认列表 |

## 7. Mock与验收

### 7.1 Mock覆盖清单

> 仅Demo，非正式验收。

- **草稿+正常** 至少1单：页头两标签；可编辑/提交/删除；回写列展示 `0` 或公式值；无关联单据、无终止信息
- **待审核+正常** 至少1单：审核/撤回/取消；无关联单据
- **已审核+正常+未全部退足** 至少1单：明细含回写列（如退100、累计实出50、可下推50）；有关联单据Tab；可下推/取消/关闭/调整截止时间（按条件）
- **已审核+正常+全部退足** 至少1单（S07）：页头仅返回列表；无下推、取消、关闭、调整截止时间
- **已关闭**、**已取消** 各至少1单：展示终止信息（已关闭含到期自动关闭示例，关闭原因与操作人留空）；页头仅返回列表
- 关联Tab：至少1单含通知单与出库单记录；至少1个Tab为空态
- 审核信息：至少1单含撤回意见；未审核单展示 `-`
- 系统信息：至少1个字段为空 `-`

### 7.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 草稿详情 | 打开草稿单 | 两枚StatusBadge；页头含提交、删除、编辑；无关联单据、无终止信息；制单字段有创建人 |
| 已审核+部分实出 | 打开详情 | 明细回写列有值；价格数量只读；关联单据双Tab |
| 关联跳转 | 点击通知单/出库单号、来源采购入库单号 | 进入对应详情 |
| 全部退足S07 | 打开详情 | 仅返回列表；无办理入口（AC11） |
| 已关闭 | 打开详情 | 终止信息展示关闭字段；到期自动关闭时关闭原因与操作人留空 |
| 已取消 | 打开详情 | 展示取消原因、取消时间、取消操作人 |
| 审核信息 | 查看撤回过又重提的单 | 撤回意见保留展示 |
