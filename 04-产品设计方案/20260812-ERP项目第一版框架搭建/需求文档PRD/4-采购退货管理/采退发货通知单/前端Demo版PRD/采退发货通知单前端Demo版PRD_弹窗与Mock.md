## 2. 取消通知单（F05）

**触发入口**：列表、详情「取消」；可用条件为**待推送**或**推送失败**（主 PRD §6.4）。

```
列表 / 详情
     │
点「取消」（待推送 / 推送失败）
     ▼
┌──────────────────────────────────────────┐
│  取消采退发货通知单                  [×] │
│  取消后通知不再执行，不可撤销…           │
│  推送失败时追加：请确认仓库尚未接收…     │
│  取消原因* [多行文本]                    │
│                    [取消] [确认取消]      │
└──────────────────────────────────────────┘
         │ 取消              │ 确认
         ▼                   ▼
    关闭弹窗，停留      已取消 + 释放占用
                        Toast「已取消」
```

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 取消采退发货通知单 |
| 正文 | 取消后通知不再执行，不可撤销，并释放退货单可下推量。 |
| 推送失败补充 | 推送失败时追加：「请确认仓库尚未接收本通知。」 |
| 必填项 | 取消原因（多行） |
| 确认按钮 | 确认取消 |
| 取消按钮 | 取消 |
| 确认后 | 单据状态→已取消；记录取消原因、取消时间、取消操作人；释放全部通知占用；采购退货单仍开放则回补可下推量，已关闭则不恢复下推资格（R08）；Toast「采退发货通知单已取消」 |

## 3. 取消通知单（待发货）（F06）

**触发入口**：列表、详情「取消」；可用条件为**待发货**（主 PRD §6.4）。

```
列表 / 详情
     │
点「取消」（待发货）
     ▼
┌──────────────────────────────────────────┐
│  取消采退发货通知单                  [×] │
│  单据已推送仓库，取消需等待仓库回执。    │
│  取消原因* [多行文本]                    │
│                    [取消] [确认取消]      │
└──────────────────────────────────────────┘
         │ 取消              │ 确认
         ▼                   ▼
    关闭弹窗，停留      取消中 + Toast
                        「已发起取消，等待仓库回执」
                              │
                    ┌─────────┴─────────┐
                    ▼                   ▼
              仓库同意              仓库拒绝
              已取消                待发货
```

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 取消采退发货通知单 |
| 正文 | 单据已推送仓库，取消需等待仓库回执。取消期间通知仍占用退货单可下推量。 |
| 必填项 | 取消原因（多行） |
| 确认按钮 | 确认取消 |
| 取消按钮 | 取消 |
| 确认后 | 单据状态→取消中；Toast「已发起取消，等待仓库回执」 |

仓库回执处理（正式环境由集成层接收，Demo 见 §5）：

| 回执 | 结果状态 | 提示 |
| :--- | :--- | :--- |
| 仓库同意 | 已取消 | 采退发货通知单已取消 |
| 仓库拒绝 | 待发货 | 仓库拒绝取消，请继续等待发货 |

取消期间到达的实际出库回传按真实结果处理：有实出则完成发货（已发货并生成采退出库单），零出则按零出取消，不以取消申请覆盖已发生事实。

## 4. 重试推送（F07）

**触发入口**：列表、详情「重试推送」；可用条件为**推送失败**（主 PRD §6.4）；正式环境须已自动重试满3次仍失败（R14）。

```
列表 / 详情
     │
点「重试推送」（推送失败）
     ▼
┌──────────────────────────────────────────┐
│  重试推送仓库                        [×] │
│  将重新向仓库发送本通知，请确认失败原因已处理。│
│                    [取消] [确认重试]      │
└──────────────────────────────────────────┘
         │ 取消              │ 确认
         ▼                   ▼
    关闭弹窗，停留      推送中 + Toast
                        「已重新推送仓库」
```

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 重试推送仓库 |
| 正文 | 将重新向仓库发送本通知，请确认失败原因已处理。 |
| 必填项 | 无 |
| 确认按钮 | 确认重试 |
| 取消按钮 | 取消 |
| 确认后 | 单据状态→推送中；Toast「已重新推送仓库」 |

正式环境：推送明确失败后系统自动重试，**最多3次**；3次仍失败才保持「推送失败」并出现本按钮。间隔本期不定秒数，由技术配置。Demo 可直接把单据置于推送失败，便于演示人工重试，不模拟间隔。

## 5. Demo Mock：模拟仓库出库回传（F08）

### 5.1 正式规则

正式环境中，仓库通过WMS接口回传实出数量与结束标记；零出按 PUR-FR04 取消通知，不生成采退出库单；有实出则由系统生成采退出库单并自动审核、扣减库存并消耗预占。

本节 Mock **仅用于 Demo 原型串联展示**，不属于 AC01～AC12 的正式验收项（主PRD F08）。

### 5.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 详情页「模拟仓库出库回传」 | 单据状态为待发货（可配置 Demo 开关，默认开启） |
| 创建后自动推送 | Demo 可配置在数秒后自动将待推送→待发货，便于演示 |

```
详情页「模拟仓库出库回传」（待发货）
         │
         ▼
┌─ 模拟仓库出库回传（Demo）──────────────────┐
│  各行实出 ≤ 通知数量；可勾选零出            │
│  明细表：通知数量只读，实出可填             │
│              [取消] [确认回传]              │
└────────────────────────────────────────────┘
         │ 取消              │ 确认
         ▼                   ▼
     关闭弹窗            有实出 → 已发货 + 生成出库单
                         零出 → 已取消，不生成出库单
                         缺量 → 已发货 + 缺出展示 + 退货单回补
```

### 5.3 Mock 回传弹窗

| 项目 | 内容 |
| :--- | :--- |
| 标题 | 模拟仓库出库回传（Demo） |
| 正文 | 各行实出数量不能超过通知数量；超过将自动调整为通知数量并提示。实出少于通知量按缺量结束本次执行。勾选零出则整单按取消结束。 |
| 明细展示 | 表格列：行号、商品编码、商品条码、商品名称、通知数量（只读）、实出数量（可填，默认=通知数量） |
| 输入 | 每行实出数量；零出勾选框 |
| 主按钮 | 确认回传 |
| 次按钮 | 取消 |

### 5.4 Mock 回传规则（演示数据）

| 项目 | Mock 规则 |
| :--- | :--- |
| 有实出 | 各行实出≤通知量，且至少一行实出>0；状态→已发货；回写明细实出、缺出=通知量−实出；本地生成演示用采退出库单 |
| 缺量 | 实出<通知量且未勾选零出：按缺量结束，缺出回补退货单可下推量 |
| 零出 | 状态→已取消；实出均为0；释放全部占用；不生成出库单 |
| 超量输入 | 实出>通知量时自动调整为通知量，并提示「实出数量不能超过通知数量，已自动调整为通知数量」 |
| 负值 | 实出<0时阻断并提示「实出数量不能为负数」 |
| 退货单联动 | 同步更新来源采购退货单累计实出、可下推量、在途通知数量 |

Mock 数据在界面标注「演示数据」或「Mock」角标。

### 5.5 Mock 不做的内容

- 不代替正式仓库接口的推送、取消回执与异常处理
- 不在 Mock 中模拟金蝶推送（结果单金蝶状态与重推见系统集成中心）
- 不把 Mock 行为写入主PRD正式验收标准

### 5.6 与采购退货单 Mock 的关系

采购退货单审核后的「生成演示通知单（Mock）」见[《采购退货单前端Demo版PRD_弹窗与Mock》](../../采购退货单/前端Demo版PRD/采购退货单前端Demo版PRD_弹窗与Mock.md)。该 Mock 创建的通知单可继续用本章 Mock 回传串联主链；正式下推创建规则以[新增编辑页 PRD](采退发货通知单前端Demo版PRD_新增编辑页.md) 为准。

### 5.7 离开未保存（表单页）

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 下推创建/编辑备注页点「取消」或路由离开，且存在未保存修改 |
| 弹窗标题 | 离开当前页面？ |
| 正文 | 离开后未保存的内容将丢失。 |
| 确认按钮 | 确认离开 |
| 取消按钮 | 取消 |
| 确认后 | 返回上一页 |

## 6. 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 取消 | 待推送点取消，填原因 | 已取消，退货单占用释放并回补可下推量 |
| 推送失败取消 | 推送失败点取消 | 正文含仓库未接收提示；已取消 |
| 待发货取消 | 待发货点取消 | 取消中，等待回执 |
| 拒绝回执 | 取消中收到仓库拒绝 | 恢复待发货；Toast 仓库拒绝取消，请继续等待发货 |
| 重试 | 推送失败点重试 | 推送中 |
| 自动重试说明 | 查看推送失败单据 | 正式规则为自动重试3次后才出现人工重试；Demo 可直接模拟失败 |
| Mock回传 | 待发货保持实出=通知量并确认 | 已发货，缺出0，退货单数量联动 |
| Mock缺量 | 实出改小于通知量后确认 | 已发货；缺出=差额；退货单可下推量回补缺量 |
| Mock零出 | 勾选零出 | 已取消，不生成出库单 |
| 超量调整 | 实出填超过通知量 | 自动调整为通知量并提示 |
| 离开未保存 | 下推创建有修改后取消 | 弹出离开确认 |

Demo 验证弹窗文案、必填项与 Mock 本地数据联动；不代表生产接口、并发或后端事务行为。
