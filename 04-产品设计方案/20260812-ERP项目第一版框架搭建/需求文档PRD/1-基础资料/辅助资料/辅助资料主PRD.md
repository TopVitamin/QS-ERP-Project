> 用途：定义辅助资料（预置类型下的资料值）和三级商品分类在ERP中的建立、启停和引用控制，作为研发实现和测试验收的依据。

## 二、需求背景与范围

商品、供应商、客户、价格和各类单据都引用一批基础选项，现状是这些选项散落在各系统里，来源不统一。本期在基础资料下增加辅助资料菜单，集中维护预置类型下的资料值，其中商品分类按固定三级维护，商品建档必须选到第三级。

| 对象 | 用途 | 数据来源 | 由哪里维护 | 被哪些业务引用 |
| --- | --- | --- | --- | --- |
| 辅助资料（资料值） | 基本单位、币别、结算方式、品牌、付款条件、收款条件等选项 | 人工维护或系统预置 | 主数据维护人员在基础资料-辅助资料维护 | 商品、供应商、客户、价格与各类单据 |
| 商品分类 | 固定三级的商品分类树；商品引用第三级 | 人工维护 | 主数据维护人员 | 商品建档，以及引用商品分类的业务单据 |

本期做：资料树导航与类型隔离、预置类型下资料值的新增与维护、币别字典维护（不含汇率）、商品分类三级树维护、批量导入、启用禁用与删除控制。

本期不做：资料类型的新增与删除、任意加字段的低代码配置、审核流程、付款节点与比例明细、独立账期配置与到期日推导、单位下的通用箱件换算、汇率维护、历史分类快照（一期业务单据不保存，历史只留商品编码和名称）。

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 类型与隔离 | 资料类型是预置的，不开放新增和删除；不同资料类型的记录互相隔离，不能把付款条件当品牌选择 | 某个类型下没有记录时显示空状态，不自动创建资料值 |
| R02 | 编码与防重 | 资料编码在同类型内唯一，保存时校验重复并阻止保存；币别使用币别代码，界面相应调整名称 | 编码规则见《6.强盛ERP的编码规则和通用字段规则》第二节（Q01）；唯一范围依《实体对象关系》第一节“类型＋资料编码唯一”。各资料类型前缀见下表 |
| R03 | 三级分类 | 商品分类固定三级，级别由归属关系决定：根节点没有上级，二级归属一级，三级归属二级，不允许循环归属 | 可以先建一级、二级，再补三级；三级不能再新增下级 |
| R04 | 分类引用 | 商品建档必须选满“一级→二级→三级”，最终引用启用的第三级，一级和二级随关系带出 | 上级禁用只阻止在其下新增分类，既有启用分类仍可被新商品引用 |
| R05 | 分类调整 | 已建分类可以调整名称和上级，调整后仍满足固定三级与不循环归属 | 当前商品读取最新分类关系；一期业务单据不保存分类快照，历史只留商品编码和名称 |
| R06 | 不审核 | 普通资料和商品分类都不审核，新增保存后默认启用，启用即可被引用 | 启停操作直接生效，没有审核状态 |
| R07 | 引用与变更 | 禁用后不允许新增引用，既有引用保留，不反向禁用业务档案；改名后按实时读取 | 一期不保存分类快照；辅助资料改名后新业务读最新名称 |
| R08 | 删除控制 | 没被引用的记录允许删除；被引用的记录不允许删除；有下级的分类不能删 | 见Q02 |
| R09 | 条件与单位边界 | 付款条件、收款条件只是选项，不拆付款节点和比例，也不自动推导到期日；单位换算由具体商品负责 | 不在单位名称下设置通用的箱件换算；币别不维护汇率 |
| R10 | 批量维护 | 导入普通资料按资料编码匹配：已存在更新非空字段，不存在新增；不审核，导入后默认启用 | 可导入字段与错误行处理按导入中心规则，待确认（Q06）；商品分类是否支持导入待确认（Q06） |

资料类型前缀（系统自增编码；唯一范围是同一资料类型内）：

| 资料类型 | 前缀 | 示例 |
| --- | --- | --- |
| 品牌 | PP | PP0001 |
| 基本单位 | DW | DW0001 |
| 结算方式 | JS | JS0001 |
| 付款条件 | FK | FK0001 |
| 收款条件 | SK | SK0001 |
| 币别 | 用币别代码，不走前缀+序号 | CNY |

商品分类编码不走上表，按层级拼接2位数字（一级01、二级0102、三级010203），系统自动生成；新建下级时自动带出上级代码。规则见[《强盛ERP的编码规则和通用字段规则》](../../../../../01-全局背景信息/6.强盛ERP的编码规则和通用字段规则.md)第二节。

### 4.2 F01 资料树导航

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 主数据维护人员在不同资料类型之间切换，维护对应选项。 |
| 操作与处理 | 左侧按分组展示预置资料类型：公共资料（基本单位、币别、结算方式）、商品资料（商品分类、品牌）、采购资料（付款条件）、销售资料（收款条件）；支持按名称搜索、展开和收起；选中类型后右侧只显示该类型的记录。 |
| 功能规则 | 类型预置，不开放新增和删除（R01）；左侧导航的层级和商品分类自身的三级结构是分开的。 |
| 成功结果 | 右侧标题和内容随选中类型切换，不混入其他类型记录。 |
| 异常与恢复 | 类型下没有记录时显示空状态和新增入口。 |

### 4.3 F02 普通资料维护

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 需要新的品牌、单位、币别或收付款条件时维护。 |
| 操作与处理 | 右侧按资料编码、名称、使用状态查询；列表显示编码、名称、状态和备注，支持新增、查看、编辑、启用、禁用和删除；新增和编辑使用相同表单，资料类型由当前节点带入。 |
| 功能规则 | 新增和编辑校验编码不重复（R02）；付款条件和收款条件只维护选项值（R09）；启用后即可被业务引用（R06）；批量启用、禁用作为操作便利，不另建审批流程。 |
| 成功结果 | 新增或更新一条资料值，启用后出现在对应业务的选择项中。 |
| 异常与恢复 | 校验不通过时阻止保存并保留已填内容；被引用的记录不能删除（R08）。 |

### 4.4 F03 商品分类维护

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 商品建档前准备分类目录，或在经营过程中补充、调整分类。 |
| 操作与处理 | 右侧以树形表格显示分类名称、编码、级别、使用状态和操作；顶部新增一级；一级、二级行内新增下级并自动带入上级；编辑时可调整名称和上级；三级不能再新增下级。 |
| 功能规则 | 分类固定三级，级别由归属关系决定，不允许循环归属（R03）；商品必须选满三级并引用启用的第三级（R04）；调整已引用分类的上级仍要满足三级结构（R05）。 |
| 成功结果 | 分类树按维护结果显示，启用分类可在商品建档时选择。 |
| 异常与恢复 | 上级禁用时不能在其下新增分类，提示原因；归类不符合层级或形成循环时阻止保存。 |

### 4.5 F04 启用、禁用与删除

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 选项或分类不再使用，或建档后发现重复、录错。 |
| 操作与处理 | 在列表或树形表格行内启用、禁用；删除只对未被引用的记录开放。 |
| 功能规则 | 禁用后不允许新增引用，既有引用保留，不反向禁用业务档案（R07）；被引用的记录不能删除（R08）；上级分类禁用不级联下级（R04）。 |
| 成功结果 | 新增引用立即受控，历史业务不受影响；重新启用后恢复可选。 |
| 异常与恢复 | 被引用时删除不可用并说明原因；有下级的分类不能删。 |

### 4.6 F05 批量导入

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 初期建档量大或集中维护辅助资料。 |
| 操作与处理 | 在普通资料列表使用导入，按资料编码匹配，已存在更新非空字段，不存在新增（R10）。 |
| 功能规则 | 导入不增加审核流程（COM-FR02）；导入的记录使用状态默认为启用。 |
| 成功结果 | 资料值批量建立或更新，结果按成功、失败分别可见。 |
| 异常与恢复 | 失败行不写入并给出原因，修正文件后重新导入；错误处理细节按导入中心规则。 |

### 4.7 状态与动作

辅助资料与商品分类只有一个使用状态，不审核。

| 状态 | 含义 | 进入条件 | 是否终态 |
| --- | --- | --- | --- |
| 启用 | 可被新增引用 | 新建保存或人工启用 | 否 |
| 禁用 | 停止新增引用，既有引用保留 | 人工禁用 | 否 |

| 当前状态 | 动作/事件 | 前置条件 | 结果与业务影响 | 失败处理 |
| --- | --- | --- | --- | --- |
| 无（新建） | 保存 | 名称、编码等校验通过 | 建档成功，使用状态为启用 | 校验失败阻止保存 |
| 启用 | 禁用 | 无特殊限制 | 新增引用停止；历史业务保留引用 | 无 |
| 禁用 | 启用 | 无 | 恢复新增引用 | 无 |
| 启用／禁用（商品分类） | 新增下级 | 当前分类为一级或二级，且自身启用 | 生成带入上级的下级分类 | 三级、自身禁用或上级禁用时阻止 |
| 启用／禁用 | 删除 | 未被引用 | 记录移除 | 被引用时阻止并提示 |
| 启用／禁用（商品分类） | 调整上级 | 调整后仍满足三级结构与不循环归属 | 分类树更新；当前商品按最新关系读取 | 不符合结构时阻止保存 |

## 六、验收标准与待确认事项

### 6.1 验收标准

| 编号 | 对应功能/规则 | 条件与操作 | 预期结果 |
| --- | --- | --- | --- |
| AC01 | F01、R01 | 切换左侧的品牌、结算方式等资料节点并查询 | 右侧显示对应类型的记录，不混入其他类型（AUX-AC01） |
| AC02 | F02、R06 | 新增品牌、币别或条件并启用 | 不用审核就可以在对应业务中选择；条件仍然只是一组选项，不产生计算规则（AUX-AC03） |
| AC03 | F03、R03、R04 | 建立三级分类，尝试新增第四级，再分别选一级、二级、三级建商品 | 不允许第四级；商品只选一级或二级不能提交，选完整三级路径可以引用，前两级随关系带出（AUX-AC02） |
| AC04 | F03、R05 | 禁用上级分类后新增下级，再用既有启用的三级分类建商品；之后调整已引用分类的上级 | 禁用的上级不能再新增下级；既有启用分类仍可引用；符合三级结构的调整允许，当前商品按最新关系读取；一期不另存分类快照（AUX-AC05） |
| AC05 | F02、R02 | 同类型内用已存在的资料编码新增记录 | 阻止保存并提示编码重复 |
| AC06 | F04、R07 | 禁用已经被引用的资料，再创建新的业务引用 | 不允许新增引用，原有档案的引用保留且不被连带禁用（AUX-AC04） |
| AC07 | F04、R08 | 分别删除没被引用和已被引用的资料；再删一个有下级、下级还没被商品引用的分类 | 没被引用的可以删，已被引用的不能删；有下级的分类不能删（Q02、AUX-AC06） |
| AC08 | F05、R10 | 导入普通资料数据 | 导入后不增加审核，默认启用，可直接被引用（COM-AC02） |

### 6.2 待确认事项
