# 商品资料前端Demo版PRD·详情页

> 模板版本：V2
> 文档版本：V0.2｜日期：2026-09-23｜状态：初稿，待评审。
> 本文说明商品档案只读详情、信息分组和允许的后续操作。业务条件见[《商品资料主PRD》](../商品资料主PRD.md)，字段含义和显示属性见[《商品资料（详细稿）》](../../../../字段清单合集/基础资料/商品资料/商品资料（详细稿）.tsv)。

关联资料：[《商品资料页面骨架》](../商品资料页面骨架.md)、[列表页](商品资料前端Demo版PRD_列表页.md)、[新增编辑页](商品资料前端Demo版PRD_新增编辑页.md)、[弹窗与Mock](商品资料前端Demo版PRD_弹窗与Mock.md)、[《原型开发说明》](../../../../../../09-产品原型/原型开发说明.md)。字段显示按TSV；公共布局与格式引用原型规范。

## 1. 页面概述

| 项目 | 说明 |
| --- | --- |
| 页面名称 | 商品详情 |
| 入口 | 商品列表点击商品编码 |
| 页面目标 | 查看商品档案的当前信息，并进入编辑或维护使用状态 |
| 容器 | 独立页面 |
| 返回 | 返回商品列表，保留原查询条件和页码 |
| 本页功能 | 主PRD F01、F05；商品分发结果不在本页维护 |

## 2. 页头

页头单行展示标题、使用状态及操作按钮；按钮顺序为“返回列表”、“编辑”、当前状态对应的“禁用”或“启用”、“删除”。商品不展示审核状态。

| 按钮 | 条件 | 行为 |
| --- | --- | --- |
| 返回列表 | 始终显示 | 返回原列表位置，保留筛选条件和页码 |
| 编辑 | 始终显示 | 进入编辑商品页；保存后回到详情并刷新信息 |
| 禁用 | 使用状态为启用 | 打开禁用确认弹窗；确认后刷新详情 |
| 启用 | 使用状态为禁用 | 直接启用并刷新详情 |
| 删除 | 商品未被单据或价目表引用 | 打开删除确认弹窗；删除成功后返回列表并提示“商品已删除” |

商品已被引用时删除按钮不可用，并说明原因。确认弹窗正文见[弹窗与Mock PRD](商品资料前端Demo版PRD_弹窗与Mock.md)。按钮可用条件引用主PRD F05及状态表。

## 3. 信息分区与字段

字段顺序遵循详细稿中的分组和字段顺序。只读区按6列栅格展示，标签在上、值在下；长文本按整段换行。商品条码仍属基础信息，单独成卡片，放在基础信息之后、经营与状态之前。未维护的普通字段显示 `-`。

| 分区 | 字段 | 展示说明 |
| --- | --- | --- |
| 基础信息 | 商品编码、商品名称、商品简称、助记码、商品分类、品牌、产品型号、规格描述、基本单位、产地、商品备注 | 商品分类显示完整三级路径；规格描述和备注换行 |
| 商品条码 | 商品条码 | 每条一行；未维护显示 `-` |
| 经营与状态 | 商品销售等级、商品生命周期状态、使用状态、首次上市日期、停售日期 | 使用状态显示状态标签；销售等级为空时显示“未评级” |
| 价格信息 | 初始供应商、初始含税采购价、初始含税销售价、币别 | 单价按4位小数、千分位展示；币别独立按「编码 名称」展示，不拼入单价；空值显示 `-` |
| 开票信息 | 商品开票名称、商品开票规格型号、商品税收分类编码、默认销售税率 | 税率显示百分比；空字段显示 `-` |
| 重量与尺寸 | 商品净重、商品长度、商品宽度、商品高度、外箱毛重、外箱长度、外箱宽度、外箱高度 | 使用字段清单定义的kg、cm单位；空字段显示 `-` |
| 包装与单位 | 外箱装箱数量、辅助计量单位、单位换算数量 | 按字段清单展示；此处只展示资料，不执行单位换算 |
| 库存预警 | 是否启用库存预警、最低库存数量、最高库存数量、安全库存数量 | 布尔值显示“是／否”；数量按基本单位展示 |
| 管理属性 | 是否含电池、是否批次管理、是否序列号管理、是否保质期管理、保质期天数、临期预警天数 | 布尔值显示“是／否”；天数显示单位“天” |
| 商品图片 | 主视图、左视图、右视图、顶视图、底视图、背视图、全景图 | 已上传图片显示缩略图，点击放大；未上传位置显示占位图 |
| 维护信息 | 创建人、创建时间、最后更新人、最后更新时间 | 系统记录只读展示；用户字段只显示姓名 |

关联资料按全局Code-Name规则展示；单价、日期时间、空值和图片预览沿用原型公共规范。数值字段为0时按0展示，只有未填写时显示`-`。商品详情页不增加字段清单以外的信息块。

## 4. 操作与反馈

| 场景 | 结果 |
| --- | --- |
| 进入详情 | 显示加载状态，加载完成后展示当前商品信息 |
| 商品不存在 | 显示“商品不存在或已删除”，提供返回列表操作 |
| 加载失败 | 显示“商品资料加载失败，请重试”，提供重试和返回列表 |
| 禁用成功 | Toast：“商品已禁用，新业务不能再选择”；刷新使用状态 |
| 启用成功 | Toast：“商品已启用”；刷新使用状态 |
| 删除成功 | Toast：“商品已删除”；返回商品列表并保留查询条件和页码 |
| 编辑保存成功 | Toast：“商品已保存”；返回当前商品详情并刷新 |

禁用失败、删除规则和二次确认文案见主PRD及弹窗与Mock PRD；本页不重复维护弹窗正文。

## 5. Mock与验收

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 完整资料 | 打开包含各类资料的虚构商品 | 分组顺序与详细稿一致，金额、单位、日期显示正确 |
| 空字段 | 打开未维护开票资料、图片和可选字段的商品 | 普通空值显示 `-`，等级为空显示“未评级”，未上传图片显示占位 |
| 多条码 | 打开包含多个条码的商品 | 商品条码卡片中每条独立一行，不合并成一长串 |
| 状态操作 | 分别打开启用和禁用商品 | 启用商品可禁用；禁用商品可启用；不显示不适用按钮 |
| 返回列表 | 从带筛选条件和页码的列表进入详情再返回 | 恢复原筛选条件和页码 |

本Demo只模拟页面和本地数据状态，不代表真实接口、并发或后端事务已验证。
