# 商品资料前端Demo版PRD·新增编辑页

> 模板版本：V2
> 文档版本：V0.2｜日期：2026-09-23｜状态：初稿，待评审。
> 本文说明商品建档和编辑页面。字段名称、属性、必填性与字段分组以[《商品资料（详细稿）》](../../../../字段清单合集/基础资料/商品资料/商品资料（详细稿）.tsv)为准；业务动作和规则以[《商品资料主PRD》](../商品资料主PRD.md)为准。页面分区见[《商品资料页面骨架》](../商品资料页面骨架.md)。

关联资料：[列表页](商品资料前端Demo版PRD_列表页.md)、[详情页](商品资料前端Demo版PRD_详情页.md)、[弹窗与Mock](商品资料前端Demo版PRD_弹窗与Mock.md)、[《UI布局公共说明》](../../../../../../05-常用模板/02-模块设计交付/UI布局公共说明.md)、[《原型开发说明》](../../../../../../09-产品原型/原型开发说明.md)。

## 1. 页面概述

| 项目 | 新增 | 编辑 |
| --- | --- | --- |
| 页面名称 | 新增商品 | 编辑商品 |
| 入口 | 商品列表“新增” | 商品列表或详情页“编辑” |
| 页面目标 | 建立可供采购、销售、库存和价格引用的成品SKU | 修改允许编辑的商品资料 |
| 页头 | 标题及“取消”“保存” | 标题、当前使用状态及“取消”“保存” |
| 保存后 | 返回列表并提示“商品已保存” | 从列表进入时返回原列表；从详情进入时返回详情并刷新，保留原筛选与页码 |

商品无审核流程。新增页不显示使用状态标签，默认保存为启用；编辑页的编码和初始价格信息只读。

## 2. 表单分组与字段

表单按详细稿分组排序，查询和编辑页面采用6列栅格，标签在上、控件在下。商品条码仍属基础信息，因一条商品可维护多条，单独成卡片，放在基础信息卡片之后、经营与状态之前，不进入6列栅格。字段属性以TSV为准；下面仅补充控件、页面差异和跨字段联动。

| 分组 | 字段 | 控件与页面表现 | 新增／编辑差异及联动 |
| --- | --- | --- | --- |
| 基础信息 | 商品编码 | 输入框；支持系统生成或手工录入 | 新增可录入；编辑只读；保存后不可改，编码格式和生成规则见全局编码规则 |
| 基础信息 | 商品名称 | 单行输入框 | 必填 |
| 基础信息 | 商品简称、助记码 | 单行输入框 | 均为可选字段 |
| 基础信息 | 商品分类 | 三级联动选择器 | 必须选到第三级；保存时引用第三级，前两级按归属带出 |
| 基础信息 | 品牌 | 下拉选择 | 仅可选择启用品牌；可为空 |
| 基础信息 | 产品型号 | 单行输入框 | 可选 |
| 基础信息 | 规格描述 | 多行输入框 | 可选；集中填写颜色、功率、容量、线长、接口、插头规格等，不另设独立字段 |
| 基础信息 | 基本单位 | 下拉选择 | 必填；仅可选启用的基本单位 |
| 基础信息 | 商品条码 | 独立卡片。一个输入框，回车或点击“添加”后逐条列在下方，每条可删除；未添加时不显示空行 | 新增和编辑可维护；每条单独保存，全系统唯一。同一商品内重复或已被其他商品使用时，提示留在输入框下，不写入列表 |
| 基础信息 | 产地 | 国家／地区下拉 | 可选；单选一个国家或地区 |
| 基础信息 | 商品备注 | 多行输入框 | 可选 |
| 经营与状态 | 商品销售等级 | 下拉：S、A、B、C、未评级 | 新增默认“未评级”；人工维护，系统不校验评级过程 |
| 经营与状态 | 商品生命周期状态 | 下拉：在售、停售、试销、淘汰 | 新增默认“在售” |
| 经营与状态 | 使用状态 | 只读文本 | 新增默认启用；编辑显示当前值，通过列表或详情的启用／禁用操作变更 |
| 经营与状态 | 首次上市日期、停售日期 | 日期选择 | 可选 |
| 价格信息 | 初始供应商 | 供应商选择器 | 新增可选；初始含税采购价有值时必填；编辑只读；仅选审核通过且启用的供应商 |
| 价格信息 | 初始含税采购价 | 金额输入 | 新增可选；有值时初始供应商和币别必填；编辑只读；单价精度见全局价格规则 |
| 价格信息 | 初始含税销售价 | 金额输入 | 新增可选；有值时币别必填；编辑只读 |
| 价格信息 | 币别 | 下拉选择 | 新增可选；任一初始价格有值时必填；编辑只读 |
| 开票信息 | 商品开票名称、商品开票规格型号、商品税收分类编码 | 单行输入框 | 可选，均允许为空 |
| 开票信息 | 默认销售税率 | 百分比输入 | 可选，最多2位小数；为空时由开单人员按业务规则填写 |
| 重量与尺寸 | 商品净重、商品长度、商品宽度、商品高度、外箱毛重、外箱长度、外箱宽度、外箱高度 | 数值输入；单位按字段清单显示kg或cm | 可选 |
| 包装与单位 | 外箱装箱数量、辅助计量单位、单位换算数量 | 数值输入、单位选择及对应明细 | 可选；一期不执行单位换算，订单和价目仍按基本单位 |
| 库存预警 | 是否启用库存预警 | 开关 | 新增默认关闭；编辑显示当前配置 |
| 库存预警 | 最低库存数量 | 正整数输入，以基本单位计 | 启用库存预警后必填；手工录入须大于0；低于该值触发预警 |
| 库存预警 | 最高库存数量 | 正整数输入，以基本单位计 | 手工录入须大于0；是否条件必填、是否触发超储预警及其口径见主PRD Q15；确认前不作为保存校验条件 |
| 库存预警 | 安全库存数量 | 正整数输入，以基本单位计 | 手工录入须大于0；只展示、不触发预警；是否条件必填见主PRD Q15，确认前不作为保存校验条件 |
| 管理属性 | 是否含电池 | 布尔控件 | 可选；新增默认值见主PRD Q16，确认前不预设为“不含电池” |
| 管理属性 | 是否批次管理、是否序列号管理、是否保质期管理 | 开关 | 新增默认关闭；批次、序列号、保质期一期仅配置，不在入出库采集 |
| 管理属性 | 保质期天数 | 数值输入，单位“天” | 启用保质期管理后条件必填 |
| 管理属性 | 临期预警天数 | 数值输入，单位“天” | 可选 |
| 商品图片 | 主视图、左视图、右视图、顶视图、底视图、背视图、全景图 | 每个图片位支持上传、预览、删除 | 可选；格式、大小和上传限制见全局附件规则 |

新增和编辑页不展示创建人、创建时间、最后更新人、最后更新时间；这些字段由系统记录，在详情页查看。

## 3. 操作与校验

保存时校验以下条件。字段类型、必填性和其他取值要求仍以详细稿及其引用规则为准。

| 校验对象 | 时机 | 失败表现 |
| --- | --- | --- |
| 商品名称 | 点击保存 | 定位到字段并提示“商品名称不能为空” |
| 商品分类 | 点击保存 | 未选到第三级时定位分类字段并提示“请选择三级商品分类” |
| 基本单位 | 点击保存 | 未选择时定位字段并提示“请选择基本单位” |
| 商品编码 | 点击保存 | 重复时提示“商品编码已存在”；已填内容保留 |
| 商品条码 | 添加条码或点击保存 | 本商品已有相同条码，或已被其他商品使用时，提示“该条码已被使用”。添加时不写入列表；保存时阻止保存 |
| 初始价格 | 点击保存 | 采购价有值但供应商为空时提示“请选择初始供应商”；任一初始价格有值但币别为空时提示“请选择币别” |
| 库存预警 | 点击保存 | 启用库存预警后最低库存数量未填写时定位字段；数量不是大于0的整数时定位对应字段并提示“库存数量须为大于0的整数”；最高库存与安全库存的必填校验按主PRD Q15确认前不执行 |
| 保质期管理 | 点击保存 | 开启保质期管理但保质期天数为空时定位相应字段 |

金额、编码、条码和文本长度校验遵循全局字段规则。商品分类、品牌、单位、供应商只能引用符合对应状态条件的资料。未在权威资料定义的数值上下界、重量精度或字段间大小关系不在本页补造。

| 操作 | 页面结果 |
| --- | --- |
| 保存成功 | 按入口返回列表或详情，刷新商品信息并提示“商品已保存” |
| 保存失败 | 留在当前页，保留已填内容，显示字段错误或“保存失败，请重试” |
| 取消或返回且没有未保存修改 | 直接返回来源页面 |
| 取消或返回且有未保存修改 | 打开离开确认弹窗，正文见弹窗与Mock PRD |

商品保存与F02生成初始价格记录须一致完成；任一步骤失败时商品和对应价目不得只成功一侧。页面失败反馈见第5节和主PRD F02。

## 4. 页面状态与反馈

| 场景 | 页面表现 | 文案或恢复方式 |
| --- | --- | --- |
| 保存中 | 保存按钮显示加载状态并阻止重复点击 | — |
| 保存成功 | 返回来源页面，刷新信息 | 商品已保存 |
| 字段校验失败 | 停留当前页、聚焦错误字段、保留输入 | 按第3节的字段级文案 |
| 请求失败 | 停留当前页并保留全部输入 | 保存失败，请重试 |
| 离开未保存页面 | 弹窗阻止意外离开 | 见弹窗与Mock PRD |

## 5. Mock与验收

| 场景 | 前置条件 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 新建基础商品 | 准备启用的三级分类、单位 | 填写商品名称、三级分类和基本单位后保存 | 建档成功，商品默认为启用 |
| 编码生成与手工录入 | 准备可用三级分类 | 分别使用系统生成编码和手工编码 | 两种方式均按全局编码规则校验；保存后不可修改 |
| 多条码 | 准备两个未使用条码 | 在商品条码卡片中添加多条并保存，再复开详情 | 基础信息栅格中无条码输入；每条条码在商品条码卡片中逐条保留 |
| 条码重复 | Mock中已有相同条码 | 保存另一商品时添加重复条码 | 阻止保存，输入内容保留并提示重复 |
| 初始价格完整 | 选启用供应商、币别并填写初始价格 | 保存商品 | 模拟生成相应采购价和／或销售基准价记录 |
| 初始价格为空 | 采购价、销售价均留空 | 保存商品 | 建档成功，不生成对应价目 |
| 条件必填 | 填采购价不选供应商，或填写价格不选币别 | 保存商品 | 阻止保存并定位到缺失字段 |
| 管理项 | 打开库存预警或保质期管理；另将库存阈值输入0、负数或小数 | 保存 | 最低库存、保质期天数留空时阻止保存；库存阈值只接受正整数；最高库存、安全库存的必填校验待Q15确认 |
| 退出未保存页面 | 修改任一字段后点击取消 | 在离开确认框选择继续编辑或确认离开 | 继续编辑留在当前页；确认离开返回来源页面 |

演示数据及保存结果均为本地Mock。演示不代表真实接口、并发或后端事务已验证。
