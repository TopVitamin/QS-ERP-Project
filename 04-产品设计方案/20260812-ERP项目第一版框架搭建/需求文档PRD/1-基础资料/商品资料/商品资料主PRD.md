## 二、需求背景与范围

商品是采购、销售、库存和价格共同引用的业务对象。现状是多套系统各自维护SKU，编码不一致，回传结果靠人工映射。本期在ERP建立统一的成品SKU档案，一次建档、全业务引用，并按主数据规则分发到第三方WMS与财务ERP。

| 对象 | 用途 | 数据来源 | 由哪里维护 | 被哪些业务引用 |
| --- | --- | --- | --- | --- |
| 商品（成品SKU） | 采购、销售、库存、价格的统一对象；开票资料与重量尺寸随单带出 | 人工建档，支持批量导入 | 商品开发与管理人员在“基础资料-商品资料”维护 | 采购订单与退货、销售订单与出库、采购与销售价目表、库存记账、WMS与财务ERP分发 |

本期做：商品建档与编辑、查看、批量导入、单条及批量启用禁用、符合条件的单条删除、初始供应商与初始价格、库存预警与批次序列号保质期配置、七个图片位与多条码、SKU分发到WMS和财务ERP。

本期不做：SPU与两级商品模型、原材料与BOM／MRP、商品与供应商的供货关系、向领星和聚水潭全量推送商品资料、历史主数据的清洗与迁移（见Q09）、商品删除后的恢复、入出库采集批次序列号保质期。

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 编码与防重 | 商品编码是唯一识别依据，保存时校验重复并阻止保存；一经保存不可修改；商品条码全系统唯一，同一商品内及跨商品均不可重复；商品名称允许重复 | 编码规则见《6.强盛ERP的编码规则和通用字段规则》第二节（Q01）；条码见该文Q15 |
| R02 | 分类引用 | 商品必须选满“一级→二级→三级”，保存时引用第三级，前两级随归属带出 | 上级分类禁用不级联，既有启用的三级分类仍可被新商品引用 |
| R03 | 税率带出 | 商品维护默认销售税率，销售取价和销售单据据此带出税率；允许为空，开单时再填 | 精度按百分比最多2位小数（Q10） |
| R04 | 引用与变更 | 商品被业务引用后，改名、调整分类或配置不改历史单据；单据保留当时的商品名称、价格与税率快照。一期不保存分类快照，当前商品读取最新分类关系 | 生成单据时从商品资料带出并固化名称、价格与税率，取值时点为建单保存时；快照字段与展示位置见各业务单据字段清单 |
| R05 | 删除控制 | 只有从未发生采购、未被任何业务单据引用且没有采购或销售价目表记录的商品可以删除；其余商品只能禁用。删除不可恢复，禁用可再启用；不提供批量删除 | 见Q06 |
| R06 | 批量导入 | 商品导入不增加审核流程；编码匹配、字段更新和错误处理按确认后的导入规则执行 | 可导入字段、重复编码处理、空值处理及错误行规则待确认（Q07） |

### 4.2 F01 商品档案维护

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 商品开发与管理人员完成寻源后建立成品SKU，供采购、销售、库存和价格引用。 |
| 操作与处理 | 在商品列表新增，填写基础信息、经营与状态、价格信息、开票信息、重量与尺寸、包装与单位、图片和管理配置，保存后商品可被业务选择。列表支持按关键词（编码、名称、简称、助记码、型号、条码）、商品分类、品牌、商品销售等级、商品生命周期状态、使用状态和最后更新时间查询；详情查看全部信息。列表默认列、可选列及匹配方式见[《商品资料前端Demo版PRD·列表页》](前端Demo版PRD/商品资料前端Demo版PRD_列表页.md)第2节和第4节。 |
| 功能规则 | 保存校验：商品名称必填，三级分类必须选满，基本单位必填，编码不重复，条码全系统不重复（R01、R02）；默认销售税率按R03；开票资料、重量尺寸和图片不强制。初始价格允许为空。其余必填性见《商品资料（详细稿）》。 |
| 成功结果 | 生成一条可用的商品记录，使用状态为启用；按F02生成初始价格。 |
| 异常与恢复 | 校验不通过时阻止保存并定位到字段，已填内容保留；编码重复时提示修改后重试，不自动改号。保存后编码不可改。 |

### 4.3 F02 价格初始化

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 商品建档时确定初始采购价格归属和初始售价。 |
| 操作与处理 | 在新增页维护初始供应商、初始含税采购价、初始含税销售价和币别；保存成功时按规则生成价格记录。 |
| 功能规则 | 初始含税采购价和初始含税销售价均允许为空；非空时必须大于0，按`PRICE_4`最多保留4位小数。采购价有值时初始供应商和币别必填；销售价有值时币别必填。有价时按初始供应商和币别生成一条采购价，按币别和所有客户范围生成一条销售基准价；空价不生成对应价目，新单手填。初始供应商只表示价格归属，不建立供货关系，也不限制以后向谁采购（PRI-FR01）。后续变价走价格调整单，不在商品档案修改（R04）。 |
| 成功结果 | 采购价目表和销售价目表出现对应记录，采购与销售业务可以取价。 |
| 异常与恢复 | 初始价格允许为空，不阻断建档（Q04）；空价不生成对应价目。非空价格为0、负数或超过4位小数时阻止保存，并定位对应价格字段。建档后初始供应商和初始价格不能改。商品保存与价格记录生成需要一致完成；页面失败反馈见[新增编辑页PRD](前端Demo版PRD/商品资料前端Demo版PRD_新增编辑页.md)和[弹窗与Mock PRD](前端Demo版PRD/商品资料前端Demo版PRD_弹窗与Mock.md)。 |

### 4.4 F03 商品管理配置

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 商品需要参与库存预警、批次、序列号、保质期管理时配置。 |
| 操作与处理 | 在新增／编辑页维护是否启用库存预警、最低／最高／安全库存数量，以及批次、序列号、保质期配置；保存后供库存模块和WMS读取。 |
| 功能规则 | 配置由商品维护。批次、序列号、保质期一期只在商品上配置开关和天数，入出库不采集（MD-FR10）。保质期天数在启用保质期管理后使用。最低库存触发预警；安全库存只展示、不触发。一期不做适用仓库，按商品配一套阈值（Q05）。库存预警、批次、序列号、保质期管理等配置开关新增默认关闭。启用库存预警时最低库存数量必填；最高库存和安全库存的条件必填范围，以及最高库存是否触发超储预警，见Q15。库存阈值按全局QTY_INT规则手工录入正整数。 |
| 成功结果 | 配置保存一致，库存模块及WMS按确认接口可读取或接收。 |
| 异常与恢复 | 配置保存失败时保留已填内容；执行效果按后续库存及接口规则验收，不在本模块处理。 |

### 4.5 F04 商品分发与外部匹配

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 商品建档后需要被第三方WMS和财务ERP识别；领星、聚水潭按SKU编码或确认后的对应关系识别回传结果。 |
| 操作与处理 | 通过系统集成能力把SKU分发到WMS、财务ERP、聚水潭、领星（2026-09-24确认）；外部商品映射在商品资料模块的独立页面按「平台＋店铺」维护多条外部编码，修改权限按角色（2026-09-24确认，具体字段与页面设计随本PRD下一轮补充）。分发字段与触发时机见Q08。 |
| 功能规则 | 分发失败不阻止内部业务继续，向下游发送单据时由失败反馈进入异常处理；外部商品映射在商品资料独立页面维护，不单独设系统集成-外部映射页（2026-09-24确认；MD-FR06、INT-FR04）。 |
| 成功结果 | 分发状态可查；外部系统能按映射识别ERP SKU。 |
| 异常与恢复 | 分发失败的记录在系统集成中心查看（INT-FR05）；重试或其他恢复方式按接口方案确认（Q08）。 |

外部同步按需说明：

| 方向及数据 | 触发时机 | 匹配依据 | 新增／更新边界 | 失败、重复与重试 |
| --- | --- | --- | --- | --- |
| ERP到第三方WMS、财务ERP、聚水潭、领星：商品（成品SKU） | 待接口方案确认（Q08） | 商品编码及商品资料维护的外部映射 | 商品字段与外部映射均由商品资料维护；字段范围及更新方式待确认（Q08） | 失败记录在推送异常-主数据分发查看；重试或其他恢复方式待接口方案确认（Q08）；不因分发失败阻断内部业务 |

### 4.6 F05 启用、禁用与删除

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 商品停售、暂停使用，或建档后发现重复、录错。 |
| 操作与处理 | 在列表或详情单条启用、禁用或删除；列表支持批量启用和批量禁用，不支持批量删除。删除只对符合R05条件的商品开放。 |
| 功能规则 | 禁用后新业务不能选择该商品，已有单据和价目表保留原引用与快照（R04）。批量启用时所选商品必须全部为禁用状态；批量禁用时必须全部为启用状态，混合状态或不满足前置状态时整批阻止，不部分执行。被采购或被单据、价目表引用的商品不能删除（R05）。 |
| 成功结果 | 新单可选性立即变化，历史业务不受影响；重新启用后恢复可选。 |
| 异常与恢复 | 商品曾发生采购、被业务单据引用或存在价目表记录时删除不可用并说明原因；删除后不能恢复。禁用不影响任何已保存业务，需要时重新启用即可。批量动作状态不符时整批不执行并提示。 |

### 4.7 F06 批量导入

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 初期建档量大或集中维护商品资料。 |
| 操作与处理 | 在列表页进入公共导入能力，按Q07确认后的商品导入规则处理。 |
| 功能规则 | 商品不审核，导入不增加审核流程（COM-FR02）；编码匹配、字段更新、空值及错误行处理由导入中心规则确认（Q07）。 |
| 成功结果 | 导入结果由公共导入能力反馈；商品无审核流程，导入不增加审核环节。 |
| 异常与恢复 | 错误行处理与重新导入方式按Q07确认后的导入中心规则执行。 |

### 4.8 状态与动作

商品不审核，只有一个使用状态。

| 状态 | 含义 | 进入条件 | 是否终态 |
| --- | --- | --- | --- |
| 启用 | 可被新业务引用 | 建档成功，或由禁用恢复 | 否 |
| 禁用 | 停止新增引用 | 人工禁用 | 否 |

| 当前状态 | 动作/事件 | 前置条件 | 结果与业务影响 | 失败处理 |
| --- | --- | --- | --- | --- |
| 无（新建） | 保存 | 商品名称、三级分类、基本单位、编码等校验通过 | 建档成功，使用状态为启用，按F02生成初始价格（空价不生成） | 校验失败阻止保存 |
| 启用 | 禁用 | 无特殊限制，已被引用也可禁用 | 新单不能选择，历史单据与价目表保留引用 | 无 |
| 禁用 | 启用 | 无 | 新单恢复可选 | 无 |
| 启用／禁用 | 删除 | 从未发生采购、无业务单据引用且无采购或销售价目表记录 | 记录移除 | 任一采购、单据或价目表关联存在时阻止并提示 |

## 六、验收标准与待确认事项

### 6.1 验收标准

| AC09 | F06、R06 | 按Q07确认的商品导入规则验证编码匹配、字段更新、空值及错误行处理 | 导入结果符合确认后的导入规则；商品不因导入增加审核（COM-AC02） |
| AC10 | F05 | 分别全选禁用商品批量启用、全选启用商品批量禁用；再测试混合使用状态的选择 | 同状态且满足前置条件时整批更新；混合状态或存在不符合前置状态的记录时整批阻止、不部分执行；列表不提供批量删除 |
| AC10 | F01、R01 | 建立两条名称相同、商品编码不同且条码不重复的商品 | 保存成功；名称不参与唯一性校验，商品编码和条码仍分别校验唯一 |
