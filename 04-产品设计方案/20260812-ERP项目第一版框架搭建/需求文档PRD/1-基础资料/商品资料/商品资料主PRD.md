## 二、需求背景与范围

商品是采购、销售、库存和价格共同引用的业务对象。现状是多套系统各自维护SKU，编码不一致，回传结果靠人工映射。本期在ERP建立统一的成品SKU档案，一次建档、全业务引用，并按主数据规则分发到第三方WMS与金蝶。

| 对象 | 用途 | 数据来源 | 由哪里维护 | 被哪些业务引用 |
| --- | --- | --- | --- | --- |
| 商品（成品SKU） | 采购、销售、库存、价格的统一对象；开票资料与重量尺寸随单带出 | 人工建档，支持批量导入 | 商品开发与管理人员在“基础资料-商品资料”维护 | 采购订单与退货、销售订单与出库、采购与销售价目表、库存记账、WMS与金蝶分发 |

本期做：商品建档与编辑、查看、批量导入、启用禁用与删除控制、初始供应商与初始价格、库存预警与批次序列号保质期配置、七个图片位与多条码、SKU分发到WMS和金蝶。

本期不做：SPU与两级商品模型、原材料与BOM／MRP、商品与供应商的供货关系、向领星和聚水潭全量推送商品资料、历史主数据的清洗与迁移（见Q09）、商品删除后的恢复。

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 编码与防重 | 商品编码是唯一识别依据，保存时校验重复并阻止保存 | 编码规则见《6.强盛ERP的编码规则和通用字段规则》第二节（Q01） |
| R02 | 分类引用 | 商品必须选满“一级→二级→三级”，保存时引用第三级，前两级随归属带出 | 上级分类禁用不级联，既有启用的三级分类仍可被新商品引用 |
| R03 | 税率带出 | 商品维护默认销售税率，销售取价和销售单据据此带出税率 | 取值、精度与修改范围待确认（Q10） |
| R04 | 引用与变更 | 商品被业务引用后，改名、调整分类或配置不改历史单据；单据保留当时的商品名称、分类、价格与税率快照 | 历史快照的保存字段与展示位置由各业务PRD定义 |
| R05 | 删除控制 | 未被单据或价目表引用的商品可以删除；被引用的不能删除，只能禁用 | 删除后的恢复与未完成单据处理待确认（Q06） |
| R06 | 批量维护 | 导入按商品编码匹配：已存在更新非空字段，不存在新增；商品不审核，导入后直接可用 | 可导入字段、更新范围与错误行处理按导入中心规则，待确认（Q07） |

### 4.2 F01 商品档案维护

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 商品开发与管理人员完成寻源后建立成品SKU，供采购、销售、库存和价格引用。 |
| 操作与处理 | 在商品列表新增，填写基础信息、经营与状态、价格信息、开票信息、重量与尺寸、包装与单位、图片和管理配置，保存后商品可被业务选择。列表支持按关键词（编码、名称、条码）、商品分类、品牌、商品销售等级和使用状态查询；详情查看全部信息。 |
| 功能规则 | 保存校验：商品名称必填，三级分类必须选满，基本单位必填，编码不重复（R01、R02）；默认销售税率按R03；开票资料、重量尺寸和图片不强制。其余必填性见《商品资料（详细稿）》。 |
| 成功结果 | 生成一条可用的商品记录，使用状态为启用；按F02生成初始价格。 |
| 异常与恢复 | 校验不通过时阻止保存并定位到字段，已填内容保留；编码重复时提示修改后重试，不自动改号。 |

### 4.3 F02 价格初始化

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 商品建档时确定初始采购价格归属和初始售价。 |
| 操作与处理 | 在新增页维护初始供应商、初始含税采购价、初始含税销售价和币别；保存成功时按规则生成价格记录。 |
| 功能规则 | 按初始供应商和币别生成一条采购价，按币别和所有客户范围生成一条销售基准价；初始供应商只表示价格归属，不建立供货关系，也不限制以后向谁采购（PRI-FR01）。后续变价走价格调整单，不在商品档案修改（R04）。 |
| 成功结果 | 采购价目表和销售价目表出现对应记录，采购与销售业务可以取价。 |
| 异常与恢复 | 初始价格为空时的阻断与恢复方式待确认（Q04）；商品保存与价格记录生成需要一致完成，任何一步失败的页面表现见Demo PRD。 |

### 4.4 F03 商品管理配置

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 商品需要参与库存预警、批次、序列号、保质期或保修管理时配置。 |
| 操作与处理 | 在新增／编辑页维护是否启用库存预警、最低／最高／安全库存数量和适用仓库，以及批次、序列号、保质期、保修期配置；保存后供库存模块和WMS读取。 |
| 功能规则 | 配置由商品维护，预警计算和收发追踪由库存模块及WMS按确认的分工执行（MD-FR10）；保质期天数在启用保质期管理后使用。预警维度、库存统计规则、最低库存与安全库存的区别待确认（Q05）。 |
| 成功结果 | 配置保存一致，库存模块及WMS按确认接口可读取或接收。 |
| 异常与恢复 | 配置保存失败时保留已填内容；执行效果按后续库存及接口规则验收，不在本模块处理。 |

### 4.5 F04 商品分发与外部匹配

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 商品建档后需要被第三方WMS和金蝶识别；领星、聚水潭按SKU编码或确认后的对应关系识别回传结果。 |
| 操作与处理 | 系统按主数据规则把SKU分发到WMS和金蝶；外部商品映射由业务人员在系统集成配置。 |
| 功能规则 | 分发失败不阻止内部业务继续，向下游发送单据时由失败反馈进入异常处理；商品档案不预设映射明细（MD-FR06、INT-FR04）。 |
| 成功结果 | 分发状态可查；外部系统能按映射识别ERP SKU。 |
| 异常与恢复 | 分发失败的记录在系统集成中心查看（INT-FR05）；修复后重试原记录。具体字段与重试机制待接口设计确认（Q08）。 |

外部同步按需说明：

| 方向及数据 | 触发时机 | 匹配依据 | 新增／更新边界 | 失败、重复与重试 |
| --- | --- | --- | --- | --- |
| ERP到第三方WMS、金蝶：商品（成品SKU） | 建档或关键字段变更后由系统分发 | 商品编码及系统集成维护的映射 | 商品字段由商品资料维护，映射由系统集成维护 | 失败记录集中查看，修复后重试；不因分发失败阻断内部业务 |

### 4.6 F05 启用、禁用与删除

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 商品停售、暂停使用，或建档后发现重复、录错。 |
| 操作与处理 | 在列表或详情执行启用、禁用、删除；删除只对未被引用的商品开放。 |
| 功能规则 | 禁用后新业务不能选择该商品，已有单据和价目表保留原引用与快照（R04）；被引用的商品不能删除（R05）。 |
| 成功结果 | 新单可选性立即变化，历史业务不受影响；重新启用后恢复可选。 |
| 异常与恢复 | 商品被引用时删除不可用并说明原因；禁用不影响任何已保存业务，需要时重新启用即可。 |

### 4.7 F06 批量导入

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 初期建档量大或集中维护商品资料。 |
| 操作与处理 | 在列表页使用导入，按商品编码匹配，已存在更新非空字段，不存在新增（R06）。 |
| 功能规则 | 商品不审核，导入不增加审核流程；导入校验与页面填写规则一致（COM-FR02）。 |
| 成功结果 | 商品批量建立或更新，结果按成功、失败分别可见。 |
| 异常与恢复 | 失败行不写入并给出原因，修正文件后可重新导入；错误处理细节按导入中心规则。 |

### 4.8 状态与动作

商品不审核，只有一个使用状态。

| 状态 | 含义 | 进入条件 | 是否终态 |
| --- | --- | --- | --- |
| 启用 | 可被新业务引用 | 建档成功，或由禁用恢复 | 否 |
| 禁用 | 停止新增引用 | 人工禁用 | 否 |

| 当前状态 | 动作/事件 | 前置条件 | 结果与业务影响 | 失败处理 |
| --- | --- | --- | --- | --- |
| 无（新建） | 保存 | 商品名称、三级分类、基本单位、编码等校验通过 | 建档成功，使用状态为启用，生成初始价格 | 校验失败阻止保存 |
| 启用 | 禁用 | 无特殊限制，已被引用也可禁用 | 新单不能选择，历史单据与价目表保留引用 | 无 |
| 禁用 | 启用 | 无 | 新单恢复可选 | 无 |
| 启用／禁用 | 删除 | 未被单据或价目表引用 | 记录移除 | 被引用时阻止并提示 |
