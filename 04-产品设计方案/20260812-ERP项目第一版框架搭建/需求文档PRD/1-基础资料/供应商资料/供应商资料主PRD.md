## 二、需求背景与范围

供应商是采购业务的必选资料。现状是供应商信息散落在各业务系统和表格里，缺少统一身份和统一的结算资料。本期在ERP建立成品供应商档案，通过提交审核和启用控制采购引用资格，一期不管理商品与供应商的供货关系。

| 对象 | 用途 | 数据来源 | 由哪里维护 | 被哪些业务引用 |
| --- | --- | --- | --- | --- |
| 供应商（成品供应商） | 采购业务的交易对象；结算与付款资料用于采购单据 | 人工建档与批量导入 | 主数据维护人员提交、资料审核人审核 | 采购订单、采购退货单、商品建档的初始供应商 |

本期做：成品供应商建档与编辑、多条联系人、地址、收款账户及默认项、分类与等级、默认币别、结算方式与付款条件选项、提交审核与驳回重提、启用禁用、批量导入。

本期不做：商品与供应商的供货关系、供应商门户与协同、等级自动评价、付款条件的付款节点、比例明细和独立账期配置、供应商侧的对账与发票功能。

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 编码与防重 | 供应商编码是唯一识别依据，保存时校验重复并阻止保存 | 编码规则见《6.强盛ERP的编码规则和通用字段规则》第二节（Q01） |
| R02 | 明细与默认项 | 联系人、地址、收款账户都支持多条；每类最多一个默认项，引用时优先带入默认记录 | 没有默认项时手动选择，不自动取第一条；新增明细不自动设为默认 |
| R03 | 分类与等级 | 分类按主要供货品类选择；等级人工维护，不自动决定采购资格 | 具体字段与评价标准待确认（Q04） |
| R04 | 结算资料 | 默认币别、结算方式、付款条件都取自辅助资料；付款条件只表达月结和分阶段付款，不拆付款节点、比例明细 | 结算方式与付款条件的正式选项待确认（Q04） |
| R05 | 修改范围 | 草稿和已驳回的档案可以修改并重新提交；审核通过后修改须重新提交审核，重新审核通过前新单不能引用该条资料 | 见Q03 |
| R06 | 引用与变更 | 改名、调整分类或等级不改历史单据；单据保留当时的供应商信息 | 历史快照的保存与展示由各业务PRD定义 |
| R07 | 删除控制 | 未被单据引用的供应商可以删除；被引用的不能删除，只能禁用。删除不可恢复，禁用可再启用 | 见Q05 |
| R08 | 批量维护 | 导入按供应商编码匹配，已存在更新非空字段，不存在新增；导入后仍要提交审核，导入不改变审核流程 | 可导入字段、更新范围与错误行处理按导入中心规则，待确认（Q06） |

### 4.2 F01 供应商档案维护

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 找到新的成品供应商，需要在采购建单前建立资料；或在合作过程中维护分类、等级和结算资料。 |
| 操作与处理 | 在供应商列表新增，填写基础信息与结算付款资料，按需添加联系人与收款账户明细，保存后进入草稿；草稿和已驳回状态可以编辑并重新提交。列表支持按关键词（编码、名称）、供应商分类、供应商等级和使用状态查询，详情查看全部信息与审核记录。 |
| 功能规则 | 保存校验：供应商名称必填，编码不重复（R01）；分类按主要供货品类选择（R03）；结算资料取自辅助资料（R04）；明细与默认项按R02。其余必填性见《供应商资料（详细稿）》。 |
| 成功结果 | 生成一条草稿状态的供应商记录，按流程提交审核。 |
| 异常与恢复 | 校验不通过时阻止保存并定位到字段，已填内容保留；编码重复提示修改后重试。 |

### 4.3 F02 联系人与收款账户明细

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 同一供应商有多个业务联系人、多个地址或多个收款账户，需要在采购单据和付款时选用。 |
| 操作与处理 | 在新增／编辑页维护联系人、地址、收款账户三条明细，每条支持添加和删除；设置默认项时系统自动取消同组的其他默认。 |
| 功能规则 | 每类最多一个默认项；业务引用优先带入默认记录，没有默认项时手动选择，不自动取第一条（R02）。默认仅影响带出顺序，不代表自动付款或自动选择。 |
| 成功结果 | 明细随档案保存，详情按分组展示，引用方可以取到默认项。 |
| 异常与恢复 | 明细行必填项不完整时阻止保存并定位到具体行；同一组出现多个默认项的，保存时按最后一次设置生效。 |

### 4.4 F03 提交、审核与驳回重提

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 供应商资料建立后需要确认才能用于采购。 |
| 操作与处理 | 草稿或已驳回的档案提交后进入待审核；有审核权限的人员审核通过或驳回；驳回后修改资料重新提交，再次进入待审核。 |
| 功能规则 | 审核是单级流程，有权限即可提交和审核，允许本人审核本人创建的数据（COM-FR01）；采购只能选择审核通过且启用的供应商（MD-FR02）。已审核后修改须重新提交审核，重新审核通过前新单不能引用该条资料（R05）。 |
| 成功结果 | 审核通过的档案进入可用范围；驳回的档案保留修改入口。 |
| 异常与恢复 | 驳回意见随记录保留，修改后重新提交进入待审核；审核不通过不影响档案继续编辑。 |

### 4.5 F04 启用、禁用与删除

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 供应商停止合作、暂停使用，或建档后发现重复、录错。 |
| 操作与处理 | 在列表或详情启用、禁用；删除只对未被引用的供应商开放。新建与导入的档案使用状态默认为启用，审核通过后才能被采购选择。 |
| 功能规则 | 采购只能选择审核通过且启用的供应商；禁用后新单不能选择，历史单据和已保存的业务保留原引用（R06）；被引用的供应商不能删除（R07）。等级不改变采购资格（R03）。 |
| 成功结果 | 新单可选性立即变化，历史业务不受影响；重新启用后恢复可选。 |
| 异常与恢复 | 供应商被引用时删除不可用并说明原因；删除后不能恢复。禁用不影响任何已保存业务，需要时重新启用即可。 |

### 4.6 F05 批量导入

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 初期建档量大或集中维护供应商资料。 |
| 操作与处理 | 在列表页使用导入，按供应商编码匹配，已存在更新非空字段，不存在新增（R08）。 |
| 功能规则 | 导入不改变审核流程，导入后的档案仍要提交和审核（COM-FR02）；导入的档案使用状态默认为启用。 |
| 成功结果 | 供应商批量建立或更新，结果按成功、失败分别可见。 |
| 异常与恢复 | 失败行不写入并给出原因，修正文件后重新导入；错误处理细节按导入中心规则。 |

### 4.7 状态与动作

供应商有两个状态：审核状态和使用状态。

| 状态 | 含义 | 进入条件 | 是否终态 |
| --- | --- | --- | --- |
| 草稿 | 档案已保存，尚未提交 | 新建保存或导入 | 否 |
| 待审核 | 已提交，等待审核 | 提交 | 否 |
| 审核通过 | 资料已确认 | 审核通过 | 否 |
| 已驳回 | 审核未通过，可修改重提 | 驳回 | 否 |
| 启用 | 可被采购引用（还需审核通过） | 新建保存、导入或人工启用 | 否 |
| 禁用 | 停止新增引用 | 人工禁用 | 否 |

| 当前状态 | 动作/事件 | 前置条件 | 结果与业务影响 | 失败处理 |
| --- | --- | --- | --- | --- |
| 草稿／已驳回 | 编辑、提交 | 资料完整 | 提交后进入待审核 | 资料不完整时阻止提交 |
| 待审核 | 审核通过 | 有审核权限 | 审核状态变为审核通过；使用状态为启用时采购可选 | 无 |
| 待审核 | 驳回 | 有审核权限 | 变为已驳回，保留修改入口 | 无 |
| 审核通过且启用 | 禁用 | 无特殊限制，已被引用也可禁用 | 新单不能选择，历史单据保留引用 | 无 |
| 禁用 | 启用 | 审核状态为审核通过 | 新单恢复可选 | 审核未通过时不进入可选范围 |
| 草稿／已驳回，未被引用 | 删除 | 未被采购单据引用 | 记录移除 | 被引用时阻止并提示 |
