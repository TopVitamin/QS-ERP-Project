## 二、需求背景与范围

物流资料是销售发货的选择依据。现状是物流商和服务方式散落在履约系统里，ERP下单时没有统一的可选项。本期在ERP建立物流商与其下的物流服务产品两级档案，发货时选择具体服务产品，或选择“由仓库指定”，自提不选物流产品。

| 对象 | 用途 | 数据来源 | 由哪里维护 | 被哪些业务引用 |
| --- | --- | --- | --- | --- |
| 物流商 | 承运企业档案；其下挂服务产品 | 人工建档 | 主数据维护人员在基础资料-物流资料维护 | 物流服务产品的归属 |
| 物流服务产品 | 发货时可以选择的物流服务；也可以选“由仓库指定”不指定产品 | 人工建档 | 主数据维护人员 | 销售发货（B2B与独立站）、发货结果记录 |

本期做：物流商与物流服务产品的建档与编辑、运输类型、启停控制、批量导入、发货选择规则、实际物流结果回传的记录方式。

本期不做：物流商运费结算与运费计算、服务限制与自动选物流、物流商直连下单与面单获取、结算银行资料与直连授权参数、跨境头程物流档案。

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 编码与防重 | 物流商编码与物流服务产品编码分别是各自对象的唯一识别依据，保存时校验重复并阻止保存；物流商、物流服务产品名称分别不允许重复，保存时一并校验并阻止保存 | 编码规则见《6.强盛ERP的编码规则和通用字段规则》第二节（Q01） |
| R02 | 不审核 | 物流商和服务产品都只维护使用状态，不设草稿、提交和审核；新增保存后默认启用，创建即可用 | 没有审核通过状态，启停操作直接生效 |
| R03 | 两级归属 | 每个物流服务产品关联一个物流商；新增产品只能关联启用的物流商 | 父物流商后续禁用不限制已有产品的使用 |
| R04 | 发货选择 | 非自提发货选择具体物流服务产品，或选择“由仓库指定”；自提不选物流产品 | “由仓库指定”不创建虚拟物流商或虚拟产品档案；字段传空值还是不传待确认（Q02） |
| R05 | 实际结果不回建档 | 下游回传的实际物流商、服务产品、运单号与轨迹记录在业务单据上 | 不把回传结果自动新增为物流商或服务产品档案的选项 |
| R06 | 引用与变更 | 改名或调整联系信息不改历史单据；单据保留当时的物流信息 | 生成单据时从物流资料带出并固化物流商与服务产品名称，取值时点为建单保存时；快照字段与展示位置见各业务单据字段清单 |
| R07 | 删除控制 | 未被任何业务对象引用的记录可以删除；物流商存在服务产品即属于被引用。被引用的不能删除，只能禁用；删除不可恢复，禁用可再启用 | 删除前检查完整引用关系，不能只查发货单据；见Q04 |
| R08 | 批量维护 | 物流商与服务产品均可导入，导入不增加审核；编码匹配、既有资料能否更新、空值覆盖与错误行处理见Q06 | 新导入建档默认启用；详细规则待导入中心确认 |

### 4.2 F01 物流商维护

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 引入新的承运企业，或在联系方式变化时维护资料。 |
| 操作与处理 | 在物流商列表新增或编辑，填写名称、联系人、联系电话、联系地址，维护使用状态；列表按关键词（编码、名称、联系人、联系电话）、使用状态、最后更新时间查询。保存后启用的物流商可用于新增服务产品关联；默认列与可选列见[《物流资料前端Demo版PRD》](物流资料前端Demo版PRD.md)第1节。 |
| 功能规则 | 物流商只有一条联系信息，不做多联系人（MD-FR05）；编码不重复（R01）；新默认启用（R02）。 |
| 成功结果 | 生成一条可用的物流商记录，其下可以新增服务产品。 |
| 异常与恢复 | 校验不通过时阻止保存并定位到字段，已填内容保留；编码重复提示修改后重试。 |

### 4.3 F02 物流服务产品维护

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 为已启用的物流商补充具体服务，例如国内快递、国际快递。 |
| 操作与处理 | 在物流服务产品列表新增或编辑，选择所属物流商和运输类型；列表按关键词（编码、名称）、所属物流商、运输类型、使用状态和最后更新时间查询。运输类型包含国内快递、国内零担、国内整车、国际快递，不含跨境头程。 |
| 功能规则 | 新增产品只能关联启用的物流商（R03）；产品按自身使用状态判断能否发货，不受父物流商禁用影响。 |
| 成功结果 | 生成一条可被发货选择的服务产品记录。 |
| 异常与恢复 | 没有启用物流商时新增入口不可用并提示原因；校验不通过时阻止保存并保留已填内容。 |

### 4.4 F03 发货物流选择与结果记录

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 销售发货时确定物流方式；仓库执行后回传实际物流结果。 |
| 操作与处理 | 非自提发货在业务单据上选择启用的物流服务产品，或选择“由仓库指定”；自提按发货方式“自提”处理，不选物流商与服务产品。ERP把选择结果下发给仓库。 |
| 功能规则 | 只有启用的服务产品可以选择；由仓库指定与自提都不创建虚拟档案（R04）；实际回传结果只记录在业务单据上，不更新档案（R05）。 |
| 成功结果 | 发货指令携带正确的物流选择；业务单据记录实际物流结果。 |
| 异常与恢复 | 选择结果下发失败按业务单据的推送异常处理；回传结果缺字段时按接口确认的协议处理（Q02）。 |

### 4.5 F04 启用与禁用

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 物流商或服务产品停止使用、暂停使用，或建档后发现重复、录错。 |
| 操作与处理 | 在列表或表单维护启用、禁用；删除只对未被任何业务对象引用的记录开放，物流商下存在服务产品时不能删除。 |
| 功能规则 | 物流商禁用只限制新增服务产品关联，已有产品按自身状态发货，历史数据不受影响，不级联禁用（MD-FR05、R03）；被引用的记录不能删除（R07）。 |
| 成功结果 | 新增引用立即受控，已有业务不受影响；重新启用后恢复可选。 |
| 异常与恢复 | 记录被引用时删除不可用并说明原因；禁用不影响已保存业务。 |

### 4.6 F05 批量导入

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 初期建档量大或集中维护物流资料。 |
| 操作与处理 | 物流商列表、服务产品列表分别提供公共导入入口；匹配、更新、空值和错误行处理按Q06确认后执行。 |
| 功能规则 | 导入不增加审核流程（COM-FR02）；新导入建档的记录使用状态默认为启用。 |
| 成功结果 | 按Q06确认后的导入规则展示处理结果。 |
| 异常与恢复 | 错误行处理与重新导入方式按Q06确认后的导入中心规则执行。 |

### 4.7 状态与动作

物流资料只有一个使用状态，不审核。

| 状态 | 含义 | 进入条件 | 是否终态 |
| --- | --- | --- | --- |
| 启用 | 可被新增引用（物流商供新增产品，服务产品供发货选择） | 新建保存或人工启用 | 否 |
| 禁用 | 停止新增引用 | 人工禁用 | 否 |

| 当前状态 | 动作/事件 | 前置条件 | 结果与业务影响 | 失败处理 |
| --- | --- | --- | --- | --- |
| 无（新建） | 保存 | 名称、编码等校验通过 | 建档成功，使用状态为启用 | 校验失败阻止保存 |
| 启用（物流商） | 禁用 | 无特殊限制 | 新增服务产品不能关联该物流商；已有产品按自身状态继续发货 | 无 |
| 禁用（物流商） | 启用 | 无 | 恢复新增产品关联 | 无 |
| 启用（服务产品） | 禁用 | 无特殊限制 | 新发货不能选择该产品；历史单据保留原信息 | 无 |
| 禁用（服务产品） | 启用 | 无 | 恢复发货可选 | 无 |
| 启用／禁用 | 删除 | 未被任何业务对象引用，物流商下无服务产品 | 记录移除且不可恢复 | 被引用时阻止并提示 |
