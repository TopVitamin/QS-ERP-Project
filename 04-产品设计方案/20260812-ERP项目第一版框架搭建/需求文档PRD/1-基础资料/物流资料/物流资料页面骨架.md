# 物流资料页面骨架

> 文档版本：V0.2｜日期：2026-09-23｜状态：初稿，待评审。
> 本文只画物流商与物流服务产品的列表、弹窗和按钮；动作条件以[《物流资料主PRD》](物流资料主PRD.md)为准，字段投影以[《物流商资料（详细稿）》](../../../字段清单合集/基础资料/物流资料/物流商资料（详细稿）.tsv)、[《物流服务产品资料（详细稿）》](../../../字段清单合集/基础资料/物流资料/物流服务产品资料（详细稿）.tsv)为准，交互见[《物流资料前端Demo版PRD》](物流资料前端Demo版PRD.md)。公共布局见[《UI布局公共说明》](../../../../../05-常用模板/02-模块设计交付/UI布局公共说明.md)。
> 导航：物流商与物流服务产品各占一个二级菜单，列表页不设对象切换页签；物流商列表点击编码进入详情页并展示服务产品子表，服务产品列表点击所属物流商进入物流商详情；服务产品新增、编辑、查看仍用弹窗。

## 页面清单

| 页面 | 入口 | 用户任务 |
| --- | --- | --- |
| 物流商列表 | 基础资料→物流商 | 查询承运企业，维护联系信息与使用状态 |
| 物流商详情 | 物流商列表点击编码 | 查看物流商基础信息，维护下属服务产品子表 |
| 物流服务产品列表 | 基础资料→物流服务产品 | 按物流商、运输类型查询和维护服务产品 |
| 物流商弹窗 | 列表新增、编辑或详情页编辑 | 新建、修改单条物流商 |
| 服务产品弹窗 | 列表/详情子表新增、编辑或点击编码 | 新建、修改、查看所属物流商与运输类型 |
| 确认弹窗 | 禁用、删除或离开未保存弹窗 | 确认有后果的操作 |

## 物流商列表

- **页头**：新增物流商、导入、导出；不设审核页签。
- **查询区**：关键词（物流商编码／名称／联系人／联系电话）、使用状态、最后更新时间；关键词内OR匹配，其余条件AND匹配。
- **默认资料列**：物流商编码、物流商名称、联系人、联系电话、使用状态、最后更新时间；右侧为操作列。
- **可选列**：联系地址、最后更新人。联系信息只维护一条，不设默认联系人。
- **行操作**：编辑、启用或禁用、删除；编码点击进入物流商详情页。批量启停与批量删除一期不纳入。

## 物流商详情

- **页头**：编辑、启用或禁用、删除、新增服务产品；返回来源列表。
- **基础信息**：物流商编码、名称、联系人、联系电话、联系地址、使用状态。
- **服务产品子表**：展示当前物流商下属产品，默认列与列表一致（不含所属物流商列）；行内查看、编辑、启停、删除；编码点击打开查看弹窗。
- **维护信息**：创建人、创建时间、最后更新人、最后更新时间。

## 物流服务产品列表

- **页头**：新增物流服务产品；至少存在一条启用物流商时可用。
- **查询区**：关键词（服务产品编码／名称）、所属物流商、运输类型、使用状态、最后更新时间。所属物流商选项包含已禁用物流商，以查询其既有产品。
- **默认资料列**：物流服务产品编码、名称、所属物流商（Code-Name）、运输类型、使用状态、最后更新时间；右侧为操作列。
- **可选列**：最后更新人。所属物流商可点击进入物流商详情页。父物流商禁用不隐藏既有产品，也不改变产品自身的发货资格。
- **行操作**：编辑、启用或禁用、删除；编码点击进入查看弹窗。

## 弹窗与确认

- **物流商新增／编辑**：编码、名称、联系人、联系电话、联系地址、使用状态；新增默认启用，编码保存后只读。查看模式展示维护信息。
- **服务产品新增／编辑**：编码、名称、所属物流商、运输类型、使用状态；新增关联启用物流商。编辑时保留既有归属，即使父物流商后续禁用；改选时仍只选启用物流商。
- **确认弹窗**：单条禁用、删除与离开未保存弹窗。物流商下已有产品或资料被其他业务对象引用时不能删除；禁用父商不级联禁用产品。
- 导入对象及匹配更新规则见主PRD Q06；批量启停与批量删除一期不纳入。
