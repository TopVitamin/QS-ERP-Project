# 仓库资料前端Demo版PRD·详情页

> 模板版本：V2
> 文档版本：V0.1｜日期：2026-09-23｜状态：初稿，待评审。
> 本文说明实体仓详情页字段展示、页头动作与逻辑仓子表操作。业务规则见[《仓库资料主PRD》](../仓库资料主PRD.md)，字段投影见[《实体仓资料（详细稿）》](../../../../字段清单合集/基础资料/仓库资料/实体仓资料（详细稿）.tsv)、[《逻辑仓资料（详细稿）》](../../../../字段清单合集/基础资料/仓库资料/逻辑仓资料（详细稿）.tsv)，页面布局见[《仓库资料页面骨架》](../仓库资料页面骨架.md)。

关联页面：[列表页](仓库资料前端Demo版PRD_列表页.md)、[新增编辑页](仓库资料前端Demo版PRD_新增编辑页.md)、[弹窗与Mock](仓库资料前端Demo版PRD_弹窗与Mock.md)。

## 1. 页面概述

| 项目 | 说明 |
| --- | --- |
| 标题与入口 | 实体仓详情；列表点击实体仓编码进入 |
| 容器形式 | 独立页 |
| 区域顺序 | 基础信息 → 地址与联系 → 对接信息 → 逻辑仓 → 审核与使用 → 维护信息 |
| 返回/关闭 | 返回来源列表，保留原查询条件、审核页签与页码；从逻辑仓列表经所属实体仓链接进入时返回逻辑仓列表，从实体仓列表进入时返回实体仓列表 |

## 2. 字段展示

| 分组 | 字段/明细列 | 显示形式 | 空值及长文本 | 关联跳转 |
| --- | --- | --- | --- | --- |
| 基础信息 | 实体仓编码、实体仓名称、运营类型、备注 | 文字 | 空值显示 `-`；备注换行展示 | 无 |
| 地址与联系 | 仓库地址、联系人、联系电话 | 文字 | 空值显示 `-` | 无 |
| 对接信息 | 对接方式、对接系统、第三方仓库编码、第三方仓库货主、对接授权配置 | 文字 | 空值显示 `-` | 无 |
| 逻辑仓 | 逻辑仓编码、逻辑仓名称、库存状态、审核状态、使用状态、最后更新时间 | 子表格；默认按最后更新时间倒序 | 空值显示 `-`；无记录显示「暂无逻辑仓」 | 无 |
| 审核与使用 | 审核状态、使用状态 | 状态标签 | — | 无 |
| 维护信息 | 审核人、审核时间、创建人、创建时间、最后更新人、最后更新时间 | 文字与日期时间 | — | 无 |

## 3. 页头操作

| 按钮文案 | 可用条件及来源 | 点击行为 | 确认与反馈 |
| --- | --- | --- | --- |
| 编辑 | 审核状态为草稿或已驳回（主PRD R10） | 进入编辑实体仓页 | 返回后刷新详情 |
| 提交审核 | 审核状态为草稿或已驳回 | 直接执行 | 二次确认后提交；校验范围与保存相同 |
| 审核通过／驳回 | 审核状态为待审核 | 直接执行 | 二次确认后执行 |
| 反审核 | 审核状态为审核通过 | 直接执行 | 二次确认后回到草稿 |
| 启用／禁用 | 启用条件为禁用，禁用条件为启用；新增逻辑仓仍须审核通过 | 直接执行 | 禁用前二次确认 |
| 新增 | 实体仓审核通过且启用（R04） | 打开新增逻辑仓弹窗 | 条件不满足时按钮不可用，悬停提示「实体仓审核通过并启用后才能新增逻辑仓」 |
| 返回列表 | 始终可用 | 返回来源列表 | 保留原查询、审核页签与页码；跨列表跳转时回到进入前的列表 |

审核通过后的档案先反审核回到草稿，再进入编辑页修改并重新提交审核（主PRD R10）。确认弹窗正文见[弹窗与Mock](仓库资料前端Demo版PRD_弹窗与Mock.md)。

## 4. 逻辑仓子表格操作

| 位置 | 按钮文案 | 可用条件及来源 | 点击行为 | 确认/校验 | 成功与失败后的表现 |
| --- | --- | --- | --- | --- | --- |
| 子表格行内 | 查看／编辑 | 编辑限草稿或已驳回 | 打开逻辑仓弹窗，查看为只读 | 无 | 保存后子表格刷新 |
| 子表格行内 | 提交审核 | 审核状态为草稿或已驳回 | 直接执行 | 二次确认 | 状态变为待审核 |
| 子表格行内 | 审核通过 | 审核状态为待审核 | 直接执行 | 二次确认 | 状态变为审核通过 |
| 子表格行内 | 驳回 | 审核状态为待审核 | 直接执行 | 二次确认 | 状态变为已驳回 |
| 子表格行内 | 反审核 | 审核状态为审核通过 | 直接执行 | 二次确认 | 回到草稿 |
| 子表格行内 | 启用／禁用 | 启用条件为禁用，禁用条件为启用；新单仍须审核通过 | 直接执行 | 禁用前二次确认 | 状态更新并提示 |
| 子表格行内 | 删除 | 未被任何业务对象引用（主PRD R08） | 直接执行 | 二次确认 | 被引用时阻止并提示 |

编辑逻辑仓时可调整所属实体仓；已有库存与未完成单据随逻辑仓挂到新实体仓（主PRD Q08）。弹窗字段与校验见[弹窗与Mock](仓库资料前端Demo版PRD_弹窗与Mock.md)。
