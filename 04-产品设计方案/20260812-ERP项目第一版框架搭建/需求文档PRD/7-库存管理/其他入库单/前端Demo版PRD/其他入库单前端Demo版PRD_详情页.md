> **通用口径**：详情页分区、状态标签、胶囊Tab见[《原型开发说明》](../../../../../../09-产品原型/原型开发说明.md)与[《UI布局公共说明》](../../../../../../05-常用模板/02-模块设计交付/UI布局公共说明.md)。

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 其他入库单详情页 |
| 页面目标 | 只读查看入库单全貌、追溯来源单据与推送结果 |
| 数据范围 | 一张入库单：单据信息、商品明细、制单信息 |
| 状态—操作矩阵 | 见主PRD §6.4；各状态页头仅 `返回列表` |

**本期边界**：无编辑、提交、审核、撤回、取消、作废；无行内重推；金蝶推送失败在系统集成中心重推原单。

---

## 2. 页头

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `其他入库单详情` · 单号（可复制） |
| 状态标签 | 两枚StatusBadge：审核状态、金蝶推送状态 |
| 操作区 | `[返回列表]` |

---

## 3. 页面分区

### 3.1 单据信息

6列栅格，标签在上、值在下；字段按TSV行序。

| 字段 | 展示 | 说明 |
| :--- | :--- | :--- |
| 单号 | 文本 | 前缀QTRK |
| 来源类型 | 文本 | 申请执行／仓库主动回传 |
| 来源其他入库申请单 | 链接 | 点击跳转申请单详情；无来源显示 `-` |
| 来源系统 | 文本 | 仅仓库主动回传有值；无值显示 `-` |
| 来源单号 | 文本 | 仅仓库主动回传有值；无值显示 `-` |
| 入库仓库 | 文本 | 逻辑仓Code-Name |
| 业务类型 | 文本 | 枚举文字 |
| 实际入库时间 | 日期时间 | 到秒 |
| 业务日期 | 日期 | 取实际入库时间的日期部分；仅详情展示 |
| 推送金蝶时间 | 日期时间 | 未推送时 `-` |
| 推送失败原因 | 多行文本（占3列） | 未失败时 `-` |
| 备注 | 多行文本（占3列） | 空值展示 `-` |

### 3.2 商品明细

| 列名 | 说明 |
| :--- | :--- |
| 行号 | 从1起 |
| 来源申请行 | 有来源时展示来源行（如 `QTRKSQ-…0001 第1行`）；无来源显示 `-` |
| 商品 | 明细展示商品名称 |
| 商品编码 | 随商品带出 |
| 商品名称 | 随商品带出 |
| 基本单位 | 随商品带出 |
| 实际入库数量 | 整数 |

### 3.3 制单信息（详情底部）

| 分区 | 内容 |
| :--- | :--- |
| 审核信息 | 审核人、审核时间；自动审核时审核人留空 |
| 制单信息 | 创建人、创建时间、最后更新人、最后更新时间；自动生成的入库单创建人与最后更新人显示「系统」 |

操作日志一期后置：完整操作日志字段与入口见主PRD Q08；一期不做独立操作日志页。

## 4. 交互与反馈

| 操作 | 行为 | 反馈 |
| :--- | :--- | :--- |
| 来源申请单跳转 | 点击来源申请单号 | 进入申请单详情；单据不存在时 Toast「单据不存在或不可访问」 |
| 重推金蝶 | 本页不提供入口 | 到系统集成中心针对原单重推（主PRD R10） |
| 加载失败 | 详情加载异常 | 错误态「其他入库单不存在或无权查看」 |

---

## 5. Mock数据要求与演示验收

### 5.1 Mock覆盖

- 至少 **6 单**：申请执行 **4 单**（推送成功2、推送失败1、未推送1）、仓库主动回传 **2 单**（盘盈，含来源系统与来源单号）
- 至少 **1 单**推送失败，详情展示失败原因，页头无重推按钮
- 至少 **1 单**来源申请单可跳转
- 至少 **1 单**实际入库数量 > 0
- **枚举与口径**：Mock 取值必须落在字段清单范围内

### 5.2 演示验收

| 场景 | 前置 | 操作 | 预期 |
| :--- | :--- | :--- | :--- |
| 申请执行单 | 有来源的入库单 | 打开详情 | 来源类型=申请执行；来源申请单可跳转；来源系统/来源单号显示 `-` |
| 仓库主动回传单 | 盘盈入库单 | 打开详情 | 来源类型=仓库主动回传；来源申请单显示 `-`；来源系统与来源单号有值 |
| 推送失败 | 推送失败单 | 打开详情 | 展示失败原因；页头仅 `返回列表`，无重推按钮 |
| 制单信息 | 自动生成单 | 查看详情底部 | 创建人、最后更新人显示「系统」；审核人 `-` |
| 操作日志（一期后置） | 任意单 | 查看详情底部 | 不提供操作日志入口；完整字段与入口见主PRD Q08 |

Demo 验证分区与只读口径；不代表真实接口、并发或后端事务行为。
