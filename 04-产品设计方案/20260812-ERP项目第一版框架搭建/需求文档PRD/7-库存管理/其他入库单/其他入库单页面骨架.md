- **与TSV的分工**：字段名称、分组、列表列与筛选项以[《其他入库单（详细稿）》](../../../字段清单合集/库存相关/其他入库单/其他入库单（详细稿）.tsv)为准；骨架示例列不全时以TSV补全。

各页结构：**图前**写用途与关键要素；**图中**为线框；**图后**用无序列表补充图中省略项、重点和条件差异。

## 绘制约定

遵循[《页面骨架模板-V2》](../../../../../05-常用模板/02-模块设计交付/页面骨架模板-V2.md)与[《UI布局公共说明》](../../../../../05-常用模板/02-模块设计交付/UI布局公共说明.md)。本模块补充：

- 字段名、按钮文案与TSV、Demo PRD一致；示例值为虚构。
- 来源其他入库申请单、入库仓库按Code-Name（`{编码} {名称}`）画示例值；商品明细拆列展示商品编码、商品名称、基本单位。
- 数量列为整数、右对齐、不带单位后缀；0按0展示。
- 页头展示**审核状态**与**推送财务ERP状态**两枚标签；不单开「状态信息」区块；推送财务ERP时间、推送失败原因并入单据信息区。
- 「审核信息」「制单信息」在详情底部分区展示；「操作日志」一期后置（字段与入口见主PRD Q08）。
- 结果单均由回传自动生成，创建即为已审核；列表**不提供新增**按钮。
- 列表默认按业务日期倒序；业务日期按TSV「列表展示=否」不作为列表列（主PRD §7.4）。
- TSV「字段所属分组」= 卡片分区；组内字段按TSV行序填入6列栅格。
- **每行必须画满6列**（用 `|` 分隔）；字段不足6个时，剩余列标「（空）」留空，不要省略列线。
- 备注占3列：单据信息行按6列排满，备注单独一行占第1～3列。

## 列表页

- **用途**：查询其他入库单、按条件筛选、进入详情。
- **关键要素**：页头导出（无新增）；审核状态与推送财务ERP状态双维筛选；来源申请单可跳转；无行内业务操作。

```text
+----------------------------------------------------------------------------------------------------+
| 其他入库单                                                                  [导出]                 |
|----------------------------------------------------------------------------------------------------|
| 查询区（6列栅格）                                                                                  |
| 单号            | 来源其他入库申请单 | 来源类型     | 入库仓库      | 业务类型      | 审核状态      |
| [请输入单号]    | [全部 v]           | [全部 v]     | [全部 v]      | [全部 v]      | [多选 v]      |
| 推送财务ERP状态    | 商品               | （空）       | （空）        | （空）        | （空）        |
| [多选 v]        | [请输入商品编码]    |              |               |               |               |
|----------------------------------------------------------------------------------------------------|
| [收起过滤 ^]                                                             [重置] [查询]             |
|----------------------------------------------------------------------------------------------------|
| 已选中 0 条                                                                            [列设置]     |
|----------------------------------------------------------------------------------------------------|
| [ ] 单号              | 来源其他入库申请单   | 来源类型   | 入库仓库      | 业务类型 | 审核   | 推送财务ERP | 实际入库数量 | 操作 |
| [ ] QTRK-20260923-0001 | QTRKSQ-20260923-0001 | 申请执行   | LWH000001 深圳仓 | 样品回收 | 已审核 | 推送成功 | 100          |      |
| [ ] QTRK-20260922-0003 | -                    | 仓库主动回传 | LWH000002 东莞仓 | 盘盈     | 已审核 | 推送失败 | 5            |      |
| （其余列：来源系统、来源单号、商品名称、创建时间、最后更新时间；默认按业务日期倒序，该列不展示）      |
|----------------------------------------------------------------------------------------------------|
| 共N条  每页20条 [20 v]                                                    < 1 2 3 >                |
+----------------------------------------------------------------------------------------------------+
```

**补充说明**：

- **重点突出**：页头仅「导出」；查询区下方独立一行，左侧「收起过滤」、右侧「重置/查询」；审核状态与推送财务ERP状态并列筛选；来源申请单可点击跳转。
- 审核状态、推送财务ERP状态为**多选**下拉，未选等同全部；正常数据审核状态均为已审核。
- **图中省略**：来源系统、来源单号、创建时间、最后更新时间等列（见TSV「列表展示=是」）；默认按业务日期倒序；校验、排序、分页交互见Demo PRD。
- 单号可点进详情，行内不设「查看」；批量操作栏一期仅已选中计数与列设置；勾选配合页头导出「已勾选」。
- 列表**无新增**按钮；**无行内重推**按钮；仓库主动回传单的来源申请单显示 `-`。

## 详情页

- **用途**：查看入库单全貌、追溯来源单据与推送结果。
- **关键要素**：页头单行——左侧标题与双枚状态标签，右侧操作按钮（`返回列表` 始终最前）；商品明细；审核信息与制单信息。

```text
+----------------------------------------------------------------------------------------------------+
| 其他入库单详情 · QTRK-20260923-0001  [已审核][推送成功]                                [返回列表]   |
|----------------------------------------------------------------------------------------------------|
| 单据信息（6列栅格；字段按TSV行序，两行）                                                            |
| 单号                 | 来源类型 | 来源其他入库申请单   | 来源系统 | 来源单号 | 入库仓库      |
| QTRK-20260923-0001   | 申请执行 | QTRKSQ-20260923-0001链接 | -        | -        | LWH000001 深圳仓 |
| 业务类型 | 实际入库时间        | 业务日期    | 推送财务ERP时间        | 推送失败原因 | （空）                |
| 样品回收 | 2026-09-23 11:20:00 | 2026-09-23  | 2026-09-23 11:21:00 | -            |                       |
| 备注（占3列）                |             |             | （空）      | （空）      | （空）                |
| -                            |             |             |             |             |                       |
|----------------------------------------------------------------------------------------------------|
| 商品明细                                                                                           |
```

**补充说明**：

- **重点突出**：页头单行布局——左标题+两枚状态标签，右操作区；`返回列表` 固定排在操作按钮最前；详情底部为审核信息与制单信息，不平铺6列维护字段。
- **图中省略**：操作日志一期后置（字段与入口见主PRD Q08）；仓库主动回传单的「来源其他入库申请单」显示 `-`，「来源系统」「来源单号」有值。
- **页头按钮**：各状态均为 `[返回列表]`；无编辑、提交、审核、重推按钮。
- 自动生成的入库单创建即为已审核；人工确认时展示审核人姓名，自动审核时审核人留空。
- 推送失败原因在单据信息区展示，重推到系统集成中心办理。
