## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 分步式调拨单详情页 |
| 入口 | 列表点单号 |
| 页面目标 | 只读查看调拨单全貌；按当前状态办理允许的操作；追溯调出通知单、调入通知单与两张直接调拨单 |
| 骨架结构 | 页头 → 单据信息 → 数量进度 → 商品明细 → 关联单据（条件） → 状态信息（仅已完结） → 终止信息（条件） → 审核信息 → 系统信息 |

本页落地 **F05**；状态—操作矩阵见主PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头状态标签：审核状态与业务状态各一枚 StatusBadge；业务状态「已关闭」展示为「已完结」。
> - 关联单据：已审核时展示胶囊 Tab（调出通知单、调入通知单、直接调拨单），带数量。
> - 状态信息（仅已完结）：关闭方式、关闭时间；终止信息：已取消展示取消原因、取消操作人、取消时间。
> - 操作信息：制单信息 Tab；完整操作日志一期后置。
> - 二次确认弹窗正文在[弹窗 PRD](分步式调拨单前端Demo版PRD_弹窗与Mock.md)维护，本文只写入口与结果表现。
> - Demo 以桌面端为基准；明细、关联简表窄视口横向滚动。

## 2. 页头

### 2.1 标题与状态

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `分步式调拨单详情 · {单号}` |
| 状态标签 | 审核状态一枚（草稿／待审核／已审核）+ 业务状态一枚（正常／已完结／已取消） |
| 布局 | 单行：左侧标题 + 状态；右侧操作区（`DocumentDetailFrame`） |

列表状态列与详情页头状态展示方式差异见《原型开发说明》（列表语义色文字 vs 详情 StatusBadge）。

### 2.2 页头操作按钮

`返回列表` **始终排在最前**；其后按状态展示业务按钮。

| 按钮 | 草稿+正常 | 待审核+正常 | 已审核+正常 | 已完结 | 已取消 | 说明 |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| 返回列表 | ✅ | ✅ | ✅ | ✅ | ✅ | 始终 |
| 提交 | ✅ | ❌ | ❌ | ❌ | ❌ | 弹窗 PRD §2.1 |
| 删除 | ✅ | ❌ | ❌ | ❌ | ❌ | 弹窗 PRD §2.4 |
| 编辑 | ✅ | ❌ | ❌ | ❌ | ❌ | 跳转编辑页 |
| 审核 | ❌ | ✅ | ❌ | ❌ | ❌ | 弹窗 PRD §2.5 |
| 撤回 | ❌ | ✅ | ❌ | ❌ | ❌ | 弹窗 PRD §2.2 |
| 取消 | ❌ | ✅ | ❌ | ❌ | ❌ | 弹窗 PRD §2.3 |

**渲染纪律**：

- 条件不满足的按钮**直接不渲染**，不展示灰色 disabled。
- 样式层级：`审核` 用 `primary`；`取消` 用 `outline`；`返回列表` 固定最左。
- 已审核+正常不提供主单取消（主PRD §6.4 说明、Q05）；已完结、已取消仅查看。

二次确认入口与确认后的页面表现统一在第五节维护；弹窗正文引用弹窗PRD。

## 3. 信息分区与字段

> 只读 **6 列栅格**（默认），标签在上、值在下；备注常占 **3 列**。字段顺序与 TSV 分组一致。

**分区总览**：页头 → **3.1 单据信息** → **3.2 数量进度** → **3.3 商品明细** → **3.4 关联单据** → **3.5 状态信息（仅已完结）** → **3.6 终止信息** → **3.7 审核信息** → **3.8 系统信息**

### 3.1 单据信息

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样展示 |
| 调出仓 | 逻辑仓 Code-Name；不能为虚拟在途仓 |
| 接收仓 | 同上 |
| 备注 | 占 3 列；空值显示 `-` |

单据信息共 4 个字段（备注占 3 列），分两行绘制。

### 3.2 数量进度

| 字段 | 展示说明 |
| :--- | :--- |
| 计划调拨数量合计 | 数值右对齐，整数 |
| 累计实际调出合计 | 数值右对齐；最终结果未确认前显示 `-` |
| 累计实际调入合计 | 同上 |
| 在途数量合计 | 数值右对齐；＝累计实际调出−累计实际调入 |

### 3.3 商品明细

- 表格只读；数量列**右对齐**；横向滚动。
- 一期不分页。
- 无价税列。

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 从1起 |
| 商品 | 商品名称 |
| 商品编码 | 原样 |
| 商品名称 | 原样 |
| 基本单位 | 原样 |
| 计划调拨数量 | 整数 |
| 累计实际调出 | 未确认时显示 `-` |
| 累计实际调入 | 未确认时显示 `-` |
| 未调出数量 | ＝计划调拨数量−累计实际调出 |
| 在途数量 | ＝累计实际调出−累计实际调入 |

### 3.4 关联单据

**展示条件**：审核状态=已审核

组件：`RelatedDocumentsCard` + `InnerTabs` `pill`；Tab 文案带数量。

| Tab | 列 | 排序 | 空态 |
| :--- | :--- | :--- | :--- |
| 调出通知单 | 单号、单据状态、通知调出数量、实际调出数量、未发数量、创建时间 | 创建时间升序 | 暂无关联的调出通知单 |
| 调入通知单 | 单号、单据状态、通知调入数量、实际调入数量、少收数量、创建时间 | 创建时间升序 | 暂无关联的调入通知单 |
| 直接调拨单 | 单号、来源类型、来源逻辑仓、目标逻辑仓、审核状态、金蝶推送状态、实际调拨数量、创建时间 | 创建时间升序 | 暂无关联的直接调拨单 |

单号可点击跳转对应详情。

### 3.5 状态信息（仅已完结）

**展示条件**：业务状态=已完结

| 字段 | 展示说明 |
| :--- | :--- |
| 关闭方式 | 原样展示 |
| 关闭时间 | 原样展示 |

### 3.6 终止信息

**展示条件**：业务状态=已取消

| 字段 | 展示说明 |
| :--- | :--- |
| 取消原因 | 原样展示 |
| 取消操作人 | 零调出取消时留空 |
| 取消时间 | 原样展示 |

零调出取消时，取消操作人留空（系统按取消处理）。

### 3.7 审核信息

| 字段 | 展示说明 |
| :--- | :--- |
| 审核人 | 未审核时显示 `-` |
| 审核时间 | 未审核时显示 `-` |
| 撤回意见 | 占第3～6列；未撤回时显示 `-` |

### 3.8 系统信息

胶囊 Tab：[制单信息] / [操作日志]

| Tab | 内容 |
| :--- | :--- |
| 制单信息 | 创建人、创建时间、最后更新人、最后更新时间 |
| 操作日志 | 表格列：操作时间、操作人、操作类型、说明；完整审计日志一期后置 |

## 4. 字段展示规范

空值、Code-Name、数字与日期格式、状态样式、关联简表均引用公共规范；不在此重抄。数量为整数、不允许小数。

| 字段或区域 | 本页差异 | 依据 |
| --- | --- | --- |
| 业务状态 | 「已关闭」展示为「已完结」 | 主PRD §6.2；《单据与状态流转》§二 |
| 累计实际调出／调入、在途数量 | 最终结果未确认前显示 `-`；确认后按回写值展示 | TSV 取值说明 |
| 调出仓／接收仓 | Code-Name 展示；不含虚拟在途仓 | 主PRD R02 |

## 5. 操作行为

| 操作 | 点击行为或弹窗入口 | 确认后页面表现 |
| :--- | :--- | :--- |
| 提交 | 弹窗 PRD §2.1 | 刷新详情；状态=待审核；页头按钮切换为「审核 撤回 取消」 |
| 撤回 | 弹窗 PRD §2.2 | 刷新详情；状态=草稿；保留撤回意见 |
| 取消 | 弹窗 PRD §2.3 | 刷新详情；业务状态=已取消；展示终止信息 |
| 审核 | 弹窗 PRD §2.5 | 刷新详情；状态=已审核+正常；关联单据出现调出通知单 |
| 删除 | 弹窗 PRD §2.4 | 删除成功返回列表 |
| 编辑 | 跳转编辑页 | 不涉及确认则填不适用 |
| 返回列表 | 返回列表 | 保留原筛选与页码 |

## 6. 反馈与页面状态

### 6.1 操作反馈（Toast）

| 操作 | 反馈类型 | 文案 |
| :--- | :--- | :--- |
| 提交成功 | Toast | 已提交，等待审核 |
| 撤回成功 | Toast | 已撤回，单据回到草稿 |
| 取消成功 | Toast | 单据已取消 |
| 审核成功 | Toast | 审核通过，已预占调出仓库存并推送调出仓 |
| 审核阻断（可用不足） | Toast | 调出仓可用库存不足，无法审核 |
| 删除成功 | Toast | 草稿已删除 |
| 状态已变更 | Toast | 操作失败，单据状态已变更，请刷新后重试 |

Mock 专属弹窗见弹窗 PRD。

### 6.2 加载与异常态

| 场景 | 页面表现 | 文案 / 操作 |
| :--- | :--- | :--- |
| 加载中 | 骨架屏 | — |
| 单据不存在 | 错误态 | 单据不存在或已被删除；返回列表 |
| 加载失败 | 错误态 | 加载失败，请重试；重试 + 返回列表 |

## 7. Mock 与验收

### 7.1 Mock 覆盖清单

- 各主状态至少 1 单：草稿、待审核、已审核+正常、已完结（在途为 0 与在途大于 0 各 1 单）、已取消（零调出）
- 关联 Tab 有数据 + 空态：已审核单至少 1 单有调出通知单，1 单有调入通知单与两张直接调拨单
- 终止信息边界：已取消展示取消信息；已完结展示关闭方式与关闭时间
- 数量进度边界：未回传显示 `-`；部分回传显示累计实际调出、在途；已完结显示在途余额

### 7.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 正常路径 | 打开已完结单 | 两枚状态标签；数量进度与明细按回写展示；关联 Tab 有调出、调入通知与两张直接调拨单 |
| 在途余额 | 打开已完结且少收的单 | 在途数量大于0；页面不自动抹平 |
| 零调出 | 打开已取消单 | 业务状态「已取消」；累计实际调出显示0；后续单据 Tab 无记录 |
| 页头按钮 | 分别打开草稿、待审核、已审核单 | 按钮按 §2.2 互斥展示 |
| 跳转 | 点击关联单号 | 进入对应详情 |

模拟的保存、状态变化和关联结果应可连续演示；Demo 验证不代表真实接口、并发或后端事务已验证。
