## 1. 页面目标与范围

- 页面名称：分步式调拨单列表页
- 查看视角：**仅单据视角**（每行 = 一张分步式调拨单；商品仅作查询条件）
- 作为新增、详情、导出的统一入口
- 一期以**行内操作**为主；本页行内提供草稿、待审核的行内办理入口
- 功能与状态—操作矩阵见[《分步式调拨单主PRD》](../分步式调拨单主PRD.md) §6.4；本页落地 F01

> **本期边界**：
> - 页头**新增**创建人工来源单（本单的业务安排），**导出**为一期正式能力（异步任务，见 §7）。
> - 批量操作栏**不放**业务按钮；勾选仅配合导出「已勾选」。
> - 已审核+正常不提供主单取消（主PRD §6.4 说明、Q05）；已完结、已取消仅查看。
> - 在途数量按「累计实际调出−累计实际调入」展示，少收差异不自动抹平。

## 2. 查询区

> 可筛选字段与顺序以[《分步式调拨单（详细稿）》](../../../../字段清单合集/库存相关/分步式调拨单/分步式调拨单（详细稿）.tsv)「可筛选=是」为准；下表为默认查询方案呈现顺序。
> **type 列**：与原型 `FilterControl` 的 `type` 一致，完整规范见[《原型开发说明》](../../../../../../09-产品原型/原型开发说明.md)「查询区通用规则」「FilterControl 控件 type」。

| 查询字段 | type | 匹配 | placeholder / 说明 |
| :--- | :--- | :--- | :--- |
| 单号 | `search` | 模糊 | 请输入单号 |
| 调出仓 | `searchable-select` | 精确 | 全部；选项为审核通过且启用的逻辑仓（Code-Name，不含虚拟在途仓） |
| 接收仓 | `searchable-select` | 精确 | 同上 |
| 审核状态 | `multi-select` | 精确（OR） | 全部；草稿／待审核／已审核；初值 `[]`，未选=全部 |
| 业务状态 | `multi-select` | 精确（OR） | 全部；正常／已关闭／已取消（已关闭展示「已完结」）；初值 `[]` |
| 商品 | `search` | 模糊 | 请输入商品编码；按明细商品筛选 |
| 创建时间 | `date-range` | 区间 | 不限；原型暂无 `datetime-range`，一期按日期比较（09《待改项》） |

查询区交互（收起过滤、重置、查询、空条件默认、查询后回第一页）见《原型开发说明》「查询区通用规则」。查询条件全空时，默认返回最新列表数据（默认按创建时间倒序）。

## 4. 列表表格

### 4.1 视角说明

本期仅**单据视角**：每行一张分步式调拨单。商品仅作查询条件，不在列表展开为多行。

### 4.2 列定义

通用对齐、千分位、空值、列表状态样式等见《原型开发说明》「列表列通用呈现规则」。下表只写本页列清单与模块差异。

| # | 列名 | 展示形式 | 对齐 | 排序 | 空值 | 格式/示例 | 说明 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 勾选 | 复选框 | 居中 | — | — | — | 配合导出「已勾选」；一期无批量业务操作 |
| 2 | 单号 | 链接 | 左 | 否 | — | `FBDB-20260923-0001` | 固定左侧；点击进详情；行内不设「查看」 |
| 3 | 调出仓 | 文本 | 左 | 否 | `-` | `LWH000001 深圳仓` | 逻辑仓 Code-Name；不能为虚拟在途仓 |
| 4 | 接收仓 | 文本 | 左 | 否 | `-` | `LWH000002 东莞仓` | 同上 |
| 5 | 审核状态 | 语义色文字 | 左 | 否 | `-` | 草稿／待审核／已审核 | 列表不用 StatusBadge；tone 见 §4.3 |
| 6 | 业务状态 | 语义色文字 | 左 | 否 | `-` | 正常／已完结／已取消 | 「已关闭」在本模块文案为「已完结」 |
| 7 | 计划调拨数量 | 数值 | 右 | 是 | `0` | `100` | 各明细行计划调拨数量之和 |
| 8 | 累计实际调出 | 数值 | 右 | 是 | `-` | `90` | 各明细行合计；最终结果未确认前显示 `-` |
| 9 | 累计实际调入 | 数值 | 右 | 是 | `-` | `88` | 各明细行合计；最终结果未确认前显示 `-` |
| 10 | 在途数量 | 数值 | 右 | 是 | `-` | `2` | 调拨在途＝累计实际调出−累计实际调入 |
| 11 | 创建时间 | 日期时间 | 左 | 是 | `-` | `2026-09-23 09:30:00` | 安排单默认排序依据 |
| 12 | 最后更新时间 | 日期时间 | 左 | 是 | `-` | `2026-09-23 09:35:00` | — |
| 13 | 操作 | 行内按钮 | 左 | — | — | — | 固定右侧；按状态互斥展示 |

列顺序原则：单号、仓库、状态、数量在前；时间靠后。

### 4.3 本页列表约定

| 项目 | 规则 |
| :--- | :--- |
| 默认排序 | `创建时间` 降序；进入页面即生效 |
| 固定列 | 勾选列 + `单号` 左固定；`操作` 右固定 |
| 审核状态 tone | 草稿→warning、待审核→info、已审核→success |
| 业务状态 tone | 正常→info、已完结→success、已取消→neutral |
| 行内操作 | 见 §6；已审核+正常不提供主单取消 |

## 5. 分页与勾选规则

### 5.1 分页

- 表格底部固定分页区：页码、每页条数、总条数摘要等，行为与工程内 `Pagination` 一致。
- 提交查询、重置筛选后回到第一页。

### 5.2 勾选

- 勾选键以**单据 ID** 为单位。
- 一期勾选仅配合页头导出「已勾选」范围。

## 6. 行操作按钮

行内操作按状态互斥展示，最多直出 3 个 +「更多」下拉。

| 审核状态 | 业务状态 | 行内操作 |
| :--- | :--- | :--- |
| 草稿 | 正常 | 编辑 提交 删除 |
| 待审核 | 正常 | 审核 撤回 取消 |
| 已审核 | 正常 | 无（不提供；收口方式见Q05） |
| 已审核 | 已完结 | 无 |
| 任意 | 已取消 | 无 |

| 步骤 | 内容 |
| :--- | :--- |
| 打开向导 | 页头「导出」 |

## 8. 反馈规范

| 操作 | 反馈方式 | 文案 |
| :--- | :--- | :--- |
| 搜索成功 | 无额外反馈 | 直接刷新列表结果 |
| 搜索失败 | Toast | 搜索失败，请检查查询条件后重试 |
| 查询无结果 | 空状态 | 该条件下暂无分步式调拨单，可调整查询条件后重试 |
| 导出 | Toast | 导出任务已创建，请到导入导出中心查看和下载 |
| 加载失败 | 错误态 | 加载失败，请重试 |

本页不触发提交、审核等弹窗（弹窗由列表行内与详情页触发，见弹窗 PRD）。

## 9. Mock 数据要求与演示验收

### 9.1 Mock 数据覆盖

- 列表至少 **8 条**单据（去重后）
- 审核状态覆盖：草稿 **2 单**、待审核 **2 单**、已审核 **4 单**
- 业务状态覆盖：正常 **4 单**、已完结 **2 单**（含 1 单在途有余额）、已取消 **2 单**（零调出取消）
- 数量进度覆盖：未回传（累计实际调出、调入为 `-`）、已调出未调入（在途有值）、已完结（在途为 0 与在途大于 0 各 1 单）
- 至少 **1 单**调出仓与接收仓跨实体仓，用于验证仓库列展示
- **枚举与口径**：凡字段清单中已定义枚举或格式的，Mock 取值**必须落在字段清单范围内**；不得自造清单外文案

### 9.2 演示验收

| 场景 | 前置 | 操作 | 预期 |
| --- | :--- | :--- | :--- |
| 正常列表 | Mock 覆盖各状态 | 打开列表 | 两状态为语义色文字；业务状态「已关闭」显示「已完结」；默认按创建时间倒序 |
| 数量进度 | 已完结单 | 查看数量列 | 累计实际调出、累计实际调入、在途数量按公式展示 |
| 未回传展示 | 待审核／已审核未回传 | 查看数量列 | 累计实际调出、累计实际调入显示 `-` |
| 筛选 | 业务状态多选「已取消」 | 查询 | 只显示已取消记录 |
| 行操作 | 草稿／待审核单 | 查看操作列 | 分别展示「编辑 提交 删除」「审核 撤回 取消」 |
| 已审核无取消 | 已审核+正常单 | 查看操作列 | 无取消按钮 |
| 导出 | 列表非空 | 点页头导出 | 创建异步导出任务并 Toast 提示 |

Demo 验证页面呈现、筛选与跳转；不代表真实接口、并发或后端事务行为。
