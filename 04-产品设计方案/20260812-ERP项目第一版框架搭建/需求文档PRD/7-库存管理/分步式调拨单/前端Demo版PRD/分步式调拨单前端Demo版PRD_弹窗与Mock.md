### 1.1 本模块不提供的弹窗

本期不提供以下弹窗：

| 弹窗 | 说明 |
| :--- | :--- |
| 手工关闭 / 反完结确认框 | 主单在第二张直接调拨单生成后自动完结，不提供手工关闭与反完结（主PRD R10、Q01） |
| 已审核主单取消确认框 | 已审核后不提供主单直接取消；零调出由仓库回传按取消处理（主PRD §6.4、R13、Q05） |
| 财务ERP重推确认框 | 主单不推财务ERP；两端直接调拨单推送失败后在**系统集成中心**针对原单重推 |
| 手工调整预占 | 预占不能手工增改，只能由审核占用、实出消耗、未发与取消释放（[《预占与冻结主PRD》](../../预占与冻结/预占与冻结主PRD.md) §二） |
| 少收差异抹平确认框 | 少收差额留在途，不自动抹平；由人工用其他出库从在途逻辑仓扣减 |

在途差异处理在**其他出库**模块办理，本模块不提供入口。

## 2. 确认弹窗

| 项目 | 内容 |
| :--- | :--- |
| 触发 | 新增/编辑页、列表或详情「提交」（草稿+正常） |
| 标题 | 确认提交分步式调拨单？ |
| 正文 | 提交后进入待审核状态，调出仓、接收仓、商品与计划调拨数量不可再修改；审核通过时按计划数量预占调出仓可用库存，可用不足不能审核；审核前仍可撤回修改。 |
| 主按钮 | 确认提交 |
| 次按钮 | 取消 |

| 主按钮 | 确认撤回 |
| 次按钮 | 取消 |

### 2.3 取消（待审核）

| 项目 | 内容 |
| :--- | :--- |
| 触发 | 列表或详情「取消」（待审核+正常） |
| 标题 | 取消分步式调拨单 |

### 2.5 审核确认

## 3. Demo Mock：调出仓回传生成（F09-A）

### 3.1 正式规则（必读）

正式环境中，调出仓执行一次调出并回传实际调出数量：实出必须大于0且不超过通知调出数量，超量整次拒绝；校验通过后通知变为已发货，系统生成调出端直接调拨单（调出仓减、在途加），消耗实出对应预占、释放未发部分，并按实际调出量生成调入通知单推送接收仓。实出为0时，来源分步式调拨单按零出取消，不生成后续单据，释放未执行预占。

本节 Mock **仅用于 Demo 原型串联展示**，不属于主PRD AC01～AC14 的正式验收项（主PRD F09）。

### 3.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 分步式调拨单详情（已审核+正常）「模拟调出仓回传(Mock)」 | 打开 §3.3 弹窗，录入实际调出数量；确认后按 §3.4 本地生成 |

```
分步式调拨单详情（已审核+正常）
      │
  Mock 调出仓回传
      │
      ▼
 实出 >0 ？ ──否──> 按零出取消主单
      │              不生成在途、调入通知与两张结果单
      是
      ▼
 实出 ≤ 通知调出数量 ？ ──否──> 整次拒绝，提示超量
      │
      是
      ▼
 §3.4 本地生成
 调出端直接调拨单（已审核）
 调出仓 −90、在途 +90
 生成调入通知单（待推送→待收货）
```

### 3.3 引导弹窗

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 模拟调出仓回传（Demo） |
| 正文 | 按实际调出数量生成演示用调出端直接调拨单与调入通知单；正式流程以仓库回传为准。 |
| 表单项 | 回传环节（固定「调出仓回传」）、实际调出数量 |
| 主按钮 | 确认回传 |
| 次按钮 | 取消 |
| 关闭图标 | 关闭后不生成任何数据 |

### 3.4 生成规则（本地 Mock）

| 项目 | Mock 规则 |
| :--- | :--- |
| 生成条件 | 主单已审核+正常；实际调出为正整数、大于0、不超过通知调出数量 |
| 调出端直接调拨单 | 来源类型=分步式调出端；来源逻辑仓=调出仓；目标逻辑仓=虚拟在途仓；审核状态=已审核；推送财务ERP状态从未推送开始 |
| 库存 | 调出仓即时库存减、在途加；写两条库存流水；消耗实出预占、释放未发预占（Demo 可在库存查询页核对） |
| 回写 | 主单累计实际调出、未调出数量与在途数量更新；调出通知单状态=已发货 |
| 调入通知单 | 按实际调出量生成，状态=待收货（Demo 可继续用 §4 模拟接收仓回传） |
| 单号 | 调出端结果按 ZJDB、调入通知按 DRTZ 编码规则生成 fictitious 编号 |
| 超量分支 | 实出大于通知调出数量时：整次拒绝并提示「回传数量超过通知数量，已整次拒绝」；不记账、不生成单据 |
| 零调出分支 | 实出=0时：主单业务状态=已取消、调出通知单=已取消；不生成后续单据、不改变库存 |
| 负库存分支 | 记账后调出仓即时或可用库存将为负时：阻断并提示「库存不足，不允许负库存」 |

界面标注「演示数据」或「Mock」角标，与正式回传生成的结果单区分。

### 3.5 不做的事

- 不代替正式接口校验与映射
- 不在 Mock 中自动执行财务ERP正式推送
- 不在 Mock 中制造负库存
- 不生成零数量的结果单

## 4. Demo Mock：接收仓回传生成与主单完结（F09-B）

### 4.1 正式规则（必读）

正式环境中，接收仓执行一次接收并回传实际接收数量：实收必须大于0且不超过通知调入数量，超量整次拒绝；实收为0属异常，拒绝整次回传并报错，通知单保持等待，不按零收取消。实收大于0时通知变为已收货，系统生成调入端直接调拨单（在途减、接收仓加），回写主单累计实际调入与在途数量，主单自动完结（业务状态=已关闭、页面展示「已完结」）。少收差额继续留在途，不自动抹平。

### 4.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 分步式调拨单详情「模拟接收仓回传(Mock)」；或调入通知单详情 Mock 回传后 | 打开弹窗录入实际调入数量；确认后按 §4.4 本地生成 |

### 4.3 引导弹窗

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 模拟接收仓回传（Demo） |
| 正文 | 按实际调入数量生成演示用调入端直接调拨单并触发主单完结；正式流程以仓库回传为准。 |
| 表单项 | 回传环节（固定「接收仓回传」）、实际调入数量 |
| 主按钮 | 确认回传 |
| 次按钮 | 取消 |

### 4.4 生成规则（本地 Mock）

| 项目 | Mock 规则 |
| :--- | :--- |
| 生成条件 | 调入通知单处于待收货；实际调入为正整数、大于0、不超过通知调入数量 |
| 调入端直接调拨单 | 来源类型=分步式调入端；来源逻辑仓=虚拟在途仓；目标逻辑仓=接收仓；审核状态=已审核；推送财务ERP状态从未推送开始 |
| 库存 | 在途减、接收仓即时库存加；写两条库存流水；少收差额留在途 |
| 回写 | 主单累计实际调入、在途数量更新；调入通知单状态=已收货、少收数量计算展示 |
| 主单完结 | 生成调入端直接调拨单后，主单业务状态=已关闭（页面展示「已完结」）；关闭方式=两端执行完成自动完结，关闭原因与关闭操作人留空 |
| 单号 | 调入端结果按 ZJDB 编码规则生成 fictitious 编号 |
| 超量分支 | 实收大于通知调入数量时：整次拒绝并提示「回传数量超过通知数量，已整次拒绝」 |
| 零调入分支 | 实收=0时：拒绝整次回传并提示「实际调入必须大于0，回传已被拒绝，请改为大于0后重新回传」；通知单保持待收货，主单保持已审核+正常 |
| 少收展示 | 实收小于通知调入数量时：主单在途数量保留差额；页面提示「少收差额留在途，不自动抹平，后续用其他出库从在途逻辑仓扣减」 |

界面标注「演示数据」或「Mock」角标。

### 4.5 不做的事

- 不代替正式接口校验与映射
- 不在 Mock 中自动抹平在途差异
- 不把 Mock 推送当作财务ERP正式验收

## 5. 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| Mock 调出回传（少发） | 主单计划100件，Mock 调出回传90 | 生成已审核调出端直接调拨单；调出仓−90、在途+90；消耗预占90、释放10；调入通知按90件生成 |
| Mock 调出回传（零调出） | Mock 调出回传0 | 主单已取消、调出通知单已取消；不生成后续单据、不改变库存、释放未执行预占 |
| Mock 调出超量 | Mock 调出回传110（通知100） | 整次拒绝并提示；不记账、不生成单据 |
| Mock 调入回传（少收） | 承接调出90，Mock 接收回传88 | 生成已审核调入端直接调拨单；在途由90减为88、接收仓+88；主单已完结；剩余2留在途 |
| Mock 调入回传（零调入） | Mock 接收回传0 | 拒绝整次回传并提示；通知单保持待收货；主单保持已审核+正常 |
| Mock 负库存 | 调出回传数量超过调出仓可用 | 阻断并提示不允许负库存；不生成结果单 |
| 无手工关闭弹窗 | 在已审核或已完结单查找关闭入口 | 无关闭按钮、无关闭确认弹窗 |
| 无主单取消弹窗 | 在已审核单查找取消入口 | 无取消按钮、无取消确认弹窗 |

Demo 验证 Mock 本地数据联动；不代表生产接口、并发或后端事务行为。**本章 Mock 仅 Demo，非正式验收。**
