## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 调出通知单详情页 |
| 入口 | 列表点单号 |
| 页面目标 | 只读查看调出指令全貌；按当前状态办理取消与重试；追溯来源主单与调出端结果单 |
| 骨架结构 | 页头 → 单据信息（含推送信息） → 商品明细 → 关联单据 → 终止信息（条件） → 系统信息 |

本页落地 **F04**；状态—操作矩阵见主PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头状态标签：单据状态一枚 StatusBadge。
> - 关联单据：商品明细之后展示胶囊 Tab（调出端直接调拨单、调入通知单），带数量。
> - 终止信息：已取消时展示取消原因、取消操作人、取消时间。
> - 操作信息：制单信息 Tab；完整操作日志一期后置。
> - 二次确认弹窗正文在[弹窗 PRD](调出通知单前端Demo版PRD_弹窗与Mock.md)维护，本文只写入口与结果表现。
> - Demo 以桌面端为基准；明细、关联简表窄视口横向滚动。

## 2. 页头

### 2.1 标题与状态

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `调出通知单详情 · {单号}` |
| 状态标签 | 单据状态一枚（待推送／推送中／推送失败／待发货／取消中／已发货／已取消） |
| 布局 | 单行：左侧标题 + 状态；右侧操作区（`DocumentDetailFrame`） |

### 2.2 页头操作按钮

`返回列表` **始终排在最前**；其后按状态展示业务按钮。

| 按钮 | 待推送 | 推送中 | 推送失败 | 待发货 | 取消中 | 已发货 | 已取消 | 说明 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| 返回列表 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | 始终 |
| 重试推送 | ❌ | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ | 弹窗 PRD §2.3 |
| 取消 | ✅ | ❌ | ✅ | ✅ | ❌ | ❌ | ❌ | 弹窗 PRD §2.1／§2.2 |

**渲染纪律**：

- 条件不满足的按钮**直接不渲染**，不展示灰色 disabled。
- 样式层级：`重试推送` 用 `outline`；`取消` 用 `outline`；`返回列表` 固定最左。
- 推送中、取消中：仅查看与等待，不提供取消、重试。

二次确认入口与确认后的页面表现统一在第五节维护；弹窗正文引用弹窗PRD。

## 3. 信息分区与字段

> 只读 **6 列栅格**（默认），标签在上、值在下。字段顺序与 TSV 分组一致。

**分区总览**：页头 → **3.1 单据信息** → **3.2 商品明细** → **3.3 关联单据** → **3.4 终止信息** → **3.5 系统信息**

### 3.1 单据信息

推送信息并入本区展示。

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样展示 |
| 来源分步式调拨单 | 链接，可跳转来源主单详情 |
| 调出仓 | 逻辑仓 Code-Name；不含虚拟在途仓 |
| 推送时间 | 未推送时显示 `-` |
| 推送失败原因 | 长文本省略，hover 看全文；未失败时显示 `-` |
| 最终发货确认时间 | 未确认时显示 `-` |

### 3.2 商品明细

- 表格只读；数量列**右对齐**；横向滚动。
- 一期不分页。
- 无价税列。

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 从1起 |
| 商品 | 商品名称 |
| 商品编码 | 原样 |
| 商品名称 | 原样 |
| 基本单位 | 原样 |
| 通知调出数量 | 整数；等于来源主单该行计划调拨数量 |
| 实际调出数量 | 未确认时显示 `-`；零调出时显示0 |
| 未发数量 | ＝通知调出数量−实际调出数量 |

### 3.3 关联单据

**展示条件**：商品明细之后（有记录时展示）

组件：`RelatedDocumentsCard` + `InnerTabs` `pill`；Tab 文案带数量。

| Tab | 列 | 排序 | 空态 |
| :--- | :--- | :--- | :--- |
| 调出端直接调拨单 | 单号、审核状态、推送财务ERP状态、实际调拨数量、创建时间 | 创建时间升序 | 暂无关联的调出端直接调拨单 |
| 调入通知单 | 单号、单据状态、通知调入数量、实际调入数量、少收数量、创建时间 | 创建时间升序 | 暂无关联的调入通知单 |

单号可点击跳转对应详情。

### 3.4 终止信息

**展示条件**：单据状态=已取消

| 字段 | 展示说明 |
| :--- | :--- |
| 取消原因 | 零调出取消时按仓库确认说明展示 |
| 取消操作人 | 零调出由系统按取消处理时显示 `-` |
| 取消时间 | 原样展示 |

### 3.5 系统信息

胶囊 Tab：[制单信息] / [操作日志]

| Tab | 内容 |
| :--- | :--- |
| 制单信息 | 创建人、创建时间、最后更新人、最后更新时间；系统自动生成时显示「系统」 |
| 操作日志 | 表格列：操作时间、操作人、操作类型、说明；完整审计日志一期后置 |

## 4. 字段展示规范

空值、Code-Name、数字与日期格式、状态样式、关联简表均引用公共规范；不在此重抄。数量为整数、不允许小数。

| 字段或区域 | 本页差异 | 依据 |
| --- | --- | --- |
| 调出仓 | Code-Name 展示；不含虚拟在途仓 | 主PRD R01；《库存与仓储业务设计》§4.2 |
| 实际调出数量 | 未确认显示 `-`；零调出显示0 | TSV 取值说明 |
| 单据状态 | 不另设「推送成功」状态；推送中按《单据与状态流转》§三保留；不设部分发货状态 | 《单据与状态流转》§三 |

## 5. 操作行为

| 操作 | 点击行为或弹窗入口 | 确认后页面表现 |
| :--- | :--- | :--- |
| 取消（待推送/推送失败） | 弹窗 PRD §2.1 | 刷新详情；单据状态=已取消；展示终止信息 |
| 取消（待发货） | 弹窗 PRD §2.2 | 刷新详情；单据状态=取消中；等待仓库回执 |
| 重试推送 | 弹窗 PRD §2.3 | 刷新详情；单据状态=推送中；推送失败原因保留历史 |
| 返回列表 | 返回列表 | 保留原筛选与页码 |

## 6. 反馈与页面状态

### 6.1 操作反馈（Toast）

| 操作 | 反馈类型 | 文案 |
| :--- | :--- | :--- |
| 取消成功（待推送/推送失败） | Toast | 通知单已取消，未执行预占已释放 |
| 取消申请已提交 | Toast | 已向仓库发起取消，等待仓库回执 |
| 重试推送 | Toast | 已重新推送调出仓 |
| 推送失败（重试） | Toast | 推送失败：{失败原因}，系统将继续自动重试 |
| 状态已变更 | Toast | 操作失败，单据状态已变更，请刷新后重试 |

Mock 专属弹窗见弹窗 PRD。

### 6.2 加载与异常态

| 场景 | 页面表现 | 文案 / 操作 |
| :--- | :--- | :--- |
| 加载中 | 骨架屏 | — |
| 单据不存在 | 错误态 | 单据不存在或已被删除；返回列表 |
| 加载失败 | 错误态 | 加载失败，请重试；重试 + 返回列表 |

## 7. Mock 与验收

### 7.1 Mock 覆盖清单

- 各主状态至少 1 单：待推送、推送中、推送失败、待发货、取消中、已发货、已取消
- 关联 Tab 有数据 + 空态：已发货单有调出端直接调拨单与调入通知单；未回传单为空态
- 终止信息边界：已取消单展示取消原因、取消时间；取消操作人为空
- 数量边界：未回传显示 `-`；少发显示未发数量；零调出显示0与未发＝通知数量

### 7.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 正常路径 | 打开待发货单 | 单据状态=待发货；页头只有「返回列表」「取消」 |
| 少发 | 打开已发货且少发的单 | 实际调出与未发按回写展示；关联 Tab 有调出端结果与调入通知 |
| 零调出 | 打开已取消单 | 单据状态=已取消；实际调出0、未发＝通知调出数量；关联 Tab 为空态 |
| 推送失败 | 打开推送失败单 | 页头展示「重试推送 取消」；展示失败原因 |
| 无取消入口 | 打开推送中/取消中/已发货单 | 无取消按钮 |

模拟的保存、状态变化和关联结果应可连续演示；Demo 验证不代表真实接口、并发或后端事务已验证。
