## 2. 本期结论

**本期不提供新增页，也不提供编辑页。**

调出通知单的创建方式为：

1. 分步式调拨单审核通过 → 系统自动生成调出通知单并分配单号（前缀DCTZ）；
2. 生成后由系统自动推送调出仓，不需要人工触发推送。

通知单的调出仓、商品与通知调出数量全部沿用来源主单，创建后不可修改。

| 不做的事 | 说明 |
| :--- | :--- |
| 人工新建通知单 | 不提供入口（主PRD §3.4） |
| 编辑通知数量、调出仓、商品 | 创建后只读（主PRD R01） |
| 编辑备注 | 当前画法不提供（主PRD Q01）；备注随来源主单 |
| 通知单导入 | 本期不做 |
| 人工推送 | 创建后系统自动推送，无人工推送按钮（主PRD R03） |
| 虚拟出库／虚拟入库处理方式 | 调出、调入通知单本期不增加处理方式字段（《单据分层设计》§5.10） |
