## 1. 页面目标与范围

- 页面名称：调出通知单列表页
- 查看视角：**仅单据视角**（每行 = 一张调出通知单；商品仅作查询条件）
- 作为详情、导出的统一入口
- 一期以**行内操作**为主；行内提供取消、重试推送
- 功能与状态—操作矩阵见[《调出通知单主PRD》](../调出通知单主PRD.md) §6.4；本页落地 F01

> **本期边界**：
> - 页头**只有导出**，**无新增**入口（通知单由主单审核后系统自动生成）。
> - 批量操作栏**不放**任何业务按钮；勾选仅配合导出「已勾选」。
> - 列表行**不提供**「联查」按钮；查看来源主单请通过单号链接或对应单据列表跳转。
> - 推送中、取消中仅查看；已发货、已取消为终态。

## 2. 查询区

> 可筛选字段与顺序以[《调出通知单（详细稿）》](../../../../字段清单合集/库存相关/调出通知单/调出通知单（详细稿）.tsv)「可筛选=是」为准；下表为默认查询方案呈现顺序。
> **type 列**：与原型 `FilterControl` 的 `type` 一致，完整规范见[《原型开发说明》](../../../../../../09-产品原型/原型开发说明.md)「查询区通用规则」「FilterControl 控件 type」。

| 查询字段 | type | 匹配 | placeholder / 说明 |
| :--- | :--- | :--- | :--- |
| 单号 | `search` | 模糊 | 请输入调出通知单号 |
| 来源分步式调拨单 | `search` | 模糊 | 请输入来源分步式调拨单号 |
| 调出仓 | `searchable-select` | 精确 | 全部；选项为审核通过且启用的逻辑仓（Code-Name，不含虚拟在途仓） |
| 单据状态 | `multi-select` | 精确（OR） | 全部；待推送／推送中／推送失败／待发货／取消中／已发货／已取消；初值 `[]`，未选=全部 |
| 商品 | `search` | 模糊 | 请输入商品编码；按明细商品筛选 |
| 创建时间 | `date-range` | 区间 | 不限；原型暂无 `datetime-range`，一期按日期比较（09《待改项》） |

查询区交互（收起过滤、重置、查询、空条件默认、查询后回第一页）见《原型开发说明》「查询区通用规则」。查询条件全空时，默认返回最新列表数据（默认按创建时间倒序）。

## 4. 列表表格

### 4.1 视角说明

本期仅**单据视角**：每行一张调出通知单。商品仅作查询条件，不在列表展开为多行。

### 4.2 列定义

通用对齐、千分位、空值、列表状态样式等见《原型开发说明》「列表列通用呈现规则」。下表只写本页列清单与模块差异。

| # | 列名 | 展示形式 | 对齐 | 排序 | 空值 | 格式/示例 | 说明 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 勾选 | 复选框 | 居中 | — | — | — | 配合导出「已勾选」；一期无批量业务操作 |
| 2 | 单号 | 链接 | 左 | 否 | — | `DCTZ-20260923-0001` | 固定左侧；点击进详情；行内不设「查看」 |
| 3 | 来源分步式调拨单 | 链接 | 左 | 否 | `-` | `FBDB-20260923-0001` | 点击跳转来源主单详情 |
| 4 | 调出仓 | 文本 | 左 | 否 | `-` | `LWH000001 深圳仓` | 逻辑仓 Code-Name；不含虚拟在途仓 |
| 5 | 单据状态 | 语义色文字 | 左 | 否 | `-` | 待推送／推送中／推送失败／待发货／取消中／已发货／已取消 | 列表不用 StatusBadge；tone 见 §4.3 |
| 6 | 通知调出数量 | 数值 | 右 | 是 | `0` | `100` | 各明细行通知调出数量之和 |
| 7 | 实际调出数量 | 数值 | 右 | 是 | `-` | `90` | 各明细行合计；最终结果未确认前显示 `-` |
| 8 | 未发数量 | 数值 | 右 | 是 | `0` | `10` | ＝通知调出数量−实际调出数量 |
| 9 | 推送时间 | 日期时间 | 左 | 是 | `-` | `2026-09-23 09:31:00` | 未推送时显示 `-` |
| 10 | 推送失败原因 | 文本 | 左 | 否 | `-` | `仓库接口超时` | 长文本省略，hover 看全文 |
| 11 | 创建时间 | 日期时间 | 左 | 是 | `-` | `2026-09-23 09:31:00` | 默认排序依据 |
| 12 | 最后更新时间 | 日期时间 | 左 | 是 | `-` | `2026-09-23 09:31:00` | — |
| 13 | 操作 | 行内按钮 | 左 | — | — | — | 固定右侧；按状态互斥展示 |

列顺序原则：单号、来源、仓库、状态、数量在前；时间靠后。

### 4.3 本页列表约定

| 项目 | 规则 |
| :--- | :--- |
| 默认排序 | `创建时间` 降序；进入页面即生效 |
| 固定列 | 勾选列 + `单号` 左固定；`操作` 右固定 |
| 单据状态 tone | 待推送→warning、推送中→info、推送失败→danger、待发货→info、取消中→warning、已发货→success、已取消→neutral |
| 行内操作 | 见 §6；推送中、取消中、已发货、已取消无操作 |

## 5. 分页与勾选规则

### 5.1 分页

- 表格底部固定分页区：页码、每页条数、总条数摘要等，行为与工程内 `Pagination` 一致。
- 提交查询、重置筛选后回到第一页。

### 5.2 勾选

- 勾选键以**单据 ID** 为单位。
- 一期勾选仅配合页头导出「已勾选」范围。

## 6. 行操作按钮

行内操作按状态互斥展示，最多直出 3 个 +「更多」下拉。

| 单据状态 | 行内操作 |
| :--- | :--- |
| 待推送 | 取消 |
| 推送中 | 无 |
| 推送失败 | 重试推送 取消 |
| 待发货 | 取消 |
| 取消中 | 无 |
| 已发货 | 无 |
| 已取消 | 无 |

零调出按取消处理时，单据状态为「已取消」、实际调出显示0、未发＝通知调出数量。

## 7. 导出

| 步骤 | 内容 |
| :--- | :--- |
| 打开向导 | 页头「导出」 |
| 范围选择 | 全部／当前筛选结果／已勾选 |

## 8. 反馈规范

| 操作 | 反馈方式 | 文案 |
| :--- | :--- | :--- |
| 搜索成功 | 无额外反馈 | 直接刷新列表结果 |
| 搜索失败 | Toast | 搜索失败，请检查查询条件后重试 |
| 查询无结果 | 空状态 | 该条件下暂无调出通知单，可调整查询条件后重试 |
| 导出 | Toast | 导出任务已创建，请到导入导出中心查看和下载 |
| 加载失败 | 错误态 | 加载失败，请重试 |

本页不触发新增、编辑弹窗；取消与重试推送弹窗见弹窗 PRD。

## 9. Mock 数据要求与演示验收

### 9.1 Mock 数据覆盖

- 列表至少 **9 条**单据（去重后）
- 单据状态覆盖：待推送 **1 单**、推送中 **1 单**、推送失败 **1 单**、待发货 **2 单**、取消中 **1 单**、已发货 **2 单**、已取消 **1 单**（零调出）
- 数量覆盖：未回传（实际调出为 `-`）、已回传（实际调出有值、未发计算展示）、零调出（实际调出0、未发＝通知数量）
- 至少 **1 单**来源主单可跳转
- **枚举与口径**：凡字段清单中已定义枚举或格式的，Mock 取值**必须落在字段清单范围内**；不得自造清单外文案

### 9.2 演示验收

| 场景 | 前置 | 操作 | 预期 |
| --- | :--- | :--- | :--- |
| 正常列表 | Mock 覆盖各状态 | 打开列表 | 单据状态为语义色文字；默认按创建时间倒序 |
| 无新增 | — | 看页头 | 只有「导出」，无「新增」 |
| 筛选 | 单据状态多选「推送失败」 | 查询 | 只显示推送失败记录 |
| 来源跳转 | 任意单据 | 点击来源分步式调拨单列 | 进入来源主单详情 |
| 数量展示 | 已发货单 | 查看数量列 | 实际调出有值；未发＝通知−实际 |
| 零调出 | 已取消单 | 查看数量列 | 实际调出显示0；未发＝通知调出数量 |
| 行操作 | 推送失败单 | 查看操作列 | 展示「重试推送 取消」 |
| 导出 | 列表非空 | 点页头导出 | 创建异步导出任务并 Toast 提示 |

Demo 验证页面呈现、筛选与跳转；不代表真实接口、并发或后端事务行为。
