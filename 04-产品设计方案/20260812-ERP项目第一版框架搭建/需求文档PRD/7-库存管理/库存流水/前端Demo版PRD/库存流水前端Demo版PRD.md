## 列表与查询

| 内容 | 设计 |
| --- | --- |
| 用户任务 | 按逻辑仓、商品、时间回看库存变动，从来源单号定位结果单，导出 |
| 页面名称与入口 | 库存流水；菜单「库存管理-库存流水」 |
| 展示数据范围 | 全部逻辑仓（含已禁用逻辑仓、虚拟在途仓）的库存变动记录，含冻结、解冻，以及B2B销售订单预占／释放流水；其他业务预占沿用原口径（《库存流水主PRD》R01）；在途仓行按普通行口径计入（Q05已定） |
| 默认排序 | `变动时间` 降序 |

### 查询条件

> **type 列**与原型 `FilterControl` 一致；通用规则见《原型开发说明》「查询区通用规则」「FilterControl 控件 type」；「变动时间」按日期＋时间范围（`datetime-range`），原型已支持该控件（见09《原型开发说明》「FilterControl 控件 type」）。

| 查询字段 | type | 匹配 | placeholder / 说明 |
| :--- | :--- | :--- | :--- |
| 逻辑仓 | `multi-select` | 精确（多选 OR） | 全部逻辑仓；选项为全部逻辑仓（含已禁用，Code-Name 展示） |
| 所属实体仓 | `select` | 精确 | 全部实体仓（含已禁用；Code-Name 展示） |
| 商品编码 | `search` | 模糊（支持批量） | 支持批量输入：多个编码用换行或逗号分隔，任一命中即返回 |
| 商品条码 | `search` | 模糊（支持批量） | 请输入商品条码；多个值用换行或逗号分隔 |
| 商品名称 | `search` | 模糊 | 请输入商品名称 |
| 库存状态 | `multi-select` | 精确（多选 OR） | 全部；选项为正常品、残次品、待检品（枚举以 TSV 为准） |
| 变动方向 | `select` | 精确 | 全部／增加／减少（冻结、解冻流水留空） |
| 变动时间 | `datetime-range` | 范围 | 不限；按日期＋时间范围比较（原型已支持 datetime-range，见09《原型开发说明》「FilterControl 控件 type」） |
| 来源单据类型 | `select` | 精确 | 全部／销售订单／采购入库单／采退出库单／销售出库单／销退入库单／其他入库单／其他出库单／直接调拨单 |
| 来源单号 | `search` | 模糊 | 请输入来源单号 |
| 业务类型 | `select` | 精确 | 全部／其他入库：盘盈、样品回收、借出归还、退料、赠品入库／其他出库：盘亏、样品领用、赠送、报废、借出（2026-09-23确认；枚举以 TSV 为准） |

查询区交互（收起过滤、重置、查询、空条件默认、查询后回第一页）见《原型开发说明》「查询区通用规则」。查询条件全空时，默认返回最新流水（按变动时间倒序）。

| 2 | 变动时间 | 日期时间 | 左 | 是 | `-` | `2026-09-23 10:20:00` | **默认排序**，降序 |
| 3 | 事件类型 | 文本 | 左 | 否 | `-` | `结果单入库` | 枚举文字，不用胶囊；含「订单预占」「订单释放」以及「冻结」「解冻」 |
| 4 | 逻辑仓 | 文本 | 左 | 否 | `-` | `LWH000001 深圳正常品仓` | Code-Name |

| 6 | 商品编码 | 文本 | 左 | 否 | `-` | `SP0102030001` | — |
| 7 | 商品条码 | 文本 | 左 | 否 | `-` | `6901001001` | 多条码合并展示 |

| 9 | 基本单位 | 文本 | 左 | 否 | `-` | `件` | 数量按基本单位 |
| 10 | 库存状态 | 文本 | 左 | 否 | `-` | `正常品` | 枚举文字 |
| 11 | 即时库存 | 文本 | 右 | 否 | `-` | `100 → 90（-10）` | 变动前 → 变动后（变动数量）；冻结、解冻显示 `x → x（0）` |
| 12 | 可用库存 | 文本 | 右 | 否 | `-` | `30 → 10（-20）` | 同上；冻结减少可用、解冻增加可用 |
| 13 | 预占库存 | 文本 | 右 | 否 | `-` | `60 → 100（+40）` | 同上；订单预占记正、订单释放记负；其他业务的单独占用与释放仍按各自规则，本组也反映出库对预占的消耗 |
| 14 | 冻结库存 | 文本 | 右 | 否 | `-` | `10 → 30（+20）` | 同上；冻结为正、解冻为负 |
| 15 | 来源单据类型 | 文本 | 左 | 否 | `-` | `直接调拨单` | 枚举文字；冻结、解冻流水为空；订单预占／释放显示销售订单 |

### 行操作

本页无行内业务操作；来源单号为链接，订单预占／释放流水进入销售订单详情，其他来源进入对应结果单详情（主PRD F02）。行内不设「查看」按钮。冻结、解冻流水来源单号为空，展示 `-`，不提供跳转。

## 页面状态与反馈文案

| 操作 | 反馈方式 | 文案 |
| :--- | :--- | :--- |
| 查询成功 | 无额外反馈 | 直接刷新列表结果 |
| 查询失败 | Toast | 搜索失败，请检查查询条件后重试 |
| 查询无结果 | 空状态 | 该条件下暂无库存变动记录，可调整查询条件后重试 |
| 来源单号跳转 | 页面跳转 | 进入结果单详情；单据不存在时 Toast「结果单不存在或不可访问」 |
| 导出 | Toast | 导出任务已创建，请到导入导出中心查看和下载 |
| 操作失败——系统繁忙 | Toast | 操作失败，请稍后重试 |

## 演示数据与验收

### Mock 数据覆盖

- 列表至少 **12 条**记录（去重后）
- 至少覆盖 **3 个逻辑仓**、**2 个实体仓**、**5 个商品**、**3 种库存状态**
- 七类结果单来源类型每种至少 **1 条**；其中 **2 条**来自同一张直接调拨单；另含至少 **1 条**销售订单预占和 **1 条**订单释放流水，用于验证销售订单来源跳转
- 至少 **2 条**冻结、解冻流水（事件类型：冻结／解冻，来源单据类型与来源单号为空，用于验证来源为空与 `x → x（0）` 表达）
- 至少 **1 条**结果单入库、**1 条**结果单出库；**1 条**业务类型有值（如盘盈）、**1 条**为空
- 四组变动明细覆盖：至少 **1 条**有变化的组、**1 条**无变化的组（显示 `x → x（0）`）；至少 **1 条**出库消耗预占（预占组记负，可用组按「即时减少−预占减少」体现变化，实出等于预占时可用不变）
- 至少 **2 条**跨不同日期与时间，用于验证变动时间范围筛选
- 至少 **1 条**虚拟在途仓行，按普通行口径计入
- **枚举与口径**：凡字段清单中已定义枚举或格式的，Mock 取值**必须落在字段清单范围内**；不得自造清单外文案

### 演示验收

| 场景 | 前置 | 操作 | 预期 |
| --- | :--- | :--- | :--- |
| 正常列表 | Mock 覆盖各类型 | 打开列表 | 默认按变动时间倒序；事件类型与四组变动明细展示 |
| 条件查询 | 选择逻辑仓、变动方向、业务类型 | 查询 | 只显示同时满足条件的流水 |
| 时间范围 | 输入变动时间区间 | 查询 | 返回区间内的变动记录（按日期＋时间比较） |
| 变动明细 | 查看入库、出库、冻结、解冻各一条 | 查看 | 有变化的组按 `前 → 后（变动）` 展示，无变化的组显示 `x → x（0）`；出库消耗预占时预占组记负（实出等于预占时可用组不变） |
| 冻结、解冻流水 | 查看冻结、解冻流水 | 查看 | 事件类型为「冻结」「解冻」；来源单据类型与来源单号为空，展示 `-` |
| 批量查询 | 商品编码粘贴多个编码 | 查询 | 返回命中任一编码的流水 |
| 追溯跳转 | 点击来源单号 | 点击 | 进入对应结果单详情 |
| 同来源多行 | 查看调拨两端流水 | 查看 | 两条方向相反的记录指向同一来源单号 |
| 无编辑入口 | 任意记录 | 查看行内与页头 | 无新增、导入、编辑、删除入口 |
| 导出 | 列表非空 | 点页头导出 | 创建异步导出任务并 Toast 提示；导出含四组变动明细 |

Demo 验证页面呈现、筛选与跳转；不代表真实接口、并发或后端事务行为。
