> **通用口径**：控件校验与错误展示见[《UI布局公共说明》](../../../../../../05-常用模板/02-模块设计交付/UI布局公共说明.md)、[《原型开发说明》](../../../../../../09-产品原型/原型开发说明.md)（表单页标准接线）；字段模板见[《6.强盛ERP的编码规则和通用字段规则》](../../../../../../01-全局背景信息/6.强盛ERP的编码规则和通用字段规则.md)。

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 直接调拨单新增 / 草稿编辑（人工一步式） |
| 页面目标 | 录入或修改ERP主动发起的账内调整：从哪个逻辑仓转到哪个逻辑仓、转什么、转多少 |
| 适用状态 | 新增页建草稿；**仅审核状态=草稿且来源类型=人工一步式**可进入编辑（含撤回后回到草稿） |
| 骨架结构 | 页头（标题 + 操作按钮）→ 单据信息 → 商品明细 |

> 操作按钮固定在**页头右侧**，不使用底部固定操作栏。待审核、已审核不可进入本页；自动生成的结果单（分步式两端、仓库主动回传）整单只读，不进入本页。本页落地 **F02（保存）**、**F03（提交入口）**；状态—操作矩阵见主PRD §6.4。

| 模式 | 入口 | 差异摘要 |
| :--- | :--- | :--- |
| **新增** | 列表「新增」 | 单号占位「保存后自动生成」；来源类型固定显示「人工一步式」；页头无状态标签 |
| **编辑** | 列表/详情「编辑」 | 单号只读；页头 `[草稿]` StatusBadge；来源类型只读 |

**本期边界**：页头 **取消 / 保存 / 提交**；本页无导入入口；不设价税字段与成本价格字段；关联单据、审核信息、制单信息不在本页；已审核后不提供本页编辑入口。本单**不推送仓库、不涉及预占**，审核通过后一减一增。

## 2. 页头

| 元素 | 规格 |
| :--- | :--- |
| 标题（新增） | `新增直接调拨单` |
| 标题（编辑） | `编辑直接调拨单`；单号在表单区只读展示 |
| 状态标签 | 新增不展示；编辑展示一枚StatusBadge（审核状态） |
| 操作区 | 从左到右：`取消` → `保存` → `提交` |

| 按钮 | 说明 |
| :--- | :--- |
| 取消 | 返回列表；有未保存修改时二次确认（弹窗PRD §2.5） |
| 保存 | 通过 §4.2校验后保存为草稿 |
| 提交 | 通过 §4.3校验 → 提交确认弹窗（弹窗PRD §2.1） |

保存/提交时当前按钮loading，另一操作按钮同步disabled，防重复点击；失败保留已填内容。

## 3. 表单分区与字段

> 单头 **6列栅格**，标签在上、控件在下；备注占 **3列**。控件 `type` 对齐原型 `FormControl` / `LineItemTable`。主数据按Code-Name（`{编码} {名称}`）展示。**placeholder** 指控件无值时的占位文案；只读/禁用填 `—`。

区域顺序：**单据信息 → 商品明细**（与TSV一致）。

### 3.1 单据信息

| 字段 | 控件type | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 单号 | `disabled` | `保存后自动生成`（新增）/ `—`（编辑有值） | 编辑只读展示系统单号，前缀ZJDB（R01） |
| 来源类型 | `disabled` | `—` | 固定显示「人工一步式」；本页只创建人工一步式（R02） |
| 来源逻辑仓 | `searchable-select` | `请选择来源逻辑仓` | 审核通过且启用的逻辑仓；**不能选虚拟在途仓**；与目标仓不能相同（R02） |
| 目标逻辑仓 | `searchable-select` | `请选择目标逻辑仓` | 同上；不能与来源仓相同（R02） |
| 备注 | `textarea` | `请输入备注` | 选填；`REMARK_500`；占3列 |

栅格排布见骨架：按TSV行序分行绘制，备注占第1～3列。

单据信息下方固定展示提示行：**「来源逻辑仓与目标逻辑仓不能相同，也不能选择虚拟在途仓；审核通过后来源仓减少、目标仓增加，不推送仓库、不涉及预占。」**

### 3.2 商品明细

独立表格区块，横向滚动。

#### 3.2.1 表格操作

| 操作 | 位置 | 说明 |
| :--- | :--- | :--- |
| 添加明细 | 工具条 | 打开SKU选择弹窗；确认后插入行 |
| 删除 | 行内 | 删除该行；草稿允许没有明细行 |

**明细区错误条**（工具条上方，可选实现）：仅用于「请至少添加一行有效商品明细」等**跨行**提示；修正后即时消除。单行字段问题优先用Toast。

#### 3.2.2 列定义

| 列名 | 可编辑 | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 行号 | 只读 | `—` | 从1起自动编号 |
| 商品 | 选品入口 | `请选择商品` | 确认后按TSV「明细展示商品名称」显示 |
| 商品编码 | 只读 | `—` | 随商品带出 |
| 商品名称 | 只读 | `—` | 随商品带出 |
| 基本单位 | 只读 | `—` | 随商品带出，与商品名称一起展示 |
| 实际调拨数量 | 可编辑 | `—` | `QTY_INT`；正整数 >0；审核后来源仓减、目标仓加 |

#### 3.2.3 SKU选择弹窗（本页配置）

| 配置项 | 本页取值 |
| :--- | :--- |
| 选品方式 | 支持搜索；可多选批量插入（与原型 `enableSkuPicker` 一致） |
| 商品范围 | 启用成品SKU |
| 确认后写入 | 按TSV展示商品名称、带出商品编码与基本单位 |
| 更换商品 | 删除行后重新选品；行内商品列不直接手改 |
| 重复商品 | 建议同一商品合并为一行（待确认Q03）；Demo按提示合并 |

#### 3.2.4 底部汇总

| 汇总项 | 展示 |
| :--- | :--- |
| 实际调拨数量合计 | 与「实际调拨数量」列右对齐，整数 |

## 4. 校验规则

提交相关弹窗见[弹窗PRD §2](直接调拨单前端Demo版PRD_弹窗与Mock.md)。下文 **保存** 指点「保存」，**提交** 指点「提交」（含保存口径 + 加强项）。

### 4.1 校验分层总览

| 层级 | 时机 | 内容 |
| :--- | :--- | :--- |
| 字段级 | 失焦/保存 | 必填、整数、大于0、两仓不相同、非在途仓 |
| 单据级 | 保存/提交 | 保存：明细可为空；提交：至少一行明细且每行实际调拨数量>0（R03、R08） |
| 服务端 | 提交/审核 | 状态允许、仓的资格与在途仓限制、可用量与负库存校验（审核时） |

### 4.2 保存校验

| 字段/场景 | 规则 | 提示 |
| :--- | :--- | :--- |
| 来源逻辑仓 | 必选 | Toast「请选择来源逻辑仓」 |
| 目标逻辑仓 | 必选；不能与来源仓相同 | Toast「目标逻辑仓不能与来源逻辑仓相同」 |
| 在途仓 | 两仓均不能选虚拟在途仓 | Toast「虚拟在途仓不能作为人工一步式的来源或目标逻辑仓」 |
| 实际调拨数量 | 每行正整数、大于0 | 行内标红 + Toast「实际调拨数量须为大于0的整数」 |
| 明细行 | 草稿允许为空；已填行须有商品且实际调拨数量为正整数 | 行内标红 + Toast「实际调拨数量须为大于0的整数」 |
| 重复商品 | Demo按提示合并（Q03） | Toast「同一商品建议合并为一行」 |

### 4.3 提交校验（保存口径 + 加强项）

| 加强项 | 规则 | 提示 |
| :--- | :--- | :--- |
| 全量校验 | 重新执行保存校验 | 同上 |
| 明细行 | 至少一行明细且每行有商品、实际调拨数量>0（R08） | 明细区错误条「请至少添加一行有效商品明细」 |
| 单据信息 | 备注超长按上限阻止输入 | 「已达上限」 |
| 状态 | 仅草稿可提交 | Toast「单据状态已变更，请刷新后重试」 |

提交成功 → 弹窗PRD §2.1 确认 → 状态变为待审核；本页不可再编辑。

### 4.4 审核时服务端校验（页面提示）

| 场景 | 提示 |
| :--- | :--- |
| 来源仓可用量不足，或记账后即时／可用库存将为负 | Toast「库存不足，不允许负库存」；阻断本次记账、不推送金蝶 |
| 来源仓已有预占，可用量不足以支撑本次调拨 | 同上（人工一步式不消耗预占，按可用量校验，主PRD R05、Q04） |

## 5. 操作行为与反馈

| 操作 | 点击行为 | 确认后表现 |
| :--- | :--- | :--- |
| 保存 | 校验通过后保存草稿 | Toast「草稿已保存」；单号出现；停留本页 |
| 提交 | 打开提交确认弹窗（弹窗PRD §2.1） | 确认后返回列表或停留详情；状态=待审核 |
| 取消 | 有修改时二次确认（弹窗PRD §2.5） | 返回列表，保留原查询条件 |
| 返回 | 同取消 | 同上 |

**反馈规范**：

| 场景 | 反馈 | 文案 |
| :--- | :--- | :--- |
| 保存成功 | Toast | 草稿已保存 |
| 提交成功 | Toast | 已提交，等待审核 |
| 提交失败 | Toast | 提交失败，请检查填写内容后重试 |
| 状态已变更 | Toast | 操作失败，单据状态已变更，请刷新后重试 |
| 加载失败 | 错误态 | 加载失败，请重试 |

## 6. Mock 与验收

### 6.1 Mock 覆盖清单

- 新增空白页；编辑草稿页
- 选品弹窗（启用成品SKU）；明细多行
- 校验失败：两仓相同、选在途仓、数量为0
- 审核阻断：来源仓可用量不足（Demo 造数）

### 6.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 新增保存 | 选来源仓、目标仓，添加1行商品10件，保存 | 单号按ZJDB生成；来源类型固定人工一步式；草稿保存成功 |
| 空明细草稿 | 只选来源仓、目标仓，不添加明细，保存 | 草稿保存成功（草稿允许明细为空）；提交时提示至少一行有效商品明细 |
| 同仓阻断 | 来源仓与目标仓选同一逻辑仓 | 阻断并提示 |
| 在途仓阻断 | 任一仓选虚拟在途仓 | 阻断并提示 |
| 提交 | 草稿点提交并确认 | 状态=待审核，页面不可编辑 |
| 审核记账 | 审核通过（Demo） | 来源仓即时减、目标仓即时加；写库存流水；金蝶推送状态从未推送开始 |
| 负库存阻断 | 来源仓可用量不足时审核 | 阻断并提示不允许负库存；不记账 |

Demo 验证页面呈现、校验与跳转；不代表真实接口、并发或后端事务行为。
