### 1.1 本模块不提供的弹窗

本期不提供以下弹窗：

| 弹窗 | 说明 |
| :--- | :--- |
| 重推财务ERP确认框 | 推送财务ERP失败后在**系统集成中心**针对原单重推（F07）；本模块列表/详情无重推按钮 |
| 分步式两端结果的无来源建单弹窗 | 回传路径不打开人工建单入口；分步式两端结果由通知单回传自动生成 |
| 取消 / 作废 / 反审核确认框 | 已审核为终态，不可撤销、不可反审核 |
| 手工调整预占 | 直接调拨不预占（人工一步式与仓库主动回传不涉及预占，分步式调出端按调出通知单R08消耗）；预占也不能手工增改（[《预占与冻结主PRD》](../../预占与冻结/预占与冻结主PRD.md) R05、§二） |
| 少收差异抹平确认框 | 在途差异由其他出库处理，本模块不提供入口 |

自动重试（正式环境）：推送明确失败后系统自动重试，**最多3次**；间隔由技术配置。3次仍失败则保持「推送失败」，到系统集成中心针对原单重推。

```
直接调拨单列表 / 详情
         │
    用户查找重推入口
         │
         ▼
    本模块无重推按钮
         │
         ▼
   到系统集成中心办理（F07）
   须：已审核 + 推送财务ERP状态=推送失败
```

## 2. 确认弹窗

### 2.1 提交确认

| 项目 | 内容 |
| :--- | :--- |
| 触发 | 新增/编辑页、列表或详情「提交」（草稿，人工一步式） |
| 标题 | 确认提交直接调拨单？ |
| 正文 | 提交后进入待审核状态，来源逻辑仓、目标逻辑仓与数量不可再修改；审核通过后来源仓减少、目标仓增加并推送财务ERP，不推送仓库、不涉及预占。 |
| 主按钮 | 确认提交 |
| 次按钮 | 取消 |

### 2.2 撤回

| 项目 | 内容 |
| :--- | :--- |
| 触发 | 列表或详情「撤回」（待审核） |
| 标题 | 撤回直接调拨单 |
| 表单 | 撤回意见（必填，`REMARK_500`） |
| 主按钮 | 确认撤回 |
| 次按钮 | 取消 |

### 2.3 删除草稿

| 项目 | 内容 |
| :--- | :--- |
| 触发 | 列表或详情「删除」（人工一步式草稿；本单无业务下游，不受引用限制） |
| 标题 | 删除直接调拨单草稿 |
| 正文 | 删除后不可恢复，确定删除该草稿？ |
| 主按钮 | 确认删除 |
| 次按钮 | 取消 |
| 失败处理 | 非草稿或状态已变化时阻断并提示 |

### 2.4 审核确认

| 项目 | 内容 |
| :--- | :--- |
| 触发 | 列表或详情「审核」（待审核） |
| 标题 | 确认审核直接调拨单？ |
| 正文 | 审核通过后来源逻辑仓即时库存减少、目标逻辑仓增加，并生成库存流水、推送财务ERP。可用库存不足时不能审核，不允许负库存。 |
| 主按钮 | 确认审核 |
| 次按钮 | 取消 |
| 失败处理 | 负库存或校验不通过时阻断，提示「库存不足，不允许负库存」；不记账、不推送 |

### 2.5 离开确认（未保存修改）

| 项目 | 内容 |
| :--- | :--- |
| 触发 | 新增/编辑页有未保存修改时点「取消」或返回 |
| 标题 | 放弃未保存的修改？ |
| 正文 | 当前填写内容尚未保存，离开后修改将丢失。 |
| 主按钮 | 放弃并离开 |
| 次按钮 | 继续编辑 |

## 3. Demo Mock：分步式两端回传生成（F08-A）

### 3.1 正式规则（必读）

正式环境中，调出通知回传实出>0时生成调出端直接调拨单（调出仓减、在途加），调入通知回传实收>0时生成调入端直接调拨单（在途减、接收仓加）；回传校验通过后自动生成并自动审核，写库存流水、回写来源通知与主单，并逐单推送财务ERP。零调出不生成、零调入拒绝整次回传、超量整次拒绝。分步式两端结果不提供无来源人工建单。

本节 Mock 的调出、调入回传规则统一在[《分步式调拨单前端Demo版PRD_弹窗与Mock》](../../分步式调拨单/前端Demo版PRD/分步式调拨单前端Demo版PRD_弹窗与Mock.md) §3、§4 维护（由主单或通知单详情触发），本模块不重复定义、不重复触发。

### 3.2 本模块的表现

| 时机 | 行为 |
| :--- | :--- |
| 调出／调入回传 Mock 成功后 | 直接调拨单列表出现新记录，来源类型=分步式调出端／分步式调入端；审核状态=已审核、推送财务ERP状态=未推送；详情可打开 |
| Demo 推送进度 | 由 Demo 模拟从未推送 → 推送中 → 推送成功；可配置模拟一次推送失败 |
| 库存联动 | Mock 同步展示两个逻辑仓数量变化与在途增减，可在库存查询页核对 |
| 主单联动 | 调入端结果生成后主单业务状态=已关闭（页面展示「已完结」） |

### 3.3 不做的事

- 不代替正式接口校验与映射
- 不提供分步式两端结果的无来源人工建单页面
- 不把 Mock 推送当作财务ERP正式验收
- 不在 Mock 中制造负库存

## 4. Demo Mock：仓库主动回传生成（F08-B）

### 4.1 正式规则（必读）

正式环境中，仓库先完成品质调整后回传，商品、仓对归属与映射正常且库存校验通过时，直接生成**已审核**直接调拨单并生效，按回传仓对一减一增；不补建申请、通知，也不要求对已完成变动先做预占（INV-FR04、INV-FR07）。处理后即时或可用库存将为负时阻断本次生效并报错；归属依据不足时保留异常，不随便选仓、不记账、不推财务ERP。

本节 Mock **仅用于 Demo 原型串联展示**，不属于主PRD AC01～AC14 的正式验收项（主PRD F08）。

### 4.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 直接调拨单列表页头「模拟回传生成(Mock)」 | 打开 §4.3 弹窗（来源类型固定「仓库主动回传」），选择两个逻辑仓、录入商品与数量；确认后按 §4.4 本地生成 |

```
直接调拨单列表
      │
  Mock 主动回传
      │
      ▼
 仓对与商品映射正常？ ──否──> 挂异常，不记账、不推财务ERP
      │
      是
      ▼
 库存校验通过？（不允许负库存）
      │
 ┌────┴────┐
否         是
 │          │
 ▼          ▼
阻断      §4.4 本地创建
负库存    已审核直接调拨单
              │
              ▼
       推送财务ERP状态=未推送
       Demo 可模拟推送进度
```

### 4.3 引导弹窗

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 模拟回传生成（Demo） |
| 正文 | 按仓库已完成的实际调整生成演示用已审核直接调拨单；正式流程以仓库回传为准，不补建申请单、不补做预占。 |
| 表单项 | 来源类型（固定「仓库主动回传」）、来源逻辑仓、目标逻辑仓、来源系统、来源单号、商品与数量（可多行） |
| 主按钮 | 确认生成 |
| 次按钮 | 取消 |
| 关闭图标 | 关闭后不生成任何数据 |

来源类型固定「仓库主动回传」，展示来源系统、来源单号；分步式两端的回传按 §3 由主单或通知单详情触发，本弹窗不重复实现。

### 4.4 生成规则（本地 Mock）

| 项目 | Mock 规则 |
| :--- | :--- |
| 生成条件 | 两个逻辑仓不相同、均非虚拟在途仓（主动回传路径按回传仓对，如涉及在途由系统按调拨口径写入）；商品与数量合法；库存校验通过 |
| 单头 | 来源类型=仓库主动回传；来源分步式调拨单、来源通知单留空；来源系统、来源单号取弹窗输入；实际调拨时间=当前时间；业务日期=当天 |
| 明细 | 按弹窗录入的商品与数量生成；来源明细行留空 |
| 审核 | 创建即为已审核；审核人留空；创建人、最后更新人显示「系统」 |
| 库存 | Mock 减少来源逻辑仓即时库存、增加目标逻辑仓即时库存；写两条库存流水；不补做预占、不消耗预占 |
| 财务ERP | 生成后从「未推送」开始，由 Demo 模拟推送进度；明确失败时可模拟自动重试3次 |
| 单号 | 按 ZJDB 编码规则生成 fictitious 编号 |
| 负库存 | 演示负库存分支时：阻断并提示「库存不足，不允许负库存」；不生成直接调拨单、不记账 |
| 归属异常 | 演示「归属依据不足」分支时：不生成直接调拨单、不记账、不推财务ERP，提示保留异常 |

界面标注「演示数据」或「Mock」角标，与正式回传生成的结果单区分。

### 4.5 不做的事

- 不代替正式接口校验与映射
- 不在 Mock 中自动执行财务ERP正式推送
- 不生成无逻辑仓、无商品的结果单
- 不在 Mock 中制造负库存

## 5. 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| Mock 调出端生成 | 由主单或调出通知单 Mock 回传90 | 生成已审核调出端直接调拨单；调出仓−90、在途+90；来源类型=分步式调出端 |
| Mock 调入端生成 | 由主单或调入通知单 Mock 回传88 | 生成已审核调入端直接调拨单；在途−88、接收仓+88；主单已完结 |
| Mock 主动回传 | 列表点「模拟回传生成(Mock)」，来源类型固定仓库主动回传，正常品转残次品、数量5 | 生成已审核直接调拨单；来源类型=仓库主动回传；来源系统、来源单号有值；不消耗预占 |
| Mock 负库存 | 主动回传数量超过来源仓可用 | 阻断并提示不允许负库存；不生成直接调拨单 |
| Mock 归属异常 | 主动回传时不选来源逻辑仓 | 阻断，提示归属依据不足，不记账 |
| 无重推弹窗 | 在列表/详情查找重推 | 无重推按钮；无重推确认弹窗 |
| 推送失败展示 | 打开推送失败单详情 | 展示失败原因；重推须到系统集成中心 |
| 无取消弹窗 | 在已审核单查找取消、作废 | 无入口、无对应弹窗 |

Demo 验证 Mock 本地数据联动；不代表生产接口、并发或后端事务行为。**本章 Mock 仅 Demo，非正式验收。**
