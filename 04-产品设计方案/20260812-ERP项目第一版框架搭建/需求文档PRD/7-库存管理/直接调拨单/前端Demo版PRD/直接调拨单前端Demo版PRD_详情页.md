## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 直接调拨单详情页 |
| 入口 | 列表点单号 |
| 页面目标 | 只读查看结果单全貌；按当前状态办理允许的操作；追溯来源主单与通知单 |
| 骨架结构 | 页头 → 单据信息 → 商品明细 → 关联单据 → 审核信息 → 制单信息 |

本页落地 **F05**；状态—操作矩阵见主PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头状态标签：审核状态与金蝶推送状态各一枚 StatusBadge。
> - 关联单据：分步式来源展示胶囊 Tab（来源分步式调拨单、来源调出／调入通知单）。
> - 详情底部：审核信息 + 制单信息；完整操作日志一期后置（主PRD Q10）。
> - 二次确认弹窗正文在[弹窗 PRD](直接调拨单前端Demo版PRD_弹窗与Mock.md)维护，本文只写入口与结果表现。
> - **不设价税列、不设成本价格列**（直接调拨不传成本价格）。
> - Demo 以桌面端为基准；明细、关联简表窄视口横向滚动。

## 2. 页头

### 2.1 标题与状态

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `直接调拨单详情 · {单号}` |
| 状态标签 | 审核状态一枚（草稿／待审核／已审核）+ 金蝶推送状态一枚（未推送／推送中／推送成功／推送失败） |
| 布局 | 单行：左侧标题 + 状态；右侧操作区（`DocumentDetailFrame`） |

列表状态列与详情页头状态展示方式差异见《原型开发说明》（列表语义色文字 vs 详情 StatusBadge）。

### 2.2 页头操作按钮

`返回列表` **始终排在最前**；其后按状态展示业务按钮。

| 按钮 | 草稿（人工一步式） | 待审核（人工一步式） | 已审核 | 说明 |
| :--- | :---: | :---: | :---: | :--- |
| 返回列表 | ✅ | ✅ | ✅ | 始终 |
| 提交 | ✅ | ❌ | ❌ | 弹窗 PRD §2.1 |
| 删除 | ✅ | ❌ | ❌ | 弹窗 PRD §2.3 |
| 编辑 | ✅ | ❌ | ❌ | 跳转编辑页 |
| 审核 | ❌ | ✅ | ❌ | 弹窗 PRD §2.4 |
| 撤回 | ❌ | ✅ | ❌ | 弹窗 PRD §2.2 |
| 重推金蝶 | ❌ | ❌ | ❌ | 入口在系统集成中心；须金蝶推送状态=推送失败 |

**渲染纪律**：

- 条件不满足的按钮**直接不渲染**，不展示灰色 disabled。
- 样式层级：`审核` 用 `primary`；`取消`／`删除` 用 `outline`；`返回列表` 固定最左。
- 自动生成的结果单（分步式两端、仓库主动回传）不展示提交、删除、编辑、审核、撤回。

二次确认入口与确认后的页面表现统一在第五节维护；弹窗正文引用弹窗PRD。

## 3. 信息分区与字段

> 只读 **6 列栅格**（默认），标签在上、值在下；备注常占 **3 列**。字段顺序与 TSV 分组一致。

**分区总览**：页头 → **3.1 单据信息** → **3.2 商品明细** → **3.3 关联单据（条件）** → **3.4 审核信息** → **3.5 制单信息**

### 3.1 单据信息

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样展示 |
| 来源类型 | 枚举文字：分步式调出端／分步式调入端／人工一步式／仓库主动回传 |
| 来源分步式调拨单 | 链接，可跳转来源主单详情；非分步式来源显示 `-` |
| 来源通知单 | 链接；调出端为调出通知单、调入端为调入通知单；其他来源显示 `-` |
| 来源系统 | 仅仓库主动回传有值；其他显示 `-` |
| 来源单号 | 同上 |
| 来源逻辑仓 | 逻辑仓 Code-Name；分步式两端可含虚拟在途仓 |
| 目标逻辑仓 | 同上 |
| 实际调拨时间 | 日期时间；自动回传取回传确认时间 |
| 业务日期 | 日期；不单列为列表列，详情展示 |
| 备注 | 占 3 列；空值显示 `-` |
| 推送金蝶时间 | 未推送时显示 `-` |
| 推送失败原因 | 长文本省略，hover 看全文；未失败时显示 `-` |

推送信息（推送金蝶时间、推送失败原因）并入本区展示，推送失败时展示失败原因。

### 3.2 商品明细

- 表格只读；数量列**右对齐**；横向滚动。
- 一期不分页。
- 无价税列。

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 从1起 |
| 商品 | 商品名称 |
| 商品编码 | 原样 |
| 商品名称 | 原样 |
| 基本单位 | 原样 |
| 实际调拨数量 | 整数 |

### 3.3 关联单据

**展示条件**：来源类型为分步式调出端或分步式调入端

组件：`RelatedDocumentsCard` + `InnerTabs` `pill`；Tab 文案带数量。

| Tab | 列 | 排序 | 空态 |
| :--- | :--- | :--- | :--- |
| 来源分步式调拨单 | 单号、审核状态、业务状态、计划调拨数量、创建时间 | — | 暂无来源分步式调拨单 |
| 来源调出通知单／来源调入通知单 | 单号、单据状态、通知数量、实际数量、未发／少收数量、创建时间 | — | 暂无来源通知单 |

单号可点击跳转对应详情。

### 3.4 审核信息

| 字段 | 展示说明 |
| :--- | :--- |
| 审核人 | 自动审核时显示 `-` |
| 审核时间 | 未审核时显示 `-` |
| 撤回意见 | 占第3～6列；未撤回时显示 `-` |

### 3.5 制单信息（详情底部）

| 字段 | 展示说明 |
| :--- | :--- |
| 创建人 | 自动生成时显示「系统」 |
| 创建时间 | 日期时间 |
| 最后更新人 | 自动生成时显示「系统」 |
| 最后更新时间 | 日期时间 |

操作日志一期后置：完整操作日志字段与入口见主PRD Q10；一期不做独立操作日志页。

## 4. 字段展示规范

空值、Code-Name、数字与日期格式、状态样式、关联简表均引用公共规范；不在此重抄。数量为整数、不允许小数。

| 字段或区域 | 本页差异 | 依据 |
| --- | --- | --- |
| 来源类型 | 四类来源逐字按TSV枚举展示 | TSV 取值说明 |
| 来源逻辑仓／目标逻辑仓 | Code-Name 展示；分步式两端由系统写入虚拟在途仓 | 主PRD R02；《库存与仓储业务设计》§4.2 |
| 审核人 | 自动审核显示 `-`（不显示「系统」） | 《6.强盛ERP的编码规则和通用字段规则》第三节 |
| 金蝶推送失败 | 展示失败原因；重推入口不在本页 | 主PRD R09 |

## 5. 操作行为

| 操作 | 点击行为或弹窗入口 | 确认后页面表现 |
| :--- | :--- | :--- |
| 提交 | 弹窗 PRD §2.1 | 刷新详情；审核状态=待审核；页头按钮切换为「审核 撤回」 |
| 撤回 | 弹窗 PRD §2.2 | 刷新详情；审核状态=草稿；保留撤回意见 |
| 删除 | 弹窗 PRD §2.3 | 删除成功返回列表 |
| 审核 | 弹窗 PRD §2.4 | 刷新详情；审核状态=已审核；金蝶推送状态=未推送→推送中 |
| 编辑 | 跳转编辑页 | 仅草稿（人工一步式） |
| 返回列表 | 返回列表 | 保留原筛选与页码 |

## 6. 反馈与页面状态

### 6.1 操作反馈（Toast）

| 操作 | 反馈类型 | 文案 |
| :--- | :--- | :--- |
| 提交成功 | Toast | 已提交，等待审核 |
| 撤回成功 | Toast | 已撤回，单据回到草稿 |
| 删除成功 | Toast | 草稿已删除 |
| 审核成功 | Toast | 审核通过，库存已生效并推送金蝶 |
| 审核阻断（负库存） | Toast | 库存不足，不允许负库存 |
| 状态已变更 | Toast | 操作失败，单据状态已变更，请刷新后重试 |

Mock 专属弹窗见弹窗 PRD。

### 6.2 加载与异常态

| 场景 | 页面表现 | 文案 / 操作 |
| :--- | :--- | :--- |
| 加载中 | 骨架屏 | — |
| 单据不存在 | 错误态 | 单据不存在或已被删除；返回列表 |
| 加载失败 | 错误态 | 加载失败，请重试；重试 + 返回列表 |

## 7. Mock 与验收

### 7.1 Mock 覆盖清单

- 各主状态至少 1 单：草稿、待审核、已审核（推送成功）、已审核（推送失败）
- 四类来源各至少 1 单：分步式调出端、分步式调入端、人工一步式、仓库主动回传
- 关联 Tab 有数据 + 空态：分步式来源单有来源主单与通知单；人工一步式为无关联区
- 边界状态：来源仓为虚拟在途仓与目标仓为虚拟在途仓各 1 单

### 7.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 分步式调出端 | 打开分步式调出端结果单 | 来源类型=分步式调出端；来源逻辑仓=调出仓、目标逻辑仓=虚拟在途仓；关联 Tab 可跳转来源主单与调出通知单 |
| 分步式调入端 | 打开分步式调入端结果单 | 来源逻辑仓=虚拟在途仓、目标逻辑仓=接收仓 |
| 人工一步式 | 打开人工一步式已审核单 | 审核人显示操作人；可查看推送状态；不显示来源主单 |
| 仓库主动回传 | 打开主动回传单 | 来源系统、来源单号有值；来源分步式调拨单显示 `-` |
| 推送失败 | 打开推送失败单 | 展示失败原因；页头无重推按钮 |
| 页头按钮 | 分别打开草稿、待审核、已审核单 | 按钮按 §2.2 互斥展示 |
| 制单信息 | 打开自动生成单 | 详情底部展示创建人、最后更新人「系统」；审核人 `-` |
| 操作日志（一期后置） | 查看任意单详情底部 | 不提供操作日志入口；完整字段与入口见主PRD Q10 |

模拟的保存、状态变化和关联结果应可连续演示；Demo 验证不代表真实接口、并发或后端事务已验证。
