## 页面与弹窗清单

| 页面/容器 | 入口 | 用途 |
| --- | --- | --- |
| 直接调拨单列表 | 库存管理-直接调拨单 | 查询结果单、进入维护与办理、导出 |
| 新增直接调拨单（人工一步式） | 列表「新增」 | 录入ERP主动发起的品质调整草稿 |
| 编辑直接调拨单 | 列表/详情「编辑」（仅草稿） | 修改草稿 |
| 直接调拨单详情 | 列表点击单号 | 查看来源、明细、推送与审核信息 |
| 提交确认弹窗 | 新增/编辑/列表/详情 | 确认进入待审核 |
| 撤回弹窗 | 列表/详情 | 填写撤回意见 |
| 删除草稿确认弹窗 | 列表/详情「删除」 | 二次确认后物理删除草稿 |
| 审核确认弹窗 | 列表/详情（待审核） | 确认审核并一减一增记账 |

## 文档说明

本文用ASCII线框固定**页面分区、字段位置、按钮入口和示例值**，供评审和原型走查。

- **与主PRD的分工**：业务范围、四类来源、状态条件与记账规则见[《直接调拨单主PRD》](直接调拨单主PRD.md)；骨架只回答「画在哪、叫什么」。
- **与Demo PRD的分工**：校验时机、联动、失败文案、Mock行为见[前端Demo版PRD](前端Demo版PRD/)目录。
- **与TSV的分工**：字段名称、分组、列表列与筛选项以[《直接调拨单（详细稿）》](../../../字段清单合集/库存相关/直接调拨单/直接调拨单（详细稿）.tsv)为准；骨架示例列不全时以TSV补全。

各页结构：**图前**写用途与关键要素；**图中**为线框；**图后**用无序列表补充图中省略项、重点和条件差异。

## 绘制约定

遵循[《页面骨架模板-V2》](../../../../../05-常用模板/02-模块设计交付/页面骨架模板-V2.md)与[《UI布局公共说明》](../../../../../05-常用模板/02-模块设计交付/UI布局公共说明.md)。本模块补充：

- 字段名、按钮文案与TSV、Demo PRD一致；示例值为虚构。
- 来源逻辑仓、目标逻辑仓按逻辑仓Code-Name（`{编码} {名称}`）画示例值；商品明细拆列展示商品编码、商品名称、基本单位。
- 数量列为整数、右对齐、不带单位后缀；0按0展示。
- **列表与详情展示调拨方向**：以「来源逻辑仓 → 目标逻辑仓」表达；分步式两端结果涉及虚拟在途仓时按系统写入值展示。
- 审核状态在**编辑页、详情页**用标签展示；推送财务ERP状态在**详情页**用标签展示（编辑页仅草稿、必为未推送，不展示）；两者在**新增页均不展示**；结果单列表默认按业务日期倒序（业务日期不单列为列）。
- 不设价税列、不设成本价格列（直接调拨不传成本价格，存货成本由财务ERP核算）。
- TSV「字段所属分组」= 卡片分区；组内字段按TSV行序填入6列栅格。
- **每行必须画满6列**（用 `|` 分隔）；字段不足6个时，剩余列标「（空）」留空，不要省略列线。
- 备注占3列：单据信息字段较多，按TSV行序分行绘制。

- 推送失败的行内不提供重推按钮，重推到系统集成中心办理（主PRD R09）。
- 批量操作栏一期仅已选中计数与列设置；勾选配合页头导出「已勾选」。
