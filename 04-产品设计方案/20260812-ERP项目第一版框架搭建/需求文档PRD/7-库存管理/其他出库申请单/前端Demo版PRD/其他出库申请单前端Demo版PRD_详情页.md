> **更新时间**：2026-09-23

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 其他出库申请单详情页 |
| 页面目标 | 查看全貌、按状态办理提交/审核/撤回/取消/重试、追溯关联其他出库单 |
| 数据范围 | 一张申请单：单据信息、商品明细、关联单据、审核信息、终止信息、系统信息 |
| 状态—操作矩阵 | 见主PRD §6.4；页头按钮与列表行操作一致，不新增动作 |

**本期边界**：无编辑入口（编辑在列表/详情页头进入新增编辑页，仅草稿）；无手动关闭；无到期自动关单；结果单重推不在本页；预占量与可用量看库存查询。

## 2. 页头

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `其他出库申请单详情` · 单号（可复制） |
| 状态标签 | 一枚StatusBadge（单据状态） |
| 操作区 | `返回列表` 固定最前，其余按状态互斥展示 |

| 状态 | 页头按钮（`返回列表` 之后） |
| :--- | :--- |
| 草稿 | `[提交] [删除] [编辑]` |
| 待审核 | `[审核] [撤回] [取消]` |
| 已审核 | `[取消]` |
| 推送失败 | `[重试推送] [取消]` |
| 待发货 | `[取消]` |
| 取消中 | 无 |
| 已取消、已发货 | 无 |

按钮顺序与骨架一致；条件不满足时**隐藏按钮**，不用置灰。

## 3. 页面分区

### 3.1 单据信息

6列栅格，标签在上、值在下；字段按TSV行序。

| 字段 | 展示 | 说明 |
| :--- | :--- | :--- |
| 单号 | 文本 | 前缀QTCKSQ |
| 出库仓 | 文本 | 逻辑仓Code-Name；可为虚拟在途仓 |
| 业务类型 | 文本 | 枚举文字 |
| 最近推送时间 | 日期时间 | 未推送时 `-`；在途仓直接记账路径不产生推送时间 |
| 推送失败原因 | 多行文本（占3列） | 未失败时 `-` |
| 备注 | 多行文本（占3列） | 空值展示 `-` |

### 3.2 商品明细

| 列名 | 说明 |
| :--- | :--- |
| 行号 | 从1起 |
| 商品 | 明细展示商品名称 |
| 商品编码 | 随商品带出 |
| 商品名称 | 随商品带出 |
| 基本单位 | 随商品带出 |
| 申请出库数量 | 整数；审核时按此数量预占 |
| 实出数量 | 由其他出库单回写；最终结果未确认前显示 `-` |
| 未出数量 | ＝申请出库数量−实出数量 |

### 3.3 关联单据（仅已发货；商品明细之后；胶囊Tab）

| Tab | 简表列 |
| :--- | :--- |
| 其他出库单（N） | 单号（链接）、审核状态、金蝶推送状态、实际出库数量、创建时间 |

- 默认选中「其他出库单」Tab；当前Tab无记录时展示「暂无关联的其他出库单」空态。
- 未发货状态不展示关联单据区块。

### 3.4 终止信息（仅已取消）

6列栅格：取消原因、取消时间、取消操作人，后3列留空。未取消时不展示本区块。

### 3.5 审核信息

6列栅格：审核人、审核时间、撤回意见（占第3～6列）。未审核时审核人与审核时间展示 `-`；未撤回时撤回意见展示 `-`。

### 3.6 操作信息（胶囊Tab：制单信息 / 操作日志）

| Tab | 内容 |
| :--- | :--- |
| 制单信息 | 创建人、创建时间、最后更新人、最后更新时间 |
| 操作日志 | 简表：操作时间、操作人、操作类型、说明；按时间倒序；含提交、审核（含预占）、撤回、推送、回传、取消（含预占释放）等记录 |

完整审计日志后置（一期不做独立操作日志页）。

## 4. 交互与反馈

| 操作 | 行为 | 反馈 |
| :--- | :--- | :--- |
| 提交 | 校验 → 弹窗 §3.1 | 成功后状态变待审核；不占库 |
| 审核 | 弹窗 §3.2 → 二次确认 | 通过后按可用库存预占；可用不足时 Toast「可用库存不足，不能审核占库」，状态不变 |
| 撤回 | 弹窗 §3.3（撤回意见必填） | 成功后回草稿，可继续编辑 |
| 取消 | 弹窗 §3.4（取消原因必填） | 成功后状态按当前状态流转（已取消并释放预占／取消中） |
| 重试推送 | 弹窗 §3.5 | 成功后进入已审核等待新的发送结果；预占不重复 |
| 删除 | 弹窗 §3.6 | 成功后返回列表，记录消失 |
| 在途仓直接记账 | 弹窗 §3.8（出库仓=虚拟在途仓：新增/编辑页选中时提示，待审核点「审核」时二次确认） | 审核后不推送仓库、系统直接记账；申请单直接已发货 |
| 关联单号跳转 | 点击其他出库单单号 | 进入结果单详情；单据不存在时 Toast「结果单不存在或不可访问」 |
| 状态不匹配 | 服务端返回状态已变化 | Toast「当前单据状态为{状态}，不可执行{动作}」 |

页头按钮与列表行操作的可用条件一致，均服从主PRD §6.4。

## 5. Mock数据要求与演示验收

### 5.1 Mock覆盖

- 至少覆盖：草稿、待审核、已审核、推送失败、待发货、取消中、已取消、已发货各 **1 单**
- 已发货单：含关联其他出库单 **1 张**，实出有值、未出为0
- 待发货单：实出显示 `-`、未出等于申请出库数量
- 已取消单：含取消原因、取消时间、取消操作人
- 推送失败单：含推送失败原因，页头有「重试推送」
- 在途仓单：出库仓=虚拟在途仓，无推送信息，已发货
- **枚举与口径**：Mock 取值必须落在字段清单范围内

### 5.2 演示验收

| 场景 | 前置 | 操作 | 预期 |
| :--- | :--- | :--- | :--- |
| 草稿详情 | 草稿单 | 打开详情 | 页头为 `[返回列表][提交][删除][编辑]`；无关联单据区块 |
| 待审核详情 | 待审核单 | 打开详情 | 页头为 `[返回列表][审核][撤回][取消]` |
| 审核预占 | 待审核单 | 点审核 | 通过则按可用量预占；不足则 Toast 阻断 |
| 推送失败详情 | 推送失败单 | 打开详情 | 展示失败原因；页头有「重试推送」「取消」 |
| 待发货详情 | 待发货单 | 打开详情 | 实出显示 `-`；页头仅「取消」；无关闭入口 |
| 已发货详情 | 已发货单 | 查看关联单据Tab | 可跳转其他出库单详情 |
| 在途仓单详情 | 在途仓单 | 打开详情 | 无推送信息；出库仓显示在途仓；页头按状态展示 |
| 已取消详情 | 已取消单 | 打开详情 | 展示终止信息；页头无业务按钮 |
| 操作日志 | 任意单 | 切换操作日志Tab | 简表按时间倒序展示，含预占与释放记录 |

Demo 验证分区、状态与入口；不代表真实接口、并发或后端事务行为。
