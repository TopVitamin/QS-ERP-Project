## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 其他出库申请单新增 / 草稿编辑 |
| 页面目标 | 录入或修改草稿：从哪个逻辑仓出、为什么出、出什么、出多少 |
| 适用状态 | 新增页建草稿；**仅单据状态=草稿**可进入编辑（含撤回后回到草稿） |
| 骨架结构 | 页头（标题 + 操作按钮）→ 单据信息 → 商品明细 |

> 操作按钮固定在**页头右侧**，不使用底部固定操作栏。待审核、已审核、推送失败、待发货、取消中、已取消、已发货不可进入本页。本页落地 **F02（保存）**、**F03（提交入口）**；状态—操作矩阵见主PRD §6.4。

| 模式 | 入口 | 差异摘要 |
| :--- | :--- | :--- |
| **新增** | 列表「新增」 | 单号占位「保存后自动生成」；页头无状态标签；明细无实出、未出列 |
| **编辑** | 列表/详情「编辑」 | 单号只读；页头一枚StatusBadge（单据状态）；明细增列实出数量、未出数量 |

**本期边界**：页头 **取消 / 保存 / 提交**；本页无导入入口；操作信息、终止信息、关联单据不在本页；已审核后不提供本页编辑入口。提交不占库，**审核才按可用库存预占**。

## 2. 页头

| 元素 | 规格 |
| :--- | :--- |
| 标题（新增） | `新增其他出库申请单` |
| 标题（编辑） | `编辑其他出库申请单`；单号在表单区只读展示 |
| 状态标签 | 新增不展示；编辑展示一枚StatusBadge（单据状态） |
| 操作区 | 从左到右：`取消` → `保存` → `提交` |

| 按钮 | 说明 |
| :--- | :--- |
| 取消 | 返回列表；有未保存修改时二次确认（弹窗PRD §3.7） |
| 保存 | 通过 §4.3校验后保存为草稿 |
| 提交 | 通过 §4.4校验 → 提交确认弹窗（弹窗PRD §3.1） |

保存/提交时当前按钮loading，另一操作按钮同步disabled，防重复点击；失败保留已填内容。

## 3. 表单分区与字段

> 单头 **6列栅格**，标签在上、控件在下；备注占 **3列**。控件 `type` 对齐原型 `FormControl` / `LineItemTable`。主数据按Code-Name（`{编码} {名称}`）展示。**placeholder** 指控件无值时的占位文案；只读/禁用填 `—`。

区域顺序：**单据信息 → 商品明细**（与TSV一致）。

### 3.1 单据信息

| 字段 | 控件type | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 单号 | `disabled` | `保存后自动生成`（新增）/ `—`（编辑有值） | 编辑只读展示系统单号，前缀QTCKSQ（R01） |
| 出库仓 | `select` | `请选择出库仓` | 审核通过且启用的逻辑仓；一张单一个；可为虚拟在途仓（R02、R20） |
| 业务类型 | `select` | `请选择业务类型` | 建单选项（2026-09-24确认）：样品领用、赠送、报废、借出；盘亏由仓库盘点回传形成结果单，仅在出库仓为虚拟在途仓（处理在途少收差异）时可选 |
| 备注 | `textarea` | `请输入备注` | 选填；`REMARK_500`；占3列 |

栅格排布见骨架：单据信息4个字段（备注占3列）分两行；第二行为备注，占第1～3列。

选中虚拟在途仓时，单据信息下方展示提示行：**「出库仓选择虚拟在途仓时，审核后不推送仓库，由系统按申请数量直接记账。」**

### 3.2 商品明细

独立表格区块，横向滚动。

#### 3.2.1 表格操作

| 操作 | 位置 | 说明 |
| :--- | :--- | :--- |
| 添加明细 | 工具条 | 打开SKU选择弹窗；确认后插入行 |
| 删除 | 行内 | 删除该行；至少保留一行 |

**明细区错误条**（工具条上方，可选实现）：仅用于「请至少添加一行有效商品明细」等**跨行**提示；修正后即时消除。单行字段问题优先用Toast。

#### 3.2.2 列定义

| 列名 | 可编辑 | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 行号 | 只读 | `—` | 从1起自动编号 |
| 商品 | 选品入口 | `请选择商品` | 确认后按TSV「明细展示商品名称」显示 |
| 商品编码 | 只读 | `—` | 随商品带出 |
| 商品名称 | 只读 | `—` | 随商品带出 |
| 基本单位 | 只读 | `—` | 随商品带出，与商品名称一起展示 |
| 申请出库数量 | 可编辑 | `—` | `QTY_INT`；正整数 >0；审核时按此数量预占 |
| 实出数量 | 只读 | `—` | **仅编辑页**展示（TSV：新增页=否）；由其他出库单回写；未确认时显示 `-` |
| 未出数量 | 只读 | `—` | **仅编辑页**展示（TSV：新增页=否）；＝申请出库数量−实出数量 |

#### 3.2.3 SKU选择弹窗（本页配置）

| 配置项 | 本页取值 |
| :--- | :--- |
| 选品方式 | 支持搜索；可多选批量插入（与原型 `enableSkuPicker` 一致） |
| 商品范围 | 启用成品SKU |
| 确认后写入 | 按TSV展示商品名称、带出商品编码与基本单位 |
| 更换商品 | 删除行后重新选品；行内商品列不直接手改 |
| 重复商品 | 建议同一商品合并为一行（待确认Q03）；Demo按提示合并 |

#### 3.2.4 底部汇总

| 汇总项 | 展示 |
| :--- | :--- |
| 申请出库数量合计 | 与「申请出库数量」列右对齐，整数 |
| 实出数量合计 | 与「实出数量」列右对齐；未确认时显示 `-` |

## 4. 校验规则

提交相关弹窗见[弹窗PRD §3](其他出库申请单前端Demo版PRD_弹窗与Mock.md)。下文 **保存** 指点「保存」，**提交** 指点「提交」（含保存口径 + 加强项）。

### 4.1 校验分层总览

| 层级 | 本页行为 | 典型错误位置 |
| :--- | :--- | :--- |
| 录入限制 | 数量禁小数、备注 `maxLength` | 阻止输入或即时提示 |
| 失焦 | 数量整数、备注长度（§4.2） | 字段下或Toast；改值后**即时**清除该项错误 |
| 保存 | 单头必填 + 明细底线（§4.3）；**不校验可用量** | 单头内联；明细Toast或错误条 |
| 提交 | 在保存基础上复核仓库启用与业务类型（§4.4）；**不校验可用量** | 同上；通过后进确认弹窗 |
| 审核（非本页） | 按可用库存预占，可用不足阻断（主PRD R07、R21） | 列表/详情审核时Toast |
| 请求中 | 保存/提交按钮loading；另一按钮disabled | — |

### 4.2 录入与失焦

| 字段 | 模板 | 格式与范围 | 录入/失焦处理 | 典型提示 |
| :--- | :--- | :--- | :--- | :--- |
| 出库仓、业务类型 | 关联选择 | 须从选项选择 | 禁用项不可选 | `{字段名}不能为空` |
| 备注 | `REMARK_500` | 0～500字 | 超限阻止输入；粘贴超长提示 | `备注已达 500 字上限` |
| 申请出库数量 | `QTY_INT` | 正整数 >0 | 禁小数点；失焦非整数视为未填 | `第 N 行申请出库数量须为正整数` |

一期不为数量设业务上限；极大值异常按技术设计处理。

### 4.3 点击「保存」

| 校验对象 | 条件 | 错误位置 | 阻断 | 文案 |
| :--- | :--- | :--- | :---: | :--- |
| 出库仓、业务类型 | 必填 | 字段下方 | 是 | `{字段名}不能为空` |
| 商品明细 | 至少一行有效明细 | Toast / 错误条 | 是 | `请至少添加一行有效商品明细` |
| 商品（每行） | 已选 | Toast | 是 | `第 N 行请选择商品` |
| 申请出库数量（每行） | 正整数 >0 | Toast | 是 | `第 N 行申请出库数量必须大于 0` |

通过后：仍为草稿；Toast「其他出库申请单已保存」；新增单首次保存生成单号。草稿不占库、不改变库存（主PRD §7.6）。

### 4.4 点击「提交」

在 §4.3全部通过基础上，追加：

| 校验对象 | 条件 | 错误位置 | 阻断 | 文案 |
| :--- | :--- | :--- | :---: | :--- |
| 出库仓 | 仍启用 | Toast / 字段下方 | 是 | `所选出库仓不可用` |
| 业务类型 | 已选且在已确认枚举内 | Toast | 是 | `所选业务类型不可用` |

提交不校验可用量，审核时才预占；校验失败时聚焦首错（单头优先）；可用Toast「请修正表单中的错误后再提交」作补充提示。提交成功后单号、出库仓、业务类型与数量锁定至撤回（R08）。

### 4.5 错误展示与纠错

| 类型 | 表现 | 纠错 |
| :--- | :--- | :--- |
| 单头必填 | 红底线 + 字段下文案；标签不变红 | 修改该字段后清除 |
| 多字段错误 | 同时标出；聚焦首错 | 逐项清除 |
| 明细/全局 | Toast（含「第N行」） | 修正后清除对应提示 |
| 跨行（明细为空） | 错误条或Toast | 补行后消除 |
| 取消离开 | 确认框 | `离开后未保存的内容将丢失，确认离开？` |

## 5. 联动规则

| 触发 | 效果 |
| :--- | :--- |
| 选择出库仓 | 选项含审核通过且启用的逻辑仓与虚拟在途仓 |
| 选中虚拟在途仓 | 展示直接记账提示行；审核后不推送仓库（R20、Q02） |
| 选择业务类型 | 建单选项（2026-09-24确认）：样品领用、赠送、报废、借出；出库仓为虚拟在途仓时额外可选盘亏 |
| 添加/删除明细 | 重算单头数量合计 |
| 改申请出库数量 | 重算该行未出数量（编辑页）与单头合计 |
| 进入编辑页 | 已审核、待发货等状态不可进入；仅草稿可编辑 |

## 6. 操作行为

| 操作 | 行为 |
| :--- | :--- |
| 保存 | 执行 §4.3；通过后写草稿并提示成功；新增首次保存生成单号；默认停留本页 |
| 提交 | 执行 §4.4 → 提交确认弹窗；成功后变待审核并提示成功 |
| 取消 | 有未保存修改则确认；确认后回列表 |
| 编辑页进入 | 加载中展示占位；失败展示「其他出库申请单不存在或无权查看」；非草稿不可进入 |

## 10. Mock与验收

### 10.1 Mock覆盖

> 仅Demo，非正式验收。

- 可保存草稿：一行SKU、申请出库数量30
- 编辑用草稿：2行明细 + 实出/未出列 + 单据状态标签
- 撤回后草稿：带撤回意见，可再次提交
- 待审核单：验证不可进入编辑页
- 在途仓草稿：出库仓=虚拟在途仓，验证提示行
- 可用不足：待审核单审核时验证阻断（列表/详情侧）

### 10.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 正常建单 | 新增 → 保存 | 草稿；单号按QTCKSQ生成；不占库 |
| 明细校验 | 数量为0或小数 | 保存阻断，提示第N行数量须为正整数 |
| 提交 | 草稿提交 | 提交确认 → 待审核；字段锁定 |
| 撤回重提 | 待审核撤回 → 修改 → 提交 | 回草稿并保留撤回意见；重新提交成功 |
| 审核预占 | 待审核单审核 | 审核按可用量预占；可用不足阻断并提示 |
| 在途仓 | 选出库仓=虚拟在途仓 | 展示直接记账提示行 |
| 不可编辑 | 待审核/已审核单点编辑 | 不进入本页 |
