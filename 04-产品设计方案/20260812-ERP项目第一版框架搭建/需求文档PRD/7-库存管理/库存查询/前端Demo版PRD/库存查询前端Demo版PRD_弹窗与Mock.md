## 2. 冻结弹窗（F02）

**触发入口**：列表行内「冻结」；可用条件为**可用库存大于0**（列表页 §6.1；虚拟在途仓行按普通行处理，主PRD Q04已定）。

### 2.1 弹窗内容

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 冻结库存 |
| 正文 | 冻结从可用库存中占用，冻结后不再参与业务占用；解冻后恢复可用。 |
| 只读信息 | 逻辑仓、商品（编码＋名称）、当前可用库存、当前冻结库存 |
| 表单项 | 冻结数量（必填，数值）；冻结原因（多行文本，必填） |
| 确认按钮 | 确认冻结 |
| 取消按钮 | 取消 |
| 确认后 | 该行冻结库存增加、可用库存减少、最后更新时间更新；生成一条冻结流水（事件类型：冻结，来源单号为空，记录操作人与时间）；Toast「已冻结 {数量}，可用库存已更新」；刷新当前行；提交期间确认按钮防重复点击，结果以最新数据为准 |

### 2.2 校验

| 校验时机 | 规则 | 失败定位与文案 |
| :--- | :--- | :--- |
| 输入时 | 只允许整数 | 控件限制非数字输入 |
| 确认时 | 冻结数量必填且大于0 | 控件内联错误：冻结数量必须为大于0的整数 |
| 确认时 | 冻结数量不超过当前可用库存（按最新数据重新校验） | Toast：冻结数量不能超过当前可用库存（当前可用 {可用库存}） |
| 确认时 | 冻结原因必填（主PRD Q03已定，2026-09-23） | 控件内联错误：请输入冻结原因 |

冻结原因长度按 REMARK_500（0～500字符）。

## 4. Demo Mock：冻结、解冻后本地更新库存行（F02、F03）

### 4.1 正式规则

按 INV-FR05 与《库存与仓储业务设计》§4.6，冻结只从可用量中占用，解冻后恢复可用；冻结、解冻只改变冻结与可用数量，不改变即时库存和预占库存。每次冻结、解冻生成一条库存流水（事件类型：冻结／解冻，来源单号为空，记录操作人与时间，见[《库存流水主PRD》](../../库存流水/库存流水主PRD.md)R01、R04）。

本节 Mock **仅用于 Demo 原型串联**：演示原型不接真实后端，冻结、解冻成功后按本地数据更新页面，不属于正式验收。

### 4.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 冻结弹窗确认校验通过后 | 按 §4.3 规则更新本地库存行，刷新列表 |
| 解冻弹窗确认校验通过后 | 按 §4.3 规则更新本地库存行，刷新列表 |

### 4.3 更新规则（本地 Mock）

| 项目 | 规则 |
| :--- | :--- |
| 数据来源 | 当前列表行（逻辑仓＋商品） |
| 冻结 | 冻结库存＋冻结数量；可用库存−冻结数量；最后更新时间取当前时间；按主PRD生成一条冻结流水（原型实现库存流水后同步追加） |
| 解冻 | 冻结库存−解冻数量；可用库存＋解冻数量；最后更新时间取当前时间；按主PRD生成一条解冻流水（原型实现库存流水后同步追加） |
| 不变项 | 即时库存、预占库存不变；不生成单据 |
| 校验 | 冻结不超过可用、解冻不超过冻结；校验按当前本地数据实时计算，失败不更新 |
| 存储 | 本地演示数据（`localStorage`）；刷新页面保留，重置演示数据后恢复初始值 |
| 标注 | 页面标注「演示数据」或「Mock」角标，与正式能力区分 |

### 4.4 不做的事

- 不代替正式的并发校验与库存记账
- 不改变即时库存与预占库存；不生成单据
- 不推送财务ERP、不产生任何外部动作
- 不把 Mock 行为写入主 PRD 验收标准

## 5. 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 冻结成功 | 可用30的行点「冻结」录入20确认 | 校验通过；冻结库存＋20、可用−20；Toast提示 |
| 冻结阻断——超过可用 | 可用30的行录入31确认 | Toast阻断；库存不变，弹窗保留输入 |
| 冻结阻断——数量非法 | 录入0或负数确认 | 字段内联错误；不执行 |
| 解冻成功 | 冻结10的行点「解冻」录入10确认 | 冻结库存−10、可用＋10；Toast提示 |
| 解冻阻断——超过冻结 | 冻结10的行录入11确认 | Toast阻断；库存不变 |
| 原因必填 | 冻结、解冻弹窗不填原因确认 | 字段内联错误；不执行 |
| 按钮条件 | 可用为0、冻结为0的行 | 对应按钮不展示 |
| Mock 联动 | 冻结、解冻成功后再打开库存流水（若已实现） | 各生成一条冻结／解冻流水（事件类型：冻结／解冻，来源单号为空）；原型未实现库存流水前不校验 |
| 刷新保留 | 冻结成功后刷新页面 | 本地更新保留（localStorage） |

Demo 验证弹窗文案、校验与本地数据联动；不代表生产接口、并发或后端事务行为。
