关联资料：[《库存查询主PRD》](../库存查询主PRD.md)、[《库存查询页面骨架》](../库存查询页面骨架.md)、[《库存查询前端Demo版PRD_弹窗与Mock》](库存查询前端Demo版PRD_弹窗与Mock.md)、[《原型开发说明》](../../../../../../09-产品原型/原型开发说明.md)、[UI布局公共说明](../../../../../../05-常用模板/02-模块设计交付/UI布局公共说明.md)。

## 1. 页面目标与范围

- 页面名称：库存查询列表页
- 查看视角：**余额视角**（每行 = 一个「逻辑仓＋商品」的即时、预占、冻结、可用）
- 用途：查询库存余额；仓储运营在行内办理手工冻结、解冻；导出
- 功能与状态—操作矩阵见[《库存查询主PRD》](../库存查询主PRD.md) §4.5；本页落地 F01、F02、F03 的列表侧入口
- 本期边界：
  - 只查看和查询，**不提供**新增、编辑、删除、导入入口；
  - 预占不能手工增改；预占来源通过「预占库存」列的「查看来源」查看产生预占的来源单据行，并可跳转库存流水核对，不新增独立预占明细页（主PRD R11）；
  - 导出按导出中心（可选全部／当前筛选／已勾选）；
  - 不提供库存调整、库存初始化入口；行内不设「查看」；
  - 虚拟在途仓行按普通行展示与操作（主PRD Q04已定）。

## 2. 查询区

> 可筛选字段与顺序以[《库存查询（详细稿）》](../../../../字段清单合集/库存相关/库存查询/库存查询（详细稿）.tsv)「可筛选=是」为准；下表为默认查询方案呈现顺序。
> **type 列**：与原型 `FilterControl` 的 `type` 一致，完整规范见[《原型开发说明》](../../../../../../09-产品原型/原型开发说明.md)「查询区通用规则」「FilterControl 控件 type」；「展示为0的库存数据」为勾选框（`checkbox` type，原型已支持）。

| 查询字段 | type | 匹配 | placeholder / 说明 |
| :--- | :--- | :--- | :--- |
| 逻辑仓 | `multi-select` | 精确（多选 OR） | 全部逻辑仓；选项为全部逻辑仓（含已禁用，Code-Name 展示） |
| 所属实体仓 | `select` | 精确 | 全部实体仓（含已禁用；实体仓禁用不级联影响既有逻辑仓，Code-Name 展示） |
| 商品编码 | `search` | 模糊（支持批量） | 支持批量输入：多个编码用换行或逗号分隔，任一命中即返回 |
| 商品条码 | `search` | 模糊（支持批量） | 请输入商品条码；任一条码命中即可，多个值用换行或逗号分隔 |
| 商品名称 | `search` | 模糊 | 请输入商品名称 |
| 库存状态 | `multi-select` | 精确（多选 OR） | 全部；选项为正常品、残次品、待检品（枚举以 TSV 为准） |
| 展示为0的库存数据 | `checkbox` | — | 默认不勾选；勾选后展示即时、预占、冻结、可用均为0的行（原型已支持 `checkbox` type） |

查询区交互（收起过滤、重置、查询、空条件默认、查询后回第一页）见《原型开发说明》「查询区通用规则」。查询条件全空时，默认返回有库存余额的行（0库存行不展示，勾选「展示为0的库存数据」后展示；主PRD Q05已定）；默认按逻辑仓编码、商品编码升序。

## 4. 列表表格

### 4.1 视角说明

每行一条「逻辑仓＋商品」库存余额，不按实体仓汇总、不展开库位或批次；同一实体仓下多个相同库存状态的逻辑仓分行展示。

### 4.2 列定义

通用对齐、千分位、空值、列表状态样式见《原型开发说明》「列表列通用呈现规则」。下表只写本页列清单与模块差异。

| # | 列名 | 展示形式 | 对齐 | 排序 | 空值 | 格式/示例 | 说明 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 勾选 | 复选框 | 居中 | — | — | — | 配合导出「已勾选」 |
| 2 | 逻辑仓 | 文本 | 左 | 否 | `-` | `LWH000001 深圳正常品仓` | Code-Name；固定左侧；默认排序列 |
| 3 | 所属实体仓 | 文本 | 左 | 否 | `-` | `WH000001 深圳自营仓` | Code-Name |
| 4 | 商品编码 | 文本 | 左 | 否 | `-` | `SP0102030001` | — |
| 5 | 商品条码 | 文本 | 左 | 否 | `-` | `6901001001` | 多条码合并展示 |
| 6 | 商品名称 | 文本 | 左 | 否 | `-` | `示例充电器` | `ellipsis`，hover 看全文 |
| 7 | 基本单位 | 文本 | 左 | 否 | `-` | `件` | 数量按基本单位 |
| 8 | 库存状态 | 文本 | 左 | 否 | `-` | `正常品` | 枚举文字，不用胶囊 |
| 9 | 即时库存 | 数值 | 右 | 是 | `0` | `100` | 整数；0按0展示 |
| 10 | 预占库存 | 数值＋入口 | 右 | 是 | `0` | `60 [查看来源]` | 同上；预占大于0时展示「查看来源」，列出产生预占的来源单据行并可跳转库存流水（主PRD R11）；来源见[《预占与冻结主PRD》](../../预占与冻结/预占与冻结主PRD.md) |
| 11 | 冻结库存 | 数值 | 右 | 是 | `0` | `10` | 同上 |
| 12 | 可用库存 | 数值 | 右 | 是 | `0` | `30` | 即时−预占−冻结 |
| 13 | 最后更新时间 | 日期时间 | 左 | 是 | `-` | `2026-09-23 10:20:00` | 本行库存最近一次变化时间 |
| 14 | 操作 | 行内按钮 | 左 | — | — | `[冻结] [解冻] [查看流水]` | 固定右侧；按条件展示，见 §6 |

列顺序原则：仓库维度在前，商品维度在中，数量在中后，时间与操作在后。

### 4.3 本页列表约定

| 项目 | 规则 |
| --- | --- |
| 默认排序 | `逻辑仓` 编码升序，同仓内 `商品编码` 升序；进入页面即生效 |
| 固定列 | `逻辑仓` 左固定；操作列右固定 |
| 数量列 | 整数、右对齐、不带币别或单位后缀；0为有效值展示 `0` |
| 0库存行 | 即时、预占、冻结、可用均为0的行默认不展示；勾选「展示为0的库存数据」后按0展示 |
| 预占来源 | 「预占库存」列在预占大于0时提供「查看来源」，列出产生该行预占的来源单据行（来源单号、行号），并可跳转该「逻辑仓＋商品」的库存流水（主PRD R11） |
| 状态列 | 库存状态用枚举文字，不用语义色；库存状态不是业务状态 |
| 无行内「查看」 | 行内只展示冻结、解冻、查看流水；无编辑、删除、调整按钮 |
| 批量栏 | 仅「已选中 N 条」与列设置；不提供批量冻结、批量解冻（本期不做） |

## 5. 分页与勾选规则

### 5.1 分页

- 表格底部固定分页区：页码、每页条数、总条数摘要等，行为与工程内 `Pagination` 一致。
- 提交查询、重置筛选后回到第一页。

### 5.2 勾选

- 勾选键以**逻辑仓＋商品的库存行**为单位。
- 一期勾选仅配合页头导出「已勾选」范围，不办理批量业务操作。

## 6. 行操作按钮

行内操作按使用频率排列；**仅展示当前条件允许的操作**（不满足时隐藏，不用 disabled）。弹窗正文、校验与本地 Mock 见[《库存查询前端Demo版PRD_弹窗与Mock》](库存查询前端Demo版PRD_弹窗与Mock.md)。

### 6.1 操作矩阵

| 按钮 | 可用库存>0 | 可用库存=0 | 冻结库存>0 | 冻结库存=0 | 说明 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| 冻结 | ✅ | ❌（隐藏） | ✅ | ✅ | 打开冻结弹窗；只能冻可用量（主PRD R06） |
| 解冻 | 不限 | 不限 | ✅ | ❌（隐藏） | 打开解冻弹窗；只能解冻冻结量（主PRD R07） |
| 查看流水 | 不限 | 不限 | 不限 | 不限 | 按当前筛选条件（逻辑仓、商品等）跳转库存流水查询页（主PRD R12） |

- 「冻结」「解冻」「查看流水」互不排斥，满足条件时都展示。
- 无权限时对应按钮不展示（主PRD §4.5）；Demo 默认演示账号具备全部按钮权限。
- 虚拟在途仓行按普通行展示与操作（主PRD Q04已定，2026-09-23）。
- 「预占库存」列的「查看来源」在预占大于0时展示，入口与行内按钮分列处理，见 §4.3。

## 7. 反馈规范

| 操作 | 反馈方式 | 文案 |
| :--- | :--- | :--- |
| 查询成功 | 无额外反馈 | 直接刷新列表结果 |
| 查询失败 | Toast | 搜索失败，请检查查询条件后重试 |
| 查询无结果 | 空状态 | 暂无符合条件的库存记录，可调整查询条件后重试 |
| 冻结成功 | Toast | 已冻结 {数量}，可用库存已更新 |
| 解冻成功 | Toast | 已解冻 {数量}，可用库存已更新 |
| 冻结失败——超过可用量 | Toast | 冻结数量不能超过当前可用库存（当前可用 {可用库存}） |
| 解冻失败——超过冻结量 | Toast | 解冻数量不能超过当前冻结库存（当前冻结 {冻结库存}） |
| 数量非法 | 字段内联错误 | 冻结数量必须为大于0的整数 / 解冻数量必须为大于0的整数 |
| 操作失败——系统繁忙 | Toast | 操作失败，请稍后重试 |
| 查看来源 | 弹层 | 列出产生该行预占的来源单据行（来源单号、行号）；来源行可跳转该「逻辑仓＋商品」的库存流水 |
| 查看来源——无来源 | 弹层内提示 | 该行暂无预占来源 |
| 跳转库存流水 | 页面跳转 | 打开库存流水并预填当前行逻辑仓、商品与查询区已选条件（主PRD R12） |
| 导出 | Toast | 导出任务已创建，请到导入导出中心查看和下载 |

弹窗内校验的定位与文案见弹窗 PRD；本页不重复维护两套文案。

## 8. Mock 数据要求与演示验收

### 8.1 Mock 数据覆盖

- 列表至少 **12 条**记录（去重后）
- 至少覆盖 **3 个逻辑仓**（含同一实体仓下两个相同库存状态的逻辑仓）、**2 个实体仓**、**5 个商品**
- 至少覆盖 **正常品、残次品、待检品**三种库存状态
- 至少 **1 条**即时100、预占60、冻结10、可用30（对照 INV-AC01 示例）
- 至少 **1 条**可用库存为0、**1 条**冻结库存为0、**1 条**预占为0
- 至少 **1 条**即时、预占、冻结、可用均为0的行，用于验证「展示为0的库存数据」勾选框（默认不展示，勾选后展示）
- 至少 **1 条**已禁用逻辑仓的存量行（只要有库存即可冻结、解冻）
- 至少 **1 条**有预占的行配来源单据行 Mock，用于验证「查看来源」
- 至少 **1 个商品有两条以上条码**，用于验证条码查询与合并展示
- 至少 **1 条**虚拟在途仓行（按普通行口径绘制：即时＝在途数量，预占、冻结按实际）
- **枚举与口径**：凡字段清单中已定义枚举或格式的，Mock 取值**必须落在字段清单范围内**；不得自造清单外文案

### 8.2 演示验收

| 场景 | 前置 | 操作 | 预期 |
| --- | :--- | :--- | :--- |
| 正常列表 | Mock 覆盖各维度 | 打开列表 | 数量列右对齐、0按0展示；默认按逻辑仓、商品编码升序 |
| 可用量口径 | 打开即时100、预占60、冻结10的行 | 查看 | 可用库存展示30 |
| 条件查询 | 选择逻辑仓、库存状态并输入商品编码 | 查询 | 只显示同时满足条件的记录 |
| 批量查询 | 商品编码粘贴3个编码 | 查询 | 返回命中任一编码的库存行 |
| 条码检索 | 输入某商品条码 | 查询 | 命中该商品库存行 |
| 冻结 | 某行可用>0 | 点「冻结」录入20 | 弹窗校验通过，行内冻结库存、可用库存更新，Toast提示 |
| 冻结阻断 | 某行可用30 | 点「冻结」录入31 | 阻断并提示不能超过当前可用库存，库存不变 |
| 解冻 | 某行冻结>0 | 点「解冻」录入解冻量 | 冻结库存、可用库存更新，Toast提示 |
| 按钮条件 | 可用为0或冻结为0的行 | 查看行内 | 不满足的按钮隐藏；「查看流水」始终展示 |
| 0库存行 | Mock 含全0行 | 打开列表；再勾选「展示为0的库存数据」 | 默认不展示全0行；勾选后按0展示 |
| 查看来源 | 某行预占大于0 | 点「查看来源」 | 弹层列出产生该行预占的来源单据行；来源行可跳转库存流水 |
| 查看流水 | 任意行 | 点「查看流水」 | 跳转库存流水并预填当前行逻辑仓、商品与查询区已选条件 |
| 无编辑入口 | 任意行 | 查看行内与页头 | 无新增、导入、编辑、删除、库存调整入口 |
| 导出 | 列表非空 | 点页头导出 | 创建异步导出任务并 Toast 提示 |

Demo 验证页面呈现、查询与弹窗联动；不代表真实接口、并发或后端事务行为。
