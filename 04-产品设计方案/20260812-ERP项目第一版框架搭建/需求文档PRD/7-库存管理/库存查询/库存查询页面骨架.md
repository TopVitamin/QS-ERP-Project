## 页面与弹窗清单

| 页面/容器 | 入口 | 用途 |
| --- | --- | --- |
| 库存查询列表 | 库存管理-库存查询 | 查询即时、预占、冻结、可用数量，办理手工冻结、解冻，查看预占来源与流水，导出 |
| 冻结弹窗 | 列表行内「冻结」 | 从可用量中冻结指定数量 |
| 解冻弹窗 | 列表行内「解冻」 | 解冻已冻结数量，恢复可用量 |
| 预占来源列表（弹层） | 列表「预占库存」列「查看来源」 | 列出产生该行预占的来源单据行，可跳转该仓＋商品的库存流水 |
| 库存流水（跳转） | 列表行内「查看流水」 | 按当前筛选条件跳转库存流水查询页 |

库存查询只查看和查询，不提供新增、编辑、详情、删除和导入页面；预占不能手工增改，来源单据规则见[《预占与冻结主PRD》](../预占与冻结/预占与冻结主PRD.md)。

## 文档说明

骨架展示页面分区、字段位置、基本控件、按钮与虚构示例值。字段以TSV为准，业务动作以主PRD为准，详细交互、校验和反馈见Demo PRD。

各页按“用途／关键要素／线框／补充说明”组织。图前简述本页任务及重点，图后只补图中省略项和条件差异；无补充内容时写“无”。

## 绘制约定

遵循[《页面骨架模板-V2》](../../../../../05-常用模板/02-模块设计交付/页面骨架模板-V2.md)与[《UI布局公共说明》](../../../../../05-常用模板/02-模块设计交付/UI布局公共说明.md)。本模块补充：

- 字段名、按钮文案与TSV、Demo PRD一致；示例值为虚构。
- 逻辑仓、所属实体仓、商品引用按 Code-Name（`{编码} {名称}`）画示例值；商品明细拆列展示编码、条码、名称（《6.强盛ERP的编码规则和通用字段规则》2.3例外）。
- 数量列为整数、右对齐、不带单位后缀；0按0展示。
- 库存状态列按枚举文字展示（正常品、残次品、待检品）。
- 行内操作列放「冻结」「解冻」「查看流水」；「预占库存」列在预占大于0时提供「查看来源」；不提供「查看」「编辑」。
- **每行必须画满 6 列**（用 `|` 分隔）；字段不足 6 个时，剩余列标「（空）」留空，不要省略列线。

## 列表页

- **用途**：查询某个逻辑仓、某个商品的即时、预占、冻结和可用数量，办理手工冻结、解冻，查看预占来源并跳转库存流水。
- **关键要素**：页头导出；查询区按逻辑仓、所属实体仓、商品编码、商品条码、商品名称、库存状态，并提供「展示为0的库存数据」勾选框（默认不勾选）；列表默认按逻辑仓编码、商品编码升序；行内按条件展示冻结、解冻；预占库存列提供「查看来源」，行内提供「查看流水」。

```text
+--------------------------------------------------------------------------------------------------+
| 库存查询                                                                                [导出]   |
|--------------------------------------------------------------------------------------------------|
| 查询区（6列栅格）                                                                                |
| 逻辑仓            | 所属实体仓        | 商品编码          | 商品条码      | 商品名称      | 库存状态      |
| [全部逻辑仓 v]    | [全部实体仓 v]    | [支持批量输入编码]| [请输入商品条码]| [请输入商品名称]| [全部 v]    |
| 展示为0的库存数据  | （空）            | （空）            | （空）        | （空）        | （空）        |
| [ ] 默认不勾选     |                   |                   |               |               |               |
|--------------------------------------------------------------------------------------------------|
| [收起过滤 ^]                                                          [重置] [查询]            |
|--------------------------------------------------------------------------------------------------|
| 已选中 0 条                                                                          [列设置]   |
|--------------------------------------------------------------------------------------------------|
| [ ] 逻辑仓            | 商品编码      | 商品名称   | 库存状态 | 即时库存 | 预占库存 | 冻结库存 | 可用库存 | 最后更新时间        | 操作          |
| [ ] LWH000001 深圳正常品仓 | SP0102030001 | 示例充电器 | 正常品   | 100      | 60 [查看来源] | 10  | 30       | 2026-09-23 10:20:00 | [冻结] [解冻] [查看流水] |
| [ ] LWH000004 深圳残次品仓 | SP0102030002 | 示例数据线 | 残次品   | 20       | 0        | 5        | 15       | 2026-09-22 16:05:00 | [冻结] [解冻] [查看流水] |
| （其余列：所属实体仓、商品条码、基本单位，见 TSV「列表展示=是」）                                  |
|--------------------------------------------------------------------------------------------------|
| 共N条  每页20条 [20 v]                                              < 1 2 3 >                  |
+--------------------------------------------------------------------------------------------------+
```

**补充说明**：

- **重点突出**：页头只有「导出」，不提供新增、导入、编辑、删除入口；查询区下方独立一行，左侧「收起过滤」、右侧「重置/查询」；商品编码、商品条码支持批量输入（多个值换行或逗号分隔）；「展示为0的库存数据」默认不勾选，勾选后展示即时、预占、冻结、可用均为0的行。
- **图中省略**：所属实体仓、商品条码、基本单位等列（见 TSV「列表展示=是」）；校验、排序、分页交互见 Demo PRD。
- 行内操作按条件展示：「冻结」在可用库存大于0时展示；「解冻」在冻结库存大于0时展示；不满足时隐藏，不用置灰（详见 Demo PRD §6）。虚拟在途仓行按普通行展示与操作（主PRD Q04已定，2026-09-23）。
- 「预占库存」列在预占大于0时提供「查看来源」，列出产生该行预占的来源单据行（来源单号、行号），并可跳转该「逻辑仓＋商品」的库存流水；不新增独立预占明细页（主PRD R11）。
- 行内「查看流水」按当前筛选条件（逻辑仓、商品等）跳转库存流水查询页（主PRD R12）。
- 批量操作栏一期仅已选中计数与列设置；勾选配合页头导出「已勾选」。
- 无「查看」按钮。

## 弹窗

冻结与解冻共用一个结构：上方只读展示当前逻辑仓、商品和数量，下方录入数量与原因（原因必填）。确认冻结、解冻后各生成一条库存流水（事件类型：冻结／解冻）。

**冻结弹窗**：

```text
+------------------------------------------------------+
| 冻结库存                                          [×] |
|------------------------------------------------------|
| 冻结从可用库存中占用，冻结后不再参与业务占用。          |
| 逻辑仓：LWH000001 深圳正常品仓                          |
| 商品：SP0102030001 示例充电器                          |
| 当前可用库存：30    当前冻结库存：10                    |
| 冻结数量 *                                             |
| [请输入冻结数量]                                       |
| 冻结原因 *                                             |
| [请输入冻结原因]                                       |
|------------------------------------------------------|
|                                [取消] [确认冻结]      |
+------------------------------------------------------+
```

**解冻弹窗**：

```text
+------------------------------------------------------+
| 解冻库存                                          [×] |
|------------------------------------------------------|
| 解冻后这部分数量重新计入可用库存。                      |
| 逻辑仓：LWH000001 深圳正常品仓                          |
| 商品：SP0102030001 示例充电器                          |
| 当前冻结库存：10    当前可用库存：30                    |
| 解冻数量 *                                             |
| [请输入解冻数量]                                       |
| 解冻原因 *                                             |
| [请输入解冻原因]                                       |
|------------------------------------------------------|
|                                [取消] [确认解冻]      |
+------------------------------------------------------+
```

**补充说明**：

- **图中省略**：数量校验（大于0、不超过可用库存／冻结库存）、并发下的重新校验、失败提示见 Demo PRD 与主PRD F02、F03。
- 冻结原因、解冻原因必填（主PRD Q03已定，2026-09-23）；确认冻结、解冻后各生成一条库存流水（事件类型：冻结／解冻，来源单号为空，记录操作人与时间，见[《库存流水主PRD》](../库存流水/库存流水主PRD.md)）。
- 按RBAC，没有对应按钮权限时不展示行内按钮，不需要弹窗阻断（主PRD §4.5）。
