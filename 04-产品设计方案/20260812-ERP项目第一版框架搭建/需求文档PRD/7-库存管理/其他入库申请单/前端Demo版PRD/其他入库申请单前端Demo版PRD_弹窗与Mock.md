## 3. 状态变更弹窗（F03、F04、F06、F07）

下列弹窗均在**二次确认**后执行。入口可用条件见主PRD §6.4 与各页页头/行内矩阵；条件不满足时**不展示按钮**，无需弹窗阻断。

**阻断类失败**（不满足业务规则、未进入成功流）：状态不匹配时 Toast「当前单据状态为{状态}，不可执行{动作}」；权限不足时 Toast「您暂无{动作}权限，请联系管理员」。

### 3.1 提交

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 新增/编辑页、列表、详情「提交」 |
| 可用条件 | 单据状态=草稿 |
| 弹窗标题 | 确认提交其他入库申请单？ |
| 正文 | 提交后进入待审核状态，入库仓、业务类型与数量不可再修改；审核前仍可撤回修改。 |
| 必填项 | 无 |
| 确认按钮 | 确认提交 |
| 取消按钮 | 取消 |
| 确认后 | 状态→待审核；Toast「其他入库申请单已提交」；不改变库存 |

### 3.2 审核

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「审核」 |
| 可用条件 | 单据状态=待审核 |
| 弹窗标题 | 确认审核其他入库申请单？ |
| 正文 | 审核通过后系统自动推送仓库；入库申请不预占、不增加库存，实际入库以仓库回传的结果单为准。 |
| 必填项 | 无 |
| 确认按钮 | 确认审核 |
| 取消按钮 | 取消 |
| 确认后 | 状态→已审核并自动推送；Toast「审核通过，正在推送仓库」；接续 §5 Mock（Demo开关开启时） |

### 3.3 撤回

| 弹窗标题 | 撤回其他入库申请单 |
| 正文 | 撤回后回到草稿，可修改后重新提交；撤回意见会保留。 |

## 4. 结果单重推（不在本模块）

推送财务ERP失败的处理属于**其他入库单**侧：自动重试最多3次，仍失败在系统集成中心针对原单重推；申请单列表/详情不提供重推入口。详见[《其他入库单主PRD》](../../其他入库单/其他入库单主PRD.md) R09、R10。

```text
其他入库申请单列表 / 详情
         │
    用户查找结果单重推入口
         │
         ▼
    本模块无重推按钮
         │
         ▼
  到「其他入库单详情 → 系统集成中心」办理
```

## 5. Demo Mock：模拟仓库回传生成其他入库单（F08）

### 5.1 正式规则（必读）

正式环境中，其他入库申请单审核后由系统自动推送仓库；仓库执行一次并回传实际入库数量：实收大于0时系统自动生成**已审核**其他入库单，增加对应逻辑仓库存并回写申请单实收与状态；实收为0时按零收取消申请单，不生成结果单、不改变库存。允许缺量、不允许超量（超过申请数量整次拒绝）。**申请单不提供手动关闭，也不设到期自动关单。**

本节 Mock **仅用于 Demo 原型串联展示**，不属于主PRD AC01～AC14 的正式验收项（主PRD F08）。

### 5.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 待收货申请单详情点「模拟回传」 | 打开 §5.3 弹窗，录入实收数量；确认后按 §5.4 本地生成演示入库单 |

```text
待收货申请单详情
         │
     Mock 回传实收数量
         │
         ▼
    实收合计 > 0？
         │
    ┌────┴────┐
   否         是
    │          │
    ▼          ▼
 申请单取消   尚无关联入库单？
 不生成结果单      │
             ┌───┴───┐
            否       是
             │        │
             ▼        ▼
          阻断     §5.4 本地创建
          重复     已审核入库单
                       │
                       ▼
                推送财务ERP状态=未推送
                Demo 可模拟推送进度
```

### 5.3 引导弹窗

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 模拟仓库回传（Demo） |
| 正文 | 按实际入库数量生成演示用其他入库单；正式流程以仓库回传为准。 |
| 必填项 | 回传实收数量（整数，大于0且不超过申请数量） |
| 确认按钮 | 确认回传 |
| 取消按钮 | 取消 |
| 确认后 | 执行 §5.4 本地创建规则 |

### 5.4 生成规则（本地 Mock）

| 项目 | Mock 规则 |
| :--- | :--- |
| 生成条件 | 来源申请单状态=待收货；实收合计>0；实收不超过申请数量；尚无关联入库单 |
| 单头 | 沿申请单带入来源其他入库申请单、入库仓库、业务类型；实际入库时间=当前时间 |
| 明细 | 实际入库数量=录入实收；来源申请行沿来源行 |
| 审核 | 创建即为已审核；审核人留空；创建人、最后更新人显示「系统」 |
| 库存与回写 | Mock 增加入库仓即时库存；回写申请单实收与状态为已收货；未收数量重算 |
| 财务ERP | 生成后从「未推送」开始，由 Demo 模拟推送进度；明确失败时可模拟自动重试3次 |
| 单号 | 按 QTRK 编码规则生成 fictitious 编号 |
| 零收 | 实收为0时：申请单按零收取消，不生成入库单、不改变库存（正式规则，Mock同样不生成） |

界面标注「演示数据」或「Mock」角标，与正式回传生成的入库单区分。

### 5.5 不做的事

- 不代替正式仓库回传与校验逻辑
- 不提供无来源人工建单页面
- 不把 Mock 推送当作财务ERP正式验收
- 不在本模块演示系统集成中心重推；人工确认在本模块申请单详情页办理，随对应模块修订

### 5.6 与结果单 Mock 的关系

本 Mock 生成演示入库单后，可在[《其他入库单前端Demo版PRD_弹窗与Mock》](../../其他入库单/前端Demo版PRD/其他入库单前端Demo版PRD_弹窗与Mock.md)查看结果单侧的推送进度模拟；两侧不重复触发同一张单的生成。

## 6. 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 提交流 | 草稿点提交 | 弹窗 → 待审核 |
| 审核流 | 待审核点审核 | 弹窗 → 已审核并自动推送 |
| 撤回 | 待审核点撤回，撤回意见为空 | 阻断，提示撤回意见必填；填写后回草稿 |
| 取消（待审核） | 待审核点取消 | 弹窗必填取消原因 → 已取消 |
| 取消（待收货） | 待收货点取消 | 弹窗 → 取消中；提示等待仓库确认 |
| Demo仓库拒绝取消 | 打开取消中单详情，点「模拟仓库回执」并选「仓库拒绝」 | 申请单恢复待收货；不调用真实仓库接口 |
| Demo仓库同意取消 | 打开取消中单详情，点「模拟仓库回执」并选「仓库同意」 | 申请单变为已取消；不调用真实仓库接口 |
| 重试推送 | 推送失败点重试推送 | 弹窗 → 已审核等待发送 |
| 删除草稿 | 草稿点删除 | 二次确认 → 记录消失 |
| 无关闭/无重推入口 | 任意状态查找关闭、结果单重推 | 无对应按钮与弹窗 |
| Mock 开启 | 待收货详情点「模拟回传」 | 出现 §5.3 弹窗 |
| Mock 生成 | 实收80，确认回传 | 本地生成已审核入库单80；申请单已收货、未收20；推送财务ERP从未推送开始 |
| Mock 零收 | 实收0，确认回传 | 申请单取消；不生成入库单 |
| Mock 超量 | 实收110（申请100） | 阻断并提示不得超过申请数量 |
| 业务阻断 | 状态不匹配时点操作 | Toast 阻断，不进入成功流 |

Demo 验证弹窗文案、必填项与 Mock 本地数据联动；不代表生产接口、并发或后端事务行为。
