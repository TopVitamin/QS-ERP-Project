## 2. 本期结论

**本期不提供无来源新增页，也不提供已审核单的编辑页。**

其他出库单的常规创建方式为：

1. 其他出库申请单审核（预占）并推送仓库 → 仓库回传实出并结束 → 系统自动生成已审核出库单；
2. 仓库先完成盘亏等实际变动并主动回传 → 校验通过后系统自动生成已审核出库单；
3. 出库仓为虚拟在途仓时，申请单不推送仓库，由系统按申请数量直接生成已审核出库单（主PRD R11）。

已交给仓库、接口拿不到结果时，可人工确认实际结果（INT-FR06），入口在**系统集成中心**，不是本模块无来源建单。形成的出库单走提交审核，不在本模块维护。

| 不做的事 | 说明 |
| :--- | :--- |
| 无来源人工建单 | 不提供入口（主PRD §3.4） |
| 已审核后编辑 | 已审核为终态，不提供编辑、取消、作废（主PRD R08） |
| 结果单重推 | 在系统集成中心针对原单重推（主PRD R12） |
| 出库单导入 | 本期不做 |
| 手工调整预占 | 预占由审核占用、实出消耗、缺量与取消释放（《预占与冻结主PRD》§二 本期不做「手工新增或修改预占」） |
