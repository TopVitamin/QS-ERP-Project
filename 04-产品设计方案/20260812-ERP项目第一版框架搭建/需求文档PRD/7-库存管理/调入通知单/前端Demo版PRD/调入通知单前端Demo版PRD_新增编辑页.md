## 2. 本期结论

**本期不提供新增页，也不提供编辑页。**

调入通知单的创建方式为：

1. 调出端直接调拨单生成后，系统**按实际调出量**自动生成调入通知单并分配单号（前缀DRTZ）；
2. 生成后由系统自动推送接收仓，不需要人工触发推送。

通知单的接收仓、商品与通知调入数量全部按实际调出量写入，创建后不可修改；不按原计划量提前下发。

| 不做的事 | 说明 |
| :--- | :--- |
| 人工新建通知单 | 不提供入口（主PRD §3.4） |
| 按原计划量提前下发接收指令 | 一期不支持（INV-FR03） |
| 编辑通知数量、接收仓、商品 | 创建后只读（主PRD R01） |
| 编辑备注 | 当前画法不提供（主PRD Q01）；备注随来源主单 |
| 通知单导入 | 本期不做 |
| 人工推送 | 创建后系统自动推送，无人工推送按钮（主PRD R03） |
| 申请取消 | 本期不提供（主PRD §6.4、Q02） |
| 虚拟入库处理方式 | 调出、调入通知单本期不增加处理方式字段（《单据分层设计》§5.10） |
