## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 调入通知单详情页 |
| 入口 | 列表点单号 |
| 页面目标 | 只读查看接收指令全貌；按当前状态办理重试；追溯来源主单与调入端结果单；提示少收与零调入异常 |
| 骨架结构 | 页头 → 单据信息（含推送信息） → 商品明细（含异常提示） → 关联单据 → 系统信息 |

本页落地 **F04**；状态—操作矩阵见主PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头状态标签：单据状态一枚 StatusBadge。
> - 关联单据：商品明细之后展示胶囊 Tab（来源调出端直接调拨单、调入端直接调拨单），带数量。
> - **无终止信息区**：本期不提供取消（主PRD §6.4、Q02）。
> - 操作信息：制单信息 Tab；完整操作日志一期后置。
> - 二次确认弹窗正文在[弹窗 PRD](调入通知单前端Demo版PRD_弹窗与Mock.md)维护，本文只写入口与结果表现。
> - Demo 以桌面端为基准；明细、关联简表窄视口横向滚动。

## 2. 页头

### 2.1 标题与状态

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `调入通知单详情 · {单号}` |
| 状态标签 | 单据状态一枚（待推送／推送中／推送失败／待收货／取消中／已收货／已取消） |
| 布局 | 单行：左侧标题 + 状态；右侧操作区（`DocumentDetailFrame`） |

### 2.2 页头操作按钮

`返回列表` **始终排在最前**；其后按状态展示业务按钮。

| 按钮 | 待推送 | 推送中 | 推送失败 | 待收货 | 已收货 | 说明 |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| 返回列表 | ✅ | ✅ | ✅ | ✅ | ✅ | 始终 |
| 重试推送 | ❌ | ❌ | ✅ | ❌ | ❌ | 弹窗 PRD §2.1 |

**渲染纪律**：

- 条件不满足的按钮**直接不渲染**，不展示灰色 disabled。
- 样式层级：`重试推送` 用 `outline`；`返回列表` 固定最左。
- **不提供「取消」**（主PRD §6.4、Q02）。

二次确认入口与确认后的页面表现统一在第五节维护；弹窗正文引用弹窗PRD。

## 3. 信息分区与字段

> 只读 **6 列栅格**（默认），标签在上、值在下。字段顺序与 TSV 分组一致。

**分区总览**：页头 → **3.1 单据信息** → **3.2 商品明细** → **3.3 关联单据** → **3.4 系统信息**

### 3.1 单据信息

推送信息并入本区展示。

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样展示 |
| 来源分步式调拨单 | 链接，可跳转来源主单详情 |
| 来源调出端直接调拨单 | 链接，可跳转调出端结果单详情；系统生成时写入 |
| 接收仓 | 逻辑仓 Code-Name；不含虚拟在途仓 |
| 推送时间 | 未推送时显示 `-` |
| 推送失败原因 | 长文本省略，hover 看全文；未失败时显示 `-` |
| 最终收货确认时间 | 未确认时显示 `-` |

### 3.2 商品明细

- 表格只读；数量列**右对齐**；横向滚动。
- 一期不分页。
- 无价税列。

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 从1起 |
| 商品 | 商品名称 |
| 商品编码 | 原样 |
| 商品名称 | 原样 |
| 基本单位 | 原样 |
| 通知调入数量 | 整数；等于该行实际调出数量 |
| 实际调入数量 | 未确认时显示 `-` |
| 少收数量 | 未回传时显示 `-`；收货完成后＝通知调入数量−实际调入数量；差额留在途 |

**明细区提示条**（按条件展示）：

| 条件 | 文案 |
| :--- | :--- |
| 始终（说明口径） | 通知调入数量按实际调出量生成；实际调入必须大于0，回传0将被拒绝并保持等待。 |
| 零调入回传被拒绝后 | 回传实际调入为0已被拒绝，请仓库改为大于0后重新回传；本单不按零收取消。 |
| 已收货且少收>0 | 少收差额留在途，不自动抹平；后续用其他出库从在途逻辑仓扣减（业务类型盘亏）。 |

### 3.3 关联单据

**展示条件**：商品明细之后（有记录时展示）

组件：`RelatedDocumentsCard` + `InnerTabs` `pill`；Tab 文案带数量。

| Tab | 列 | 排序 | 空态 |
| :--- | :--- | :--- | :--- |
| 来源调出端直接调拨单 | 单号、审核状态、金蝶推送状态、实际调拨数量、创建时间 | 创建时间升序 | 暂无来源调出端直接调拨单 |
| 调入端直接调拨单 | 单号、审核状态、金蝶推送状态、实际调拨数量、创建时间 | 创建时间升序 | 暂无关联的调入端直接调拨单 |

单号可点击跳转对应详情。

### 3.4 系统信息

胶囊 Tab：[制单信息] / [操作日志]

| Tab | 内容 |
| :--- | :--- |
| 制单信息 | 创建人、创建时间、最后更新人、最后更新时间；系统自动生成时显示「系统」 |
| 操作日志 | 表格列：操作时间、操作人、操作类型、说明；完整审计日志一期后置 |

## 4. 字段展示规范

空值、Code-Name、数字与日期格式、状态样式、关联简表均引用公共规范；不在此重抄。数量为整数、不允许小数。

| 字段或区域 | 本页差异 | 依据 |
| --- | --- | --- |
| 接收仓 | Code-Name 展示；不含虚拟在途仓 | 主PRD R01；《库存与仓储业务设计》§4.2 |
| 通知调入数量 | 等于实际调出数量，不按原计划量 | 主PRD R01；INV-FR03 |
| 少收数量 | 未回传时显示 `-`；收货完成后计算；差额留在途 | TSV 取值说明 |
| 单据状态 | 取消中／已取消为共用状态机取值，本期不开放入口 | 主PRD §6.1、Q02 |

## 6. 反馈与页面状态

### 6.1 操作反馈（Toast）

| 操作 | 反馈类型 | 文案 |
| :--- | :--- | :--- |
| 重试推送 | Toast | 已重新推送接收仓 |
| 推送失败（重试） | Toast | 推送失败：{失败原因}，系统将继续自动重试 |

## 7. Mock 与验收

### 7.1 Mock 覆盖清单

- 各主状态至少 1 单：待推送、推送中、推送失败、待收货（含零调入被拒绝后仍为待收货）、已收货（含收足与少收）；不演示已取消（共用取值，本期不提供进入入口）
- 关联 Tab 有数据 + 空态：来源调出端直接调拨单有数据；已收货单有调入端直接调拨单；未回传单的调入端 Tab 为空态
- 数量边界：未回传时实际调入与少收数量均显示 `-`；少收大于0与等于0各 1 单
- 异常提示边界：零调入被拒绝后提示条展示

### 7.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 正常路径 | 打开待收货单 | 单据状态=待收货；页头只有「返回列表」 |
| 少收 | 打开已收货且少收的单 | 少收数量大于0；提示条说明差异留在途 |
| 收足 | 打开已收货且少收为0的单 | 少收数量0；关联 Tab 有调入端直接调拨单 |
| 推送失败 | 打开推送失败单 | 页头展示「重试推送」；展示失败原因 |
| 无取消 | 打开任意状态单据 | 页头与详情均无取消入口 |
| 来源调出端结果单 | 打开任意单据 | 单据信息区展示来源调出端直接调拨单并可跳转；关联单据有对应 Tab |

模拟的保存、状态变化和关联结果应可连续演示；Demo 验证不代表真实接口、并发或后端事务已验证。
