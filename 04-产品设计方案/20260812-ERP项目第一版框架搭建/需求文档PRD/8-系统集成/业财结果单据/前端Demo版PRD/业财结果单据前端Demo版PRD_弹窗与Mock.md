## 2. 推送记录查看弹窗（F02）

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表行内「推送记录」（全部推送状态可用） |
| 弹窗标题 | 推送记录 · {结果单号} |
| 内容 | 按推送时间倒序展示：推送序号、推送时间、推送结果、推送失败原因、触发方式、操作人、处理说明（字段口径见 TSV「推送记录」分组） |
| 空态 | 暂无推送记录 |
| 关闭按钮 | 关闭 |
| 只读边界 | 记录不可编辑、删除；不提供重推按钮（重推在列表行内） |

弹窗内不展示财务ERP单号；推送失败原因为空时展示 `-`。

## 3. 状态变更弹窗（F03、F04）

下列弹窗均在**二次确认**后执行。入口可用条件见主 PRD §4.7 与列表页 PRD §6；条件不满足时**不展示按钮**。

### 3.1 重推

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表行内「重推」（推送财务ERP状态=推送失败） |
| 可用条件 | 推送财务ERP状态=推送失败（主 PRD R04） |
| 弹窗标题 | 确认重推财务ERP？ |
| 正文 | 将对结果单 {结果单号} 重新推送财务ERP。重推不重新审核、不重复记账，库存与业务结果不回滚。 |
| 必填项 | 处理说明（选填，0~500字符） |
| 确认按钮 | 确认重推 |
| 取消按钮 | 取消 |
| 确认后 | 状态回到「推送中」，推送结束后更新为「推送成功」或「推送失败」；追加一条推送记录；Toast 见列表页 PRD §7；接续 §4 Mock |

### 3.2 异常运维重推

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表行内「异常运维重推」（推送财务ERP状态=推送成功） |
| 可用条件 | 推送财务ERP状态=推送成功，且账号具备异常运维权限（主 PRD R05、Q02） |
| 弹窗标题 | 异常运维重推 |
| 正文 | 用于推送成功后财务ERP侧发现异常的情形：请先在财务ERP删除错误单据，再重新推送本结果单。 |
| 必填项 | 重推原因（0~500字符） |
| 确认按钮 | 确认重推 |
| 取消按钮 | 取消 |
| 确认后 | 重新推送原结果单；追加一条触发方式为「异常运维重推」、操作人为当前账号的推送记录；不修改原单业务信息；接续 §4 Mock |

**阻断类失败**：推送状态不满足时按钮不展示；原因未填写时字段内联提示「请输入重推原因」，不进入成功流程。

## 4. Demo Mock：重推后的本地状态与记录变化（F03、F04）

### 4.1 正式规则

正式环境中，重推由系统向财务ERP重新推送原结果单，推送结果与失败原因来自真实接口；自动重试最多3次、间隔由技术配置（主 PRD R03、R04）。本节 Mock **仅用于 Demo 原型串联**，不属于正式验收项。

### 4.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 重推或异常运维重推确认后 | 行状态立即变为「推送中」；按 Mock 延时（约1.2秒）后按演示开关结果变为「推送成功」或「推送失败」 |
| 推送失败演示开关 | 默认「成功」；开启后重推固定失败，用于演示失败原因更新与继续重试 |

```text
[确认重推] -> [状态：推送中]
                 | 延时约1.2秒
                 v
           [演示开关]
             | 默认 -> [推送成功] -> [追加推送记录（成功）]
             | 开启 -> [推送失败] -> [更新失败原因，追加推送记录（失败）]
```

### 4.3 本地数据规则

| 项目 | 规则 |
| :--- | :--- |
| 状态更新 | 重推后按上述分支更新该结果单的「推送财务ERP状态」「最近推送时间」「失败原因」 |
| 推送记录 | 追加一条记录：序号递增、推送时间为当前时间、触发方式按入口（人工重推／异常运维重推）、操作人为当前演示账号、处理说明取弹窗填写值 |
| 跨页联动 | 重推成功后，「推送异常-推送财务ERP」页签中该结果单的异常记录置为「已处理」；重推仍失败时保持「待处理」并更新失败原因 |
| 外部系统 | Demo 不调用财务ERP；结果单所属模块的详情与列表数据不回滚、不重复记账 |

### 4.4 不做的事

- 不模拟财务ERP单据的创建、删除与对账结果；
- 不改变原结果单的业务信息、审核状态与库存结果；
- 不把 Mock 结果写入主 PRD 验收标准。

## 5. 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 推送记录查看 | 对有 3 条记录的结果单点「推送记录」 | 按时间倒序展示序号、时间、结果、原因、触发方式与操作人；系统自动显示「系统」 |
| 重推成功流 | 对推送失败行点「重推」并确认 | 状态先变推送中，随后按默认开关变推送成功；记录新增一条；Toast 提示成功 |
| 重推失败流 | 开启失败演示开关后重推 | 状态回到推送失败并更新失败原因；记录新增一条；Toast 提示失败 |
| 异常运维重推 | 对推送成功行点「异常运维重推」，不填原因提交 | 字段内联提示「请输入重推原因」，不提交；填写后确认，新增「异常运维重推」记录 |
| 状态互斥 | 分别查看未推送、推送中、推送成功、推送失败行 | 仅推送失败显示「重推」；仅推送成功显示「异常运维重推」；所有行都显示「推送记录」 |
| 跨页联动 | 在业财结果单据重推成功后打开「推送异常-推送财务ERP」页签 | 对应异常记录变为「已处理」，默认待处理视图不再展示 |

Demo 验证弹窗文案、必填项与 Mock 本地数据联动；不代表生产接口、并发或后端事务行为。
