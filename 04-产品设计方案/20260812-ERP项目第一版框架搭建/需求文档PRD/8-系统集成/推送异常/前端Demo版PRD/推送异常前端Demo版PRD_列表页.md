## 1. 页面目标与范围

- 页面名称：推送异常列表页
- 查看视角：**异常记录视角**（每行一条失败记录；推送类按原单聚合为最新一条失败记录）
- 用途：按推送对象页签查看外部推送失败与结果处理失败；查看处理记录；跳转原单；财务ERP异常去重推；导出
- 功能与状态—操作矩阵见[《推送异常主PRD》](../推送异常主PRD.md) §4.10；本页落地 F01～F05 的列表侧入口
- 本期边界：
  - 页面**只读**：不提供重试推送、取消单据、修改业务信息、维护映射、人工关闭异常；不提供新增、编辑、删除、导入入口；
  - 页内页签五个：推送财务ERP、推送外部仓库、推送电商平台、主数据分发、结果处理；切换页签后查询区与列表列随页签切换，并回到第一页、清空勾选；
  - 行内只有「处理记录」；推送财务ERP页签在**待处理**时另有「去重推」（跳转业财结果单据并预填结果单号）；
  - 处理状态默认「待处理」；已处理记录保留可查；
  - 导出按导出中心（可选全部／当前筛选／已勾选），导出当前页签。

## 7. 反馈规范

| 操作 | 反馈方式 | 文案 |
| :--- | :--- | :--- |
| 查询成功 | 无额外反馈 | 直接刷新列表结果 |
| 查询失败 | Toast | 搜索失败，请检查查询条件后重试 |
| 查询无结果 | 空状态 | 该条件下暂无推送异常记录，可调整查询条件后重试 |
| 去重推跳转 | 页面跳转 | 进入「系统集成-业财结果单据」并预填结果单号 |
| 原单不存在 | Toast | 单据不存在或不可访问 |
| 导出 | Toast | 导出任务已创建，请到导入导出中心查看和下载 |
| 操作失败——系统繁忙 | Toast | 操作失败，请稍后重试 |

## 8. Mock 数据要求与演示验收

### 8.1 Mock 数据覆盖

- 五个页签各至少 **6 条**异常记录，合计不少于 **30 条**
- 每个页签处理状态「待处理」「已处理」各至少 **2 条**
- 推送财务ERP页签覆盖 **七类结果单**各至少1条；至少 **1 条**已处理记录用于验证默认视图不展示
- 推送外部仓库页签覆盖通知单、申请单、独立站订单至少各1条，目标系统覆盖至少3种
- 推送电商平台页签覆盖两种推送内容各至少1条
- 主数据分发页签覆盖四个目标系统（第三方仓／WMS、金蝶云·星空、聚水潭、领星）各至少1条
- 结果处理页签覆盖四种异常环节各至少1条，来源系统覆盖至少3种
- 至少 **1 条**记录有 **3 条**处理记录（系统自动重试、人工重试、修复恢复），用于演示处理记录弹窗
- **枚举与口径**：凡字段清单中已定义枚举或格式的，Mock 取值**必须落在字段清单范围内**；不得自造清单外文案

### 8.2 演示验收

| 场景 | 前置 | 操作 | 预期 |
| --- | --- | --- | --- |
| 页签切换 | 各页签有数据 | 依次切换五个页签 | 查询区与列表列随页签切换；回到第一页、清空勾选；默认处理状态为待处理 |
| 默认视图 | 存在待处理与已处理记录 | 打开任一页签 | 只展示待处理记录；切换处理状态为「已处理」或「全部」后可看到历史记录 |
| 筛选 | 各页签有数据 | 按目标系统、异常环节、失败时间等筛选 | 多选条件OR匹配；未选等同全部；无匹配时展示空状态 |
| 处理记录 | 该记录有 3 条处理记录 | 点「处理记录」 | 按时间倒序展示处理时间、方式、结果、操作人与说明；系统自动显示「系统」 |
| 去重推跳转 | 推送财务ERP页签有 1 条待处理记录 | 点「去重推」 | 跳转业财结果单据并按结果单号预填筛选；已处理记录不显示该按钮 |
| 只读边界 | 任意页签任意行 | 查看页头与行内 | 无重试、取消、编辑、删除、导入入口；无人工关闭入口；处理状态不可手工修改 |
| 跨页联动 | 在业财结果单据重推成功 | 返回推送异常-推送财务ERP页签 | 该记录变为「已处理」，默认待处理视图不再展示 |
| 导出 | 任一页签非空 | 点页头导出 | 创建异步导出任务并 Toast 提示；导出列与当前页签列表列一致 |

Demo 验证页面呈现、页签切换与 Mock 联动；不代表真实外部接口、并发或后端事务行为。
