## 2. 处理记录查看弹窗（F03）

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表行内「处理记录」（全部处理状态可用） |
| 弹窗标题 | 处理记录 · {对象编号}（结果单号／单据编号／商品编码／来源单号） |
| 内容 | 按处理时间倒序展示：处理时间、处理方式、处理结果、操作人、说明（字段口径见 TSV「处理记录」分组） |
| 空态 | 暂无处理记录 |
| 关闭按钮 | 关闭 |
| 只读边界 | 记录不可编辑、删除；不提供重试、关闭异常等动作 |

处理说明为空时展示 `-`；系统自动触发时操作人显示「系统」；推送财务ERP页签的处理记录与业财结果单据的推送记录同源，字段按本口径展示。

## 3. Demo Mock：处理记录数据与跨页联动（F04）

### 3.1 正式规则

正式环境中，处理记录由各链路的实际处理动作产生：仓库推送失败在原单重试、推送财务ERP失败在业财结果单据重推、映射修复后处理原记录，处理结果更新异常记录的处理状态并保留记录（主 PRD R04、R05、R06）。本节 Mock **仅用于 Demo 原型串联**，不属于正式验收项。

### 3.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 打开任一页签 | 从演示种子读取异常记录与处理记录；默认只展示待处理 |
| 在业财结果单据重推成功 | 推送财务ERP页签对应记录置为「已处理」并追加一条处理记录（处理方式：重推） |
| 处理记录弹窗打开 | 只读展示种子与联动产生的记录 |

```text
[业财结果单据重推成功]
    -> [推送财务ERP异常记录：处理状态 -> 已处理]
        -> [追加处理记录：重推／成功／操作人／说明]
            -> [返回推送异常：默认待处理视图不再展示该记录]
```

### 3.3 本地数据规则

| 项目 | 规则 |
| :--- | :--- |
| 数据来源 | 异常记录与处理记录为演示种子；跨页联动只更新推送财务ERP页签的记录 |
| 处理状态 | 默认「待处理」；重推成功后自动置为「已处理」，不提供人工修改入口 |
| 处理记录 | 追加记录：处理时间为当前时间、处理方式按来源、处理结果按结果、操作人为当前演示账号或「系统」 |
| 外部系统 | Demo 不调用财务ERP、WMS、Shopify；不产生真实推送、取消或记账 |

### 3.4 不做的事

- 不在本页模拟重试推送、取消单据或修复映射；
- 不改变原单业务信息与库存结果；
- 不把 Mock 结果写入主 PRD 验收标准。

## 4. 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 处理记录查看 | 对有 3 条记录的行点「处理记录」 | 按时间倒序展示处理时间、方式、结果、操作人与说明；系统自动显示「系统」 |
| 空处理记录 | 对刚失败、尚无处理记录的行点「处理记录」 | 展示空态「暂无处理记录」 |
| 跨页联动 | 在业财结果单据对某结果单重推成功后返回推送异常 | 推送财务ERP页签该记录为「已处理」；默认待处理视图不再展示；处理记录新增一条「重推」 |
| 只读边界 | 任意行 | 弹窗与列表均无编辑、删除、重试、关闭异常入口 |

Demo 验证弹窗内容与 Mock 本地数据联动；不代表生产接口、并发或后端事务行为。
