# 销退入库单前端Demo版PRD·详情页

> **版本**：V0.1
> **更新时间**：2026-09-22
> **定位**：供 AI 生成销退入库单详情页前端原型。字段见[《销退入库单（详细稿）》](../../../../字段清单合集/销售相关/销退入库单（详细稿）.tsv)；业务规则见[《销退入库单主PRD》](../销退入库单主PRD.md)（§6.4、R04～R08、F04）。**本文件只写页面呈现，不重复字段含义与枚举。**

关联资料：[《销退入库单页面骨架》](../销退入库单页面骨架.md)、[《销退入库单前端Demo版PRD_弹窗与Mock》](销退入库单前端Demo版PRD_弹窗与Mock.md)。布局见骨架。

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 销退入库单详情页 |
| 入口 | 列表点击单号；销退收货通知单详情关联单据跳转 |
| 页面目标 | 只读查看一张入库单全貌；追溯来源单据与推送结果 |
| 骨架结构 | 页头 → 单据信息 → 商品明细 → 操作信息 |

本页落地 **F04（分区域只读展示与追溯）**；状态—操作矩阵见主 PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头固定展示**审核状态、推送财务ERP状态**两枚 **StatusBadge**。
> - 整单只读；**不提供**编辑、提交、审核、撤回、重推财务ERP按钮。
> - 推送失败时展示失败原因；重推到**系统集成中心**办理（F08）。
> - 操作信息含**制单信息 / 操作日志**胶囊 Tab。

## 3. 信息分区与字段

**分区总览**：页头 → **3.1 单据信息** → **3.2 商品明细** → **3.3 操作信息**

### 3.1 单据信息

单据信息区字段取 TSV「单据信息」分组全部 18 个字段（TSV 详情展示=是）：

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样 |
| 来源类型 | 销退收货通知／外部ToC |
| 来源销退收货通知单 | Code-Name；路径一可跳转通知详情；路径二为 `—` |
| 来源销售退货单 | Code-Name；路径一可跳转退货单详情；路径二为 `—` |
| 外部原始订单 | 仅路径二展示来源单号，可跳转或展示来源信息；路径一为 `—` |
| 客户 | Code-Name |
| 币别 | `{币别编码} {币别名称}` |
| 收货仓库 | 逻辑仓 Code-Name；路径二为按来源与映射识别的逻辑仓 |
| 价税合计 / 税额 / 金额 | 千分位；2 位小数 |
| 业务日期 | 日期；**取实际收货时间的日期部分** |
| 实际收货时间 | 日期时间；仓库最终回传或虚拟入库确认时间 |
| 推送财务ERP时间 | 日期时间；未推送时 `-` |
| 推送失败原因 | 占 3 列；仅推送财务ERP状态=推送失败时展示 |
| 备注 | 占 3 列 |

布局：第 1 行—单号、来源类型、来源通知、来源退货单、外部原始订单、客户；第 2 行—币别、收货仓库、业务日期、实际收货时间、价税合计、税额；第 3 行—金额、推送财务ERP时间、推送失败原因（占后 3 列，仅失败时）；第 4 行—备注（占 3 列）。

### 3.2 商品明细

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 自动编号 |
| 来源收货通知行 | 路径一关联来源通知明细；路径二为 `—` |
| 商品编码 | 文本 |
| 商品条码 | 文本；无条码为 `-` |
| 商品名称 | 文本 |
| 基本单位 | 文本 |
| 实际收货数量 | 整数；不超过通知数量 |
| 含税单价 | 4 位小数 |
| 税率 | 百分比；允许 0% |
| 不含税单价 | 4 位小数 |
| 价税合计 / 税额 / 金额 | 2 位小数 |

**底部汇总行**：合计实际收货数量、价税合计、税额、金额，与对应列右对齐。

### 3.3 操作信息

胶囊 Tab：**制单信息** / **操作日志**。

**制单信息**：审核人、审核时间、创建人、创建时间、最后更新人、最后更新时间。自动生成的入库单创建人与最后更新人显示「系统」，自动审核时审核人留空。

**操作日志** Tab：操作时间、操作人、操作类型、说明；按时间倒序；含自动生成、自动审核、推送财务ERP、重推等记录。

## 4. 来源路径差异展示

| 来源类型 | 差异 |
| :--- | :--- |
| 销退收货通知（路径一） | 展示来源通知与来源销售退货单链接、来源收货通知行；价格沿销售退货单；经通知追溯到原销售出库单 |
| 外部ToC（路径二） | 来源通知与来源退货单为 `—`；展示外部原始订单；金额沿用来源结果，不重新定价 |

两条路径都展示：审核状态、推送财务ERP状态、业务日期（=实际收货时间的日期部分）、推送记录、收货仓库。

---

## 5. 只读与操作说明

- 整单只读：不提供任何字段编辑入口，包括备注。
- 推送失败时在单据信息区展示失败原因与指向：`财务ERP接口超时，请至系统集成中心重推原单。`（文案示例，见弹窗与Mock篇）。
- 本页**不提供**重推财务ERP按钮、导出按钮；导出在列表页头。

---

## 6. Mock 数据要求

- 两条路径各至少 **1 单**
- 至少 **1 单** 推送财务ERP失败，用于失败原因展示
- 路径一单可与销退收货通知单详情关联单据互相跳转
- 至少 **1 单** 覆盖虚拟入库来源（实收=通知数量）
