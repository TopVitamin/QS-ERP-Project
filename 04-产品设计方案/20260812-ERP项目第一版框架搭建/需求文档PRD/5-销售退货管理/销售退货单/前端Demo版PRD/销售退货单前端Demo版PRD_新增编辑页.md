## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 销售退货单新增 / 草稿编辑 |
| 页面目标 | 录入或修改草稿退货单：向谁退、退什么、退多少、入哪个仓、退到什么时候、价格与税率 |
| 适用状态 | 新增页建草稿；**仅审核状态=草稿**可进入编辑（含撤回后回到草稿） |
| 骨架结构 | 页头（标题 + 操作按钮）→ 单据信息 → 商品明细 |

> 操作按钮固定在**页头右侧**，不使用底部固定操作栏。待审核、已审核、已取消、已关闭不可进入本页；已审核后改截止时间走详情/列表弹窗。本页落地 **F02（保存）**、**F03（提交入口）**；状态—操作矩阵见主 PRD §6.4。

| 模式 | 入口 | 差异摘要 |
| :--- | :--- | :--- |
| **新增** | 列表「新增」 | 单号占位「保存后自动生成」；页头无状态标签 |
| **编辑** | 列表/详情「编辑」 | 单号只读；页头两枚 StatusBadge（审核/业务） |

**本期边界**：页头 **取消 / 保存 / 提交**；无业务员、部门、物流字段；操作信息、终止信息、关联单据不在本页；导入建单在列表页头办理（见[列表页 §8 导入](销售退货单前端Demo版PRD_列表页.md)）；草稿删除在列表/详情办理（主 PRD R19）；**无单据日期字段**，页面时间口径用创建时间（主 PRD Q01）；**不画单据日期控件**。

**两种建单方式**（主 PRD R02、R06、R07）：

| 方式 | 入口 | 页面差异 |
| :--- | :--- | :--- |
| 溯源退货 | 单据信息选「来源销售出库单」 | 带出客户、币别（只读）与明细商品、数量、价格与税率；**收货仓库锁定为原出库单仓库，不可切换** |
| 无来源退货 | 不选来源 | 收货仓自由选择启用的逻辑仓，不要求与历史发货仓一致；每行退货数量>0、不套原出库额度 |

## 3. 表单分区与字段

> 单头 **6 列栅格**，标签在上、控件在下；备注占 **3 列**。控件 `type` 对齐原型 `FormControl` / `LineItemTable`。主数据按 Code-Name（`{编码} {名称}`）展示。**placeholder** 指控件无值时的占位文案；只读/禁用填 `—`。

区域顺序：**单据信息 → 商品明细**（与 TSV 分组一致）。

### 3.1 单据信息

| 字段 | 控件 type | placeholder | 规格摘要 |
| :--- | :--- | :--- | :--- |
| 单号 | `disabled` | `保存后自动生成`（新增）/ `—`（编辑有值） | 编辑只读展示系统单号（R01，前缀 XSTH） |
| 来源销售出库单 | `select` | `请选择销售出库单（可选）` | 先选来源再带出；点开后进入「选择来源销售出库单」弹窗，**弹窗展示各行剩余可退额度**，确认后带出客户、币别、仓库与明细（R06、Q09）；留空即无来源建单，清空用字段右侧清除按钮 |
| 客户 | `select` | `请选择客户` | 审核通过且启用；变更清空明细价并默认带出币别（R02、R03）；**溯源时由来源带出并只读** |
| 币别 | `select` | `请选择币别` | 选项如 `CNY 人民币`；变更清空明细价并重取（R03、R04）；**溯源时由来源带出并只读** |
| 价税合计 | `disabled` | `—` | 明细汇总；千分位，带币别符号 |
| 税额 | `disabled` | `—` | 同上 |
| 金额 | `disabled` | `—` | 不含税金额合计；同上 |
| 收货仓库 | `select` | `请选择收货仓库` | 启用的逻辑仓 Code-Name；**溯源时自动带出原出库单仓库并禁用**（R02） |
| 退货截止日期 | `date` | `请选择日期` | 必填；**不设默认值**（Q02，已确认）；到期未退部分按 T+2 规则自动关闭（R16） |
| 备注 | `textarea` | `请输入备注` | 选填；`REMARK_500`；占 3 列 |

行布局：第 1 行—单号、来源销售出库单、客户、币别、价税合计、税额；第 2 行—金额、收货仓库、退货截止日期、备注（占后 3 列）。

**来源联动**（2026-09-23确认：来源前置，选择后带出客户/币别/仓库/明细）：

| 动作 | 客户、币别 | 收货仓库 | 商品明细 |
| :--- | :--- | :--- | :--- |
| 选择来源销售出库单 | 带出来源客户与币别并**只读** | 自动带出原出库单仓库并**禁用**，不可切换 | 清空后按原出库明细重新带出：商品、数量、价格、税率、来源出库单行 |
| 更换来源销售出库单 | 二次确认后按新来源重新带出 | 更新为新来源的仓库并保持禁用 | 同上，按新来源重新带出 |
| 取消来源关联 | 清空带出的客户与币别（币别回默认） | 恢复为可选择（启用逻辑仓） | 保留现有明细，「来源出库单行」清空，按无来源口径校验 |
| 全程无来源 | 自由选择客户、币别 | 可自由选择启用的逻辑仓 | 由「添加明细」手工选品 |

> 更换/取消来源的页面处理为 Demo 交互口径，业务规则以主 PRD R02、R06、R07 为准。

#### 3.1.x 选择来源销售出库单弹窗（溯源，Q09已确认）

点「请选择销售出库单」打开，两步完成：**第一步**候选单列表（选项为已审核的销售出库单），列：单号、出库仓库、业务日期、价税合计，点「选择」进入第二步；**第二步**展示该单明细行：商品编码、商品名称、实际出库数量、**剩余可退额度**（=原实际出库−已退累计−其他办理中退货占用，进入第二步时实时计算），点「确认带出」后带出明细与价格并锁定原出库仓。额度不足的行标灰并在确认时提示「退货数量不能超过该行剩余可退额度」；无来源建单不打开本弹窗。弹窗分页、空态与滚动见《原型开发说明》通用弹窗规则，本文只写本弹窗特有列与文案。

## 4. 校验规则

提交相关弹窗见[弹窗 PRD §2](销售退货单前端Demo版PRD_弹窗与Mock.md)。下文 **保存** 指点「保存」，**提交** 指点「提交」（含保存口径 + 加强项）。

### 4.1 校验分层总览

| 层级 | 本页行为 | 典型错误位置 |
| :--- | :--- | :--- |
| 录入限制 | 数量禁小数、备注 `maxLength`、金额禁负数等 | 阻止输入或即时提示 |
| 失焦 | 数量整数、单价小数位、截止时间、备注长度（§4.2） | 字段下或 Toast；改值后**即时**清除该项错误 |
| 保存 | 单头必填 + 明细底线（§4.3）；**允许单价为空** | 单头内联；明细 Toast 或错误条 |
| 提交 | 在保存基础上补全价格与税率（§4.4）；零价二次确认 | 同上；通过后进确认弹窗 |
| 请求中 | 保存/提交按钮 loading；另一按钮 disabled | — |

**可退额度不在本页校验**：溯源退货的额度占用与阻断发生在**审核**（主 PRD R09）；本页只保证格式与必填。

### 4.2 录入与失焦

| 字段 | 模板 | 格式与范围 | 录入/失焦处理 | 典型提示 |
| :--- | :--- | :--- | :--- | :--- |
| 退货截止日期 | DATE_ONLY | 有效日期 | 日期选择器 | `退货截止日期不能为空` |
| 客户、币别、收货仓库 | 关联选择 | 须从选项选择 | 禁用项不可选；溯源时仓库禁改 | `{字段名}不能为空` |
| 备注 | `REMARK_500` | 0～500 字 | 超限阻止输入；粘贴超长提示 | `备注已达 500 字上限` |
| 退货数量 | `QTY_INT` | 正整数 >0 | 禁小数点；失焦非整数视为未填 | `第 N 行退货数量须为正整数` |
| 含税单价 | `PRICE_4` | ≥0；最多 4 位小数 | 禁负数；超 4 位失焦四舍五入 | `第 N 行含税单价不能为负` |
| 税率 | `PCT_4` | 允许 0% | 下拉不可输非法值 | `第 N 行税率不能为空`（提交时） |
| 系统计算列 | — | 只读 | 不校验录入 | 见 §4.5 |

### 4.3 点击「保存」

| 校验对象 | 条件 | 错误位置 | 阻断 | 文案 |
| :--- | :--- | :--- | :---: | :--- |
| 客户、币别、收货仓库、退货截止日期 | 必填 | 字段下方 | 是 | `{字段名}不能为空` |
| 商品明细 | 至少一行有效明细 | Toast / 错误条 | 是 | `请至少添加一行有效商品明细` |
| 商品（每行） | 已选 | Toast | 是 | `第 N 行请选择商品` |
| 退货数量（每行） | 正整数 >0 | Toast | 是 | `第 N 行退货数量必须大于 0` |
| 含税单价（每行） | ≥0（可为空） | Toast | 是 | `含税单价不能为负数` |
| 收货仓库 | 未被禁用的选项为启用逻辑仓 | 字段下方 | 是 | `请选择启用的逻辑仓` |

通过后：仍为草稿+正常；Toast「销售退货单已保存」；新增单首次保存生成单号。

### 4.4 点击「提交」

在 §4.3 全部通过基础上，追加：

| 校验对象 | 条件 | 错误位置 | 阻断 | 文案 |
| :--- | :--- | :--- | :---: | :--- |
| 含税单价（每行） | 非空 | Toast | 是 | `第 N 行含税单价不能为空` |
| 税率（每行） | 已选 | Toast | 是 | `第 N 行税率不能为空` |
| 含税单价 = 0 | 零价 | 确认框 | 确认后继续 | 见弹窗 PRD |
| 客户、收货仓库 | 仍启用 | Toast / 字段下 | 是 | `所选客户不可用` / `所选收货仓库不可用` |
| 无来源口径 | 无来源时每行退货数量>0 | Toast | 是 | `第 N 行退货数量必须大于 0` |

税率 0% 允许提交，不额外确认；**提交不校验可退额度**（额度在审核时校验）。校验失败时聚焦首错（单头优先）；可用 Toast「请修正表单中的错误后再提交」作补充提示。

### 4.5 价税计算与汇总

依据 R05；明细变更**即时重算**。

| 计算项 | 公式 | 精度 |
| :--- | :--- | :--- |
| 行不含税单价 | 含税单价 ÷ (1 + 税率÷100)；税率 0 时等于含税单价 | 4 位 |
| 行价税合计 | 退货数量 × 含税单价 | 2 位 |
| 行金额 | 退货数量 × 行不含税单价 | 2 位 |
| 行税额 | 行价税合计 − 行金额 | 2 位；尾差进税额 |
| 单头三项汇总 | 汇总各行 | 2 位；展示带币别符号 |

### 4.6 错误展示与纠错

| 类型 | 表现 | 纠错 |
| :--- | :--- | :--- |
| 单头必填 | 红底线 + 字段下文案；标签不变红 | 修改该字段后清除 |
| 多字段错误 | 同时标出；聚焦首错 | 逐项清除 |
| 明细/全局 | Toast（含「第 N 行」） | 修正后清除对应提示 |
| 跨行（明细为空） | 错误条或 Toast | 补行后消除 |
| 取消离开 | 确认框 | `离开后未保存的内容将丢失，确认离开？` |

## 5. 联动规则

| 触发 | 效果 |
| :--- | :--- |
| 选客户 | 默认带出币别；清空明细含税单价与税率并按新条件重取（R03、R04） |
| 改币别 | 清空明细价并重取 |
| 选/换来源销售出库单 | 带出客户与币别（只读）；收货仓库锁定为原出库仓；明细按来源重新带出（商品、数量、价格、税率、来源行）；更换时二次确认后整组重带 |
| 取消来源关联 | 清空带出的客户与币别（币别回默认），收货仓库恢复可选；明细保留，来源行清空 |
| 选商品（无来源） | 带出条码、名称、单位；按客户+商品+币别查当前销售价，无价留空 |
| 改数量/单价/税率 | 重算行内价税四项 |
| 明细增删 | 重算单头价税合计、税额、金额 |

## 6. 操作行为

| 操作 | 行为 |
| :--- | :--- |
| 保存 | 执行 §4.3；通过后写草稿并提示成功；新增首次保存生成单号；默认停留本页 |
| 提交 | 执行 §4.4 → 零价确认（如有）→ 提交确认弹窗；成功后变待审核并提示成功 |
| 取消 | 有未保存修改则确认；确认后回列表 |
| 编辑页进入 | 加载中展示占位；失败展示「销售退货单不存在或无权查看」；非草稿不可进入 |

## 7. 本页不展示

| 内容 | 说明 |
| :--- | :--- |
| 单据日期 | 本单不设该字段，时间口径用创建时间（主 PRD Q01） |
| 制单信息、审核信息 | 仅在详情页「操作信息」 |
| 终止信息 | 按状态在详情页展示 |
| 关联单据 | 销退收货通知单、销退入库单在详情页 |
| 状态编辑控件 | 编辑页仅在页头只读展示 StatusBadge |
| 收货处理方式 | 写在销退收货通知单上，不写在退货单上（主 PRD §4.4） |
| 剩余可退额度 | TSV 无该字段；是否展示待确认（主 PRD Q09），额度阻断在审核时给出 |
| 库存校验提示 | 销售退货为收货增加库存，审核不按可用库存卡数量（主 PRD R09），本页与审核环节都不出现库存校验提示 |
| 品质调拨入口 | 实物先按指定仓收下，再由库存业务办理品质调拨，本单不改原退货入库归属（主 PRD R12） |
| 删除按钮 | 本页不画：草稿删除在列表行内或详情页头办理，须草稿+正常且未被下游引用（主 PRD R19） |

## 10. Mock 与验收

### 10.1 Mock 覆盖

- 溯源草稿：选来源出库单后仓库锁定、明细带价，可保存
- 无来源草稿：自选收货仓、一行 SKU、数量 100、无价格留空
- 编辑用草稿：2 行明细 + 回写列 + 两枚状态标签
- 零价明细：验证提交二次确认
- 待审核单：验证不可进入编辑页

### 10.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 正常建单 | 新增 → 保存 | 草稿/正常；单号已生成（XSTH 前缀） |
| 溯源带入 | 选择来源出库单 | 客户与币别带出并只读；明细带出商品、数量、价格、税率；收货仓库禁用且等于原出库仓 |
| 切换来源 | 换另一张出库单 | 二次确认后客户、币别、明细与仓库按新来源刷新 |
| 取消来源 | 清除来源字段 | 客户与币别清空且可编辑，收货仓库恢复可选；明细保留 |
| 无来源建仓 | 不选来源 | 收货仓库可自由选择；无来源不套原出库额度 |
| 币别联动 | 选客户 | 默认币别带出 |
| 改客户/币别 | 已有明细后更换 | 明细价格清空 |
| 无价保存 / 无价提交 | 明细无单价 | 保存成功；提交阻断 |
| 零价提交 | 单价为 0 | 零价确认 → 提交确认弹窗 |
| 数量小数 / 单价超 4 位 / 备注超长 | 见 §4.2 | 录入约束或保存/提交阻断 |
| 截止时间必填 | 清空截止时间提交 | 阻断并提示 `退货截止日期不能为空` |
| 不可编辑 | 待审核单点编辑 | 不进入本页 |
