## 1. 页面目标与范围

- 页面名称：销售退货单列表页
- 查看视角：**仅单据视角**（每行 = 一张销售退货单；单据行视角本期不做）
- 作为新增、导入、详情、导出的统一入口
- 一期以**行内操作**为主；勾选列配合页头导出「已勾选」范围
- 功能与状态—操作矩阵见[《销售退货单主PRD》](../销售退货单主PRD.md) §6.4；本页落地 F01、F08 及列表侧行操作入口

> **本期边界**：
> - 页头**导出**、**导入**均为一期正式能力（导出异步任务见 §7；导入四步向导见 §8；主 PRD Q06、R20）。
> - 批量操作栏**不放**批量删除、提交、审核、取消、关闭等业务按钮——单据状态各异，取消/关闭须逐单填原因。
> - **一期提供草稿删除**：草稿行有编辑、提交、删除（草稿+正常且未被下游引用，主 PRD R19、Q04），删除须二次确认。
> - 列表行**不提供**「联查」按钮；查看下游销退收货通知单、销退入库单请通过详情页「关联单据」或对应单据列表跳转。
> - 已审核取消按 R17：无实际入库且无仍需执行的通知时可取消；待推送/推送失败通知随单取消；推送中/已推送通知须先取得仓库取消成功；**已有实收不能取消整单，只能关闭余量**。
> - **全部退足**（累计实退=退货数量，R18）时列表不保留可办理态，仅查看追溯。
> - 数量列按 TSV 与主 PRD R10 口径直接展示明细汇总值，**不按状态置0**；有无可下推数量只影响「下推通知单」入口。

## 2. 查询区

> 可筛选字段与顺序以[《销售退货单（详细稿）》](../../../../字段清单合集/销售相关/销售退货单（详细稿）.tsv)「可筛选=是」为准；下表为默认查询方案呈现顺序。
> **type 列**：与原型 `FilterControl` 的 `type` 一致，完整规范见[《原型开发说明》](../../../../../../09-产品原型/原型开发说明.md)「查询区通用规则」「FilterControl 控件 type」。布局、折叠、重置/查询行为不在本文重复定义。

| 查询字段 | type | 匹配 | placeholder / 说明 |
| :--- | :--- | :--- | :--- |
| 单号 | `search` | 模糊 | 请输入销售退货单号 |
| 客户 | `select` | 精确 | 全部客户；选项为审核通过且启用的客户；Code-Name 展示 |
| 收货仓库 | `select` | 精确 | 全部仓库；实际选择逻辑仓；Code-Name 展示 |
| 来源销售出库单 | `select` | 精确 | 请选择销售出库单；选项为已审核的销售出库单（实际出库结果），单号展示 |
| 审核状态 | `multi-select` | 精确（OR） | 全部；草稿／待审核／已审核；初值 `[]`，未选=全部 |
| 业务状态 | `multi-select` | 精确（OR） | 全部；正常／已取消／已关闭；初值 `[]`，未选=全部 |
| 退货截止日期 | `date-range` | 范围 | 不限；默认 `{ from: '', to: '' }` |
| 商品编码 | `search` | 模糊 | 请输入商品编码；按明细 SKU 编码筛选 |
| 商品条码 | `search` | 模糊 | 请输入商品条码；按明细条码筛选；多条码任一条码命中即可（主 PRD Q08，已确认） |
| 创建时间 | `date-range` | 范围 | 不限；按日期比较 |

查询区交互（收起过滤、重置、查询、空条件默认、查询后回第一页）见《原型开发说明》「查询区通用规则」。查询条件全空时，默认返回最新列表数据（默认按创建时间倒序）。

本页**没有单据日期筛选**：销售退货单不设单据日期字段，时间口径用创建时间（主 PRD Q01）。

### 4.3 本页列表约定

| 项目 | 规则 |
| --- | --- |
| 默认排序 | `创建时间` 降序；进入页面即生效 |
| 固定列 | 勾选列 + `单号` 左固定；`操作` 右固定 |

## 5. 分页与勾选规则

### 5.1 分页

- 表格底部固定分页区：页码、每页条数、总条数摘要等，行为与工程内 `Pagination` 一致。
- 提交查询、重置筛选后回到第一页。

### 5.2 勾选

- 勾选键以**单据 ID** 为单位。
- 一期勾选仅配合页头导出「已勾选」范围，不支持按行级键单独办理业务。

## 6. 行操作按钮

行内操作按**使用频率**从左到右排列；**仅展示当前状态允许的操作**（不满足时隐藏，不用 disabled）。风险动作须二次确认；弹窗正文与校验见[《销售退货单前端Demo版PRD_弹窗与Mock》](销售退货单前端Demo版PRD_弹窗与Mock.md)。

### 6.1 操作矩阵

| 按钮 | 草稿+正常 | 待审核+正常 | 已审核+正常 | 已关闭/已取消 | 说明 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| 编辑 | ✅ | ❌ | ❌ | ❌ | 跳转编辑页 |
| 提交 | ✅ | ❌ | ❌ | ❌ | 风险动作，需二次确认 |
| 删除 | ✅ | ❌ | ❌ | ❌ | 风险动作，需二次确认；草稿+正常且未被下游引用（R19） |
| 审核 | ❌ | ✅ | ❌ | ❌ | 风险动作，需二次确认；溯源额度不足时失败，不校验可用库存（R09） |
| 撤回 | ❌ | ✅ | ❌ | ❌ | 风险动作，需二次确认 |
| 取消 | ❌ | ✅ | 条件✅ | ❌ | 已审核时须满足 R17；风险动作，需二次确认 |
| 下推通知单 | ❌ | ❌ | 条件✅ | ❌ | 有可下推数量且未全部退足（R10、R14、R18） |
| 关闭 | ❌ | ❌ | 条件✅ | ❌ | 仍有未退足余量且未全部退足（R15、R18）；风险动作，需二次确认 |
| 调整截止时间 | ❌ | ❌ | 条件✅ | ❌ | 审核后仅可改截止时间（R13）；全部退足时不展示（R18） |

单号列可点击进入详情，行内不设「查看」。页头新增/导入/导出见 §3。草稿行**提供删除**（R19），删除弹窗正文见[《销售退货单前端Demo版PRD_弹窗与Mock》](销售退货单前端Demo版PRD_弹窗与Mock.md) §5。

已审核+正常行最多直出 3 个按钮，推荐顺序：`下推通知单` `关闭` `更多`；「更多」下拉内放 `调整截止时间`、`取消`（按条件出现）。全部退足行不渲染任何行内操作。草稿行直出 `编辑` `提交` `删除` 三个按钮。

## 8. 导入（一期正式）

> 正式能力，**不是 Mock**。规则 owner：[《销售退货单主PRD》](../销售退货单主PRD.md) R20；来源 COM-FR02、COM-AC02。向导内弹窗文案见[《销售退货单前端Demo版PRD_弹窗与Mock》](销售退货单前端Demo版PRD_弹窗与Mock.md) §5.2。

**入口**：列表页头「导入」（页头顺序：新增 → 导入 → 导出）。

### 8.1 向导四步

| 步骤 | 内容 |
| :--- | :--- |
| ① 下载模板 | 下载标准 Excel 模板；不设导入行数上限 |
| ② 上传文件 | 支持 `.xlsx`；同一「单据序号」归并为一张退货单，同组单头必须一致；无来源（溯源）留空来源单号 |
| ③ 校验预览 | 按保存草稿口径逐行校验；展示成功/失败行数与逐行原因，可下载错误说明 |
| ④ 完成导入 | 全部通过才落单：生成N张草稿（草稿+正常，单号按XSTH规则分配），关闭向导并刷新列表 |

### 8.2 模板列

| 列 | 说明 |
| :--- | :--- |
| 单据序号 | 同一序号的多行归并为一张退货单；同组单头字段必须一致 |
| 客户 | 审核通过且启用的客户 |
| 币别 | 客户默认币别或指定币别 |
| 收货仓库 | 逻辑仓；溯源退货须与来源出库单仓库一致 |
| 退货截止日期 | 单头必填 |
| 来源销售出库单号 | 可空；有值时须为已审核销售出库单；无来源留空 |
| 备注 | 选填 |
| 商品编码 | 每行必填，须为启用商品 |
| 退货数量 | 每行必填，整数且大于0 |
| 含税单价 | 非空且非负；来源合法且价格留空按原出库价带入 |
| 税率 | 与价格配套；允许0% |

### 8.3 校验与整批策略

| 项目 | 规则 |
| :--- | :--- |
| 校验口径 | 与保存草稿一致：单头必填（客户、币别、收货仓库、退货截止日期）、每行商品存在且退货数量>0、价格非空非负、客户审核通过且启用、来源单号须为已审核销售出库单、溯源不超剩余可退额度 |
| 库存口径 | **销售退货为收货业务，导入校验不按可用库存卡数量**（与 R09 一致） |
| 整批策略 | **任一行失败则整批不导入**；返回逐行原因，可下载错误说明 |
| 零价 | 草稿级允许；提交时再确认（零价确认弹窗） |

### 8.4 结果反馈

| 结果 | 反馈 |
| :--- | :--- |
| 成功 | 提示「成功导入N张退货单草稿，请逐单检查后提交审核」；列表刷新可见新草稿 |
| 失败 | 整批不导入；Toast 提示导入失败并展示逐行原因，可下载错误说明 |
| 后续 | 导入不改变流程，草稿仍须提交、审核（COM-FR02、COM-AC02）；导入草稿与手工草稿同权（可编辑、可提交、可删除） |

| 操作失败——状态不匹配 | Toast | 当前单据状态为{状态}，不可执行{动作} |
| 操作失败——权限不足 | Toast | 您暂无{动作}权限，请联系管理员 |
| 操作失败——系统繁忙 | Toast | 操作失败，请稍后重试 |

列表页触发的提交、撤回、关闭、取消、删除等弹窗正文与校验，统一见[《销售退货单前端Demo版PRD_弹窗与Mock》](销售退货单前端Demo版PRD_弹窗与Mock.md)。

## 10. Mock 数据要求与演示验收

### 10.1 Mock 数据覆盖

- 列表至少 **10 条**单据（去重后）
- 审核状态至少各 **2 单**：草稿、待审核、已审核
- 业务状态至少覆盖：正常、已取消、已关闭各 **1 单**
- 至少 **1 单** 溯源退货（关联来源销售出库单）与 **1 单** 无来源退货（收货仓自选、来源留空）
- 至少 **1 单** 已审核+正常+可下推数量 > 0
- 至少 **1 单** 已审核+正常+累计实退数量 > 0，用于验证「已有实收不可取消」拦截
- 至少 **1 单** 已审核+正常+全部退足（累计实退=退货数量），行内无操作
- 至少 **1 单** 已审核+已关闭（手动关闭，含关闭原因与操作人）
- 至少 **1 单** 待审核可测撤回与取消；至少 **1 单** 存在执行中销退收货通知，用于验证 R17 取消拦截
- 至少 **1 单** 到期自动关闭（关闭方式=到期自动关闭、原因与操作人留空）
- 至少 **1 单** 草稿用于验证「编辑 提交 删除」三个行操作与删除确认弹窗；至少 **1 单** 草稿存在下游通知引用，用于验证删除阻断
- **枚举与口径**：凡字段清单中已定义枚举或格式的，Mock 取值**必须落在字段清单范围内**；不得自造清单外文案

### 10.2 演示验收

| 场景 | 前置 | 操作 | 预期 |
| --- | --- | --- | --- |
| 正常列表 | Mock 覆盖各审核状态 | 打开列表 | 两状态为语义色文字；币别列如 `CNY 人民币`、金额列无币别前缀；默认按创建时间倒序；无备注列、无单据日期列 |
| 筛选 | 审核状态多选「草稿」「待审核」 | 查询 | 只显示草稿或待审核记录 |
| 筛选 | 来源销售出库单选某张已审核出库单 | 查询 | 只显示该来源的退货单；无来源单不出现在结果中 |
| 空条件查询 | 清空全部筛选 | 查询 | 返回最新列表，回到第一页 |
| 提交阻断 | 草稿单存在空价明细 | 提交 | 弹窗或前置校验阻断，提示具体原因 |
| 审核阻断 | 溯源单额度不足 | 审核 | Toast 提示超出可退额度，不占额度；不出现“库存不足”文案 |
| 下推入口 | 已审核+正常+可下推量>0 | 看行操作 | 显示「下推通知单」，且无「查看」 |

| 全部退足 | 已审核+正常+全部退足单 | 看行操作与详情页头 | 无下推、取消、关闭、调整截止时间；仅查看 |
| 取消拦截 | 已审核+存在执行中通知 | 取消 | Toast 提示须先处理通知，不进入成功流 |
| 导入入口 | 列表页头 | 查看按钮 | 按「新增 → 导入 → 导出」排列，导入为正式按钮（无 Mock 角标） |

| 导入整批失败 | 文件中任一行校验失败 | 点确认导入 | 整批不导入；返回逐行原因并可下载错误说明；列表无新增记录 |
| 删除草稿 | 草稿+正常且未被引用 | 点行内删除 → 确认 | 删除成功，列表消失并 Toast「销售退货单已删除」 |
| 删除阻断 | 待审核/已审核单，或被下游引用的草稿 | 点删除 | 无删除入口或二次确认后阻断，列表仍保留该单 |
| 导出 | 列表非空 | 点页头导出 | 创建异步导出任务并 Toast 提示 |
