关联资料：[《销售退货单页面骨架》](../销售退货单页面骨架.md)、[《销售退货单前端Demo版PRD_弹窗与Mock》](销售退货单前端Demo版PRD_弹窗与Mock.md)。布局见骨架。

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 销售退货单详情页 |
| 入口 | 列表点击单号；操作完成后可刷新本页 |
| 页面目标 | 只读查看一张销售退货单全貌；按当前状态办理允许的操作 |
| 骨架结构 | 页头 → 单据信息 → 商品明细 → 关联单据（条件）→ 终止信息（条件）→ 操作信息 |

本页落地 **F05（分区域展示与追溯）** 及详情侧 **F02/F03/F04/F06** 操作入口；状态—操作矩阵见主 PRD §6.4。

| 模式 | 说明 |
| :--- | :--- |
| 容器 | 独立页 |
| 返回 | `返回列表`，保留原查询条件与页码 |

> **本期边界**：
> - 页头固定展示**审核状态、业务状态**两枚 **StatusBadge**（不单开「状态信息」卡片）。
> - **关联单据**仅**审核状态=已审核**时展示；草稿、待审核不展示下游 Tab。
> - 终止信息仅在**业务状态=已关闭或已取消**时展示；正常单不展示该分组。
> - 操作信息含**制单信息 / 操作日志**胶囊 Tab；完整审计日志后置，一期由单据字段推导。
> - 二次确认弹窗正文在[弹窗 PRD](销售退货单前端Demo版PRD_弹窗与Mock.md) 维护，本文只写入口与结果表现。
> - **草稿态页头提供删除**：草稿+正常且未被销退收货通知单等下游引用时可删（主 PRD R19、Q04），须二次确认，正文见[弹窗 PRD §5.1](销售退货单前端Demo版PRD_弹窗与Mock.md)。
> - 本页**无单据日期**，时间口径用创建时间（主 PRD Q01）。
> - 金蝶不推送本单；重推入口在系统集成中心，本页不提供重推按钮。
> - Demo 以**桌面端**为基准；商品明细、关联简表在窄视口内**横向滚动**，不承诺移动端布局。

## 2. 页头

### 2.1 标题与状态

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `销售退货单详情 · {单号}`（单号随记录展示） |
| 状态标签 | 两枚 StatusBadge：审核状态 / 业务状态 |
| 布局 | 单行：左侧标题 + 状态标签；右侧操作区（`DocumentDetailFrame`） |

列表状态列用语义色文字；**详情页头用 StatusBadge 胶囊**，tone 与列表语义一致（见《原型开发说明》）。

### 2.2 页头操作按钮

`返回列表` **始终排在最前**；其后按状态展示业务按钮。编辑为草稿主按钮，由详情框架 `canEdit` 提供。

| 按钮 | 草稿+正常 | 待审核+正常 | 已审核+正常 | 已审核+正常+全部退足 | 已取消/已关闭 | 说明 |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| 返回列表 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 编辑 | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ |
| 提交 | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ |
| 审核 | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ |
| 撤回 | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ |
| 取消 | ❌ | ✅ | 条件✅ | ❌ | ❌ | ❌ |
| 下推通知单 | ❌ | ❌ | 条件✅ | ❌ | ❌ | ❌ |
| 关闭 | ❌ | ❌ | 条件✅ | ❌ | ❌ | ❌ |
| 调整截止时间 | ❌ | ❌ | 条件✅ | ❌ | ❌ | ❌ |
| 删除 | ✅ | ❌ | ❌ | ❌ | ❌ | 草稿+正常且未被下游引用（R19）；二次确认 |

条件说明（详见主 PRD）：

| 按钮 | 条件摘要 |
| :--- | :--- |
| 取消（已审核） | R17：无实际入库且无待执行通知；已推送通知须仓库取消成功；已有实收不能取消整单 |
| 下推通知单 | 有可下推数量（R10、R14）且未全部退足（R18）；入口文案「下推通知单」 |
| 关闭 | 仍有未退足余量（R15）且未全部退足（R18） |
| 调整截止时间 | R13：审核后仅可改截止时间；全部退足时不展示（R18） |
| 取消与关闭 | 已审核+正常时可**同时出现**，按各自条件独立判断 |

已审核态按钮建议顺序（`返回列表` 之后）：下推通知单 → 取消 → 关闭 → 调整截止时间。

**渲染纪律**：

- 条件不满足的按钮**直接不渲染**，不展示灰色 disabled 占位。
- 样式层级：**提交、审核** 用主要按钮（`primary`）；**编辑** 为草稿主按钮；**取消、关闭、撤回、调整截止时间、下推通知单** 用次要按钮（`outline`）；**删除** 用次要按钮的危险色（`outline danger`）；**返回列表** 为幽灵/次要样式，固定最左。

### 2.3 二次确认与弹窗

| 操作 | 弹窗 PRD | 确认后页面表现 |
| :--- | :--- | :--- |
| 提交 | §2 | 刷新为待审核；Toast「销售退货单已提交」 |
| 审核 | §3.1 | 刷新为已审核；Toast「销售退货单已审核」；可选 Mock 引导（§4） |
| 撤回 | §3.2 | 回到草稿；Toast「销售退货单已撤回，请修改后重新提交」 |
| 取消 / 关闭 / 调整截止时间 | §3.3～§3.5 | 刷新详情；对应成功 Toast |
| 删除 | §5.1 | 物理删除并返回列表；Toast「销售退货单已删除」 |

弹窗标题、正文、必填项不在本文重复。

## 3. 信息分区与字段

> 只读 **6 列栅格**，标签在上、值在下；备注占 **3 列**。字段顺序与 TSV 分组一致。

**分区总览**：页头 → **3.1 单据信息** → **3.2 商品明细** → **3.3 关联单据**（已审核）→ **3.4 终止信息**（已关闭/已取消）→ **3.5 操作信息**

### 3.1 单据信息

| 字段 | 展示说明 |
| :--- | :--- |
| 单号 | 原样 |
| 客户 | Code-Name |
| 币别 | `{币别编码} {币别名称}`（如 `CNY 人民币`） |
| 价税合计 / 税额 / 金额 | 金额；千分位；可与币别符号同区展示 |
| 收货仓库 | 逻辑仓 Code-Name；溯源单等于原出库单仓库 |
| 退货截止时间 | 日期时间 `YYYY-MM-DD HH:mm:ss` |
| 来源销售出库单 | 单号链接，点击跳转[《销售出库单主PRD》](../../../3-销售管理/销售出库单/销售出库单主PRD.md)对应详情；无来源展示 `-` |
| 备注 | 占 3 列；长文本可换行 |

布局：第 1 行—单号、客户、币别、价税合计、税额、金额；第 2 行—收货仓库、退货截止时间、来源销售出库单、备注占后 3 列。

### 3.2 商品明细

- 表格只读；**数量、单价、价税列右对齐**；横向滚动。
- 一期**不分页**，展示全部明细行。
- 不单独展示后台「商品」关联列；以**商品编码**列承载。
- 价税列顺序：**含税单价 → 税率 → 不含税单价 → 价税合计 → 税额 → 金额**。

| 列名（从左到右） | 说明 |
| :--- | :--- |
| 行号 | 自动编号 |
| 商品编码 | 文本 |
| 商品条码 | 文本；多条码一期可用英文分号 `;` 拼接展示，无条码为 `-` |
| 商品名称 | 文本 |
| 基本单位 | 文本 |
| 来源出库单行 | 关联原出库明细行；无来源留空展示 `-` |
| 退货数量 | 整数 |
| 含税单价 | 千分位；4 位小数 |
| 税率 | 百分比，如 `13%` |
| 不含税单价 | 系统计算；4 位小数 |
| 价税合计 / 税额 / 金额 | 系统计算；2 位小数 |
| 累计实退数量 | 回写列 |
| 在途通知数量 | 回写列 |
| 可下推数量 | 回写列 |

**回写列显隐**：详情页一期**始终展示**上述三列；草稿、待审核时尚无执行数据，数值按主 PRD R10 公式计算（无通知时可下推数量等于退货数量），不隐藏列；已关闭单保留可下推数量数值但不再具备新增通知资格（TSV）。

**底部汇总行**（`DocumentSummaryBar`）：

| 汇总项 | 展示 |
| :--- | :--- |
| 首列 | 文案 `合计`（占行号列） |
| 退货数量合计 | 与「退货数量」列右对齐，整数 |
| 价税合计 / 税额 / 金额 | 与对应列右对齐；千分位、2 位小数 |
| 样式 | 汇总行与表头列对齐分别展示 |

### 3.3 关联单据

**展示条件**：审核状态 = **已审核**（含业务已取消/已关闭的已审核单，若有下游历史）。

组件：`RelatedDocumentsCard`；胶囊 Tab（`InnerTabs` `pill` 变体）；Tab 文案带数量，如 `销退收货通知单 (2)`。默认选中「销退收货通知单」。

| Tab | 列 | 排序 | 空态 |
| :--- | :--- | :--- | :--- |
| 销退收货通知单 | 单号、单据状态、通知数量、实收数量、缺收数量、创建时间 | 创建时间倒序 | 暂无关联的销退收货通知单 |
| 销退入库单 | 单号、来源销退收货通知单、审核状态、金蝶推送状态、实际收货数量、价税合计、创建时间 | 创建时间倒序 | 暂无关联的销退入库单 |

空态仅提示暂无数据，不强制引导创建（下推通知单入口在页头）。单号可跳转对应详情；下推通知单按钮不出现在空态里。

### 3.4 终止信息

**展示条件**：业务状态 = **已关闭** 或 **已取消**。

| 业务状态 | 字段（占前 4 列） |
| :--- | :--- |
| 已关闭 | 关闭方式、关闭原因、关闭时间、关闭操作人 |
| 已取消 | 取消原因、取消时间、取消操作人（占前 3 列，后 3 列留空） |

系统自动关闭时关闭原因与关闭操作人留空，以关闭方式区分（主 PRD R15、R16）。

### 3.5 操作信息

胶囊 Tab：**制单信息**（默认）/ **操作日志**。

| Tab | 内容 |
| :--- | :--- |
| 制单信息 | 创建人、创建时间、审核人、审核时间、最后更新人、最后更新时间（6 列栅格）；第 2 行撤回意见占 3 列，未撤回时留空 |
| 操作日志 | 表格：操作时间、操作人、操作类型、说明；按时间倒序；一期从创建、提交、审核、撤回、调整截止时间、取消、关闭等推导 |

不在新增/编辑页展示本分区。

## 4. 字段展示规范

| 规范 | 说明 |
| :--- | :--- |
| 空值 | 文本类统一英文连字符 `-`（`EMPTY_PLACEHOLDER`） |

| 日期时间 | `YYYY-MM-DD HH:mm:ss` |
| 页头状态 | StatusBadge 胶囊，非列表语义色文字 |

## 5. 操作行为

| 操作 | 行为 |
| :--- | :--- |
| 编辑 | 跳转编辑页；返回后刷新详情 |
| 删除 | 打开删除草稿确认弹窗（弹窗 PRD §5.1）→ 物理删除 → 返回列表并刷新 |
| 下推通知单 | 跳转销退收货通知单创建页并带入来源退货单（非弹窗） |
| 提交 / 审核 / 撤回 / 取消 / 关闭 / 调整截止时间 | 打开弹窗 PRD 对应弹窗 → 成功后刷新详情或返回列表 |
| 返回列表 | 回到列表，保留筛选、页码与列表上下文 |

## 6. 反馈与页面状态

### 6.1 操作反馈（Toast）

| 操作 | 反馈类型 | 文案 |
| :--- | :--- | :--- |
| 提交成功 | Toast | 销售退货单已提交 |
| 审核成功 | Toast | 销售退货单已审核 |
| 审核失败——溯源额度不足 | Toast | 溯源退货超出原出库单可退额度，审核失败 |
| 撤回成功 | Toast | 销售退货单已撤回，请修改后重新提交 |
| 删除成功 | Toast | 销售退货单已删除 |
| 删除失败——被引用或非草稿 | Toast | 该退货单非草稿或已被下游引用，不能删除 |
| 取消成功 | Toast | 销售退货单已取消 |
| 关闭成功 | Toast | 销售退货单已关闭 |
| 调整截止时间成功 | Toast | 退货截止时间已更新 |
| 取消/关闭失败（R17、R18 等） | Toast | 如「存在执行中的收货通知，请先处理后再取消」「本单已全部退足，不能关闭」 |
| 状态已变更（阻断） | Toast | 操作失败，单据状态已变更，请刷新后重试 |

### 6.2 加载与异常态

| 场景 | 页面表现 | 文案 / 操作 |
| :--- | :--- | :--- |
| 加载中 | 骨架屏；分区占位 | — |
| 单据不存在 | 错误态 | 销售退货单不存在或无权查看；提供「返回列表」 |
| 加载失败 | 错误态 | 加载失败，请重试；提供「重试」与「返回列表」 |
| 返回列表 | 跳转列表 | 恢复进入前的查询条件与页码 |

## 7. Mock 与验收

### 7.1 Mock 覆盖清单

- **草稿+正常** 至少 1 单（溯源）与 1 单（无来源）：页头两标签；可编辑/提交/删除；回写列按公式展示；无关联单据、无终止信息
- **待审核+正常** 至少 1 单：审核/撤回/取消；无关联单据
- **已审核+正常+部分退** 至少 1 单：明细含回写列；有关联单据 Tab；可下推/取消/关闭/调整截止时间（按条件）
- **已审核+正常+全部退足** 至少 1 单：页头仅返回列表
- **已审核+已关闭** 至少 1 单（手动关闭）与 1 单（到期自动关闭）：展示终止信息；页头仅返回列表
- **已取消** 至少 1 单：展示取消终止信息
- 关联 Tab：至少 1 单含通知单与入库单记录；至少 1 个 Tab 为空态

### 7.2 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 草稿详情 | 打开草稿单 | 两枚 StatusBadge；可下推数量等于退货数量、累计实退为 0；制单信息有创建人；无终止信息、无关联单据 |
| 溯源详情 | 打开溯源单 | 收货仓库等于原出库单仓库；来源销售出库单可点击跳转 |
| 已审核+部分退 | 打开详情 | 明细回写列有值；价格数量只读；关联单据双 Tab |
| 关联跳转 | 点击通知单/入库单号 | 进入对应详情 |
| 全部退足 | 打开全部退足单 | 页头仅返回列表；累计实退=退货数量；可下推数量为 0 |
| 已关闭 | 打开详情 | 终止信息展示关闭字段；系统自动关闭时原因与操作人留空 |
| 已取消 | 打开详情 | 终止信息展示取消字段；无业务按钮 |
| 操作信息 | 切换 Tab | 默认制单信息；操作日志倒序只读 |
| 删除入口 | 打开草稿 | 页头提供「删除」；确认后删除并返回列表；非草稿单无删除按钮 |
