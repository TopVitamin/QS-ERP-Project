## 2. 提交相关弹窗（F03）

**触发入口**：新增/编辑页、列表、详情「提交」；可用条件均为**审核状态=草稿 + 业务状态=正常**（主 PRD §6.4）。

**校验前置**：打开任何提交弹窗前，先按主 PRD R04、R05、R07 与[新增编辑页 §4.4](销售退货单前端Demo版PRD_新增编辑页.md) 校验当前单据。未通过则 Toast 或字段提示阻断，**不进入**下列弹窗。提交不校验可退额度（额度在审核时校验，R09）。

**弹窗顺序**：先零价确认（如有）→ 再提交确认。

```
列表 / 详情 / 新增·编辑页
         │
     点「提交」
         ▼
  新增编辑 §4.4 校验
         │
    ┌────┴────┐
  失败       通过
    │          │
    ▼          ▼
 Toast      存在零价明细？
 阻断          │
            ┌──┴──┐
           否      是
            │       │
            │       ▼
            │   §2.1 零价确认弹窗
            │    取消 │ 确认继续
            │       └──┬──┘
            └────┬────┘
                 ▼
         §2.2 提交确认弹窗
          取消 │ 确认提交
               ▼
        待审核 + Toast「已提交」
```

### 2.1 零价确认

| 项目 | 内容 |
| :--- | :--- |
| 出现条件 | 任一明细行含税单价 = 0 |
| 弹窗标题 | 确认使用零价？ |
| 正文 | 第 {N} 行含税单价为 0，请确认业务约定。多行零价时正文列出各行或合并为「存在零价明细，请确认业务约定。」 |
| 确认按钮 | 确认继续 |
| 取消按钮 | 取消 |
| 确认后 | 进入 §2.2 提交确认弹窗 |

### 2.2 提交确认

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 确认提交销售退货单？ |
| 正文 | 提交后进入待审核状态，价格和税率将锁定，审核后仅可调整退货截止日期，审核前仍可撤回修改。 |
| 确认按钮 | 确认提交 |
| 取消按钮 | 取消 |
| 确认后 | 审核状态→待审核；Toast「销售退货单已提交」；刷新当前页或列表 |

| 来源页 | 确认后页面表现 |
| :--- | :--- |
| 新增/编辑页 | 停留本页并变为只读待审核态，或返回列表（以实现为准，须可连续演示） |
| 列表 / 详情 | 刷新；行内/页头操作变为审核、撤回等 |

## 3. 状态变更弹窗（F04、F06）

下列弹窗均在**二次确认**后执行。入口可用条件见主 PRD §6.4 与各页页头/行内矩阵；条件不满足时**不展示按钮**，无需弹窗阻断。

**阻断类失败**（不满足业务规则、未进入成功流）：取消/关闭若触发 R17、R18 等规则，直接 Toast，例如「存在执行中的收货通知，请先处理后再取消」「退货单已有实际收货记录，无法取消整单，请使用关闭余量」「本单已全部退足，不能关闭」。全部退足单不展示下推、关闭、取消、调整截止时间入口。

### 3.1 审核

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「审核」 |
| 可用条件 | 待审核 + 正常 |
| 弹窗标题 | 确认审核？ |
| 正文 | 审核后将占用原出库单可退额度（溯源退货），数量和价格不可再修改。本单为收货业务，不校验可用库存。 |
| 必填项 | 无 |
| 确认按钮 | 确认审核 |
| 取消按钮 | 取消 |
| 确认后 | 审核状态→已审核；校验可退额度（R06、R09）：溯源额度充足则占用并记录审核人、审核时间，Toast「销售退货单已审核」，刷新页面；无来源退货不做额度校验直接通过。额度不足时 Toast「溯源退货超出原出库单可退额度，审核失败」，状态不变、不占额度。Demo 可接续 §4 Mock 引导弹窗 |

### 3.2 撤回

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「撤回」 |
| 可用条件 | 待审核 + 正常 |
| 弹窗标题 | 撤回销售退货单 |
| 正文 | 请填写撤回意见 |
| 必填项 | 撤回意见（多行） |
| 确认按钮 | 确认撤回 |
| 取消按钮 | 取消 |
| 确认后 | 审核状态→草稿；保存撤回意见；Toast「销售退货单已撤回，请修改后重新提交」 |

### 3.3 调整截止时间

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「调整截止时间」 |
| 可用条件 | 已审核 + 正常；未全部退足（R13、R18） |
| 弹窗标题 | 调整退货截止日期 |
| 正文 | 审核后仅可调整截止时间，数量和价格不变。 |
| 必填项 | 新退货截止日期（日期） |
| 确认按钮 | 确认 |
| 取消按钮 | 取消 |
| 确认后 | 更新退货截止日期；Toast「退货截止日期已更新」；到期自动关闭按新截止时间重新起算（R16） |

### 3.4 关闭退货单

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「关闭」 |
| 可用条件 | 已审核 + 正常；仍有未退足余量；未全部退足（R15、R18） |
| 弹窗标题 | 关闭销售退货单 |
| 正文 | 关闭后不可撤销，不能再新增收货通知；已有通知继续执行。关闭释放未退且无通知继续执行的可退额度，已退部分继续计入累计。 |
| 必填项 | 关闭原因（多行） |
| 确认按钮 | 确认关闭 |
| 取消按钮 | 取消 |
| 确认后 | 业务状态→已关闭；关闭方式=手动关闭；记录关闭人、关闭时间；Toast「关闭成功，单据已关闭」 |

### 3.5 取消退货单

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「取消」 |
| 可用条件 | 待审核或已审核 + 正常；已审核时须满足 R17（无实际入库、无待执行通知） |
| 弹窗标题 | 取消销售退货单 |
| 正文 | 取消后整单不再执行，不可撤销。须无实际入库且无待执行通知，已推送通知须仓库确认取消成功。 |
| 必填项 | 取消原因（多行） |
| 确认按钮 | 确认取消 |
| 取消按钮 | 取消 |
| 确认后 | 业务状态→已取消；记录取消人、时间；释放未退且无通知继续执行的可退额度（R17）；待推送、推送失败通知随单取消；Toast「取消成功」 |

### 3.6 离开未保存（表单页）

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 新增/编辑页点「取消」或路由离开，且存在未保存修改 |
| 弹窗标题 | 离开当前页面？ |
| 正文 | 离开后未保存的内容将丢失。 |
| 确认按钮 | 确认离开 |
| 取消按钮 | 取消 |
| 确认后 | 返回列表或上一页 |

## 4. Demo Mock：审核后生成销退收货通知（F07）

### 4.1 正式规则

按 SAL-FR05，**审核通过不会自动生成销退收货通知单**。销售人员手工创建通知单，创建时选择收货处理方式（仓库收货／虚拟入库，默认仓库收货），处理方式写在通知单上、不写在退货单上。

本节 Mock **仅用于 Demo 原型串联**，不属于主 PRD §12.1 正式验收（F07、AC10）。

### 4.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 列表/详情「审核」成功后 | 弹出 Mock 引导弹窗（Demo 开关可配置，默认开启） |

### 4.3 引导弹窗

| 项目 | 内容 |
| :--- | :--- |
| 标题 | 销售退货单已审核 |
| 正文 | 正式流程需手工创建销退收货通知单并选择收货处理方式。Demo 可一键生成本次演示用通知单，便于查看主链。 |
| 主按钮 | 生成演示通知单（Mock） |
| 次按钮 | 稍后手工创建 |
| 关闭图标 | 关闭弹窗，仅刷新退货单状态 |

### 4.4 生成规则（本地 Mock）

点击「生成演示通知单（Mock）」时，在本地 Mock 存储创建一条**销退收货通知单**：

| 项目 | 规则 |
| :--- | :--- |
| 来源 | 当前销售退货单 |
| 收货仓库 | 沿用本退货单收货仓 |
| 收货处理方式 | 仓库收货（默认） |
| 单据状态 | 待推送 |
| 明细 | 按本单每个 SKU 一行；通知数量 = 当前可下推数量（演示简化，不代表实际分批） |
| 单号 | 按 XTSHTZ 前缀生成 fictitious 编号 |
| 占用 | 本单在途通知数量增加；可下推数量相应减少 |
| 推送 | Demo 不调用真实仓库；可配置数秒后模拟「待推送→待收货」 |

界面标注「演示数据」或「Mock」角标，与手工创建的通知单区分。

### 4.5 不做的事

- 不代替正式「创建销退收货通知单」页的数量录入、收货处理方式选择与校验（见[《销退收货通知单主PRD》](../../销退收货通知单/销退收货通知单主PRD.md)）
- 不在 Mock 中自动审核退货单、不生成销退入库单、不推送金蝶
- 不把 Mock 行为写入主 PRD 验收标准

## 5. 正式能力弹窗（R19、F08）

本节两个容器都是**一期正式能力，不是 Mock**。

### 5.1 删除草稿确认（R19）

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「删除」 |
| 可用条件 | 草稿 + 正常，且未被销退收货通知单等下游引用（主 PRD §6.4、R19）；其他状态不渲染该按钮 |
| 弹窗标题 | 删除销售退货单草稿 |
| 正文 | 删除后不可恢复，确定删除该草稿？ |
| 确认按钮 | 确认删除 |
| 取消按钮 | 取消 |
| 确认后 | 物理删除该草稿；Toast「销售退货单已删除」；列表移除该行，详情页返回列表 |
| 阻断 | 非草稿，或已被下游引用时阻断；Toast「该退货单非草稿或已被下游引用，不能删除」，状态不变 |

删除**不可恢复**，无回收站、不可撤销；导入生成的草稿同样适用本弹窗（R20）。

### 5.2 列表导入向导（F08）

四步与模板列见[列表页 PRD §8](销售退货单前端Demo版PRD_列表页.md)；本节只定义**向导内文案与反馈**。

```
列表页头「导入」（正式）
         ▼
┌─ 导入向导（Modal）────────────────────────────┐
│ ① 下载模板  →  ② 上传文件  →  ③ 校验预览  →  ④ 完成导入 │
│     │              │              │              │
│  标准模板       上传文件      逐行校验结果      导入结果  │
│              （.xlsx）      [下载错误说明]   生成N张草稿  │
│                                任一行失败则整批不导入   │
└───────────────────────────────────────────────────┘
全程提示：成功导入N张退货单草稿，请逐单检查后提交审核
```

| 场景 | 文案或表现 |
| :--- | :--- |
| 步骤条 | ① 下载模板 → ② 上传文件 → ③ 校验预览 → ④ 完成导入 |
| 校验预览——通过 | 展示成功行数与归并后的退货单张数；按钮「确认导入」 |
| 校验预览——失败 | **任一行失败则整批不导入**；逐行展示失败原因，按钮「下载错误说明」 |
| 导入成功 | Toast「成功导入N张退货单草稿，请逐单检查后提交审核」；关闭向导、刷新列表 |
| 导入失败 | Toast「导入校验未通过，本次导入已取消；可下载错误说明」；列表无新增记录 |
| 库存口径 | 向导不做可用库存校验提示（销售退货为收货业务，主 PRD R09、R20） |
| 后续 | 导入只生成草稿，仍须提交审核（COM-FR02、COM-AC02）；零价草稿级允许、提交时再确认 |

## 7. 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 提交 | 完整草稿点提交 | 校验通过→（零价确认）→提交确认→待审核 |
| 提交阻断 | 含税单价为空提交 | Toast 阻断，不进入待审核 |
| 零价 | 零价明细提交 | 先零价确认，再提交确认 |
| 撤回 | 待审核点撤回 | 必填撤回意见→草稿 |
| 审核成功 | 待审核点审核，溯源额度充足 | 已审核并占额度；Mock 开启时出现 §4 引导弹窗 |
| 审核成功（无来源） | 无来源单点审核 | 不做额度校验、不校验库存，审核通过 |
| 审核失败 | 溯源单额度不足 | Toast 阻断，不占额度，状态不变；文案不含“库存不足” |
| 调整截止时间 | 已审核点调整 | 必填新截止时间→更新成功 |
| 关闭 | 已审核+有余量点关闭 | 必填关闭原因→已关闭，关闭方式=手动关闭 |
| 全部退足关闭阻断 | 全部退足单尝试关闭 | 入口不展示；若强行触发则 Toast 阻断 |
| 取消阻断 | 有执行中通知或已有实收时取消 | Toast 阻断，不进入取消成功流 |
| Mock 生成 | 点生成演示通知单 | 本地出现 Mock 通知；退货单在途通知增加、可下推量减少 |
| 导出 | 列表点导出 | 创建异步导出任务并 Toast 提示 |
| 导入成功 | 列表点导入，上传合法文件走完四步 | 生成N张草稿（草稿+正常）并提示“成功导入N张退货单草稿，请逐单检查后提交审核”；仍须提交审核 |
| 导入整批失败 | 上传文件中任一行校验失败 | 逐行返回原因、可下载错误说明；**整批不导入**，列表无新增记录 |
| 删除成功 | 草稿+正常且未被引用，点删除并确认 | 物理删除，列表消失、详情返回列表；Toast「销售退货单已删除」 |
| 删除阻断 | 非草稿，或草稿已被下游引用 | 二次确认后阻断；Toast 提示不能删除，记录仍在列表 |
