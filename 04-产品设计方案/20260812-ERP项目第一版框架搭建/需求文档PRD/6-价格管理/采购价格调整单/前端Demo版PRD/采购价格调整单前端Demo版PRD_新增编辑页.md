## 1. 页面目标与范围

| 项目 | 内容 |
| :--- | :--- |
| 页面目标 | 新建一张采购调价申请；修改草稿或已驳回单 |
| 入口 | 列表页头「新增」、列表/详情「编辑」 |
| 容器形式 | 独立页 |
| 状态标签 | **新增页不展示**；编辑页页头展示 `[草稿]` 或 `[已驳回]` |
| 本期边界 | 不提供调价前价格对照（主PRD Q04）；不提供批量添加商品；不提供导入 |

草稿或已驳回单可进入本页；待审核、已审核不可进入。

## 2. 页头与按钮

| 按钮 | 位置 | 显示条件 | 点击行为 |
| :--- | :--- | :--- | :--- |
| 取消 | 页头右侧 | 始终 | 有未保存修改时弹「离开当前页面？」；否则返回列表 |
| 保存 | 页头右侧 | 始终 | 按保存草稿口径校验；通过后保存并停留本页，Toast「采购价格调整单已保存」 |
| 提交 | 页头右侧 | 始终 | 按提交口径校验；通过后进入提交确认弹窗（弹窗 PRD §2） |

编辑页标题为「编辑采购价格调整单 {单号}」，并在标题旁展示状态标签。

## 3. 表单字段

### 3.1 单据信息（6列栅格）

| 字段 | 控件 | placeholder | 新增表现 | 编辑表现 | 联动与约束 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 单号 | 只读文本 | — | 显示「保存后显示」 | 只读 | 保存草稿时按 CGJGTZ 规则分配，不可修改（R01） |
| 供应商 | `select` | 请选择供应商 | 可编辑 | 可编辑 | 选项为审核通过且启用的供应商，Code-Name 展示；变更后清空已填价格（R02） |
| 币别 | `select` | 请选择币别 | 可编辑 | 可编辑 | 选供应商后默认带出供应商默认币别，无默认则手选；变更后清空已填价格（R03） |
| 明细条数 | 只读文本 | — | 不展示 | 只读 | 系统计算，等于明细行数 |
| 备注 | 多行文本 | 请输入备注 | 可编辑 | 可编辑 | 占3列；最多500字符 |

### 3.2 商品明细

| 列 | 控件 | placeholder | 表现 | 约束 |
| :--- | :--- | :--- | :--- | :--- |
| 行号 | 只读 | — | 从1开始 | 系统生成 |
| 商品编码 | `select`（选品入口） | 请选择商品 | 可编辑 | 选项为启用的成品SKU；不按该供应商是否已有价格过滤（R04） |
| 商品条码 | 只读 | — | 选品后带出 | 多条码合并展示 |
| 商品名称 | 只读 | — | 选品后带出 | — |
| 基本单位 | 只读 | — | 选品后带出 | 计价口径 |
| 含税单价 | 金额输入 | 请输入含税单价 | 可编辑 | 大于0；4位小数；页面按千分位展示，录入不带千分位（R05） |
| 税率 | `select` | 请选择 | 可编辑 | `PCT_4`；Demo 下拉 0%／6%／9%／13%；允许0%；用户手动填写，不从商品带出；提交前必填（R05、Q01已定） |
| 不含税单价 | 只读 | — | 系统计算 | 含税单价÷(1+税率÷100)，4位小数 |
| 操作 | 删除 | — | 始终 | 删除该行；明细至少保留一行 |

明细支持「添加明细」；同一商品重复添加时阻断并定位到行（R04）。

## 4. 校验与提交

### 4.1 保存草稿

| 校验项 | 时机 | 失败表现 |
| :--- | :--- | :--- |
| 明细至少一行 | 保存 | Toast「请至少添加一行商品明细」 |
| 已填含税单价必须大于0 | 输入失焦、保存 | 字段内联错误「含税单价必须大于0」；零值、负值在保存时阻断（R05） |
| 已填税率在允许范围内 | 输入失焦、保存 | 字段内联错误「税率最多2位小数，允许0%」 |
| 同一商品不重复 | 选品、保存 | 行内错误「该商品已存在，请勿重复添加」 |
| 备注长度 | 输入 | 超长阻止继续输入并显示字数 |

保存草稿允许供应商、币别、含税单价、税率留空待补。已驳回单保存后回到草稿状态，保留驳回记录，可继续修改或重新提交（2026-09-24确认）。

### 4.2 提交

| 校验项 | 失败表现 |
| :--- | :--- |
| 供应商必填且审核通过、启用 | 定位到供应商字段并提示 |
| 币别必填 | 定位到币别字段并提示 |
| 明细至少一行 | Toast「请至少添加一行商品明细」 |
| 每行商品已选 | 定位到首个缺失行 |
| 每行含税单价已填且大于0 | 定位到首个缺失行，提示「请填写大于0的含税单价」 |
| 每行税率已选 | 定位到首个缺失行，提示「请选择税率」 |

校验失败时聚焦首错（单头优先），可补 Toast「请修正表单中的错误后再提交」。提交成功后单头和明细锁定（R06），时间口径按创建时间。

### 4.3 价税计算

- 行不含税单价 ＝ 含税单价 ÷ (1 ＋ 税率÷100)，四舍五入保留4位小数；税率0%时等于含税单价。
- 调整单不含数量，因此不计算价税合计、税额和金额。
- 示例（标明为示例）：含税单价113.0000、税率13% → 不含税单价100.0000；税率改为6% → 约106.6038。

## 5. 联动

| 触发 | 行为 |
| :--- | :--- |
| 选供应商 | 带出供应商默认币别（有默认时）；清空明细已填的含税单价和税率 |
| 改供应商 | 清空明细已填的含税单价和税率，并提示「供应商已变更，请重新填写价格」（R02） |
| 改币别 | 清空明细已填的含税单价和税率，并提示「币别已变更，请重新填写价格」（R03） |
| 选商品 | 带出商品条码、名称、基本单位；税率不从商品带出，与含税单价一起留空待填（R05） |
| 改含税单价或税率 | 重算该行不含税单价 |
| 删除明细行 | 剩余行号重排；明细为空时保留一行空行 |

---

## 6. 失败与异常

| 场景 | 表现 |
| :--- | :--- |
| 保存失败（系统） | Toast「保存失败，请稍后重试」；表单输入保留 |
| 提交时单据已被他人提交或审核 | Toast「当前单据状态为{状态}，不可执行{动作}」；提供刷新入口 |
| 编辑时单据状态已变化 | Toast「单据状态已变化，请刷新后重试」；不覆盖他人结果 |
| 离开未保存 | 弹「离开当前页面？」，见弹窗 PRD §3.5 |

## 7. Mock 与演示验收

### 7.1 Mock 数据覆盖

- 可保存草稿：一行SKU、供应商和币别已选、含税单价113.0000、税率13%
- 可保存草稿：多行SKU、价格部分留空
- 已驳回单：带驳回意见，可编辑后重新提交
- 已审核单：不可进入本页

### 7.2 演示验收

| 场景 | 前置 | 操作 | 预期 |
| :--- | :--- | :--- | :--- |
| 保存草稿 | 填写供应商、币别、一行明细 | 保存 | 分配单号，停留本页；Toast「已保存」 |
| 选品带出 | 选择商品 | 选品 | 带出条码、名称、基本单位；税率不带出，留空待填写 |
| 零价阻断 | 含税单价填0 | 保存 | 字段错误提示，不保存 |
| 负价阻断 | 含税单价填-1 | 保存 | 字段错误提示，不保存 |
| 空价提交 | 含税单价留空 | 提交 | 阻断并定位到该行 |
| 改币别清价 | 已填两行价格 | 改币别 | 已填含税单价和税率清空并提示 |
| 重复商品 | 同一商品添加两行 | 选品/保存 | 行内错误提示，不保存 |
| 不含税重算 | 含税单价113、税率13%改6% | 修改税率 | 不含税单价由100.0000变为约106.6038 |
| 提交锁定 | 完整单据 | 提交并确认 | 状态变为待审核，不可再编辑 |

Demo 验证表单呈现、联动与校验；不代表真实接口、并发或后端事务行为。
