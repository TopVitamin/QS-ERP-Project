销售价目表是系统维护的当前价视图，不提供人工新增、编辑、删除和禁用。商品建档生成面向所有客户的销售基准价，之后由销售价格调整单审核通过后新增或覆盖客户价、等级价和基准价。

## 二、需求背景与范围

销售价格既要有面向所有客户的通用基准价，也要有按客户等级和具体客户分别约定的价格，并且同一笔业务可能同时命中多层价格，需要明确的优先顺序。没有统一的销售价目表时，销售成交价缺少统一维护入口，取价和调价也无法追溯。

| 范围 | 说明 |
| --- | --- |
| 本期要做 | 按「商品＋币别＋面向范围」保存当前销售价；商品建档生成所有客户基准价；调整单审核通过后新增或覆盖；三层取价优先级；列表查询与追溯；供销售订单、销售退货单取价 |
| 本期不做 | 生效开始和结束日期、未来价格排期、跨币别自动换汇、价目禁用及禁用后回退、单位换算、数量阶梯价、价目表直接编辑、价目表导入、外部ToC重新定价 |
| 适用对象 | B2B成品销售；按商品基本单位计价；面向范围取所有客户、一个客户等级或一个具体客户三者之一 |

## 三、需求追溯与功能清单

销售价格按面向范围分三层：所有客户基准价、客户等级价、具体客户价。取价时按具体客户价 → 客户等级价 → 所有客户基准价依次匹配，三层都没有时由用户手工填写。

### 3.1 需求追溯

| 上游场景与需求 | 本PRD功能 | 本PRD验收 |
| --- | --- | --- |
| PRI-BR01；PRI-FR01：商品建档形成初始价格 | F03 | AC01 |
| PRI-BR03；PRI-FR03、PRI-FR04：按销售对象优先级取得当前价格 | F01、F02 | AC02、AC03、AC04 |
| PRI-BR04；PRI-FR06：通过审核单据新增或调整价格 | F03 | AC02、AC06 |
| PRI-BR05；PRI-FR05、PRI-FR08：保留单据成交价格；外部ToC不重算 | F02 | AC05、AC07 |

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 维度与唯一性 | 销售价目表按「商品＋币别＋面向范围」保存一条当前有效价格，面向范围含范围值；组合唯一，同一组合只被覆盖，不产生第二条 | 一条价格只对应一种范围及一个具体范围值（PRI-FR03、《实体对象关系》第一节） |
| R02 | 面向范围 | 面向范围分为所有客户、一个客户等级、一个具体客户；客户等级取《客户资料（详细稿）》的枚举（S、A、B、C、未评级）；客户必须审核通过且启用 | 客户等级不影响销售资格，只影响取价层级 |
| R03 | 价格来源 | 商品建档有初始含税销售价时，生成面向所有客户的销售基准价；之后由销售价格调整单审核通过后新增或覆盖 | 商品建档保存与价目生成须一致完成（《商品资料主PRD》F02） |
| R04 | 计价口径 | 按商品基本单位计价 | 一期不做单位换算、数量阶梯价（PRI-FR03；《6.强盛ERP的编码规则和通用字段规则》Q16） |
| R05 | 价税与精度 | 维护含税单价和税率，不含税单价由系统计算。含税单价保留4位小数；税率按百分比最多2位小数、允许0%；不含税单价＝含税单价÷(1＋税率÷100)，四舍五入保留4位小数；税率0%时不含税单价等于含税单价；税率为空时不含税单价为空。商品建档生成销售基准价时，税率按商品税务信息带出，取不到时留空，开单时再填；销售价格调整单生效时按调整单税率写入 | 精度依据PRI-FR04、《6.强盛ERP的编码规则和通用字段规则》Q14；税率来源见Q01、Q02（2026-09-23已定） |
| R06 | 币别独立 | 同一商品和范围可以分别维护多个币别价格；只匹配所选币别，不通过汇率换算其他币别价格 | 不做跨币别换汇（PRI-FR04） |
| R07 | 有效期与禁用 | 价格默认长期有效，直到新的调整单审核通过后覆盖；不设生效开始、结束日期，不安排未来价格；一期不做价目禁用和禁用后回退 | 错价用新的调整单覆盖当前价，老单不变（PRI-FR03、PRI-FR06） |
| R08 | 取价优先级 | 按具体客户价 → 客户等级价 → 所有客户基准价依次匹配，命中即取；三层都没有时允许手工填写，不跨币别借用价格 | PRI-FR03、PRI-AC04 |
| R09 | 取价结果与锁定 | 取价结果只用于帮助填充业务单据；草稿阶段可改含税单价和税率，改税率后重算不含税单价；提交后价格和税率锁定 | 锁定与零价确认按PRI-FR05及各业务单据PRD |
| R10 | 条件变化清价 | 业务单据的客户、商品或币别变化时，原价格作废，按新条件重新取价或手工填写，不得沿用 | PRI-FR05 |
| R11 | 列表查询与排序 | 查询条件、列表列与筛选项按详细稿；列表默认按最后更新时间倒序 | 价目表不属于安排单或结果单，排序按最近更新优先（本模块定义） |
| R12 | 追溯 | 每条当前价可回溯到最近一次审核通过的调整单，记录在最近调整单号；商品建档生成的记录该字段为空 | 《价格业务设计》§5.2 |
| R13 | 外部ToC边界 | 聚水潭、领星回传的ToC出库和退货结果、独立站订单金额沿用来源金额，不调用ERP销售价目表重新定价 | PRI-FR08、PRI-AC12 |

价税计算示例（标明为示例）：含税单价113.0000元、税率13%时，不含税单价为100.0000元；税率改为10%时，不含税单价约102.7273元。示例只用于解释算法，不是实际报价。

### 4.2 F01 销售价目表列表

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 销售人员、业务负责人查询某个商品面向某类客户当前是什么价，以及最近一次调价来自哪张单。 |
| 操作与处理 | 按面向范围、客户等级、客户、商品编码、商品名称、商品条码、币别、最近调整单号、最后更新时间查询；列表按最后更新时间倒序；点击最近调整单号进入对应销售价格调整单详情。 |
| 功能规则 | 只查看和查询，不提供新增、编辑、删除、禁用和导入入口；导出按导出中心（Q05已定）；面向范围为所有客户的记录不显示客户等级和客户（展示 `-`）。 |
| 成功结果 | 列表返回匹配的当前价记录，字段按详细稿展示。 |
| 异常与恢复 | 查询无结果时展示空状态，不自动创建价格；最近调整单号为空时展示 `-`。 |

### 4.3 F02 销售取价（供销售业务调用）

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 销售订单、销售退货单在草稿阶段确定本单价格。 |
| 操作与处理 | 业务单据选完客户、商品和币别后按R08优先级取价：命中时带出含税单价、税率和系统计算的不含税单价；三层都未命中时返回空，由用户手工填写或主动查询当前价。 |
| 功能规则 | 取价只读，不修改价目表；只有销售价格调整单审核通过才写入价目表（F03）；独立站订单和外部电商订单不调用本取价（R13）。 |
| 成功结果 | 业务单据行上有本单价格和税率，提交后按各单据规则锁定。 |
| 异常与恢复 | 取不到价不阻断选商品和制单；提交时价格、币别和税率必须完整合法（PRI-FR05）。 |

取价接口（谁在什么状态取价、取哪张价目表）：

| 取价方 | 取价时机 | 匹配条件 | 取价内容 | 依据 |
| --- | --- | --- | --- | --- |
| 销售订单（B2B） | 草稿阶段选完客户和币别后再选商品时自动带价；草稿内可重取或手填 | 客户＋客户等级＋商品＋币别，按三层优先级 | 含税单价、税率、不含税单价 | PRI-FR03～PRI-FR05；《销售订单主PRD》R04 |
| 销售退货单 | 有来源时带出原销售出库单价格；来源缺价或无来源时，可查询当前销售价快速填入（一并带税率） | 客户＋客户等级＋商品＋币别，按三层优先级 | 含税单价、税率 | PRI-FR05、PRI-FR07；《销售退货单主PRD》R04 |
| 独立站订单、外部电商订单 | 不取ERP销售价目表 | — | 沿用来源金额 | PRI-FR08 |
| 已提交或已审核的业务单据 | 不再取价 | — | 价格和税率已锁定 | PRI-FR05 |

### 4.4 F03 当前价生成与覆盖（系统）

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 新商品建档形成销售基准价；销售价格调整单审核通过后更新当前价。 |
| 操作与处理 | 商品建档有初始含税销售价时，按币别和所有客户范围生成一条销售基准价；销售价格调整单审核通过时，按商品＋币别＋面向范围新增或覆盖当前价，写入含税单价、税率、不含税单价和最近调整单号。 |
| 功能规则 | 调整单价格必须大于零；初始价必须大于零（空值允许，空价不生成；Q06已定）；写入按R05计算不含税单价；覆盖时不产生第二条记录（R01）。商品建档侧校验由商品资料补充，见交付清单交接项。 |
| 成功结果 | 新单据按最新当前价和三层优先级取价；已保存单据价格不变。 |
| 异常与恢复 | 价目写入失败时整单失败并提示，不留下部分成功记录；已审核单据的价格不回溯（PRI-FR05）。 |

### 4.5 状态与动作

销售价目表是当前价视图，没有审核状态和业务状态，也不发生状态流转。价格记录由商品建档和调整单审核生成或覆盖，人工不能直接改变。

## 六、验收标准与待确认事项

### 6.1 验收标准

| 编号 | 对应功能/规则 | 条件与操作 | 预期结果 |
| --- | --- | --- | --- |
| AC01 | F03/R03 | 商品以初始含税销售价和币别建档；另测初始价留空 | 有价时生成一条面向所有客户的同币别基准价，含税单价与建档一致；空价不生成记录，新单手填（PRI-AC01） |
| AC02 | F03/R01、R03 | 对同一商品＋币别分别审核通过所有客户、客户等级、具体客户三类调整单 | 三类记录并存互不覆盖；重复调价只更新对应组合，不产生第二条（PRI-AC05） |
| AC03 | F02/R08 | 同一销售订单同时可命中客户价、等级价和基准价；依次移除高优先级价格 | 使用具体客户价；回退到等级价、基准价和人工填写（PRI-AC04） |
| AC04 | F02/R06、R10 | 单据先按人民币取价，再修改为美元；再修改客户或商品 | 原价格清空，仅匹配新条件价格；不存在时重新手填，不自动换汇、不沿用（PRI-AC06） |
| AC05 | F02/R05 | 价目含税单价4位小数；税率分别填13%和0% | 不含税单价按公式计算并保留4位；税率0%时等于含税单价（PRI-FR04、PRI-AC13）；价目表不接受零价记录，初始价必须大于零、空值允许（Q06已定，2026-09-23） |
| AC06 | F01/R07 | 打开列表尝试编辑或删除价格 | 无编辑、删除、禁用入口；错价通过新建调整单覆盖（PRI-FR06） |
