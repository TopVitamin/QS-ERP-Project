## 本轮设计边界

- 价目表是系统维护的当前价视图：不提供新增、编辑、删除、禁用和导入；价格由商品建档生成初始记录，之后由调整单审核通过后新增或覆盖。
- 价目表不设生效起止日期、不做跨币别换汇、不做单位换算和数量阶梯价、一期不做价目禁用；错价用新的调整单覆盖。
- 调整单只有审核状态一个维度，状态链为草稿 → 待审核 → 已审核／已驳回；没有业务状态、取消和关闭；已审核不可修改、删除、撤销或反审核。
- 调整单只有单价，不含数量和金额，因此不汇总价税合计、税额和金额；含税单价必须大于零，税率允许0%。
- 取价接口在价目表主PRD中明确：采购订单、采购退货单按供应商＋商品＋币别取价；销售订单、销售退货单按具体客户价 → 客户等级价 → 所有客户基准价三层取价；独立站与外部电商沿用来源金额，不取ERP价目表。
- 追溯双向：价目表通过最近调整单号回链调整单；调整单详情通过「查看价目表」按本单维度预筛选。
- 本次同步[《系统与模块地图》](../../系统架构和流程/00-系统与模块地图.md)的覆盖说明；《单据与状态流转》价格调整单状态已有定义，本次未改。

## 已定结论与后续事项

| 事项 | 结论与处理 |
| --- | --- |
| 初始价目记录的税率与不含税单价来源 | 已定（2026-09-23）：商品建档生成初始价时，税率按商品税务信息带出，取不到时留空、不含税单价为空，开单时再填；商品税务信息不可用时可由商品建档补充税率维护作为备选路径。两个价目表主PRD与详细稿TSV已同步 |
| 采购侧税率带出字段 | 已定（2026-09-23）：不从商品带出、默认为空，由用户手动填写，提交前必填（商品资料只有默认销售税率，没有默认采购税率）。采购调整单主PRD与详细稿TSV已同步 |
| 销售侧税率带出字段与空值处理 | 已定（2026-09-23）：按主体纳税人身份和商品税务信息带出；带出为空时用户手填，提交前必填。销售调整单主PRD与详细稿TSV已同步 |
| 已驳回调整单能否删除 | 已定（2026-09-23）：允许删除，与草稿同口径（未生效、不影响价目表）；已审核不可删除。两个调整单主PRD、骨架与Demo弹窗已同步 |
| 调整单是否记录调价前价格 | 已定（2026-09-23）：一期不保存，审核时对照价目表当前价 |
| 价目表与调整单的导入导出范围 | 已定（2026-09-23）：导出纳入导出中心；导入一期不做。02《价格管理需求分析》§五的导入表述已同步 |

| 客户等级价的「未评级」是否允许维护 | 已定（2026-09-23）：允许维护，与《客户资料（详细稿）》枚举一致 |
| 价目表创建人、最后更新人展示口径 | 已定（2026-09-23）：显示触发人员姓名（商品建档人、调整单审核人），不显示「系统」。两个价目表详细稿TSV与Demo PRD已同步 |
