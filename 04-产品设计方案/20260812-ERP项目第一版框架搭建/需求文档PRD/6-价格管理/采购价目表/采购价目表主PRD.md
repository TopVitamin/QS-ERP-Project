## 一、文档概要

需求类型：新建模块（价格管理-采购价目表）。

采购价目表是系统维护的当前价视图，不提供人工新增、编辑、删除和禁用。价格由商品建档生成初始记录，之后由采购价格调整单审核通过后新增或覆盖。

## 二、需求背景与范围

采购价格会随供应商、商品和币别不同而变化，业务制单时需要按这三个维度取到当前价；同时，已经保存的业务单据不能被后来的调价改动。没有统一的采购价目表时，价格散落在Excel和沟通记录里，取价、调价和追溯都缺少统一依据。

| 范围 | 说明 |
| --- | --- |
| 本期要做 | 按「供应商＋商品＋币别」保存当前采购价；商品建档生成初始价；调整单审核通过后新增或覆盖；列表查询与追溯；供采购订单、采购退货单取价 |
| 本期不做 | 生效开始和结束日期、未来价格排期、跨币别自动换汇、价目禁用及禁用后回退、单位换算、数量阶梯价、价目表直接编辑、价目表导入 |
| 适用对象 | 成品采购；按商品基本单位计价；币别按辅助资料启用的币别维护 |

## 三、需求追溯与功能清单

价格从商品建档开始就有了：商品建档生成一条初始采购价，后续变价统一走采购价格调整单，审核通过后覆盖当前价。价目表本身不编辑，只查询和取价。

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 维度与唯一性 | 采购价目表按「供应商＋商品＋币别」保存一条当前有效价格，组合唯一；同一组合只被覆盖，不产生第二条 | 维度口径见PRI-FR02；唯一性依据《实体对象关系》第一节 |
| R02 | 价格来源 | 商品建档时按初始供应商和币别生成初始采购价；之后由采购价格调整单审核通过后新增或覆盖 | 商品建档保存与价目生成须一致完成，失败不留单侧数据（《商品资料主PRD》F02） |
| R03 | 计价口径 | 按商品基本单位计价 | 一期不做单位换算、数量阶梯价（PRI-FR02；《6.强盛ERP的编码规则和通用字段规则》Q16） |
| R04 | 价税与精度 | 维护含税单价和税率，不含税单价由系统计算。含税单价保留4位小数；税率按百分比最多2位小数、允许0%；不含税单价＝含税单价÷(1＋税率÷100)，四舍五入保留4位小数；税率0%时不含税单价等于含税单价；税率为空时不含税单价为空。商品建档生成初始价时，税率按商品税务信息带出，取不到时留空，开单时再填；采购价格调整单生效时按调整单填写的税率写入 | 精度依据PRI-FR04、《6.强盛ERP的编码规则和通用字段规则》Q14；税率来源见Q01、Q02（2026-09-23已定） |
| R05 | 币别独立 | 同一供应商和商品可以分别维护多个币别价格；只匹配所选币别，不通过汇率换算其他币别价格 | 不做跨币别换汇（PRI-FR04） |
| R06 | 有效期与禁用 | 价格默认长期有效，直到新的调整单审核通过后覆盖；不设生效开始、结束日期，不安排未来价格；一期不做价目禁用和禁用后回退 | 错价用新的调整单覆盖当前价，老单不变（PRI-FR02、PRI-FR06） |
| R07 | 取价匹配 | 采购业务按供应商、商品、币别匹配当前价；不按该供应商是否已有价格过滤可选商品；取不到价允许手工填写，不阻止制单 | 价格是参考值，不是供货资格（PRI-FR02、PRI-FR05、《价格业务设计》§6.2） |
| R08 | 取价结果与锁定 | 取价结果只用于帮助填充业务单据；草稿阶段可改含税单价和税率，改税率后重算不含税单价；提交后价格和税率锁定 | 锁定与零价确认按PRI-FR05及各业务单据PRD |
| R09 | 条件变化清价 | 业务单据的供应商、商品或币别变化时，原价格作废，按新条件重新取价或手工填写，不得沿用 | PRI-FR05 |
| R10 | 列表查询与排序 | 查询条件、列表列与筛选项按详细稿；列表默认按最后更新时间倒序 | 价目表不属于安排单或结果单，排序按最近更新优先（本模块定义） |
| R11 | 追溯 | 每条当前价可回溯到最近一次审核通过的调整单，记录在最近调整单号；商品建档生成的记录该字段为空 | 《价格业务设计》§5.2 |

价税计算示例（标明为示例）：含税单价113.0000元、税率13%时，不含税单价为100.0000元；税率改为10%时，不含税单价约102.7273元。示例只用于解释算法，不是实际报价。

### 4.2 F01 采购价目表列表

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 采购人员、业务负责人查询某个供应商、某个商品当前是什么价，以及最近一次调价来自哪张单。 |
| 操作与处理 | 按供应商、商品编码、商品名称、商品条码、币别、最近调整单号、最后更新时间查询；列表按最后更新时间倒序；点击最近调整单号进入对应采购价格调整单详情。 |
| 功能规则 | 只查看和查询，不提供新增、编辑、删除、禁用和导入入口；导出按导出中心（Q04已定）。 |
| 成功结果 | 列表返回匹配的当前价记录，字段按详细稿展示。 |
| 异常与恢复 | 查询无结果时展示空状态，不自动创建价格；最近调整单号为空时展示 `-`。 |

### 4.3 F02 采购取价（供采购业务调用）

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 采购订单、采购退货单在草稿阶段确定本单价格。 |
| 操作与处理 | 业务单据选完供应商、商品和币别后调用取价：匹配到当前价时带出含税单价、税率和系统计算的不含税单价；匹配不到时返回空，由用户手工填写或主动查询当前价。 |
| 功能规则 | 取价只读，不修改价目表；只有采购价格调整单审核通过才写入价目表（F03）；取价不清空用户已填内容之外的字段，条件变化时按R09处理。 |
| 成功结果 | 业务单据行上有本单价格和税率，提交后按各单据规则锁定。 |
| 异常与恢复 | 取不到价不阻断选商品和制单；提交时价格、币别和税率必须完整合法（PRI-FR05）。 |

取价接口（谁在什么状态取价、取哪张价目表）：

| 取价方 | 取价时机 | 匹配条件 | 取价内容 | 依据 |
| --- | --- | --- | --- | --- |
| 采购订单 | 草稿阶段选完供应商和币别后再选商品时自动带价；草稿内可重取或手填 | 供应商＋商品＋币别 | 含税单价、税率、不含税单价 | PRI-FR02、PRI-FR04、PRI-FR05；《采购订单主PRD》R04 |
| 采购退货单 | 有来源时带出原采购入库单价格；来源缺价或无来源时，可查询当前采购价快速填入（一并带税率） | 供应商＋商品＋币别 | 含税单价、税率 | PRI-FR05、PRI-FR07；《采购退货单主PRD》R04 |
| 已提交或已审核的业务单据 | 不再取价 | — | 价格和税率已锁定 | PRI-FR05 |

### 4.4 F03 当前价生成与覆盖（系统）

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 新商品建档形成初始价；采购价格调整单审核通过后更新当前价。 |
| 操作与处理 | 商品建档有初始含税采购价时，按初始供应商和币别生成一条采购价；采购价格调整单审核通过时，按供应商＋商品＋币别新增或覆盖当前价，写入含税单价、税率、不含税单价和最近调整单号。 |
| 功能规则 | 调整单价格必须大于零；初始价必须大于零（空值允许，空价不生成；Q05已定）；写入按R04计算不含税单价；覆盖时不产生第二条记录（R01）。商品建档侧校验由商品资料补充，见交付清单交接项。 |
| 成功结果 | 新单据按最新当前价取价；已保存单据价格不变。 |
| 异常与恢复 | 价目写入失败时整单失败并提示，不留下部分成功记录；已审核单据的价格不回溯（PRI-FR05）。 |

### 4.5 状态与动作

采购价目表是当前价视图，没有审核状态和业务状态，也不发生状态流转。价格记录由商品建档和调整单审核生成或覆盖，人工不能直接改变。

## 六、验收标准与待确认事项

### 6.1 验收标准

| 编号 | 对应功能/规则 | 条件与操作 | 预期结果 |
| --- | --- | --- | --- |
| AC01 | F03/R02 | 商品以初始供应商、初始含税采购价和币别建档；另测初始价留空 | 有价时生成一条同币别采购价，含税单价与建档一致；空价不生成记录，新单手填（PRI-AC01） |
| AC02 | F03/R01、R02 | 对同一供应商＋商品＋币别审核通过两张调整单 | 价目表只保留一条当前价，展示最新价，最近调整单号为最新一张（PRI-AC05） |
| AC03 | F02/R07 | 采购订单先选供应商，再分别选择有价和无价SKU | 有价带出含税单价和税率；无价可手填；未补齐不能提交（PRI-AC03） |
| AC04 | F02/R05、R09 | 单据先按人民币取价，再修改为美元；再修改供应商或商品 | 原价格清空，仅匹配新条件的价格；不存在时重新手填，不自动换汇、不沿用（PRI-AC06） |
| AC05 | F02/R04 | 价目含税单价4位小数；税率分别填13%和0% | 不含税单价按公式计算并保留4位；税率0%时等于含税单价（PRI-FR04、PRI-AC13）；价目表不接受零价记录，初始价必须大于零、空值允许（Q05已定，2026-09-23） |
| AC06 | F01/R06 | 打开列表尝试编辑或删除价格 | 无编辑、删除、禁用入口；错价通过新建调整单覆盖（PRI-FR06） |
| AC07 | F02/R08 | 草稿保存价格后审核一张采购价格调整单，再重新打开草稿 | 草稿仍保留原价格；提交后价格和税率锁定（PRI-AC07） |
| AC08 | F01/R10 | 按供应商、商品编码、币别、最近调整单号分别查询 | 返回对应记录；未选条件等同全部；默认按最后更新时间倒序 |
| AC09 | F01/R11 | 点击最近调整单号；打开商品建档生成的记录 | 跳转对应调整单详情；建档生成的记录最近调整单号展示 `-` |

| Q03 | 价目表的创建人、最后更新人显示触发人员姓名还是「系统」 | 价目表可选列展示 | 待指定 | 与09原型对齐前 | 已定（2026-09-23）：显示触发人员姓名（商品建档人、调整单审核人），不显示「系统」 |
| Q04 | 价目表与价格调整单的导入导出范围 | 列表页头、导出中心 | 待指定 | 导出中心PRD定稿前 | 已定（2026-09-23）：导出纳入导出中心；导入一期不做 |
| Q05 | 商品建档的初始含税采购价是否必须大于零（商品资料未定义零值校验） | 价目表可能产生零价记录，影响新单取价 | 待指定 | 商品资料PRD下一轮修订 | 已定（2026-09-23）：初始含税采购价必须大于零（空值允许）；价目表不接受零价记录。商品建档侧校验由《商品资料主PRD》补充，见交付清单交接项 |
