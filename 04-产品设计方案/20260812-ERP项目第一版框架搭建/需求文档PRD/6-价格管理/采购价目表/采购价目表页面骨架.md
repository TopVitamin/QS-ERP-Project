骨架展示页面分区、字段位置、基本控件、按钮与虚构示例值。字段以TSV为准，业务动作以主PRD为准，详细交互、校验和反馈见Demo PRD。

各页按“用途／关键要素／线框／补充说明”组织。图前简述本页任务及重点，图后只补图中省略项和条件差异；无补充内容时写“无”。

## 绘制约定

遵循[《页面骨架模板-V2》](../../../../../05-常用模板/02-模块设计交付/页面骨架模板-V2.md)与[《UI布局公共说明》](../../../../../05-常用模板/02-模块设计交付/UI布局公共说明.md)。本模块补充：

- 字段名、按钮文案与TSV、Demo PRD一致；示例值为虚构。
- 供应商按 Code-Name（`{编码} {名称}`）画示例值；商品明细拆列展示编码、条码、名称（《6.强盛ERP的编码规则和通用字段规则》2.3例外）。
- 币别按「{币别编码} {币别名称}」展示；价税字段顺序：含税单价、税率、不含税单价；金额列只展示数值，不加币别符号。
- 单价按千分位展示、保留4位小数；税率展示百分比。
- 列表无行内操作列，最近调整单号可点击。
- **每行必须画满 6 列**（用 `|` 分隔）；字段不足 6 个时，剩余列标「（空）」留空，不要省略列线。

## 列表页

- **用途**：查询某个供应商、某个商品当前是什么价，以及最近一次调价来自哪张单。
- **关键要素**：页头导出；查询区按供应商、商品、商品编码与条码、币别、最近调整单号、最后更新时间；列表按最后更新时间倒序。

```text
+--------------------------------------------------------------------------------------------------+
| 采购价目表                                                                              [导出]   |
|--------------------------------------------------------------------------------------------------|
| 查询区（6列栅格）                                                                                |

| [全部供应商 v]    | [请输入商品编码]  | [请输入商品条码]| [请输入商品名称]| [全部 v]    | [请输入调整单号]  |
| 最后更新时间      |                   |               |               |               |                   |
| [不限 v]          |                   |               |               |               |                   |
|--------------------------------------------------------------------------------------------------|
| [收起过滤 ^]                                                          [重置] [查询]            |
```

**补充说明**：

- **重点突出**：页头只有「导出」，不提供新增、导入、编辑、删除和禁用入口；查询区下方独立一行，左侧「收起过滤」、右侧「重置/查询」；最近调整单号为链接列，商品建档生成的记录展示 `-`。
- **图中省略**：创建时间、创建人、最后更新人等列（见 TSV「列表展示=是」）；校验、排序、分页交互见 Demo PRD。
- 批量操作栏一期仅已选中计数与列设置；勾选配合页头导出「已勾选」。
- 无行内操作列，不设「查看」按钮；价格变化过程通过最近调整单号追溯。
