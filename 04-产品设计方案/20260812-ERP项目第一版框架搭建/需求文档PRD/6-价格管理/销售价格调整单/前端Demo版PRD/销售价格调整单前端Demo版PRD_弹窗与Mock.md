## 2. 提交相关弹窗（F03）

**触发入口**：新增/编辑页、列表、详情「提交」；可用条件均为**审核状态=草稿或已驳回**（主 PRD §6.4）。

**校验前置**：打开提交弹窗前，先按主 PRD R06 与[新增编辑页 §4.2](销售价格调整单前端Demo版PRD_新增编辑页.md)校验当前单据。未通过则 Toast 或字段提示阻断，**不进入**弹窗。列表/详情提交已有草稿时，校验口径与表单页一致。

```
列表 / 详情 / 新增·编辑页
         │
    点「提交」
         ▼
   新增编辑 §4.2 校验
         │
    ┌────┴────┐
   失败       通过
    │          │
    ▼          ▼
 Toast      §2.1 提交确认弹窗
 阻断      取消 │ 确认提交
               ▼
        待审核 + Toast「已提交」
```

### 2.1 提交确认

| 项目 | 内容 |
| :--- | :--- |
| 弹窗标题 | 确认提交销售价格调整单？ |
| 正文 | 提交后进入待审核状态，面向范围、币别和明细价格将被锁定；审核通过后立即更新销售价目表当前价。审核前仍可等待审核或由审核人驳回。 |
| 确认按钮 | 确认提交 |
| 取消按钮 | 取消 |
| 确认后 | 审核状态→待审核；Toast「销售价格调整单已提交」；刷新当前页或列表 |

| 来源页 | 确认后页面表现 |
| :--- | :--- |
| 新增/编辑页 | 停留本页并变为只读待审核态，或返回列表（以实现为准，须可连续演示） |
| 列表 / 详情 | 刷新；行内/页头操作变为审核、驳回 |

## 3. 状态变更弹窗（F04、F06）

下列弹窗均在**二次确认**后执行。入口可用条件见主 PRD §6.4 与各页页头/行内矩阵；条件不满足时**不展示按钮**，无需弹窗阻断。

**通用弹窗结构**（无表单项时省略中间输入区）：

```
┌──────────────────────────────────────────┐
│  {弹窗标题}                          [×] │
├──────────────────────────────────────────┤
│  {正文说明}                               │
│  ┌────────────────────────────────────┐  │  ← 有必填项时，如驳回意见
│  │ {多行文本}                           │  │
│  └────────────────────────────────────┘  │
├──────────────────────────────────────────┤
│                    [取消]  [确认{动作}]   │
└──────────────────────────────────────────┘
         │ 取消              │ 确认
         ▼                   ▼
    关闭弹窗，停留      执行业务 + Toast + 刷新页面
```

**入口与阻断关系**（按钮不满足条件时直接不展示，不弹窗）：

```
页头 / 行内「{操作}」
         │
    主 PRD §6.4 允许？
         │
    ┌────┴────┐
   否        是
    │          │
    ▼          ▼
 不展示    打开 §3.x 弹窗
 该按钮
```

### 3.1 审核

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「审核」 |
| 可用条件 | 待审核 |
| 弹窗标题 | 确认审核？ |
| 正文 | 审核通过后立即新增或覆盖销售价目表当前价，已审核的调整单不可修改、删除或撤销。 |
| 必填项 | 无 |
| 确认按钮 | 确认审核 |
| 取消按钮 | 取消 |
| 确认后 | 审核状态→已审核；记录审核人、审核时间；按明细更新价目表当前价；Toast「销售价格调整单已审核，价目表当前价已更新」；Demo 可接续 §4 本地联动 |

### 3.2 驳回

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「驳回」 |
| 可用条件 | 待审核 |
| 弹窗标题 | 驳回销售价格调整单 |
| 正文 | 驳回后单据进入已驳回状态，可修改后重新提交。 |
| 必填项 | 驳回意见（多行） |
| 确认按钮 | 确认驳回 |
| 取消按钮 | 取消 |
| 确认后 | 审核状态→已驳回；保存驳回意见、审核人、审核时间；Toast「销售价格调整单已驳回，可修改后重新提交」 |

### 3.3 删除

| 项目 | 内容 |
| :--- | :--- |
| 触发入口 | 列表、详情「删除」 |
| 可用条件 | 草稿或已驳回（主PRD §6.4） |
| 弹窗标题 | 删除销售价格调整单？ |
| 正文 | 仅草稿和已驳回且未生效的调整单可以删除，删除后不可恢复，单号不重用；已审核不可删除（Q03已定，2026-09-23）。 |

## 4. Demo Mock：审核通过后本地更新价目表（F07）

### 4.1 正式规则

按 PRI-FR06，审核通过后**立即新增或覆盖销售价目表当前价**：同一「商品＋币别＋面向范围」组合有记录则覆盖，没有则新增，并写入最近调整单号。

本节 Mock **仅用于 Demo 原型串联**，用本地数据模拟该写入，不属于正式验收（主 PRD F07）。

### 4.2 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 列表/详情「审核」成功后 | 按明细在本地价目数据中新增或覆盖记录，并回写最近调整单号（Demo 开关可配置，默认开启） |

```
§3.1 审核成功（已审核）
         │
    Demo Mock 开关？
         │
    ┌────┴────┐
  关闭       开启（默认）
    │          │
    ▼          ▼
 Toast     本地价目数据更新
 结束       ┌──────────────────────────────┐
            │ 同一组合：覆盖含税单价、税率、  │
            │ 不含税单价、最近调整单号        │
            │ 无记录：新增一条当前价          │
            └──────────────────────────────┘
                     │
                     ▼
            销售价目表列表可见新价
            （可继续演示销售订单三层取价）
```

### 4.3 生成规则（本地 Mock）

| 项目 | 规则 |
| :--- | :--- |
| 匹配键 | 商品＋币别＋面向范围（含范围值） |
| 有记录 | 覆盖含税单价、税率、不含税单价、最近调整单号、最后更新时间 |
| 无记录 | 新增一条当前价，创建时间取当前时间 |
| 不含税单价 | 按含税单价÷(1+税率÷100)计算，4位小数 |
| 追溯 | 价目表「最近调整单号」指向本调整单，点击可回链详情 |
| 标注 | 界面标注「演示数据」或「Mock」角标 |

### 4.4 不做的事

- 不代替正式价目表写入校验与并发处理
- 不修改已保存业务单据的价格快照，不改变独立站与外部电商金额
- 不推送金蝶、不产生库存
- 不把 Mock 行为写入主 PRD 验收标准

## 5. 验收场景

| 场景 | 操作 | 预期 |
| :--- | :--- | :--- |
| 提交 | 完整草稿点提交 | 校验通过→提交确认→待审核 |
| 提交阻断 | 面向范围=客户等级但未选等级 | 阻断并定位字段，不进入待审核 |
| 审核 | 待审核点审核 | 已审核；价目表本地数据更新 |
| 驳回 | 待审核点驳回 | 必填驳回意见→已驳回 |
| 删除 | 草稿点删除 | 二次确认→记录移除 |
| Mock 联动 | 审核通过后打开销售价目表 | 对应组合价格更新，最近调整单号回链本单 |
| Mock 关闭 | Demo 配置关闭 Mock | 审核后仅成功提示，价目表数据不变化 |
| 离开未保存 | 编辑页有改动点取消 | 弹出离开确认 |

Demo 验证弹窗文案、必填项与 Mock 本地数据联动；不代表生产接口、并发或后端事务行为。
