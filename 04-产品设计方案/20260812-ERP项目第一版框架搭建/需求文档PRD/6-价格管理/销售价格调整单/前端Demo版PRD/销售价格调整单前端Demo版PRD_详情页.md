## 1. 页面目标与范围

| 项目 | 内容 |
| :--- | :--- |
| 用户任务 | 查看调整单全貌；按状态办理提交、编辑、删除、审核、驳回；已审核后核对生效结果 |
| 标题与入口 | 「销售价格调整单详情 · {单号}」；列表点击单号进入 |
| 容器形式 | 独立页 |
| 区域顺序 | 页头 → 单据信息 → 商品明细 → 驳回信息（条件）→ 操作信息 |
| 返回/关闭 | 「返回列表」返回列表页；不保留查询条件和页码（以实现为准） |

页头左侧为标题与审核状态标签，右侧为操作按钮；`返回列表` 始终排在最前。

## 2. 页头按钮矩阵

> 与主PRD §6.4 一致；不满足条件时隐藏按钮，不用 disabled。

| 状态 | 页头按钮 |
| :--- | :--- |
| 草稿 | `[返回列表] [提交] [删除] [编辑]` |
| 待审核 | `[返回列表] [审核] [驳回]` |
| 已审核 | `[返回列表] [查看价目表]` |
| 已驳回 | `[返回列表] [提交] [删除] [编辑]` |

| 按钮 | 可用条件 | 点击行为 | 确认与反馈 |
| :--- | :--- | :--- | :--- |
| 提交 | 草稿／已驳回 | 校验后打开提交确认弹窗 | 弹窗 PRD §2；成功 Toast「销售价格调整单已提交」 |
| 编辑 | 草稿／已驳回 | 进入编辑页 | 返回后刷新详情 |
| 删除 | 草稿／已驳回（R11） | 打开删除确认弹窗 | 弹窗 PRD §3.3；成功 Toast「销售价格调整单已删除」 |
| 审核 | 待审核 | 打开审核确认弹窗 | 弹窗 PRD §3.1；成功 Toast「已审核，价目表当前价已更新」 |
| 驳回 | 待审核 | 打开驳回弹窗（意见必填） | 弹窗 PRD §3.2；成功 Toast「已驳回，可修改后重新提交」 |
| 查看价目表 | 已审核 | 跳转销售价目表列表，并按本单面向范围、客户等级或客户和币别预置筛选 | 跳转；无匹配记录时展示价目表空状态 |

## 3. 区域结构

### 3.1 单据信息（6列栅格）

| 字段 | 显示形式 | 空值及长文本 |
| :--- | :--- | :--- |
| 单号 | 文字 | — |
| 面向范围 | 文字（枚举） | `-` |
| 客户等级 | 文字（枚举） | 不适用时 `-` |
| 客户 | 文字，Code-Name | 不适用时 `-` |
| 币别 | 文字，`{编码} {名称}` | `-` |
| 明细条数 | 数值 | `0` |
| 审核状态 | StatusBadge | `-` |
| 备注 | 文字，跨列 | `-`；过长省略，hover 看全文 |

### 3.2 商品明细

| 列 | 显示形式 | 说明 |
| :--- | :--- | :--- |
| 行号 | 数值 | 从1开始 |
| 商品编码 | 文字 | 拆列展示 |
| 商品条码 | 文字 | 多条码合并展示 |
| 商品名称 | 文字 | `ellipsis` |
| 基本单位 | 文字 | — |
| 含税单价 | 金额 | 千分位、4位小数 |
| 税率 | 文字 | 百分比，最多2位小数 |
| 不含税单价 | 金额 | 千分位、4位小数 |

调整单不含数量，明细不展示数量、价税合计、税额和金额列。

### 3.3 驳回信息（仅已驳回）

| 字段 | 显示形式 | 说明 |
| :--- | :--- | :--- |
| 驳回意见 | 文字，跨列 | 未驳回时整块不展示 |
| 审核人 | 文字 | 最近一次驳回人 |
| 审核时间 | 日期时间 | 最近一次驳回时间 |

### 3.4 操作信息

胶囊 Tab：**制单信息**（默认）/ **操作日志**。

| Tab | 内容 |
| :--- | :--- |
| 制单信息 | 创建人、创建时间、最后更新人、最后更新时间（6列栅格） |
| 操作日志 | 表格：操作时间、操作人、操作类型、说明；按时间倒序；一期从创建、提交、审核、驳回等推导；完整审计日志后置 |

## 4. 状态差异

| 状态 | 页面表现 |
| :--- | :--- |
| 草稿 | StatusBadge 草稿；单据信息和明细只读；无驳回信息；页头为提交、删除、编辑 |
| 待审核 | StatusBadge 待审核；单据信息和明细只读；页头为审核、驳回 |
| 已审核 | StatusBadge 已审核；页头仅查看价目表；提示「本单价格已生效，只影响之后的新单；独立站与外部电商金额不受影响」 |
| 已驳回 | StatusBadge 已驳回；展示驳回信息；页头为提交、删除、编辑 |

---

## 5. 追溯跳转

- 已审核后点「查看价目表」：跳转销售价目表列表，并按本单面向范围、客户等级或客户和币别预置筛选条件，用于核对生效结果（R13）。
- 价目表侧「最近调整单号」回链本单详情；两侧互为追溯入口。
- 调整单详情不展示调价前价格（主PRD Q05）；审核人可在审核前打开销售价目表核对当前价。

## 6. 反馈规范

| 操作 | 反馈方式 | 文案 |
| :--- | :--- | :--- |
| 提交成功 | Toast | 销售价格调整单已提交 |
| 审核成功 | Toast | 销售价格调整单已审核，价目表当前价已更新 |
| 驳回成功 | Toast | 销售价格调整单已驳回，可修改后重新提交 |
| 删除成功 | Toast | 销售价格调整单已删除 |
| 查看价目表 | 跳转 | 进入销售价目表列表，按本单范围与币别筛选 |
| 操作失败——状态不匹配 | Toast | 当前单据状态为{状态}，不可执行{动作} |
| 操作失败——权限不足 | Toast | 您暂无{动作}权限，请联系管理员 |
| 操作失败——系统繁忙 | Toast | 操作失败，请稍后重试 |

## 7. Mock 与演示验收

### 7.1 Mock 数据覆盖

- 四种审核状态各至少 1 单，用于验证页头按钮矩阵
- 面向范围三类各至少 1 单
- 至少 1 单已驳回并带驳回意见、审核人、审核时间
- 至少 1 单已审核且对应价目表当前价已更新，用于验证「查看价目表」跳转
- 至少 1 单多行明细（≥3个SKU）、1 单税率含0%

### 7.2 演示验收

| 场景 | 前置 | 操作 | 预期 |
| :--- | :--- | :--- | :--- |
| 草稿详情 | 打开草稿单 | 查看 | StatusBadge 草稿；页头为提交、删除、编辑；无驳回信息 |
| 待审核详情 | 打开待审核单 | 查看 | 页头为审核、驳回；无编辑、删除 |
| 已审核详情 | 打开已审核单 | 查看 | 页头仅返回列表、查看价目表；无编辑、删除、撤销、反审核 |
| 已驳回详情 | 打开已驳回单 | 查看 | 展示驳回信息；页头为提交、删除、编辑 |
| 范围展示 | 分别打开三类范围单据 | 查看 | 不适用的范围值展示 `-` |
| 追溯跳转 | 已审核单点「查看价目表」 | 点击 | 进入销售价目表列表并按本单范围与币别筛选 |
| 操作日志 | 任意单据 | 切换 Tab | 默认制单信息；操作日志倒序只读 |

Demo 验证页面呈现、状态差异与跳转；不代表真实接口、并发或后端事务行为。
