## 一、先厘清：市面上对 ERP 的理解并不一样

「ERP」这个词在不同公司、不同行业、不同语境下，含义差别很大。常见几种理解：


| 理解方式          | 典型含义                 | 强盛科技是否采用                       |
| ------------- | -------------------- | ------------------------------ |
| **财务 ERP**    | 以财务核算、凭证、报表为核心，管账为主  | 部分借鉴（业财推送金蝶），但不是 ERP 的全部       |
| **进销存 ERP**   | 采购、销售、库存、简单财务一体化     | 覆盖了其中一部分，但范围更广                 |
| **制造业 ERP**   | 重生产、BOM、MRP、车间管理     | **不涉及**——强盛为成品采销模式，无生产制造模块 |
| **电商 ERP**    | 重订单拉取、打单发货、平台对接      | 订单归集是 ERP 能力之一，但打单发货交给领星 / 聚水潭 |
| **全渠道零售 ERP** | 订单 + 库存 + 结算中枢，拉通全渠道 | 最接近强盛的定位，但现阶段以线上渠道为主           |


**强盛科技的定义**：

> 自研 ERP 是公司的 **业务中台 / 业务管理后台**——承接成品采购、成品销售、库存等核心经营业务，统一管理商品主数据与业务单据，做跨渠道调度与业财转换，再把标准化结果推送给财务系统和第三方 SaaS。**它不是财务系统，不是仓库执行系统，也不是渠道打单系统，更不是生产制造系统。**

## 二、系统定位



### 2.1 一句话定位

**强盛科技自研 ERP = 业务中台 + 后台管理主系统**

```plain
  供应商（ERP 内维护）──→ 采购业务（ERP 内闭环）
                                │
        第三方 SaaS（渠道 / 仓储）  ↕ 订单、库存、商品资料
                                │
        ┌─────────────────────┐
        │   强盛科技 自研 ERP   │  ← 业务中台：管业务、管规则、管单据
        │  采购 / 销售 / 库存  │
        │  业财转换 / 主数据    │
        └──────────┬──────────┘
                   ↓ 应记账结果
              金蝶云·星空（财务底座）
```



### 2.2 在整体架构中的位置


| 层级        | 系统                   | 与 ERP 的关系           |
| --------- | -------------------- | ------------------- |
| **业务中台**  | **自研 ERP**（本项目）      | 核心——统一管理经营业务与业务单据   |
| **财务底座**  | 金蝶云·星空               | 下游——接收 ERP 推送的应记账结果 |
| **渠道执行**  | 领星、聚水潭               | 平级对接——订单入、执行回、库存互同步 |
| **仓储执行**  | 第三方 WMS              | 平级对接——实物库存入出、库存互同步  |
| **供应商与采购** | **ERP 内维护**（无第三方 SaaS） | 供应商主数据、采购单据在 ERP 创建；线下协同靠人工，未来自研 SRM |




### 2.3 ERP 不是什么


| ERP 不是          | 实际由谁承担         |
| --------------- | -------------- |
| 财务总账系统          | 金蝶云·星空         |
| 国内仓实物库存执行系统     | 第三方 WMS        |
| 跨境打单 / FBA 管理系统 | 领星             |
| 国内电商打单发货系统      | 聚水潭            |
| 供应商深度协同系统       | 现阶段人工；未来自研 SRM |
| 生产制造 / BOM / MRP 系统 | **本 ERP 不涉及**    |

## 三、核心业务范畴

强盛科技 ERP 承接 **五大类经营业务**：

### 3.1 采购业务

+ 向供应商 **采购成品**（采购申请、采购订单、到货入库）
+ **供应商主数据在 ERP 内创建与维护**（约 300 家成品供应商）
+ 与供应商的采购协同（基础流程在 ERP 内完成；线下沟通暂靠微信 / 邮件，无采购类第三方 SaaS）
+ 采购价格、交期等与供应商主数据关联
+ 为后续自研 SRM 预留接口



### 3.2 销售业务

- **ToB 批发**：批发开单、信用管控、发货、退货
- **ToC 订单归集**：从领星（跨境）、聚水潭（国内电商）接收 B2C 销售订单，统一归集、拆单、路由
- 销售政策、渠道价格、客户（经销商）管理



### 3.3 库存管理业务

+ **商品主数据**：成品 SPU/SKU、单位、条码、规格属性
+ **逻辑库存**：跨渠道可承诺库存、渠道预留、锁库、安全库存
+ **实物库存同步**：从第三方 WMS（国内仓）、领星（FBA）、聚水潭同步实物库存，不在 ERP 内做仓内执行
+ **调拨**：跨仓调拨单据与调度规则



### 3.4 财务单据处理

- 采购入库单、销售出库单、调拨单、退货单等业务单据在 ERP 内生成与流转
- 业务单据是业财转换的源头，确保每笔经营动作有单据可追溯



### 3.5 业财一体转换

- 将业务动作转为 **应记账结果**（标准化结算数据）
- 统一推送至金蝶云·星空，生成财务凭证
- 利润口径以金蝶财务结账为准；ERP 负责「业务 → 应记账」的转换，不负责财务核算本身



### 3.6 业务范畴总览


| 业务域     | ERP 内的核心对象         | 说明                          |
| ------- | ------------------ | --------------------------- |
| **采购**  | 成品采购申请、采购订单、入库单  | 向供应商采购成品，从金蝶 + Excel 收回   |
| **销售**  | ToB 销售单、ToC 订单（归集） | ToB 在 ERP 内闭环；ToC 从 SaaS 接入 |
| **库存**  | 逻辑库存、调拨单、渠道预留      | 实物库存在第三方 WMS / 领星           |
| **主数据** | 成品商品、客户、供应商        | ERP 唯一维护入口，向外部系统分发        |
| **业财**  | 应记账结果、结算规则         | 推送金蝶，不做财务核算                 |

## 四、上下游链路



### 4.1 链路全景

> **说明**：供应商在 ERP 内创建与维护，采购业务直接在 ERP 内完成，**不经过任何第三方 SaaS**。第三方 SaaS 仅对接仓储执行与渠道销售场景。

```plain
  供应商（ERP 内创建与维护）
        │
        │  采购申请 / 采购订单 / 到货入库（ERP 内闭环，不经第三方 SaaS）
        ↓
┌─────────────────────────────────────────────────────────┐
│                   强盛科技 自研 ERP                        │
│        供应商 │ 主数据 │ 采购 │ 销售 │ 库存 │ 业财转换       │
└────────┬──────────────────────────────┬─────────────────┘
         │                              │ 收 / 推
         ↓ 推送应记账结果                  │
  ┌──────────────┐          ┌────────────┴────────────────────┐
  │  金蝶云·星空   │          │      第三方 SaaS（平级对接）       │
  │  （财务底座）  │          │  ┌────────┐ ┌──────┐ ┌──────┐ │
  └──────────────┘          │  │第三方WMS│ │ 领星 │ │聚水潭 │ │
                             │  │(国内仓) │ │(跨境)│ │(国内电商)│
                             │  └────────┘ └──────┘ └──────┘ │
                             └───────────────────────────────┘
```

**三条链路，各司其职**：

| 链路 | 方向 | 说明 |
| --- | --- | --- |
| **采购链路** | 供应商 ↔ ERP | 供应商主数据、采购单据均在 ERP 内；现阶段协同靠人工（微信 / 邮件），无采购类第三方 SaaS |
| **渠道 / 仓储链路** | 第三方 SaaS ↔ ERP | 订单、库存、商品资料的双向同步（见 4.3） |
| **财务链路** | ERP → 金蝶 | 应记账结果单向推送（见 4.2） |



### 4.2 下游：推送金蝶（财务系统）

ERP 与金蝶之间是 **「业务 → 财务」的单向推送关系**：


| 方向           | 内容      | 说明                        |
| ------------ | ------- | ------------------------- |
| **ERP → 金蝶** | 应记账业务结果 | 采购入库、销售发货、调拨、退货等核心场景的结算数据 |
| **ERP → 金蝶** | 财务凭证依据  | 金蝶据此生成凭证，完成财务入账           |
| **金蝶 → ERP** | 一般不回流业务 | 金蝶管财务核算；利润口径以金蝶结账为准       |


```plain
业务动作（ERP 内发生）
    → 生成业务单据（采购入库单、销售出库单……）
    → 业财转换（结算中心：匹配结算规则）
    → 输出应记账结果
    → 推送金蝶
    → 金蝶生成凭证、完成财务核算
```

**原则**：ERP 是业务的「源头系统」，金蝶是财务的「归口系统」。ERP 不替代金蝶做财务核算，金蝶不替代 ERP 管经营业务。

### 4.3 平级对接：第三方 SaaS

> **范围说明**：本节仅涵盖 **仓储执行**（第三方 WMS）和 **渠道销售**（领星、聚水潭）的对接。供应商与采购不在此列——它们在 ERP 内直接管理，不经过第三方 SaaS。

ERP 与第三方 SaaS 之间是 **双向数据交换**，各自在优势领域深耕，通过 ERP 中枢拉通。

#### （a）接收：第三方 SaaS → ERP


| 来源系统         | 接收的数据                 | 用途                     |
| ------------ | --------------------- | ---------------------- |
| **聚水潭**      | B2C 销售订单（天猫 / 京东等）    | 订单中心归集、拆单、锁库           |
| **领星**       | B2C 销售订单（亚马逊等）、FBA 库存 | 订单中心归集；库存中心同步 FBA 实物库存 |
| **第三方 WMS**  | 入库 / 出库结果、国内仓实物库存     | 库存中心同步国内仓实物库存；采购入库回写   |
| **聚水潭 / 领星** | 发货结果、退货结果             | 更新订单状态，触发结算            |




#### （b）推送：ERP → 第三方 SaaS


| 目标系统         | 推送的数据           | 用途                   |
| ------------ | --------------- | -------------------- |
| **聚水潭 / 领星** | 可售库存 / 逻辑库存     | 渠道侧读取库存，控制超卖         |
| **聚水潭 / 领星** | 商品资料（SKU、条码、属性） | 主数据分发，保证各系统商品一致      |
| **第三方 WMS**  | 入库指令、出库指令、调拨指令  | 驱动仓内执行（实物操作在 WMS 完成） |
| **第三方 WMS**  | 商品资料            | 主数据分发，保证仓内商品与 ERP 一致 |




#### 数据流向小结

```plain
【接收】第三方 SaaS → ERP
  · B2C 销售订单（领星、聚水潭）
  · 实物库存（第三方 WMS、领星 FBA）
  · 发货 / 退货结果

【推送】ERP → 第三方 SaaS
  · 商品资料（主数据分发）
  · 可售库存 / 逻辑库存（供渠道读取）
  · 入库 / 出库 / 调拨指令（给第三方 WMS）

【推送】ERP → 金蝶
  · 应记账结果（业财转换后的结算数据）
```

## 五、职责边界：谁管什么


| 数据 / 职责       | 归口系统         | 说明                     |
| ------------- | ------------ | ---------------------- |
| 商品主数据（成品 SKU）、**供应商** | **ERP**      | 唯一维护入口；向外部系统分发（如有需要） |
| 成品采购、ToB 销售 | **ERP**      | 后台经营业务在 ERP 内闭环，不经第三方 SaaS |
| ToC 订单归集与调度   | **ERP**      | 订单从 SaaS 接入，ERP 做归集与路由 |
| 逻辑库存、渠道预留、锁库  | **ERP**      | 跨渠道库存调度规则              |
| 国内仓实物库存与仓内执行  | **第三方 WMS**  | 入库、出库、库位；ERP 同步与下发指令   |
| FBA 实物库存      | **领星**       | ERP 同步                 |
| 渠道打单发货        | **领星 / 聚水潭** | ERP 下发调度结果，SaaS 执行     |
| 应记账结果 → 财务凭证  | **ERP → 金蝶** | ERP 转换推送，金蝶核算          |
| 财务总账、利润口径     | **金蝶**       | 以财务结账为准                |
