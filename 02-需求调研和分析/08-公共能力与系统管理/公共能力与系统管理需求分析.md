## 一、分析结论与业务边界

公共能力负责跨模块共用的机制，不重新定义业务状态、库存和金额规则。一期采用RBAC权限控制：有相应权限就可以提交、审核，允许审核自己创建的数据。审核是单级流程：草稿提交，待审核时审核通过或驳回（有独立已驳回态的对象，如主数据、价格调整单），或审核或撤回（无已驳回态的业务单据，撤回回到草稿）。不做多级审批、会签和条件审批流。账号来源、具体角色和数据权限留到设计阶段，不按公司组织架构直接推定权限。

完整的操作日志不列为一期必做，可以后续补充；待办和消息提醒一期不做，保留后续规划。这不会取消[系统集成](../07-系统集成/系统集成需求分析.md)已经确认的异常单据、推送结果和必要的处理记录。

## 二、原始诉求处理

| 原始诉求 | 处理结论 | 理由 |
| --- | --- | --- |
| 有权限即可提交、审核，可以自己审自己 | 采用RBAC，不强制制单和审核分离 | 先明确业务操作资格，不展开岗位矩阵 |
| 导入数据仍需提交和审核 | 对需要审核的对象保留原流程 | 导入不等于审核通过 |
| 编码、导入导出的细节后续再规划 | 编码统一规范；导入导出按具体PRD | 不提前列全量对象和字段 |
| 操作日志、待办与提醒可后补 | 完整日志不强制一期，提醒后置 | 不扩大一期必做范围 |
| 业务参数先由技术配置 | 技术支持或运维维护代码配置文件 | 后续再开放对应功能模块 |

## 四、功能需求

| 编号 | 功能 | 核心要求 |
| --- | --- | --- |
| COM-FR01 | 权限与提交审核 | 采用RBAC。有提交权限就可以提交，有审核权限就可以审核，允许本人审核本人创建的数据。权限不替代模块已有的状态、库存和金额校验 |
| COM-FR02 | 导入审核原则 | 对原本需要提交审核的对象，导入后仍然要提交和审核；辅助资料、物流这些原本没有审核的对象，不因为导入就多一道审核。导入不改变对应的业务流程 |
| COM-FR03 | 编码规范规划 | 主数据编码和业务单号统一按[《强盛ERP的编码规则和通用字段规则》](../../01-全局背景信息/6.强盛ERP的编码规则和通用字段规则.md)执行；生成格式、唯一范围和修改规则以该文为准 |
| COM-FR04 | 参数维护 | 暂时由技术支持或运维通过代码配置文件维护业务参数；参数的含义和取值规则由所属业务模块定义，后续再提供配置功能模块 |
| COM-FR05 | 导出中心 | 一期提供导出中心，覆盖主数据和业务单据；打印后置 |
| COM-FR06 | 个人中心 | 一期提供个人中心，维护登录后的基本资料和修改密码；工作台后置 |

## 五、一期范围与模块依赖

| 范围 | 处理 |
| --- | --- |
| 本期原则 | RBAC、允许本人审核、导入保留适用审核流程、技术配置参数；一期做导出中心和个人中心 |
| 本期不做 | 多级审批、会签和条件审批流；审核保持单级提交审核；打印和工作台后置 |
| 后续设计 | 账号建立与禁用、角色和数据权限；具体对象的导入、错误与批量处理 |
| 后续规划 | 完整操作日志、待办和消息提醒、业务参数配置页面；完整日志不作为一期必做，待办提醒一期不做 |
| 各业务模块 | 定义审核前置条件、状态和参数的业务含义，本模块不改变已经确认的规则 |
| 系统集成 | 保留异常查看、必要推送和处理记录，不因为公共日志后置就删掉 |

## 六、验收标准

下面这些是需求验收示例，不代表已经执行过系统测试。规划类事项在对应设计交付时检查。

| 编号 | 关联功能 | 条件与操作 | 预期结果 |
| --- | --- | --- | --- |
| COM-AC01 | COM-FR01 | 用一个有提交和审核权限的用户，创建满足业务条件的数据，提交后自己审核；再换一个没有相应权限的用户操作 | 前者能完成，没有相应权限的用户不能执行对应动作；仍然要通过所属模块的业务校验 |
| COM-AC02 | COM-FR02 | 分别导入需要审核的对象和没有审核的辅助资料 | 前者不因为导入就直接生效，仍按原流程提交审核；后者不增加审核流程 |
| COM-AC03 | COM-FR03 | 编制具体的主数据或业务单据PRD | 编码规则关联[《强盛ERP的编码规则和通用字段规则》](../../01-全局背景信息/6.强盛ERP的编码规则和通用字段规则.md)；不把Mock编码当作正式规则 |
| COM-AC04 | COM-FR04 | 按模块已经确认的参数规则配置，并验证对应业务 | 由技术支持或运维通过代码配置文件维护，业务采用对应的参数；一期不要求参数管理页面 |
| COM-AC05 | COM-FR05 | 从导出中心分别导出一条主数据和一张业务单据 | 能导出；不提供打印 |
| COM-AC06 | COM-FR06 | 在个人中心修改基本资料和密码 | 保存成功；工作台不作为一期功能 |
