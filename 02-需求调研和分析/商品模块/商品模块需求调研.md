# 商品的需求分析（初版）

> 依据：`01-全局背景信息`（公司业务 / 项目背景 / 系统定义 / 上下游链路）及采购模块初版。  
> 定位：商品模块负责维护 **成品 SKU 业务主数据**，作为采购、仓储、结算的唯一 SKU 来源；一期聚焦能支撑「采购进、入库扫、推金蝶」的核心字段，**不做运营素材中心和 PLM**。  
> **口径同步（已对齐）**：一期只建成品 SKU，不做 SPU、BOM、物料；状态简化为 **在售 / 停售**；规格用固定通用字段 + 文本说明，不做属性模板；主数据 **异步分发** 至金蝶和第三方 WMS；领星 / 聚水潭一期通过订单归集时的 SKU 编码匹配关联，不做全量资料推送；图片 / 文案 / 属性模板等延后。

## 1. 业务场景

强盛科技商品模块一期聚焦 **成品 SKU 主数据**——即可直接采购、入库、销售的经营单元。不涉及 SPU 拆分、物料编码、BOM 维护；渠道侧商品映射（ASIN、平台 ID 等）留待后期迭代。

### 场景 1：成品 SKU 建档（新品上市）

产品中心确定一款氮化镓 65W 充电头上市 → 在 ERP 创建成品 SKU，录入编码、中英文名、品类、条码、基础物理属性、供应来源信息 → 异步推送至金蝶和第三方 WMS → 采购可按该 SKU 下单，仓库可扫码入库，订单中心通过 SKU 编码归集各渠道订单。

### 场景 2：成品 SKU 信息变更

仓库发现某 SKU 外箱条码有误，或研发更新了产品尺寸规格 → 在 ERP 修改对应字段 → 保存后异步推送金蝶和 WMS → 各系统业务资料保持一致，避免仓内扫码失败或财务物料对不上。

### 场景 3：供应来源信息维护

强盛科技采用哑铃型模式，成品可能来自参股工厂代工，也可能直接采购外部供应商的成品。采购建单前需明确该 SKU 的默认供应商 / 制造商、产地等信息 → 在 ERP 维护并与 SKU 绑定（关联采购模块供应商主数据）→ 采购建单时自动带出，减少反复确认。

### 场景 4：成品 SKU 生命周期管理

某老款数据线决定停售 → 在 ERP 将 SKU 状态改为「停售」→ 推送下游系统 → 采购不再对该 SKU 新建订单，销售侧可配合人工下架（渠道映射一期不做自动联动）。

### 场景 5：采购与销售引用同一 SKU

采购向供应商下成品采购单、第三方 WMS 按 SKU 入库、ToB 批发按 SKU 开单、领星 / 聚水潭订单按 SKU 编码归集——全链路以 **同一套 SKU 编码** 贯通，不再多系统重复建档。

## 3. 一期范围（先做什么、不做什么）

### 3.1 设计决策（已对齐）

| 决策项 | 一期口径 |
| --- | --- |
| **SPU / SKU 划分** | 不做。电商 SaaS 侧管 SPU，ERP 只按 **SKU 维度** 管控成品 |
| **物料与 BOM** | 不做。一期只建 **成品（销售级 SKU）**，不处理原材料、包材、BOM |
| **渠道映射** | 有需求，**后期迭代**。一期订单中心通过 SKU 编码匹配归集 |
| **分发策略** | **异步推送**——SKU 创建 / 变更保存后触发异步任务；一期只推 **金蝶 + 第三方 WMS** |
| **金蝶边界** | 主数据在 ERP 维护，维护完成后 **同步一份至金蝶**（财务物料）；金蝶不做主数据维护入口 |
| **供应来源信息** | 不强绑定「自产」概念。成品可能来自参股工厂代工，也可能直接外采成品；一期维护 **默认供应商、制造商、产地、厂商货号**，并关联采购模块供应商主数据 |
| **规格维护方式** | 固定通用物理字段 + **规格说明（文本）**；不做按品类配置的属性模板 |
| **运营素材** | 图片、详情文案、listing 资料 **不在 ERP 维护**，继续由领星 / 聚水潭管理 |

### 3.2 一期主重点

- 成品 SKU 主档案（编码、中英文名、品类、状态、基本单位）
- 主条码 + 可选备条码
- 基础物理属性（产品净尺寸、净重；外箱尺寸、外箱毛重、箱规）
- 规格说明（文本字段，记录功率、接口、颜色等补充信息）
- 供应来源信息（默认供应商、制造商、产地、厂商货号；关联采购模块供应商主数据）
- 简单品类树（1～2 级）
- SKU 生命周期状态（在售 / 停售）
- 异步分发至金蝶、第三方 WMS（含基础分发日志）
- SKU 变更基础审计
- ERP → 金蝶物料同步

### 3.3 一期轻支持

- 分发失败手动重推
- 品类扩展至 3 级（视产品中心实际需要）

### 3.4 明确不做（后续）

- 商品图片管理、商品介绍文案、富文本 / 多语言
- 属性模板、按品类动态扩展属性
- 主数据全量推送领星 / 聚水潭（二期视接口成本再定）
- 认证证书附件（CE / FCC / 3C 等）
- 打托信息、复杂箱规换算
- 独立计量单位模块
- SPU 管理与 SPU-SKU 层级关系（归电商 SaaS）
- 物料编码、原材料 / 包材建档
- BOM 维护、版本管理、MRP 展开
- 渠道商品映射（内部 SKU ↔ 亚马逊 ASIN / 天猫 ID / 京东 SKU 等）
- 停售 SKU 自动联动渠道下架
- 替代料、可配置 BOM、工程变更（ECN）流程
- 批次 / 序列号全链路管理（二期视品质追溯需求再定）
- 复杂 PLM（图文档、项目管理）

## 4. 初步方案

### 4.1 模块定位

商品模块一期 = **成品 SKU 业务主数据中心 + 金蝶 / WMS 分发**。

```plain
                    ┌─────────────────┐
  产品中心 / 供应链  → │  ERP 商品模块    │
  （唯一维护入口）    │  成品 SKU 主数据  │
                    └────────┬────────┘
                             │ 异步推送
                    ┌────────┴────────┐
                    ↓                 ↓
               金蝶（物料）       第三方 WMS

  领星 / 聚水潭：一期通过订单归集时的 SKU 编码匹配，不做全量资料推送
```

### 4.2 SKU 信息结构（一期）

一个成品 SKU 按以下信息块组织，均在 ERP 统一维护：

| 信息块 | 主要内容 | 主要使用方 |
| --- | --- | --- |
| **基础信息** | 编码、中英文名、品类、状态、基本单位 | 全模块 |
| **物理属性** | 产品净尺寸（长 / 宽 / 高）、净重；外箱尺寸、外箱毛重、箱规 | 仓储、关务 |
| **规格说明** | 功率、接口、颜色、材质等补充说明（文本） | 产品中心、运营 |
| **供应来源信息** | 默认供应商、制造商、产地、厂商货号 | 产品中心、采购 |
| **标识** | 主条码 + 可选备条码 | 仓储、订单归集 |

> **区分说明**：
> - 「物理属性」涵盖产品本身和外箱层面的尺寸重量，一期用固定字段维护，不做属性模板。
> - 「供应来源信息」指标明该 SKU 从谁那里来——可能是参股工厂代工，也可能是外部供应商的成品。
> - 图片、详情文案、listing 素材不在 ERP 维护，继续由领星 / 聚水潭管理。

### 4.3 核心对象（一期）

| 对象 | 说明 |
| --- | --- |
| **SKU** | 成品唯一标识，全链路主键（采购、入库、销售、结算均引用） |
| **品类** | 简单分类树（1～2 级），用于归类和报表 |
| **物理属性** | 固定字段：净尺寸、净重、外箱尺寸、外箱毛重、箱规 |
| **规格说明** | 文本字段，记录各品类差异化参数 |
| **供应来源信息** | 与 SKU 绑定的默认供应商、制造商、产地、厂商货号 |
| **条码** | 主条码 + 可选备条码 |
| **变更日志** | 记录 SKU 关键字段变更 |

### 4.4 分发链路

| 目标系统 | 推送内容 | 推送时机 | 用途 |
| --- | --- | --- | --- |
| **金蝶** | SKU 编码、名称、品类、单位 | 一期，异步 | 财务核算、成本入账 |
| **第三方 WMS** | SKU 编码、名称、条码、净尺寸、外箱属性 | 一期，异步 | 国内仓入库 / 出库扫码 |
| **领星** | — | 一期不推 | 订单归集时按 SKU 编码匹配 |
| **聚水潭** | — | 一期不推 | 订单归集时按 SKU 编码匹配 |

推送机制：保存后触发异步任务；记录每次推送结果（成功 / 失败 / 时间）；失败支持手动重推。

### 4.5 与周边模块的衔接

| 模块 | 衔接方式 |
| --- | --- |
| **采购** | 采购单引用 ERP 成品 SKU，自动带出默认供应商 / 制造商；仅「在售」状态 SKU 允许新建采购 |
| **库存** | 逻辑库存、实物库存同步均以 SKU 为粒度 |
| **订单中心** | ToB 开单、ToC 订单归集均以 SKU 编码匹配（渠道映射二期再做） |
| **结算中心** | 采购入库、销售出库推送金蝶时，携带 SKU 编码 |

### 4.6 待调研确认项

- SKU 编码规则（谁定、格式、是否与旧系统编码兼容）
- 品类树初版清单（产品中心主导，建议 1～2 级）
- 基础物理属性必填字段清单（产品中心 + 仓储）
- 供应来源信息字段清单（默认供应商、制造商、产地、厂商货号哪些是必填）
- 默认供应商与采购模块供应商主数据的关联方式（下拉选择 vs 手工录入）
- ERP ↔ 金蝶、ERP ↔ 第三方 WMS 的字段映射表
- 历史 SKU 迁移方案（存量 SKU 如何迁入 ERP）
- 「停售」SKU 对在途采购、在库库存的业务处理规则
- 二期是否向领星 / 聚水潭推送基础 SKU 字段（编码、名称、条码）

本模块后续再下沉 SKU 字段清单、状态机及分发接口规范。
