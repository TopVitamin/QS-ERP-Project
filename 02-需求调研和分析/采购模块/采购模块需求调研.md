# 采购的需求分析（初版）

> 依据：`01-全局背景信息`（公司业务 / 项目背景 / 系统定义 / 上下游链路）及商品模块需求调研（精简版）。  
> 定位：采购模块负责把 **供应商主数据、成品采购申请/订单、到货入库、采购退货** 串起来，从金蝶 + Excel 收回后台采购主链条，对接第三方 WMS 完成国内仓入库回写，经结算中心推送金蝶应记账结果，并为后续自研 SRM 预留接口。  
> **口径同步（已对齐）**：强盛科技为 **成品采销贸易型** 企业，向约 300 家供应商采购成品，**不涉及生产制造、BOM、MRP**；供应商主数据在 **采购模块** 维护，商品模块的默认供应商引用采购供应商档案；采购单引用商品模块成品 SKU（仅「在售」状态），自动带出供应来源信息；商品模块 SKU 异步分发至金蝶和 WMS，采购不重复维护 SKU 主数据；国内仓实物入库由 **第三方 WMS** 执行，ERP 下发入库指令并接收回写；FBA 备货不走采购入库到 FBA 仓的直链（FBA 库存由领星管理）；采购订单不直接影响逻辑库存或应付；采购入库增加逻辑库存，并按价税规则形成供应商应付；业务日期默认当天；安全库存预警和自动补货建议放二期。

## 1. 业务场景（货怎么进来）

强盛科技的采购由 **供应链中心** 主导：产品中心在商品模块完成 SKU 建档（含编码、条码、供应来源信息），并将默认供应商关联至采购模块供应商档案后，采购根据销售预测、渠道备货和各仓库存情况，向成品供应商下单；供应商将成品送至国内仓，**第三方 WMS** 执行收货、质检、上架，并将入库结果回写 ERP；ERP 更新逻辑库存，结算中心将采购入库应记账结果推送金蝶。

一期要先把下面这条链路跑顺：

```text
选品定 SKU（商品模块）
    ↓
采购需求判断 → 采购申请 / 采购订单（ERP）
    ↓
供应商送货至国内仓
    ↓
ERP 下发入库指令 → 第三方 WMS 执行收货入库 → 回写 ERP
    ↓
逻辑库存增加 → 结算中心推送金蝶应记账结果
    ↓
各渠道（领星 / 聚水潭 / ToB）可销售该批成品
```

如果没有系统（现状），采购最容易出现的问题包括：

- 采购单散落在 Excel 和金蝶，和 WMS 入库、渠道销售各管一段，对不上；
- 问供应商「货什么时候到」只能靠微信，新品上市常因交期不透明而延期；
- 同一 SKU 向多家供应商采购，价格和交期没有统一记录，事后难以追溯；
- 采购入库和第三方 WMS 实物库存不同步，逻辑库存层无法建立；
- 供应商应付靠月末人工估算，和财务金蝶对不齐；
- 质量问题要追溯「哪个供应商、哪次采购、哪批入库」，需翻多个系统拼链路。

## 3. 一期范围（先做什么、不做什么）

### 3.1 设计决策（已对齐）

| 决策项 | 一期口径 |
| --- | --- |
| **采购对象** | 只采购 **成品 SKU**，不采购原材料、包材，不做 BOM / MRP |
| **供应商管理** | 供应商主数据在 **ERP 内维护**，无采购类第三方 SaaS；深度协同等自研 SRM |
| **入库执行** | 国内仓实物操作在 **第三方 WMS**；ERP 下发入库指令，接收回写入库结果 |
| **FBA 备货** | FBA 库存由领星管理；一期采购入库目标仓为 **国内仓（第三方 WMS）** |
| **库存影响** | 采购订单不影响逻辑库存；**采购入库回写后**增加逻辑库存 |
| **业财衔接** | 采购入库经结算中心推送金蝶应记账结果；金蝶不做采购业务入口 |
| **主数据引用** | 采购单引用商品模块成品 SKU（编码、中英文名、品类、基本单位、主条码）；自动带出供应来源信息（默认供应商、制造商、产地、厂商货号）；仅「在售」状态 SKU 允许新建采购 |
| **供应商归属** | 供应商主数据在 **采购模块** 维护；商品模块 SKU 的默认供应商下拉引用采购供应商档案，两边不重复建档 |
| **价税口径** | 采购订单录入含税单价和税率（默认 0%）；入库单继承只读；金额系统计算 |

### 3.2 一期主重点

- 供应商主数据建档与维护（基础信息、结算方式、默认联系人等）；
- 成品采购申请 → 采购订单，记录供应商、SKU、数量、含税价格、预计到货；
- 采购订单与入库数量分离：支持分批到货，累计入库数量不得超过订单数量；
- ERP 向第三方 WMS 下发采购入库指令，接收 WMS 入库回写，生成采购入库单；
- 采购入库增加逻辑库存，并按价税合计形成供应商应付；
- 与商品模块衔接：采购单引用成品 SKU，自动带出供应来源信息（默认供应商、制造商、产地、厂商货号）；仅「在售」SKU 可建单；供应商档案由采购模块维护，商品模块引用；
- 与结算中心衔接：采购入库推送金蝶应记账结果。

### 3.3 一期轻支持

- 采购付款登记，冲减供应商应付余额；
- 采购退货单及退货出库（对接 WMS），扣减库存并冲减应付；
- 到货差异与人工结束：合格品入库，差异线下处理；不补发时可人工结束未交部分；
- 采购订单交期与入库进度查看；
- 采购价格变更留痕。

### 3.4 明确不做（后续）

- 安全库存预警、自动补货建议（二期，基于销售与库存数据，非 MRP）；
- 供应商在线协同、电子对账、招投标（自研 SRM 项目）；
- 复杂采购计划、自动询价、供应商绩效评级；
- 原材料 / 包材采购、BOM、物料计划；
- FBA 直采入库（跨境头程入 FBA 仓的复杂链路）；
- 完整质检流程和质检单据（一期 WMS 侧基础质检，ERP 只承接合格入库数量）。

## 4. 初步方案（只到单据/能力层）

### 4.1 模块定位

采购模块一期 = **成品采购后台主链条 + 供应商主数据 + WMS 入库协同**。

```plain
  产品中心定 SKU（商品模块）
  编码 / 条码 / 供应来源信息
           │
           │ 默认供应商 ←── 引用采购模块供应商档案
           ↓ 采购建单引用 SKU + 自动带出供应来源
  ┌─────────────────────┐
  │   ERP 采购模块        │
  │  供应商 │ 申请 │ 订单  │
  └──────────┬──────────┘
             │ 下发入库指令（携带 SKU 编码、条码）
             ↓
      第三方 WMS（国内仓执行）
             │ 入库回写
             ↓
  ┌─────────────────────┐
  │  采购入库 → 逻辑库存   │ ──→ 库存中心（渠道可售）
  │  结算中心 → 金蝶      │ ──→ 应记账结果
  └─────────────────────┘
```

### 4.2 关键单据与能力

| 单据/能力 | 作用 | 一期 |
| --- | --- | --- |
| 供应商档案 | 维护约 300 家成品供应商主数据 | ✅ |
| 采购申请单 | 记录备货需求来源和申请数量 | ✅ |
| 采购订单 | 记录采购约定：供应商、SKU、数量、价格、交期 | ✅ |
| 采购入库单 | 承接 WMS 回写，确认入库，增加逻辑库存并形成应付 | ✅ |
| 采购退货单 → 退货出库 | 不良品退回，扣减库存并冲减应付 | ✅ 轻支持 |
| 采购付款单 | 登记实际付款，冲减供应商应付余额 | ✅ 轻支持 |
| 安全库存 / 补货建议 | 基于销售与库存数据的备货建议 | ❌ 二期 |
| 供应商在线协同 | 订单确认、发货通知、对账 | ❌ 自研 SRM |

### 4.3 与周边模块的衔接口径

| 口径 | 含义 | 影响 |
| --- | --- | --- |
| 按采购订单 | 原本约定买什么、买多少、什么价 | 不影响逻辑库存，不形成应付 |
| 按实际入库 | WMS 确认进入国内仓的合格数量 | 增加逻辑库存，形成供应商应付 |
| 按分批入库 | 同一采购订单的多次到货 | 每次回写生成一张采购入库单 |
| 按 WMS 执行 | 国内仓收货、上架、库位管理 | 实物操作在 WMS，ERP 管单据与逻辑库存 |
| 按含税采购价 | 采购订单和入库明细的计价口径 | 默认税率 0%；价税分离金额系统计算 |
| 按采购付款 | 实际付给供应商的金额 | 冲减供应商应付余额 |
| 按采购退货 | 实际退回供应商的合格/不良品 | 扣减逻辑库存，冲减应付；对接 WMS 出库 |

一句话衔接：

- **商品**：采购单引用成品 SKU（编码、中英文名、品类、单位、主条码），自动带出供应来源信息（默认供应商、制造商、产地、厂商货号）；仅「在售」SKU 可采购；商品模块不维护采购价格，价格在采购订单录入；
- **仓储**：ERP 下发入库指令给第三方 WMS（携带 SKU 编码、条码），WMS 回写后 ERP 确认采购入库；
- **库存**：采购入库增加逻辑库存，退货出库扣减；供订单中心渠道预留与锁库；
- **结算**：采购入库推送金蝶应记账结果；采购付款冲减应付；
- **供应商**：主数据在采购模块维护，商品模块默认供应商引用采购供应商档案；一期协同靠人工，预留 SRM 接口。

### 4.3.1 与商品模块衔接（专节）

| 方向 | 内容 | 说明 |
| --- | --- | --- |
| **商品 → 采购** | SKU 基础信息 | 采购建单时选择 SKU，带出编码、中英文名、品类、基本单位、主条码 |
| **商品 → 采购** | 供应来源信息 | 自动带出默认供应商、制造商、产地、厂商货号；采购订单供应商默认取「默认供应商」，允许手工修改 |
| **采购 → 商品** | 供应商档案 | 商品模块 SKU 的默认供应商下拉选择，数据源为采购模块供应商档案 |
| **采购约束** | 状态管控 | 仅商品模块「在售」状态 SKU 允许新建采购订单；「停售」SKU 禁止新建 |
| **职责边界** | 不重复维护 | 商品模块管 SKU 主数据和供应来源；采购模块管供应商档案、采购价格、采购单据；商品图片 / 文案不在 ERP 维护，与采购无关 |

> **前置条件**：新品采购前，商品模块须完成 SKU 建档且状态为「在售」，默认供应商已关联采购模块供应商档案；SKU 异步分发至 WMS 完成后，方可正常下发采购入库指令。

### 4.4 到货差异与退货边界

- 合格商品：WMS 收货入库 → 回写 ERP → 生成采购入库单；
- 破损 / 缺件 / 型号不符：差异在线下处理，不入库单；是否补发由采购决定；
- 不补发时：采购人员按剩余未入库数量人工结束采购订单；
- 采购退货：关联原采购入库来源时校验可退数量；退货出库对接 WMS 执行；
- 已付款退货：可形成负应付或后续抵扣；一期不做供应商退款流程。

### 4.5 一期主链路（示意）

```text
产品中心在商品模块完成 SKU 建档（编码、条码、供应来源信息；状态「在售」）
  → 默认供应商关联采购模块供应商档案；SKU 异步分发至金蝶和 WMS
  → 供应链判断备货需求，创建采购申请
  → 审批通过后生成采购订单（引用 SKU，自动带出供应来源；录入数量 + 含税价 + 交期）
  → 供应商送货至国内仓
  → ERP 下发采购入库指令至第三方 WMS
  → WMS 收货、质检、上架 → 回写 ERP
  → ERP 生成采购入库单 → 逻辑库存增加
  → 结算中心推送采购入库应记账结果至金蝶
  → 财务登记采购付款 → 冲减供应商应付余额

逆向：采购退货单 → WMS 退货出库 → 扣减逻辑库存、冲减应付
```

### 4.6 待调研确认项
