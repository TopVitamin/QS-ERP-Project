## 一、调研范围与资料来源

本轮调研覆盖商品寻源及建档时如何形成初始价格、采购和销售人员如何使用价格、价格变化如何交接，以及采购、销售和两类退货业务中的价格来源。本文只保留当前业务做法、原始诉求和证据缺口；一期目标规则统一见[价格管理需求分析](价格管理需求分析.md)。

- 商品寻源、供应商引入及建档时初步判断采购价、销售价，由用户在本轮说明；商品资料范围参考[商品与主数据需求调研](../01-商品与主数据/商品与主数据需求调研.md)。
- 采购人员使用 Excel、BI 测算采购需求并与供应商线下沟通，来源于[采购业务管理需求调研](../02-采购业务管理/采购业务管理需求调研.md)。
- B2B 销售通过微信、电话等线下谈妥商品、数量和价格后记录成交结果，来源于[销售与履约需求调研](../04-销售与履约/销售与履约需求调研.md)。
- 纳税人身份现状在金蝶维护，来源于本轮说明。

当前尚未取得现行采购价表、销售价表、调价申请、业务单据样例、系统截图或实际审批记录。因此，现行价格究竟记录在哪个 Excel 或系统、由谁最终确认、变价后如何通知制单人员，都不能写成已验证事实。

## 二、当前角色与系统分工

| 参与方 | 当前做法或已取得的业务线索 |
| --- | --- |
| 商品开发与管理人员 | 完成商品寻源和供应商引入，对采购价、销售价形成初步判断；商品建档时维护初始供应商、初始含税采购价和初始含税销售价 |
| 采购人员 | 结合 Excel、BI 进行采购测算，并通过邮件、微信等与供应商沟通；采购价格和税率可能因供应商、SKU、币别而不同，但现行价格载体和调价交接方式未取得证据 |
| 销售人员 | B2B 在线下谈妥商品、数量和价格后录单；实际成交价可能因客户或客户等级不同，但现行基准价、等级价和客户价是否已有统一记录尚未核实 |
| 采购、销售业务负责人 | 价格需要业务确认，但当前由谁提交、谁审批、使用何种表单尚未取得样例 |
| 财务 | 当前是否参与价格确认、如何接收含税价和税率尚未核实；已知预付款及平台结算等部分事项仍在线下或金蝶处理 |
| 金蝶（系统） | 维护小规模纳税人、一般纳税人等纳税人身份信息；当前字段样例尚未取得 |

用户说明商品建档时关联初始供应商，是为了记录初始采购价格的归属；这不表示当前已有经过验证的默认供应商或供货关系机制。采购业务中先确定供应商再选择商品，现行系统是否按供应商过滤 SKU 尚未取得界面或数据证据。

## 三、核心场景与业务问题

| 场景 | 业务情况及需要解决的问题 | 证据状态 |
| --- | --- | --- |
| PRI-S01 | 新品寻源和供应商引入后，商品开发与管理人员已经能够判断初始采购价、销售价；PRI-P01：这些价格当前记录在哪里、怎样交给采购和销售使用尚未核实 | 本轮业务说明，记录载体待取证 |
| PRI-S02 | 采购价格和税率会随供应商、SKU、币别变化；PRI-P02：现行价表是否覆盖这些维度、无价格时如何处理尚未取得样例 | 本轮业务说明，价表样例待取证 |
| PRI-S03 | B2B 销售在线下谈价，实际价格可能面向具体客户或客户等级；PRI-P03：现行基准价、等级价、客户价如何记录和选择尚未核实 | 销售调研及本轮业务说明 |
| PRI-S04 | 采购、销售人员会面对价格变化；PRI-P04：当前调价由谁发起、谁确认、如何通知业务人员及如何保留历史尚未核实 | 本轮仅确认存在变价场景，流程证据待补 |
| PRI-S05 | 采购、销售及退货制单都需要确定本单价格；PRI-P05：现行单据自动带价、查询价和手工改价的具体行为尚未取得界面或单据证据 | 采购、销售调研及本轮业务说明 |

以上只说明已经获得的业务线索和待取证问题，不据此推定现行系统功能、发生频率或损失金额。

## 四、原始业务诉求

| 来源场景 | 业务诉求 | 当前判断 |
| --- | --- | --- |
| PRI-S01 | 商品建档时形成可用的初始采购、销售价格 | 目标处理见 PRI-FR01 |
| PRI-S02 | 采购制单按实际业务维度取得价格，无匹配价格时仍能完成合理处理 | 目标处理见 PRI-FR02、PRI-FR04、PRI-FR05 |
| PRI-S03 | 销售支持通用基准价、客户等级价和具体客户价，并明确冲突时的选择顺序 | 目标处理见 PRI-FR03、PRI-FR05 |
| PRI-S04 | 采购、销售价格分别调整，变价需有审批依据和历史记录 | 目标处理见 PRI-FR06 |
| PRI-S05 | 已保存业务单据保留本单价格，退货优先沿用原业务价格 | 目标处理见 PRI-FR05、PRI-FR07、PRI-FR08 |

## 五、需要重点补充的现状证据

- 当前采购价、销售价分别记录在哪个 Excel、系统或沟通工具中，是否存在统一模板及唯一维护入口。
- 新品初始价格从商品开发与管理人员交接给采购、销售人员的实际步骤，以及发生遗漏时的处理方式。
- 采购价变动和销售价变动目前由谁提出、谁确认、谁维护，变价后怎样通知正在制单或已经保存草稿的人员。
- 当前采购、销售、退货单据实际保存哪些价税字段，零价、空价、负价和改币别时系统怎样表现。
- 当前是否保留历史调价记录，变价前后的历史价格如何处理。

上述证据缺口不阻止一期目标分析继续推进；已确认的目标方案及仍待设计的边界见《价格管理需求分析》第七章。
