## 一、分析结论与业务边界

一期建设采购价目表、销售价目表、采购价格调整单和销售价格调整单。价目表保存当前有效价格，价格调整单负责新增、修改和审核变价；业务单据取得价格后形成自身快照，不随价目表后续变化自动更新。

采购价格按采购组织、供应商、SKU、币别区分。销售价格按销售组织、SKU、币别和面向范围区分，面向范围为所有客户、客户等级或具体客户，取价优先级为：

**具体客户价 → 客户等级价 → 所有客户基准价 → 人工填写。**

价目表不设置生效开始、结束日期，不进行跨币别汇率换算。新的价格调整单审核通过后立即覆盖对应当前价格，原调整单继续保留。采购、销售价格调整单必须分开，财务不作为默认价格审核方。

商品建档负责产生初始价格，后续变价统一通过价格调整单。平台及 SaaS 承接的外部 ToC 结果沿用来源金额，不由 ERP 销售价目表重算；完整税务核算、应收应付和金蝶目标字段不属于本模块。

## 二、原始诉求处理

| 原始诉求 | 处理结论 | 理由 |
| --- | --- | --- |
| 商品寻源后已经能够判断初始采购价和销售价 | 商品建档时初始化当前各采购、销售组织的价格记录 | 避免商品初始价格留在档案中而业务单据无法统一取价 |
| 采购价格因组织、供应商、SKU、币别不同而不同 | 按四个维度维护唯一当前采购价格 | 支撑供应商先选、商品后选的采购制单方式 |
| 销售既有基准价，也有等级价和客户价 | 建立三层销售价格范围及固定匹配优先级 | 具体约定优先于客户等级，等级价优先于通用基准价 |
| 业务价格允许调整，但不能直接改后失去依据 | 采购、销售分别建设价格调整单，审核后生效 | 两类单据维护人员、字段及适用对象不同 |
| 未匹配价格仍需要继续制单 | 允许手工填写；提交时校验价格完整合法 | 不使用价目表限制业务可选商品 |
| 已保存单据不能被后续调价改变 | 业务单据保存自己的价格和税率快照 | 保留当时业务约定，避免静默改价 |
| 退货优先沿用原交易价格 | 有来源带原入库／出库价格，无来源或缺价时查询当前价或手填 | 当前价查询只作为人工快速填充方式 |
| 赠品可以零价 | 四类业务订单／退货单允许零价并在提交时确认 | 零价表达本单特殊业务，不改变 SKU 通用价格 |
| 价目表价格不能为零 | 两类价格调整单价格必须大于零 | 防止后续新单批量取得错误零价 |
| 新组织没有历史商品初始价格 | 组织同步后先用价格调整单批量建价，再开展业务 | 不对历史商品自动复制价格 |

## 四、功能需求

### PRI-FR01：商品价格初始化

商品开发与管理人员完成寻源和供应商引入后创建商品，维护初始供应商、初始含税采购价、初始含税销售价及币别。初始供应商只表示初始采购价格归属，不作为默认供应商，也不限制后续采购资格。

商品建档成功时，系统按当时已有组织初始化价格：

- 对每个采购组织，以相同初始采购价、初始供应商和币别生成采购价格记录。
- 对每个销售组织，以相同初始销售价和币别生成面向所有客户的销售基准价格。
- 销售组织纳税人身份不同，可以导致相同含税基准价对应不同税率和不含税单价。

后续新增组织不补建历史商品价格。组织须先在金蝶建立、审核并同步到 ERP，再通过价格调整单批量建立价格，之后开展采购或销售业务。

### PRI-FR02：采购价目表

采购价目表按“采购组织＋供应商＋SKU＋币别”保存当前有效价格。同一组合只保留一个当前价格，内容包括含税单价、税率及系统计算的不含税单价。

采购价格默认长期有效，直到新的采购价格调整单审核通过后覆盖。价目表不直接编辑，不设置生效开始、结束日期，也不安排未来价格。

商品建档中的初始供应商及价目表中的供应商价格只表示价格归属，不建立商品供货资格。采购订单先选择供应商，再选择 SKU；商品范围不按该供应商是否已有价格过滤。

### PRI-FR03：销售价目表

销售价目表按“销售组织＋SKU＋币别＋面向范围”保存当前有效价格。面向范围分为所有客户、一个客户等级或一个具体客户；一条价格只对应一种范围及一个具体范围值。

同一业务同时命中多层价格时，依次使用具体客户价、客户等级价、所有客户基准价。三层均未匹配时不跨组织、跨币别借用价格，由用户在业务单据中人工填写。

销售价格默认长期有效，直到新的销售价格调整单审核通过后覆盖；不设置生效开始、结束日期，不安排未来价格。

### PRI-FR04：币别与税价

不同币别的价格完全独立。同一组织、供应商／销售范围和 SKU 可以分别维护多个币别价格；业务单据只匹配所选币别，不通过汇率换算其他币别价格。供应商、客户默认币别可作为制单默认值，业务单据修改币别时清空原有价格，再按新币别重新取得或填写。

采购价格维护含税单价和税率，系统计算不含税单价。税率可从商品默认信息带出；无法取得时由用户填写，草稿阶段允许按供应商及商品实际情况调整。采购价格调整单审核后，将币别、含税单价、税率和不含税单价一起更新采购价目表。

销售组织的小规模纳税人／一般纳税人身份来自金蝶组织信息，商品税收分类编码和默认销售税率提供税率依据。销售价格及业务单据据此计算不含税单价；草稿阶段允许修改税率和含税单价，税率变化后重新计算不含税单价。不同组织可以使用相同含税基准价，但因税率不同形成不同不含税单价。

本稿确认自动计算关系，不定义金额和税率精度、舍入顺序及尾差处理。

### PRI-FR05：业务单据取价、改价与锁定

采购订单按采购组织、供应商、SKU、币别匹配采购价格。销售订单按销售组织、客户、客户等级、SKU、币别及 PRI-FR03 优先级匹配销售价格。未匹配到价目表时允许人工填写，不阻止选择商品；提交时价格、币别和税率必须完整合法。

业务单据在草稿阶段允许修改价格和税率，自动取价及查询价目表都只是帮助填充。提交后及审核后不可修改。空价格及负数价格不能提交；采购订单、销售订单、采购退货单、销售退货单允许零价，提交时统一提醒用户确认后继续。

价格写入并保存业务单据后形成该单价格快照，后续价目表变化不自动影响草稿或已提交单据。币别、组织、供应商、客户或 SKU 等价格匹配条件发生变化时，原匹配价格不得继续沿用，应清空并按新条件重新取得或填写。

### PRI-FR06：采购与销售价格调整单

采购价格调整单与销售价格调整单为两个独立单据：

- 一张采购价格调整单只对应一个采购组织、一个供应商和一个币别，明细可包含多个 SKU。
- 一张销售价格调整单只对应一个销售组织、一个币别和一种面向范围；范围为所有客户、一个客户等级或一个具体客户，明细可包含多个 SKU。

两类调整单均可新增此前不存在的价格，也可修改已有价格。价格必须大于零，空值、零值及负数均不能提交。采购调整明细维护含税单价和税率并自动计算不含税单价；销售调整明细按组织纳税人身份、商品税务信息带出税率并计算，草稿阶段可修正。

状态主链为“草稿 → 待审核 → 已审核／已驳回”。草稿可修改；提交后进入待审核且不可修改；驳回后修改并重新提交；审核通过时立即新增或覆盖价目表当前价格。已审核调整单不可修改、删除、撤销或反审核，发现错误时新建调整单再次调整，前后单据均保留。

调整单由相应采购或销售业务人员创建，由相应业务线有权人员审核；财务不作为默认审核方。具体岗位、人员及权限配置留到详细设计。

### PRI-FR07：采购与销售退货取价

有来源采购退货默认带出原采购入库单价格，有来源销售退货默认带出原销售出库单价格，不用当前价目表自动覆盖原交易价格。

无法取得原业务价格或无来源退货时，用户可以直接手工填写，也可以主动查询当前采购价或销售价进行快速填充。查询当前价属于草稿阶段的人工改价方式，填入后仍可修改；提交后按 PRI-FR05 锁定和校验。

### PRI-FR08：外部 ToC 金额边界

聚水潭、领星等外部 SaaS 承接的 ToC 实际出库、退货结果，沿用来源系统提供的成交优惠后金额和退货金额。ERP 价目表不重新取价或重算；必要金额缺失时沿用销售模块异常处理，不自行补价。

### PRI-FR09：新组织价格准备

采购组织、销售组织必须先在金蝶建立并审核，再同步至 ERP。新增组织不自动复制历史商品价格；业务开展前，由对应业务人员使用价格调整单批量建立该组织价格。具体批量录入或导入方式在页面及详细设计中明确。

## 五、一期范围与模块依赖

提交与审核权限、允许本人审核及导入沿用原审核流程，统一引用[公共能力需求分析](../08-公共能力与系统管理/公共能力与系统管理需求分析.md) COM-FR01、COM-FR02，不改变本模块业务校验。

| 分类 | 范围或依赖 |
| --- | --- |
| 本期包含 | 商品初始价格生成；采购、销售价目表；采购、销售价格调整单；业务订单及退货取价、手工改价、零价确认和价格锁定 |
| 本期不包含 | 生效起止日期、未来价格排期、跨币别自动换汇、外部 ToC 重新定价、财务价格审核及完整税务核算 |
| 商品与主数据 | 提供 SKU、初始供应商、初始含税采购价／销售价、币别、税收分类编码和默认销售税率 |
| 供应商与客户 | 提供审核通过且启用的业务对象、默认币别、客户等级等取价条件；价格关系不作为供货或销售资格 |
| 组织 | 金蝶提供已审核组织、纳税人身份等资料；ERP 同步只读引用，新组织价格由调整单建立 |
| 采购与销售 | 负责业务单据取价、改价、锁定、零价确认及退货来源价格；外部 ToC 使用来源金额 |
| 结算与业财 | 承接价税精度、核算、应收应付、金蝶目标字段及财务结果，不反向决定本模块调价审批 |
| 公共能力 | 承接用户、岗位、权限、操作记录及批量处理的技术机制 |

本稿不定义完整字段、页面、接口报文及技术异常，不据此推断原型或外部系统已经实现。

## 六、验收标准

以下为基于已确认规则的业务验收示例，不代表已执行系统测试。

| 编号 | 关联功能 | 条件与操作 | 预期结果 |
| --- | --- | --- | --- |
| PRI-AC01 | PRI-FR01 | 当前有三个采购组织、两个销售组织，商品以一个初始供应商及初始采购／销售价建档 | 三个采购组织分别生成该供应商采购价；两个销售组织分别生成所有客户基准价；初始金额一致 |
| PRI-AC02 | PRI-FR01、PRI-FR09 | 金蝶新增并审核组织后同步 ERP，检查历史商品并尝试开展业务 | 历史商品不自动生成价格；先通过价格调整单批量建价，再开展对应组织业务 |
| PRI-AC03 | PRI-FR02、PRI-FR05 | 采购订单先选供应商，再选择有价及无价 SKU | 所有符合使用条件的 SKU 均可选；按组织、供应商、SKU、币别带价，无价可手填，未补齐不能提交 |
| PRI-AC04 | PRI-FR03、PRI-FR05 | 同一销售订单同时可命中客户价、客户等级价和所有客户基准价 | 使用具体客户价；依次移除高优先级价格后分别回退到等级价、基准价和人工填写 |
| PRI-AC05 | PRI-FR06 | 分别创建采购、销售价格调整单，测试新增价格及修改已有价格 | 待审核不生效；审核通过后立即新增或覆盖对应价目表当前价格，两类单据范围不混用 |
| PRI-AC06 | PRI-FR04、PRI-FR05 | 单据先按人民币取价，再修改为美元 | 原价格清空，仅匹配美元价格；不存在美元价格时重新手工填写，不自动换汇 |
| PRI-AC07 | PRI-FR05 | 草稿保存价格后审核一张价格调整单，再重新打开草稿 | 草稿仍保留原价格；提交后价格及税率锁定，不因价目表变化自动更新 |
| PRI-AC08 | PRI-FR06 | 调整单录入空价格、零价、负价；审核后发现价格错误 | 三类非法价格均不能提交；已审核单不回改，以新调整单纠正并保留前后记录 |
| PRI-AC09 | PRI-FR05 | 四类业务订单／退货单分别录入零价并提交 | 系统提醒确认；用户确认后可继续提交，负价和空价仍被阻断 |
| PRI-AC10 | PRI-FR07 | 分别创建有来源、来源缺价及无来源退货 | 优先带原入库／出库价格；缺价可查询当前价或手填，查询结果仍可在草稿修改 |
| PRI-AC11 | PRI-FR04 | 采购调价带出默认税率后修改，销售组织以不同纳税人身份使用相同含税价 | 系统按最终税率计算不含税价；相同销售含税价可形成不同组织的不含税价，提交后税价锁定 |
| PRI-AC12 | PRI-FR08 | 接收外部 ToC 出库及退货结果 | 沿用来源成交及退货金额，不调用 ERP 销售价目表重新定价 |

| 初始化异常 | 商品建档时初始价格为空、组织初始化部分失败如何阻断或恢复 | 商品及价格联动设计前 |
| 审核权限 | 采购、销售价格调整单的最终审核岗位、跨组织权限及代理机制 | 权限设计前 |
| 批量建价 | 新组织批量建价采用单据多行录入还是另含导入能力，如何确认准备完成 | 页面及实施设计前 |

以上事项不改变已确认的价格主线；未确认前不自行补充具体数值、岗位和异常机制。
