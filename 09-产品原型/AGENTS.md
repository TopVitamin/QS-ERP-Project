# 产品原型 · 开工须知

适用范围：本目录，React＋Vite＋Tailwind演示原型，不接真实后端。通用纪律见[根AGENTS.md](../AGENTS.md)。

## 开工依据

- 先读相关[待改项](待改项.md)，再读04对应模块的字段清单、主PRD、页面骨架与Demo PRD。业务含义不清回查03，需求范围不清回查02，全局约束回查01。
- 代码用于核实现状，已确认设计用于确定目标。实现与设计不一致时记录差异；不为迁就原型改上游，不用待确认内容补造规则。
- 视觉遵循当前任务指定的参考截图或线上原型及项目公共规范；参考图仅约束视觉，不替代字段、业务动作和校验依据。

## 实现约束

- 优先配置已有列表、表单、详情及导入导出组件，不在页面重复实现公共能力。组件用法、样式、控件type和样板页按任务查[《原型开发说明》](原型开发说明.md)对应章节。
- 模块动作条件、校验与弹窗文案留在模块Logic／ActionDialogs等文件；不为单页差异增加通用抽象。公共组件变化同步开发说明及受影响引用。
- 主数据选项统一从`src/data/masterData.js`读取；单据关联从本地Mock集合读取，Mock数据用`localStorage`保留。展示与格式复用公共工具，Mock入口和行为须明确标识。
- UI代码放`src/`。普通页面任务不改`.openai/hosting.json`、`worker/index.js`、`scripts/prepare-sites-build.mjs`、`tests/sites-worker.test.mjs`；明确涉及部署或相关测试的任务才处理这些文件。
- 一次性决定留在模块设计或代码中；AGENTS.md只保留开工、边界与验证要求，公共组件细节放开发说明。

## 交付验证

- 只改文档时检查内容与链接，无须起服务或构建。
- 改原型代码后运行`npm run build`；改部署、构建链路或站点路由时另跑`npm run test:sites`。后者验证站点worker，不代表业务交互通过。
- 改页面或交互时，复用可用服务或自行启动`npm run dev`，在浏览器走查受影响页面、关键动作和控制台；改公共组件时选受影响的代表页面回归。颜色变化按实际背景复核对比度。
- 验证受限时说明未验证项，不把构建成功当成视觉或交互验证。修复待改项后同步其状态。
