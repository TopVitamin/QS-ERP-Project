# UI布局公共说明（强盛ERP项目）

本说明汇总强盛ERP页面的公共约定，供页面骨架与Demo PRD引用。跨项目复用时，应替换为目标项目的UI规范，不能把本项目的6列栅格、组件和一期范围当作通用要求。

字段事实以TSV及[《6.强盛ERP的编码规则和通用字段规则》](../../01-全局背景信息/6.强盛ERP的编码规则和通用字段规则.md)为准，业务条件以主PRD为准。下表是公共规范的阅读摘要，组件、样式尺寸和通用交互以[《原型开发说明》](../../09-产品原型/原型开发说明.md)相应章节为准。模块Demo PRD保留实际字段与控件，只写模块特有的呈现、联动、校验和反馈。

| 区域 | 页面约定 | 适用说明与来源 |
| --- | --- | --- |
| 查询区、表单、详情只读区 | 6列栅格，标签在上、控件或值在下；按TSV分组和行序排列 | 普通字段占1列，备注等多行文本占3列；当前行剩余不足3列时，备注换行。ASCII画法见《页面骨架填写说明》 |
| 明细表格 | 表头在上、单元格在下，不使用6列栅格 | 基础信息区用底线输入；明细控件完整边框，见原型规范 |
| 列表框架 | 标题与页头操作 → 查询区 → 左侧“收起过滤”、右侧“重置／查询” → 表格卡片（批量栏、表格、分页） | 新增、导入、导出仅按本期范围展示；业务单据页头采用这些入口时，按新增、导入(Mock)、导出顺序绘制 |
| 批量操作栏 | 默认左侧为已选中计数，右侧为列设置；导入、导出在页头 | 主数据可按模块PRD增加批量业务动作；业务单据一期以行内操作为主。导出范围为全部／当前筛选／已勾选，实际能力由模块PRD明确 |
| 状态类筛选 | 业务单据并列状态维度默认多选；未选等同全部，同一维度多项按OR匹配 | 主数据若用页内Tab切换审核状态，查询区不重复该字段；其他枚举筛选由模块PRD明确 |
| 列表列与操作列 | 列表状态为语义色文字；操作列左对齐，最多直出3个操作，其余放“更多” | 对齐、排序、固定列、长文本、勾选与分页见原型规范「列表列通用呈现规则」「列表页标准接线」 |
| 表单卡片 | 卡片标题沿用TSV分组；新增页在单据尚未保存时不展示状态标签，编辑页展示状态标签 | 控件类型及实现见原型规范「表单页标准接线」 |
| 表单校验 | 单头必填失败时，控件红底线并在下方显示“{字段名}不能为空”，标签不变红；同时标出未填项、聚焦首错，填写后清除该项错误 | 不用必填项汇总Toast；明细行级错误默认Toast，如“第N行XX不能为空”。保存／提交的校验条件引用主PRD，模块差异写在Demo PRD |
| 主数据与空值 | 关联资料默认Code-Name；未填写显示英文连字符`-`，数量和金额的0是有效值，按规定格式显示 | 字段清单拆成独立编码列、名称列的除外；导出与接口空值留空，不写入`-`。见全局字段规则 |
| 系统记录字段 | 创建人、创建时间、最后更新人、最后更新时间 | 不使用“更新人”“更新时间”，见全局字段规则 |
| 详情页页头 | 左侧标题与状态标签，右侧“返回列表”最前，其后为业务按钮；草稿另有编辑主按钮 | 单行布局；按钮可用条件服从主PRD状态矩阵，实际顺序写在页面骨架与Demo PRD |
| 详情页分区 | 业务分组 → 商品明细 → 关联单据（按需）→ 其他扩展分组 → 操作信息 | 终止信息等条件分组放扩展区；按模块实际范围保留，见原型规范「详情页标准接线」 |
| 关联单据 | 按下游单据类型分Tab并显示数量；单号可跳转，无数据时显示空态，不隐藏Tab | 卡片是否展示由模块规则决定，“已审核”仅是可能的条件 |
| 操作信息 | 制单信息／操作日志采用胶囊Tab；制单信息为只读字段，日志列为操作时间、操作人、操作类型、说明，按时间倒序 | 关联单据也采用胶囊Tab；尺寸、间距、内嵌简表样式统一见原型规范「详情页标准接线」 |

采用公共默认值时不重抄整套规则；差异要指出字段或区域、依据及具体表现。公共规范变化时同步检查引用它的模板与模块文档。
