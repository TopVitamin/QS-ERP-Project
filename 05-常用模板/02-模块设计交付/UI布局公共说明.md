# UI布局公共说明（Demo PRD 引用）

填写 Demo PRD 时，在「UI布局」节引用本说明，并链接[《09-产品原型/AGENTS.md》](../../../09-产品原型/AGENTS.md)。布局须与[页面骨架模板-V2](../页面骨架模板-V2.md)及模块页面骨架一致。

| 区域 | 规则 |
| --- | --- |
| 查询区、表单、详情只读区 | **6列栅格**（`grid-cols-6`）；按 TSV 顺序从左到右、从上到下填充，满 6 个换行 |
| 字段结构 | **标签在上、控件或值在下**（`FormField` / `DetailField`）；禁止「标签：值」横排 |
| 列宽 | 普通字段 **1 列**；备注等多行文本 **3 列** |
| 列表框架 | 标题行（含导入导出）→ 查询区 → `[收起过滤]` / `[重置]` / `[查询]` → 表格卡片（批量操作栏 + 表格 + 分页） |
| 批量操作栏 | 左侧默认 **已选中 N 条**；右侧 **列设置**。导入导出在页头，导出可选全部／当前筛选／已勾选 | **主数据**列表可按模块 PRD 增加批量提交审核、启用禁用、删除等；**业务单据**列表一期以行内操作为主，批量栏不放删除、取消、关闭等业务按钮（状态与校验因单而异，取消关闭须逐单填原因） |
| 表单卡片 | TSV「字段所属分组」= 卡片标题；**编辑页**页头展示流程状态标签；**新增/创建页**在单据尚未保存前不展示状态标签 |
| 表单校验 | 单头必填失败：**控件红色底线** + 字段下方「{字段名}不能为空」；**标签不变红**；同时标出所有未填项；自动聚焦首错；用户填写后清除该字段错误。不用「请补充 A、B、C」汇总 Toast。明细行级错误暂用 Toast（如「第N行XX不能为空」） | 文案用 `{字段名}不能为空`；实现见 09 原型 `useDocumentForm` + `fieldErrors` |
| 明细表格 | 表头在上、单元格在下；**不走 6 列栅格** |
| 控件样式 | 基础信息区底线输入；明细表内完整边框（见 AGENTS） |
| 主数据展示 | 供应商、客户、仓库、商品等关联选择默认按 Code-Name（`{编码} {名称}`）展示，见《6.强盛ERP的编码规则和通用字段规则》2.3 |
| 空值占位 | 列表、详情只读区、明细表等**未填写**字段统一显示英文连字符 `-`；不用中文破折号 `—`。数量、金额的 `0` 是有效值，按 `0` 展示 | 与《6.强盛ERP的编码规则和通用字段规则》展示规则一致；导出 Excel 或接口传参为空时直接留空，不写入 `-` |
| 系统记录字段 | 创建人、创建时间、**最后更新人**、**最后更新时间** | 不用「更新人」「更新时间」；见《6.强盛ERP的编码规则和通用字段规则》第三节 |
| 状态类筛选 | 业务单据列表的**并列状态维度**（如审核状态、业务状态、收货/发货状态）默认用**多选**下拉；未选等同全部，选中多项为 **OR** 匹配 | 主数据若用页内 Tab 切审核状态，则查询区不重复该字段；其他枚举筛选项仍按模块 PRD 定单选或多选 |
| 操作列 | 表头「操作」与行内按钮**左对齐**；按钮紧凑 `px-1`、间距 `gap-1.5`；最多直出 3 个 +「更多」下拉（带下拉图标） | 列宽随当前页可见按钮估算；业务规则决定 `visibleWhen`，见 09 原型 `DataTable` |
| 详情页分区顺序 | 业务分组 → 商品明细 → **关联单据**（按需）→ 其他扩展分组 → **操作信息** | 关联单据插在明细后；终止信息等条件分组、操作信息放底部；见 09「详情页标准接线」 |
| 详情页胶囊 Tab | 卡片内切换（关联单据、操作信息）用**胶囊**样式，不用列表页下划线 Tab | `InnerTabs` `variant="pill"`；高 28px；选中浅主色底；Tab 与内容间距 **12px**；间距常量见 `detailTabSection.js` |
| 操作信息 | 底部「操作信息」卡片内：**制单信息** / **操作日志** 胶囊切换 | 制单信息为 6 列只读字段（创建人、创建时间、最后更新人、最后更新时间）；日志为表格（操作时间、操作人、操作类型、说明），按时间倒序 |
| 关联单据 | 已审核等条件满足时展示；按下游单据类型分 Tab，Tab 文案带数量 | 简表展示关键列；单号可跳转对应详情；无数据时卡片内居中提示，不隐藏 Tab |
| 详情内嵌简表 | 关联单据、操作日志等**非主明细**表格 | 外框圆角描边；表头 28px、数据行 32px；数据区白底；空态最小高度 120px；不走 6 列栅格 |

样式、尺寸、列设置、排序、分页、Toast 等交互细节以 [《09-产品原型/AGENTS.md》](../../../09-产品原型/AGENTS.md)（含「列表页标准接线」「详情页标准接线」）为准，Demo PRD 只写模块差异。
