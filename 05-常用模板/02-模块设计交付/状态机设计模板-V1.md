# 状态机设计模板-V1

> 版本：V1

用于主PRD中的状态与动作说明，不默认增加独立交付文档。已有权威状态设计时引用原文，避免重复维护。

- 简单启停：状态说明和操作表即可。
- 多状态流转：增加流转图，流转表写清条件和结果。
- 动作多且限制复杂：增加动作矩阵。
- 易混淆的操作：按需增加对比说明。

示例只说明表达方式，状态名称、动作和流转均按实际业务填写。

## 检查要点

- 状态名和含义清楚，与TSV和主PRD一致。
- 图与表覆盖相同流转，条件和成功、失败结果可判断。
- 正常、退回、取消、关闭等路径按实际业务覆盖，不强制增加动作。
- 不同状态维度及自动事件的影响已说明。
