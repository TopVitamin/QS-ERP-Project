## UI布局（与骨架、09原型一致）

| 区域 | 本页规则 |
| --- | --- |
| 查询区 | 6列栅格；每个筛选项占1列，标签在上、控件在下；按 TSV「可筛选=是」顺序填充，满6个换行 |
| 页头 | 标题 + 主操作（如新增）+ 导入导出（见 AGENTS）；导出可选全部／当前筛选／已勾选 |
| 批量操作栏 | 见[UI布局公共说明](../UI布局公共说明.md)：默认已选中计数 + 列设置；主数据可写批量审核等，业务单据一期通常无批量业务按钮 |
| 列表表格 | 不走6列栅格；列名与 TSV「列表展示=是」一致；勾选列配合导出「已勾选」范围 |
| 分页 | 标准分页；查询按钮文案用「查询」；重置不改列显隐（见 AGENTS） |

字段在6列栅格中的位置以模块页面骨架为准。
