## UI布局（与骨架、09原型一致）

| 区域 | 本页规则 |
| --- | --- |
| 只读字段 | 6列栅格；标签在上、值在下；空值显示 `-` |
| 备注 | 占3列；仍保留6条列线 |
| 分区顺序 | 业务分组 → 商品明细 → 关联单据（按需）→ 其他扩展分组 → 操作信息 | 见[UI布局公共说明](../UI布局公共说明.md)与 09「详情页标准接线」 |
| 操作信息 | 详情页最底部；胶囊 Tab：**制单信息**（6列只读）/ **操作日志**（简表） | 新增/编辑页不展示；制单字段：创建人、创建时间、最后更新人、最后更新时间 |
| 关联单据 | 明细之后；按下游单据类型分胶囊 Tab（带数量）；简表 + 单号跳转 | 展示条件写清（如仅已审核）；无数据时 Tab 仍展示、内容区提示暂无 |
| 详情内嵌简表 | 关联单据、操作日志等 | 圆角描边、表头28px、数据行32px、空态最小高度120px |
| 流程状态 | 页头状态标签，不单开「状态信息」卡片（除非主PRD明确要求） |

字段在6列栅格中的位置以模块页面骨架为准。
