# 强盛科技自研 ERP 项目

这是一个基于「强盛科技」虚拟企业发展史的供应链 ERP 产品设计与前端原型项目。

故事从阶段 4 开始：2020 年下半年，前台完成领星、聚水潭切换后，后台主链条仍断在金蝶与各仓储节点之间。公司决定从 0 到 1 自研 ERP，作为衔接外部 SaaS 与金蝶的**后台业务中枢**。

这个仓库记录的重点，不只是一个 ERP 页面长什么样，而是**一个企业为什么需要自研 ERP，以及如何从业务问题一步步落到系统设计和可交互原型**。

> 项目中的强盛科技、时间、规模、财务指标和业务数据均为课程演练设计的虚拟内容，不代表任何真实企业的公开资料或经营数据。

## 怎么读这个项目

README 只说明**目录分工和阅读方法**，不维护具体文件清单。新增或调整文档时，放进对应目录即可，**不必改 README**。

按层级往下读，不要跳层：

| 层级 | 目录 | 回答什么 | 怎么找 |
| --- | --- | --- | --- |
| 1. 立项背景 | `01-全局背景信息/` | 公司什么样、为什么做、系统怎么衔接、跨模块规则怎么约束 | 按文件名序号读：`1.`–`3.` 讲公司与系统分工，`4.` 是全局业务规则，`5.` 是单据分层 |
| 2. 模块需求 | `02-需求调研和分析/` | 某个业务模块做什么、有哪些单据 | 进入对应模块子目录 |
| 3. 业务设计 | `03-业务分析和设计/` | 各业务域如何协作、规则如何闭环 | 从业务蓝图进入对应模块设计 |
| 4. 产品设计 | `04-产品设计方案/` | 字段、PRD、流程图 | 按模块或版本子目录查找 |
| 5. 可交互原型 | `09-产品原型/` | 页面长什么样、能点什么 | 看 `src/config/pages.js` 注册了哪些页 |

有冲突时：**背景看 01，模块规则看 02，业务设计看 03，字段与 PRD 看 04，页面行为看 09 代码**。文内标记「待确认」的，不算最终方案。

## 这个仓库适合学习什么

1. **ERP 相关知识**：ERP、WMS、渠道 SaaS、财务系统如何分工，数据如何在系统间流转。
2. **产品设计知识**：从业务背景到需求调研、单据、字段、PRD、原型的逐层拆解。
3. **AI 产品经理工作流**：用 AI 辅助整理与分析；业务取舍仍由产品经理判断。

## 本地运行

```bash
cd 09-产品原型
npm install
npm run dev
```

默认地址：<http://localhost:5180>。技术栈：React、Vite、Tailwind CSS。

## 迭代方式

```text
业务背景 → 需求调研 → 流程与单据 → 字段与 PRD → 原型 → 走查
```

README 不跟踪「已完成 / 待办」清单，避免和实际进度双重维护。要看当前进展，直接浏览各目录内容或 Git 提交记录。
