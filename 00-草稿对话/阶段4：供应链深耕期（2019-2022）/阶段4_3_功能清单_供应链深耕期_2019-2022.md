| **业财中枢** | 多源单据归集、ASIN/平台 SKU 映射转换、移动加权成本、头程杂费分摊、金蝶单据映射规则、供应链单据推送任务池 |
| **系统设置** | 用户权限、接口监控（领星/聚水潭/WMS/SRM/金蝶）、操作日志 |

**补货公式（自研 ERP 固化）**

```
目标库存 = 加权日均销量 ×（采购交付周期 + 安全库存天数）
净可用 = 全渠道实物在库 − 订单锁定占用 − 渠道专属预留 − 待检不良隔离
库存头寸 = 净可用 + 采购在途 + 头程在途
建议采购量 = max(0, 目标库存 − 库存头寸)
```

> 注：采购交付周期覆盖供应商生产交付周期、海运在途与质检上架时间，即从下单到上架可售的完整周期；全渠道实物在库汇总深圳主仓、东莞电商仓、第三方海外仓与 FBA 在库。

### 3.6 金蝶云·星空（外采｜业财核算底座）

金蝶标准产品含 **供应链云、财务云、制造云** 等。强盛阶段4的定位是：**不做业务执行主系统，做业财承接与法定核算底座**。

- **不在金蝶做**：采购计划、PO 审批下发、逻辑库存配额、渠道锁库、WMS 现场作业——这些在自研 ERP/WMS/SRM。
- **在金蝶做**：接收自研 ERP 编排推送的**标准供应链单据** → 驱动存货核算与应收应付 → 生成总账凭证与法定报表。

**业财一体推送链路**

```text
自研 ERP/WMS 业务过账
  → ERP 单据中枢编排（采购入库 / 销售出库 / 调拨 / 盘点损益 / 应收应付）
  → API 推送金蝶供应链云
  → 金蝶存货核算 + 应收应付处理
  → 自动生成财务云总账凭证
```

| 云/一级模块 | 功能菜单（产品能力） | 强盛阶段4实际使用 |
| :--- | :--- | :--- |
| **供应链云** | 采购管理：采购入库单、采购退料单、采购发票 | ● **接收** ERP 推送的入库/退货过账单；PO 在金蝶不创建 |
| | 销售管理：销售出库单、销售退货单、销售发票 | ● **接收** ERP 推送的 B2B/渠道结算出库单 |
| | 库存管理：调拨单、盘点单、其他出入库、财务库存账 | ● **接收** 跨仓调拨、盘点损益过账单；记财务存货账 |
| | 信用管理：客户信用档案 | ○ 档案同步参考；**信控拦截在自研 ERP** |
| | 组织间结算：跨组织销售/采购/调拨结算 | ○ 跨法人仓网时启用 |
| **财务云** | 总账、报表、出纳、票据、固定资产 | ● 法定总账与三表 |
| | 应收款管理、应付款管理、收款/付款核销 | ● 由供应链单据驱动生成 |
| | 存货核算、移动加权平均成本结转 | ● 入库/出库/盘点单据自动触发 |
| | 资金管理、多币种、期末调汇 | ● |
| **制造云** | 生产管理、委外加工、BOM | ✗ 不使用 |

> 「金蝶回归财务底座」= 退出**业务执行主系统**角色，不是关掉供应链云。供应链云在金蝶侧是**单据接收与存货/往来过账层**，与自研 ERP 的业财中枢配合完成一体化。

## 五、明确不出现的功能（走查结论）

以下能力在**外采产品里可能存在**，但不符合强盛品牌商链主定位，案例功能清单**一律不纳入自研系统**，外采侧标注为「不使用」：

| 不应出现 | 典型误写来源 | 处理 |
| :--- | :--- | :--- |
| BOM / 物料清单展开 | 金蝶制造云、聚水潭组合装 BOM | 自研不做；外采标注 ✗ |
| MRP / 物料需求计划 | 传统 ERP 制造模块 | 自研只做**成品**补货 |
| 生产工单 / 工序报工 | MES、聚水潭加工单、领星加工单 | 自研不做；领星/聚水潭标注 ✗ |
| 车间排产 / APS | 代工厂内部系统 | 不在强盛任何系统 |
| 委外加工 / 本地加工 | 领星采购单、聚水潭智能采购加工 | 强盛买成品，不做组装加工 |

## 六、阶段4没覆盖的，阶段5补

1. **无中央 OMS**：天猫缺货不能自动拆单调深圳仓，仍靠聚水潭独立处理。
2. **无门店触点**：聚水潭门店菜单、POS、O2O 均未启用。
3. **指标口径未统一**：领星、聚水潭与自研后台仍需定期汇总，IPO 穿透核查吃力。
4. **自营仓单点辐射全国**：仅深圳一个自营仓辐射全国，跨区发货运费高、时效慢，门店落地后也缺乏就近补货支撑。

详见《业务背景》§七、《系统架构》§五。
